# Ch 22 — 該讀誰：建立自己的取樣庫

> 寫作的風格，九成是你讀過什麼的副作用。你想寫得漂亮，不是多想，是多讀對的人。這一章不是給你一份權威書單 — 那種東西網路上太多。這是教你如何為自己建立一個**個人取樣庫**，以及幾個新手適合從哪裡起步的建議。

## 為什麼需要「取樣庫」

DJ 有他的唱片庫，畫家有他的 reference 資料夾，寫作者也該有**自己的取樣庫** — 一組你反覆回去翻閱的作家、作品、段落。

取樣庫的功能有三：

1. **給你標準**：知道「好」長什麼樣。沒有標準，你寫的東西沒有比較的參照點。
2. **給你靈感**：卡住的時候翻一翻，別人的句子會提示你自己可以怎麼寫。
3. **給你偷的機會**：不是剽竊，是學習。下一章談。

大部分寫作者的取樣庫**太小**。他們可能讀過幾本名著，但沒把任何一個作家讀透。沒讀透的作家不算在取樣庫裡 — 你得知道他的慣用手法、語氣、節奏、缺點，才能真的從他身上偷東西。

## 讀誰：一個起步建議

這份名單不是權威，是一個我認為對「想提升敘事散文與小說文字」的人**最有幫助的組合**。依重要性排。

### 華語現代 — 必讀

**張愛玲**
- 主要作品：〈金鎖記〉〈傾城之戀〉〈紅玫瑰與白玫瑰〉〈小團圓〉
- 學什麼：比喻的新鮮、意象的具體、情感的克制、文白交融的語感
- 提示：她是華語現代文學最有資格被系統閱讀的作家之一。建議從〈金鎖記〉〈傾城之戀〉起步。

**沈從文**
- 主要作品：〈邊城〉〈蕭蕭〉〈從文自傳〉
- 學什麼：節制的描寫、動詞的準確、景物的運用、淳樸的語感
- 提示：他的語感是張愛玲的反面 — 不華麗，但極準。兩個人都讀，你會找到自己要往哪裡走。

**魯迅**
- 主要作品：《吶喊》《彷徨》《野草》、散文〈秋夜〉〈過客〉
- 學什麼：冷峻、克制、意象的重量、短句的力道
- 提示：〈秋夜〉〈過客〉的語言實驗對寫作者極有啟發。

**汪曾祺**
- 主要作品：《受戒》《大淖記事》、散文〈故鄉的食物〉系列
- 學什麼：白描、動詞的工匠感、食物/日常的詩意
- 提示：汪曾祺是讀來最「舒服」的現代作家之一。他的平淡有深度。

**白先勇**
- 主要作品：《台北人》《孽子》
- 學什麼：視角的切換、人物描寫、時代氛圍、對白的質感
- 提示：《台北人》是短篇示範的經典。每一篇拆開看都是一堂課。

### 華語當代 — 強烈推薦

**朱天文 / 朱天心**
- 天文：《世紀末的華麗》《荒人手記》
- 天心：《古都》《想我眷村的兄弟們》
- 學什麼：當代的感官密度、時間感、長句的構築

**駱以軍**
- 《西夏旅館》《經驗匱乏者筆記》等散文
- 學什麼：意象的堆疊、離散感、記憶的操作
- 提示：他的風格強烈，讀久了會染上。要小心，但偶爾染一下有益。

**吳明益**
- 《複眼人》《苦雨之地》《天橋上的魔術師》
- 學什麼：寫實與幻境的交界、自然的描寫、散文與小說的融合

**賴香吟**
- 《其後》《文青之死》
- 學什麼：文字的靜、敘事的控制、情感的深藏

**黃錦樹、胡淑雯、童偉格**
- 學什麼：當代短篇小說的各種可能
- 提示：這幾位各有特色，選一個你讀得下去的深讀。

**木心**
- 《文學回憶錄》《哥倫比亞的倒影》
- 學什麼：隨筆的精煉、句子的音感
- 提示：《文學回憶錄》不是他寫的（學生筆記），但是華語寫作者都該讀的一本書。

### 翻譯文學 — 必讀（拿英文原典對照更好）

**契訶夫**
- 短篇：〈The Lady with the Dog〉〈The Student〉〈The Darling〉
- 學什麼：克制、日常化、潛台詞、結尾的餘韻
- 提示：所有寫短篇的人都該讀契訶夫。他是現代短篇之父。

**海明威**
- 《老人與海》、短篇〈Hills Like White Elephants〉〈A Clean, Well-Lighted Place〉
- 學什麼：乾瘦的語言、動詞的力量、冰山理論
- 提示：他的短篇最有教學價值。長篇有時會顯得重複。

**卡佛（Raymond Carver）**
- 短篇：〈Cathedral〉〈A Small, Good Thing〉〈What We Talk About When We Talk About Love〉
- 學什麼：極簡主義、藍領視角、對白的潛在張力
- 提示：讀卡佛之前先讀海明威會更有感覺 — 卡佛是海明威的當代後裔。

**石黑一雄（Kazuo Ishiguro）**
- 《The Remains of the Day》《Never Let Me Go》
- 學什麼：不可靠敘事、克制、第一人稱的運用
- 提示：他的英文不難讀，是學「克制敘事」的極佳範本。

**波赫士（Borges）**
- 短篇集：《Ficciones》《The Aleph》
- 學什麼：結構的奇巧、哲思與敘事的交織、短篇的極簡
- 提示：他的短篇通常極短（3–10 頁），每一篇是一個完整的結構實驗。

**馬奎斯（Gabriel García Márquez）**
- 《百年孤寂》《一樁事先張揚的兇殺案》
- 學什麼：敘事聲音、魔幻寫實、時間的操作
- 提示：《百年孤寂》第一句可能是所有寫作者都該背下來的。

**卡爾維諾**
- 《看不見的城市》《如果在冬夜，一個旅人》
- 學什麼：想像力的精緻、結構的可能性、散文化的小說

**芥川龍之介**
- 〈羅生門〉〈竹林中〉〈河童〉
- 學什麼：短篇的緊緻、諷刺、視角的實驗

**川端康成**
- 《雪國》《山之音》
- 學什麼：氛圍的營造、物哀美學

**太宰治**
- 《人間失格》
- 學什麼：第一人稱的自剖、現代性的絕望

**村上春樹**
- 長篇《挪威的森林》《海邊的卡夫卡》；短篇集《東京奇譚集》
- 學什麼：第一人稱的親密、日常與奇幻的交織
- 提示：村上極容易模仿，但模仿久了會中毒。他的節奏獨特，可學但別被染透。

## 為什麼要讀翻譯文學

有些寫作者會說：「我寫中文，就該只讀中文。」

這是錯的。原因：

1. **中文的可能性被翻譯擴張過**。現代中文的長句、心理描寫、敘事結構，很大一部分是翻譯文學帶進來的資源。
2. **好的華語作家大多讀翻譯**。張愛玲讀毛姆、契訶夫、Jane Austen；白先勇讀 Henry James、Katherine Mansfield；駱以買公開承認讀了大量當代拉美文學。
3. **翻譯文學給你看「中文還沒寫出來的東西」**。這是最珍貴的輸入。

但要注意：翻譯腔（Ch 8）是真的病。**讀翻譯文學是為了擴張想像，不是為了模仿其語法**。讀完要消化成自己的中文，不是直譯式地學。

## 如何讀：三個層次

### 層次一：初讀 — 享受

第一次讀一本書，就是看故事、感受情緒。不要寫筆記、不要拆解。**享受是記憶的前提**。

### 層次二：重讀 — 技術拆解

好的作家值得重讀。第二次讀時，開始問：

- 這個開頭為什麼抓我？
- 這段描寫的動詞是哪幾個？
- 這個對白做了什麼？
- 這個場景切換是怎麼做的？
- 這個比喻用的是什麼喻體？

重讀時你讀的不是故事，是**技法**。

### 層次三：抄讀 — 肌肉記憶

最深的層次：**手抄一段**。

選一段你重讀時特別有感的文字，拿紙筆抄下來。抄的時候你的眼睛會一個字一個字經過，抄完你會看見你讀時漏掉的細節 — 一個標點、一個斷句、一個不起眼的動詞。

抄過的段落會變成你的。下次寫作時，你手會不自覺用那個節奏。

我知道這個動作在當代很少人做。但它是所有寫作訓練法裡**效果最強的**。

## 建立取樣庫的一個原則

寧可**深讀五個作家，不要淺讀五十個**。

讀五十個作家你知道很多人的名字，但你寫作時大腦搜尋不到任何人的具體句子、具體節奏、具體場景處理。

深讀五個作家你會把他們的 DNA 吸收進你的文字。這五個人會變成你寫作時的**內在評審團** — 你寫一句話，你的腦中會自動響起「契訶夫會怎麼寫？」「張愛玲看到這句會怎麼改？」— 這種內化才是真的養分。

## 一個挑選取樣庫的建議

你的取樣庫應該有以下幾類：

1. **一兩個你想成為的作家** — 不是最像你現在的，是你想「寫成那樣」的。
2. **一兩個跟你反方向的作家** — 用來平衡你的偏見。例如你愛華麗的語言，就讀一個極簡派。
3. **一個你欣賞但完全不想像他的作家** — 用來開眼界，但不會誤導你的風格。
4. **一個死去超過一百年的作家** — 用來提醒你時代的更迭中，什麼東西是真正留下的。

四個領域加起來五到八個人，深讀一輩子。這比你讀一百本淺嚐的書有用。

## 一個常被忽略的建議：讀詩

即使你寫散文或小說，也要讀詩。

為什麼？**詩教你字的重量**。

一首十六字的絕句和一句一千字的長句，都能表達情感。但詩訓練你讓每一個字扛起自己的重量。讀過詩的寫作者，寫散文時每個字的選擇都會變謹慎。

推薦起步：

- 古典：王維、杜甫、李後主、蘇東坡
- 現代華語：洛夫、楊牧、夏宇、商禽
- 外國：里爾克、艾略特、葉慈（Yeats）

不用多。幾個人讀透就好。

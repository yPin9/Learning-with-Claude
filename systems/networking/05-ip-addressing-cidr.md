# Ch 5 — IP 位址、subnet、CIDR

> 目標：搞懂 IPv4 位址的數學、CIDR 怎麼算、私有 vs 公網位址、為什麼 `192.168.1.0/24` 是這個寫法。

## IPv4 位址

32 bit = 4 byte，常寫成 4 個十進位（0-255）：

```
 192.168.1.10
 │   │   │ │
 192 168  1 10
 = 11000000 10101000 00000001 00001010 (binary)
 = 0xC0A8010A (hex)
```

範圍：0.0.0.0 ~ 255.255.255.255 = 43 億個位址。

**1980 年代覺得超多，現在不夠用**（全球 80 億人 + 物聯網設備）。

## 位址分類（Classful Addressing，已過時）

歷史上 IP 分 5 類：

| Class | 範圍 | Subnet | 用途 |
|---|---|---|---|
| A | 1.0.0.0 - 126.255.255.255 | /8 | 大型網路 |
| B | 128.0.0.0 - 191.255.255.255 | /16 | 中型 |
| C | 192.0.0.0 - 223.255.255.255 | /24 | 小型 |
| D | 224.0.0.0 - 239.255.255.255 | - | Multicast |
| E | 240.0.0.0 - 255.255.255.255 | - | Reserved |

**這個分類在 1993 年被 CIDR 取代**，現在只是歷史名詞。

## CIDR（Classless Inter-Domain Routing）

把位址寫成 `位址 / 前綴長度`：

```
 192.168.1.0/24
 │           │
 │           └── 前 24 bit 是「網路部份」，後 8 bit 是「主機部份」
 └────────── 起始位址
```

`/24` 表示「前 24 個 bit 固定，剩 8 bit 可變」。

8 bit 可變 = 2^8 = 256 個位址（含 .0 跟 .255）。

## 子網路（subnet）的數學

`192.168.1.0/24`：

- 網路位址：`192.168.1.0`（主機部分全 0）
- 廣播位址：`192.168.1.255`（主機部分全 1）
- 可用主機位址：`192.168.1.1` ~ `192.168.1.254`（254 個）

`192.168.0.0/16`：

- 網路位址：`192.168.0.0`
- 廣播位址：`192.168.255.255`
- 可用：`192.168.0.1` ~ `192.168.255.254`（65534 個）

| CIDR | 主機數 | 用例 |
|---|---|---|
| /8 | 16,777,214 | 大型企業 / 國家級 |
| /16 | 65,534 | 中型企業 |
| /24 | 254 | 家用 / 小辦公室 |
| /28 | 14 | 小 server group |
| /30 | 2 | 點對點 link |
| /32 | 1 | 單一主機（host route） |

**重要**：總可用 = 2^(32-prefix) - 2（扣掉網路位址 + 廣播位址）。

`/31` 跟 `/32` 是特例，分別用於 P2P 跟 host route。

## subnet mask（子網遮罩）

CIDR 的另一種寫法。`/24` 等於 mask `255.255.255.0`：

```
 /24:
   11111111 11111111 11111111 00000000
   = 255.255.255.0

 /28:
   11111111 11111111 11111111 11110000
   = 255.255.255.240

 /30:
   11111111 11111111 11111111 11111100
   = 255.255.255.252
```

**現代寫法用 CIDR**（`/24`）；老設定用 mask（`255.255.255.0`）。同一件事。

## 算「兩個 IP 在不在同網段」

「**bitwise AND with mask**」 → 相同 = 同網段：

```
 IP A:  192.168.1.10  (11000000.10101000.00000001.00001010)
 IP B:  192.168.1.20  (11000000.10101000.00000001.00010100)
 Mask:  /24           (11111111.11111111.11111111.00000000)

 A AND mask: 192.168.1.0
 B AND mask: 192.168.1.0
 → 相同 → 同網段
```

```
 IP A:  192.168.1.10
 IP B:  192.168.2.10
 Mask:  /24

 A AND mask: 192.168.1.0
 B AND mask: 192.168.2.0
 → 不同 → 不同網段，要走路由
```

OS 內部就是這樣判斷「直連 vs 走 router」。

## 私有 IP 範圍

不能在公網上用，但 LAN 隨便用：

| 範圍 | CIDR | 通用稱呼 |
|---|---|---|
| 10.0.0.0 - 10.255.255.255 | 10.0.0.0/8 | 大型 |
| 172.16.0.0 - 172.31.255.255 | 172.16.0.0/12 | 中型 |
| 192.168.0.0 - 192.168.255.255 | 192.168.0.0/16 | 家用 / 小型 |

也叫 **RFC 1918 位址**。

家用路由器幾乎都用 `192.168.0.0/24` 或 `192.168.1.0/24`。雲端 VPC 常用 `10.0.0.0/16`。

## 特殊 IP

| 範圍 | 用途 |
|---|---|
| 127.0.0.0/8 | Loopback（自己） |
| 169.254.0.0/16 | Link-local（DHCP fail 時） |
| 224.0.0.0/4 | Multicast |
| 0.0.0.0 | 「所有 interface」/「未指定」 |
| 255.255.255.255 | 全網段廣播 |
| 100.64.0.0/10 | CGNAT（電信業者用） |

`127.0.0.1` 是 loopback 地址 — 永遠是「**這台機器自己**」。

## 公網 IP

不在私有範圍 / 特殊範圍的就是公網。**全球唯一**，由 IANA 分配給各 RIR（regional internet registry）：

- ARIN（北美）
- RIPE NCC（歐洲）
- APNIC（亞太）
- LACNIC（拉美）
- AFRINIC（非洲）

RIR 再分給 ISP，ISP 分給用戶。

**IPv4 已經分完**了（2011 年 IANA 池子用光）。所以才需要 NAT（Ch 8）跟 IPv6（Ch 38）。

## CIDR 計算實例

「**`10.0.0.0/16` 包含哪些位址？**」

- 前 16 bit 固定：`10.0.x.x`
- 後 16 bit 可變
- 範圍：`10.0.0.0` ~ `10.0.255.255`
- 主機數：65534

「**`172.20.5.32/29` 是什麼**」

- /29 = 前 29 bit 固定，後 3 bit 可變 = 8 個位址
- 起始：把 32 對齊到 /29 邊界
  - 32 = 00100000，後 3 bit = 000，已對齊
- 範圍：`172.20.5.32` ~ `172.20.5.39`
- 可用主機：`172.20.5.33` ~ `172.20.5.38`（6 個）

**新手常算錯邊界**。用工具：

```bash
# 用 sipcalc
sipcalc 172.20.5.32/29
```

或 online subnet calculator。

## CIDR 在路由表

```bash
ip route
# default via 192.168.1.1 dev wlan0
# 10.0.0.0/8 via 10.0.0.1 dev tun0
# 172.16.0.0/12 via 10.0.0.1 dev tun0
# 192.168.1.0/24 dev wlan0 ...
```

每條 route 用 CIDR 表示。**最具體（longest prefix）優先**：

- 找 `10.0.0.50` → 匹配 `10.0.0.0/8`
- 找 `192.168.1.50` → 匹配 `192.168.1.0/24`（不是 default）
- 找 `8.8.8.8` → 沒匹配 → 走 `default`

## 一個常見誤解：「/24 永遠是 192.168.x.0」

**錯**。`/24` 只是「前綴長度」。任何位址都能配 /24：

- `192.168.1.0/24`
- `10.20.30.0/24`
- `203.0.113.0/24`

**前綴長度跟「網路類別」沒關係**。

## 一個常見誤解：「IP 位址夠用」

**錯**。IPv4 全球 43 億位址，扣除特殊用 / 私有 / 浪費 → 實際公網約 36 億。**全球設備數遠超這數**。

解決：

- **NAT**：多設備共用 1 個公網 IP
- **CGNAT**：ISP 級別 NAT（多用戶共用 1 個公網 IP）
- **IPv6**：徹底解決（128 bit 位址）

## 一個常見誤解：「我家 IP 是 192.168.1.10 就是 IP 公開了」

**錯**。`192.168.x.x` 是私有 IP，**全世界數百萬家庭都用**。對外公網看到的是你家路由器的公網 IP（從 ISP 拿）。

```bash
curl ifconfig.me
# 你的「對外」公網 IP（不是 192.168.x.x）
```

## 動手練習

**1. 確認自己的 IP**

```bash
ip a                    # 你的私有 IP
curl ifconfig.me        # 你的公網 IP
```

兩個常常不同。

**2. CIDR 計算**

回答：

- `10.10.10.10/8` 的網路位址、廣播、主機範圍？
- `172.16.5.0/22` 包含多少個位址？
- 你家 LAN 是什麼 CIDR？（看 router 設定）

**3. 判斷同網段**

寫 5 對 IP，判斷在不在同 /24 / /16 網段。手算 + 用 sipcalc 驗證。

**4. 看雲端 VPC 設定**

如果你有 AWS / GCP 帳號，看看 VPC 的 CIDR 設定。通常是 `10.0.0.0/16` 或 `172.31.0.0/16`。

# Ch 21 — 開局三大原則與新手陷阱

> 目標：掌握開局三大原則（中心、出子、王的安全），認得幾個經典新手陷阱不再中招。**這章不教背譜** — 教你怎麼用原則走出合理開局。

業餘棋手的最大迷思是「學開局 = 背譜」。**錯**。大師背 50 步深的主變，因為他們的對手也會到第 50 步。你和 1400 對手下棋，對方第 10 步就會脫離任何主流開局 — 你背的譜完全用不上。

**業餘階段正確的開局方式**：懂**原則**，遇到任何對手走法都能走出合理一步。配合一個簡單的開局 repertoire（Ch 22、23 給你），就夠用到 1500+ rating。

## 三大原則

### 原則 1：Control the Center（控制中心）

**中心四格**：d4、d5、e4、e5。

**為什麼中心重要**：
- 子在中心控制最多格子（馬在 e4 控 8 格，在 a1 控 2 格）
- 中心控制 = 兩翼都能快速支援
- 對方想攻擊你的王必須穿過中心

**實踐方法**：

- 第一步用兵占中心：`1. e4` 或 `1. d4`
- 不能用兵直接占就用子間接控制（`1. Nf3` 控 e5、d4）
- **不要第一步動邊兵**（`1. a3` 或 `1. h4` 是浪費，不控中心）

### 原則 2：Develop Your Pieces（出子）

**發展 = 把子從起始位置搬到活躍位置**。

**順序**：
1. **馬先於象**（馬的自然起點是 f3、c3、f6、c6；象的好位要看兵推到哪）
2. **小子先於大子**（馬、象 → 車、后）
3. **不要同一個子連續動兩次**（除非有明確目的）

### 原則 3：Keep Your King Safe（王的安全）

**開局 10 步內要易位**。中央王在開局後期很危險（見 Ch 20）。

**易位前提**（Ch 1 講過）：
- 王、該車都沒動
- 王不在將、不經過被攻擊格、不到被攻擊格
- 中間無子

**短易位（O-O）比長易位（O-O-O）更常見**：
- 短易位王到 g1 / g8（兵完好）
- 長易位王到 c1 / c8（王翼暴露但車快速到 d 列）

## 三原則的衝突

有時候三原則會打架。**優先順序大致**：

1. 王的安全（不安全就沒有之後）
2. 出子（不出子王也不會安全）
3. 中心（中心不佔的後果比前兩者輕）

**實戰常見**：為了搶中心推兵把發展耽誤 → 對方搶先發展 → 攻你 → 輸。**發展 > 中心爭奪**。

## 開局十條通用守則

1. **前 3-4 步推中央兵**（e4/d4 系或 c4/e4 系）
2. **馬先發展**（Nf3、Nc3 或對應黑方）
3. **象發展到活躍格**（Bc4、Bf4、Bg5 等）
4. **10 步內易位**（通常短易位）
5. **不重複走同一子**（發展還沒完前）
6. **不早出后**（Scholar's Mate 風險，也會被擾）
7. **不推邊兵**（除非有明確計畫）
8. **不推 g / h 兵前自己王翼**（否則易位後弱化王）
9. **車連接**（易位後讓兩個車沿底排能互相看到）
10. **發展完後再想戰術** — 發展未完前沒本錢打

## 幾個經典新手陷阱（要會避開也要會下）

### Scholar's Mate（Ch 0 講過）

四步將死。白方：`1. e4 e5 2. Bc4 Nc6 3. Qh5 Nf6?? 4. Qxf7#`

**黑方防守**：第 3 步後黑方有很多選項。`3...g6`（逼后讓 h5 + 保住 f7）是常見簡單防法。或 `3...Qe7`（后保護 e5 + 同時防 f7 — 比較少見但可）。

**別用 Scholar's Mate 打有經驗對手** — 你白方后被擾攻一整盤。

### Fool's Mate（最蠢的 mate）

**兩步將死**（白方被 mate）：`1. f3? e5 2. g4?? Qh4#`。這是「推兩個王翼兵」的懲罰。

**教訓**：f 兵和 g 兵不要亂推（開局 h3、f3 也不推）。

### Wayward Queen Attack（早出后的陷阱）

白方 `1. e4 e5 2. Qh5` — 白后太早出。黑方簡單回應 `2...Nc6`（發展 + 保護 e5），白后被迫走，接下來 `3. Bc4 g6 4. Qf3 Nf6` 白后被擾、無建樹。

**教訓**：不要第 2 步出后，等出子發展完。

### Blackburne Shilling Gambit（黑方給白方的陷阱）

黑方 `2...Nd4!?` 引誘白方吃兵 `3. Nxe5??` 結果 `3...Qg5` 威脅白 g2 兵 + 威脅 `Qxg2#`。

**白方防**：第 3 步不吃，走 `3. Nxd4` 或 `3. Bc4` 正常發展。

### Légal's Mate（中央王懲罰）

白方 `1. e4 e5 2. Nf3 d6 3. Bc4 Bg4 4. Nc3 g6? 5. Nxe5! Bxd1?? 6. Bxf7+ Ke7 7. Nd5#`。

**教訓**：Pin 不等於絕對，有時候 pin 的子能動打破 pin 反殺。

三原則檢查：
- **中心控制**：0（h 兵離中心最遠）
- **發展**：0（沒動任何子）
- **王的安全**：0 or 負（h 兵推開後自己 h1 車位置改變，王翼弱化）

**三原則全違反**。這是**差的開局步**。

但實戰上 h4 不是立刻輸棋 — 一手開局不會決定對局。它只是**浪費一個節奏**。黑方回應 `1...e5` 或 `1...d5` 就取得中心先手。

這題訓練你**用原則判斷走法**，不是看到「大師也走過 h4」就以為可以。

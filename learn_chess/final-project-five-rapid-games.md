# Final Project — 5 盤 Rapid 復盤報告

> 目標：把 Ch 0-26 學的所有東西接回實戰。下 5 盤 Rapid (15+10)、每盤用這門課框架做完整復盤、交出一份整合報告。這是驗證你「學到」vs 「真的會」的唯一方式。

## 為什麼是實戰 5 盤

讀 26 章和做練習不代表你會下棋。**會下棋 = 在時間壓力下能跑思考流程、戰術 pattern 一眼看到、殘局能收、復盤能找到自己的錯**。

這個專案是**最後的整合檢驗**。做完這 5 盤加 5 份復盤，你就完成了從「讀課程」到「能實戰」的轉換。

## 任務規格

### 下棋要求

- **5 盤 Lichess Rapid 對局（15+10 或 10+5）**
- 用戶名：你自己的 Lichess 帳號
- 對手：**匹配的人類對手**（不是電腦）
- 節奏：Rapid，不要 Blitz 或 Classical
- 時間：**不強制連續下完** — 一天一盤到兩盤比較健康
- **不准作弊**（開引擎、開 PGN 看答案等）

### 復盤要求

每盤復盤交出一份 **written report**（文字檔或 Lichess Study）。每份包含：

1. **Opening 評價**（第 1-10 步）
2. **Middle game 關鍵 moment**（選 2-3 步說明）
3. **Endgame 評價**（如果進入殘局）
4. **3 個 blunder / 錯誤**（不管贏輸，每盤都找 3 個）
5. **對應的 takeaway**（每個錯誤對應一條）
6. **從這門課哪幾章學到的東西被用上 / 被漏**

## Final Project 的評量標準

**合格標準**（自評即可，沒人會幫你打分）：

- [ ] 下完 5 盤 Rapid
- [ ] 每盤有完整復盤報告
- [ ] Summary 找出至少 2 個反覆出現的錯誤類型
- [ ] Summary 至少指出課程中 3 個章節的應用實例
- [ ] Summary 包含接下來的改進計畫

**A 級標準**：
- [ ] 5 盤中至少 2 盤的 takeaway 不是「下次小心」而是**具體行動改變**（如「下次看到 open e 列強制做 back rank 檢查」）
- [ ] Summary 認出自己**強 vs 弱**類型清楚（戰術強 / 殘局弱 / 或相反）
- [ ] 接下來計畫是**具體訓練動作**（「下週每天 20 題 pin puzzle + 2 局 Lucena 練習」）

## 做完 Final Project 後的狀態

理論上：

- **Puzzle rating 穩定 1500+**
- **Lichess 實戰 rating 有初步基礎**（具體依你起點）
- **能認出自己的弱點類型並有具體訓練計畫**
- **建立下棋後復盤的習慣**

你還沒到「中階棋手」，但你**從課程畢業進入「自主提升」階段**。這是這門課目標的終點。

## 超出本課的方向（做完 Final Project 後）

如果你想繼續進步：

1. **繼續下 Rapid**，每盤復盤，每月看 takeaway 找重複
2. **加入戰術 puzzle 日常**：Lichess 每日 10-15 題持續累積
3. **開始讀一本好書**：《Silman's Complete Endgame Course》(殘局分級) 或《Amateur's Mind》(局面思考)
4. **研究 GM 對局**：選 10-15 盤 Carlsen 或 Caruana 的 Rapid 棋，慢慢看
5. **考慮線上課程**：Chessable 的 course 系統針對特定開局有好內容

## 結語

這 27 章的內容都可以忘記細節 — 但**復盤習慣**、**思考流程**、**分段式訓練**這三件事要**內化成肌肉**。這三件做到，你不需要這門課也能繼續進步。

祝你下得愉快，也希望你享受這個過程 — 西洋棋最大的樂趣不是贏，是那種「我剛剛看到一個我以前看不到的 pattern」的瞬間。那一瞬間累積起來，就是從新手到中階到大師的全部過程。

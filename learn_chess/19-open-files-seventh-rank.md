# Ch 19 — 開放線與第七排

> 目標：認得 open file、half-open file，懂得車為什麼要搶 open file。理解「進到第七排」的車為什麼威力倍增。這兩個概念是中局用車的核心。

車的威力幾乎完全來自**開放線**。車站在堵死的 file 等於沒放，車站在開放 file 上瞬間變最強的子。這章給你「怎麼看 file 開放狀態、怎麼搶 file、怎麼利用搶到的 file」的完整思路。

## File 的三種狀態

### Open File（開放 file）

**雙方都沒有兵在這 file**。

```
  a b c d e f g h
7 p p . . p p p p  7    <- 黑方 c、d 沒兵（c、d 列對黑方來說空）
6 . . . . . . . .  6
2 P P . . P P P P  2    <- 白方 c、d 沒兵
```

c、d 列對雙方都是開放 file。站上去的車享受整條 file 的攻擊力。

### Half-Open File（半開放 file）

**只有一方有兵在這 file，另一方沒有**。

```
  a b c d e f g h
7 p p p . p p p p  7    <- 黑方 d 有兵（d7）
2 P P . . P P P P  2    <- 白方 d 沒兵
```

d 列**對白方是 half-open**（白方沒兵擋、能用車）、**對黑方是 closed**（黑方自己的 d7 兵擋著）。

**Half-open file 的戰略含義**：你有攻擊線、對方沒有 → **你主動攻擊這條線**、對方 d7 兵變攻擊目標。

### Closed File（封閉 file）

**雙方都有兵在這 file**。

車用不上這條 file，除非先製造開放（交換兵）。

## 為什麼車要上開放 file

直白：車只有在開放或半開放 file 上才有效率。封閉 file 的車**幾乎等於沒有**。

- 開放 file 的車：控制 14 格（整 file + 站格的 rank 全部）
- 封閉 file 的車：只控制從本格到自己兵之間的幾格 — 可能 0-2 格有效控制

**這就是為什麼開局要快點開 file 給車用**。多數開局的中局目標就是「搶 e / d 或 c file 給自己車」。

## 搶 File 的兩種方式

### 方式 1：直接換兵

推自己的兵換對方的兵 → 那條 file 變開放 / 半開放。

例：白方 `e4 exd5` 換掉黑方 d 兵 → d 列半開放對白方。

### 方式 2：用子吃掉擋的兵

用子吃對方擋在那列的兵。

### 誰搶到 file 誰贏？

**搶到 file 後，車要實際占據才有用**。常見進程：

1. 推或吃兵製造開放 file
2. 雙方都想占 file → 互相調車上去
3. 搶先到 file 的一方**加倍**（雙車疊 file）
4. 雙車壓對方弱點兵 → 對方被迫讓步

**Battery**（車 + 車疊同 file 或車 + 后疊同 file）= 傾斜力壓倒性的攻擊組合。

## 第七排（Seventh Rank）

**車進到對方第七排（你的第 7 排 = 黑方第 2 排 = 白方看的對方兵排）** → 威力放大到不可思議。

### 為什麼第七排這麼強

1. **對方剩的兵大多在第二排** — 車在第七排直接吃兵
2. **對方王在第一排** — 車第七排就是攻王隔壁
3. **對方的子想回防第七排很難** — 底排空間小

### 絕對第七排（Absolute Seventh）= 車 + 對方王 在第七排

當你的車**在對方的第七排**（例：白車在 rank 7），且**對方王在第八排（被車橫切）**：

- 車橫掃對方整個第七排兵
- 對方王困在第八排
- 這就是「Pigs on the Seventh」（第七排的豬 — Nimzowitsch 的經典用詞）

### 雙車進第七排 = 幾乎贏定

兩個車都上第七排 → 威力指數級放大。常常直接出現 back rank mate 或掃光所有兵 → 升變。

實戰目標「雙車第七排」叫 **Blind Pigs**（盲豬），因為這兩個車「看什麼吃什麼」。

## 實戰搶 file 的流程

1. **評估哪些 file 是 / 會是開放或半開放**
2. **預測會變 half-open 的 file**（可能透過某次交換）
3. **提前把車調到該 file 的準備位置**
4. 當 file 開了，你的車搶先占
5. 加倍（雙車疊）→ 進第七排

## 動手練習

**題 1**：哪些 file 對白方 half-open？

```
  a b c d e f g h
7 p p . . p p p p  7
6 . . p . . . . .  6
5 . . . . . . . .  5
4 . . . . P . . .  4
3 . . . . . . . .  3
2 P P . P . P P P  2
  a b c d e f g h
```

<details>
<summary>答案</summary>

對白方 half-open file = 白方無兵、黑方有兵的 file。

掃 file 清單：
- a：白 a2、黑 a7 → closed
- b：白 b2、黑 b7 → closed  
- c：白**沒**、黑 c6 → 對白 half-open
- d：白 d2、黑**沒** → 對白 closed（白方自己有）；對黑 half-open
- e：白 e4、黑 e7 → closed
- f：白 f2、黑 f7 → closed
- g：白 g2、黑 g7 → closed
- h：白 h2、黑 h7 → closed

**對白 half-open：c 列**。
**對黑 half-open：d 列**。

雙方都有一個目標 file，實戰會圍繞這兩列打。

</details>

**題 2**：白車 Ra7 與黑王 Kb8。白車在絕對第七排嗎？

<details>
<summary>答案</summary>

白車在 rank 7、黑王在 rank 8 → **是絕對第七排**。白車能橫掃第七排，黑王困在 rank 8。

實戰這個 pattern 常常直接 mate 或賺所有第七排兵。

</details>

# Ch 15 — 殘局過渡思路

> 目標：判斷「該不該化簡到殘局」。知道哪些局面多兵的一方換子化簡是贏、哪些化簡是和。這章比前四章短、但沒這個判斷力前面殘局技巧就白學。

前面 Ch 10-14 講的是「殘局已經到了」的技巧。**這章是接中局到殘局的橋**：你中局某一刻面臨「是否主動化簡」的選擇，判斷錯了多 1 兵可能變和棋、判斷對了 1 分劣勢也能逆轉。

## 化簡（Simplification）的意義

「化簡」= 主動交換雙方子力 → 走向少子殘局。

**原則**：**子力占優的一方喜歡化簡**（因為百分比差距放大 — 8 vs 7 和 3 vs 2 都差 1 分但贏的機率差很大）。**子力劣勢的一方討厭化簡**（想保留複雜戰術機會）。

但這個原則**不絕對**。以下三種例外你要認得。

## 例外 1：你多兵但對方多子力種類 → 多兵方不一定贏

多一個兵但對方有 N+B vs N+N、雙象對馬象等組合 → 多兵方雖然帳面贏 1，**但沒升變路徑時不一定能把兵推到底**。

**典型場景**：中局 3 兵對 2 兵 + 雙象 vs 雙馬。你多一個兵但對方的雙象機動力壓倒性強 → 化簡到殘局雙象發揮更大。

**判斷**：化簡前問「**我的多餘兵有沒有升變路徑？**」沒路徑就不急化簡。

## 例外 2：你 K+R+P vs K+R 但兵到不了 Lucena → 和棋

Ch 14 講過：車兵殘局雖然多一個兵，但如果不能化簡成 Lucena 形狀，多半是 Philidor 形狀 → 和棋。

**所以**：你中局多一個兵、對方主動要全部交換剩車兵殘局。**先算這個殘局是 Lucena 還是 Philidor**。如果是 Philidor 形狀，**拒絕化簡**、保留更多子去攻王。

## 例外 3：Bishop pair 雙象優勢在殘局放大

前面 Ch 2 提過 bishop pair 值 +0.5。這個 bonus 在**殘局放大到 +1 甚至更多**，因為：
- 殘局盤面空，象的長對角攻擊力滿血
- 雙象可以同時覆蓋兩個顏色的格子

**判斷**：如果你有 bishop pair，**主動化簡到殘局**（保留雙象）可能比保留中局張力更好。

## 什麼時候該化簡（基本情況）

**化簡偏好的條件**：

1. 你子力多（至少一個兵或更多）
2. 你的多餘子有明確升變 / 活動路徑
3. 對方王沒有攻擊機會（保留中局對你無利）
4. 你有 bishop pair 或對方有明顯弱子（如被困馬、爛象）

滿足 2-3 個 → 可以化簡。全部滿足 → 該化簡。

## 什麼時候不該化簡

**保留中局張力的條件**：

1. 你子力少但有戰術 / 王攻機會
2. 對方王暴露、你能用雙車或后車攻王
3. 化簡後殘局你多出的兵沒升變路徑（Philidor 形狀）
4. 對方的弱點只在中局存在，殘局會消失

滿足 2+ 個 → 不化簡，繼續打中局。

## 交換的「誰提議誰賺」原則

換子通常**對一方有利、對另一方不利**。被動接受對方提議的交換 → 多半你虧。

**實務守則**：**檢查對方剛提議的交換對誰有利**。對你有利再接受、對他有利想辦法拒絕（插入反威脅、或走不同子不換）。

## 殘局判斷的「子力清單」思維

到中局後期要化簡前，列兩個 list：

```
白方（我方）：K + Q + R + B + 5 P，bishop pair 無（只剩 1 B）
黑方：K + Q + R + N + 4 P，無 bishop pair
```

化簡到 K + R + B vs K + R + N 少兵殘局，局面如何？

- 白多 1 兵 → 基本優勢
- 白 B 對黑 N → 看局面形狀（開放 B 好、封閉 N 好）
- 白兵多在哪個翼？外圍通路兵可能？

**子力清單讓你看到「化簡後」的樣子**。清單看起來優 → 化簡。看起來平甚至劣 → 不化簡。

## 動手練習

**題**：中局你多一個兵（5P vs 4P），但對方有 bishop pair。對方提議 Q 換 Q。接受嗎？

<details>
<summary>答案</summary>

**多半不接受**。理由：

- 你多 1 兵（帳面 +1）但對方 bishop pair 殘局值 +1 → **抵消**
- 換后後，對方雙象在開放殘局會變很強
- 你的戰術機會（后 + 后攻擊可能）消失

**優先做法**：保留中局，找機會**先換掉對方一個象**（破掉雙象），再考慮化簡。

如果你被迫換后（不換后立刻虧更大），**換了之後要立刻找計畫** — 目標逼對方雙象中至少一個到不活躍位置。

</details>

# Ch 24 — 思考流程

> 目標：每一步棋要用固定的**思考流程**，而不是憑感覺。掌握 CCT 原則、「對方想幹嘛」檢查、候選步篩選。用流程限制自己不要漏看。

你前面 23 章學了很多東西 — 戰術、殘局、局面要素、開局。實戰時**你會漏看**，因為沒有流程確保每件事被想過。這章給你一個「固定流程」，一有時間就跑一遍。

## 核心思考流程（每步都跑）

### Step 1: 「對方剛剛那步想幹嘛？」

**最重要的一步**。對方剛剛走了一步 → **它為什麼走這步？**

可能的答案：
- **發展 / 計畫性走法**：沒立即威脅，長期構想
- **一步威脅**：威脅吃我的某個子、威脅 fork、威脅 pin 等
- **兩步威脅**：這步準備下步做某件事
- **防守我剛才的威脅**：它在守
- **陷阱**：表面無害但下幾步有連環戰術

**你不問這題 → 你會漏看對方威脅 → 無腦走完後下一步丟子**。

### Step 2: 「我現在有什麼威脅（CCT）？」

跑 Checks / Captures / Threats：

- **Checks**：我有哪些將軍走法？
- **Captures**：我有哪些吃子走法？特別是不平等吃子
- **Threats**：我有哪些威脅一步內吃子 / mate 的走法

列出所有候選。如果這步列出來的有**強制戰術 → 算到底 → 走**。

### Step 3: 「我要做什麼 plan？」

如果 Step 1 和 2 都沒有戰術緊急 → 進 positional 思考：

- 我的廢子要不要復活？
- 雙方 pawn structure 哪方好？
- 有沒有 open file 要搶？
- 王的安全是否要加強？

選出 1-2 個 plan。**不要每步都重新想 plan**，承接上一步的 plan 就好 — 除非局面變了。

### Step 4: 「選哪步最好？」

從候選步中選：

- 如果戰術緊急 → 選戰術解
- 如果 plan 明確 → 選最符合 plan 的走法
- 如果不確定 → 選「**最難被懲罰**」的走法（不是「最好」，是「最保險不會虧大」）

### Step 5: 「走這步對方會怎麼回應？」

**下之前想一次對方下一步**。跑對方的 Step 1（他看到我走這步後的威脅）。如果他有強制反擊 → 你這步可能 blunder，重選。

## 時間分配

**Rapid（15+10）**：
- 每步平均 30 秒左右
- 關鍵步（戰術 / 大交換 / 進殘局）花 1-2 分鐘
- 例行步（發展 / 易位）10-20 秒就走

**Blitz（5+0）**：
- 沒時間跑完流程
- 但 CCT 和 Step 1「對方幹嘛」至少要做 — 漏這兩個會 hang piece

## 兩個最常用的檢查點

實戰跑完整流程不現實。用**兩個最省時的檢查**：

### 檢查 1：走之前問「我這步有沒有 hang piece？」

**Hang piece** = 把子走到沒被保護、且被對方某子攻擊的格子 → 送子。

走之前 5 秒檢查：**我這步要到的格子，誰攻擊它、誰保護它？**

- 攻擊者 > 保護者 + 被吃子價值 = hang
- 除非這是戰術犧牲有回收

業餘棋手**超過 50% 的輸棋是 hang piece**。做好這個檢查分數立刻跳 100。

### 檢查 2：走之前問「對方的回應我有算過嗎？」

**至少算一步對方回應**。跑對方 CCT（他下步最強 Check / Capture / Threat 是什麼）。

## 常見思考錯誤

### 錯誤 1：「我有戰術所以衝」的急躁

看到一個戰術機會立刻走 → 沒算完對方回應 → 發現對方有反戰術。

**解法**：每次看到戰術，**強迫自己算到終點**再走，而不是中途覺得「看起來贏」就下。

### 錯誤 2：「隨便走一步不重要的」

沒仔細想就走一個看起來安全的發展步 → 結果這步是 blunder。

**解法**：即使是「看起來普通」的步，也跑 hang piece 檢查。

### 錯誤 3：Tunnel Vision（隧道視野）

盯著一個計畫忘了看整個盤面 → 對方另一邊做了重大事件你沒注意。

**解法**：每 3-4 步重新掃一次全盤（對方剛做了什麼、全局如何變化）。

### 錯誤 4：時間壓力下走快

時間剩 30 秒你開始亂下 → 變成純反應走 → 各種 blunder。

**解法**：Rapid 時間不夠時優先做 Step 1 和 hang piece 檢查，**其他全跳過**。

## 完整走棋 checklist（印出來貼螢幕）

```
1. [ ] 對方剛剛那步想幹嘛？（至少一個具體威脅猜測）
2. [ ] 我的 Checks / Captures / Threats 列過嗎？
3. [ ] 有戰術嗎？有的話算到底
4. [ ] 沒戰術就承接 plan / 選走法
5. [ ] 走這步會 hang piece 嗎？
6. [ ] 對方最強回應我有算嗎？
7. [ ] 下棋
```

## 動手練習

**情境練習**：對方剛走 `Ng4`。你跑 Step 1。

「對方走 Ng4 想幹嘛？」

可能原因：
- **威脅 Nxe5 / Nxh2**（看馬到 g4 位置能吃什麼）
- **威脅 Nxe3**（如果 e3 有我的子）
- **威脅 Nf6+ / Nxf2** 發動戰術（如果我方 f2 弱）
- **準備 Qh5 共同攻 f7 或 h7**

**你不想清楚就隨便走** → 下一步對方 Nxf2+ 你就虧車了。

**跑 Step 1 的價值 = 看清威脅，然後針對它下**。

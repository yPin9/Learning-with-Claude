# Ch 39 — 題型辨識總表：看到什麼 → 用什麼

> 目標：建立「看到題目關鍵字 → 聯想解法」的快速反應，縮短面試中的思考時間。

## 使用方式

這章不是用來背的。是你做了一段時間題目後，回來對照「我的直覺是否和這張表一致」。

不一致的地方，就是你還沒完全內化的模式。

---

## 陣列 / 字串類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 已排序陣列，找兩個數 | Two Pointers（相向） |
| 去除重複 / in-place 修改有序陣列 | Two Pointers（同向） |
| 連續子陣列，固定長度 K | Sliding Window（固定） |
| 最長 / 最短連續子陣列，滿足某條件 | Sliding Window（可變） |
| 子陣列總和 = K | Prefix Sum + HashMap |
| 多次查詢子陣列總和 | Prefix Sum |
| 找重複 / 配對 / 頻率 | HashMap / HashSet |
| 括號匹配 | Stack |
| 下一個更大 / 更小元素 | Monotonic Stack |
| 最大矩形面積（Histogram） | Monotonic Stack（遞增）|
| 接雨水 | Two Pointers 或 Prefix Max |

---

## 二分搜尋類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 已排序陣列，找 target | Binary Search（閉區間） |
| 第一個 ≥ / > target 的位置 | lower_bound / upper_bound |
| 「最小化最大值」或「最大化最小值」 | Binary Search on Answer |
| 答案有明確的數值範圍 + O(N) 驗證 | Binary Search on Answer |

---

## 樹類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 遍歷 / 搜尋整棵樹 | DFS（前/中/後序） |
| 按層收集 / 最短路徑到達某層 | BFS（層序） |
| 子樹的最佳值（深度/直徑/最大路徑）| DFS + 全域變數 |
| LCA（最近公共祖先） | 遞迴 LCA |
| BST 的有序操作 | 中序遍歷 |
| 路徑問題（根到葉） | DFS + backtracking |

---

## Graph 類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 最短步數 / 最短路徑（無權重） | BFS |
| 連通分量 / 能否到達 | DFS 或 Union-Find |
| 有前置依賴的排序 | Topological Sort（Kahn） |
| 動態合併 / 判斷是否在同一組 | Union-Find |
| 有向圖環偵測 | 三色 DFS 或 Kahn（看 order.size()） |
| 最短路徑（有正權重） | Dijkstra |

---

## DP 類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 「最多 / 最少 / 最長 / 最短」的子序列或子陣列 | DP |
| 「有幾種方法」 | DP（計數） |
| 網格路徑，只能往右 / 下 | 二維 DP |
| 每個物品只用一次，背包容量限制 | 0/1 背包 |
| 長度最長的遞增子序列 | LIS（DP 或 Patience Sort） |
| 兩個字串的最長公共部分 | LCS |
| 區間 [i,j] 的最佳解 | 區間 DP |

---

## Greedy 類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 最多不重疊區間 / 最少移除 | Greedy（結束時間排序） |
| 合併重疊區間 | Greedy（開始時間排序） |
| 最少會議室 | Greedy + min-heap |
| 能否到達終點 / 最少跳躍 | Greedy（維護最遠距離）|
| 排程問題（最少等待時間） | Greedy（頻率 / 截止時間）|

---

## 數學 / 位元類

| 關鍵字 / 題目特徵 | 優先考慮 |
|---|---|
| 找唯一出現的數（其他出現偶數次） | XOR |
| 2 的冪次判斷 | `n & (n-1) == 0` |
| 計算 a^n mod m | 快速冪 |
| 找最大公因數 | GCD（Euclidean）|
| [2, n] 的所有質數 | Sieve of Eratosthenes |
| 計算路徑數 / 組合數 | C(n, k) 或 Pascal's Triangle |

---

## 面試快速判斷流程

```
1. 看資料類型：陣列？字串？樹？圖？
2. 看問什麼：最大/最小？計數？判斷存在性？
3. 看約束：已排序？有重複？有環？
4. 暴力解是什麼？複雜度是多少？
5. 能不能用上面的表格優化？
```

# Ch 26 — 二維 DP：網格路徑

> 目標：建立二維 DP 的狀態定義習慣，能處理網格路徑問題，並理解遍歷順序的重要性。

## 二維 DP 的本質

一維 DP 的狀態是 `dp[i]`（只有一個維度）。
二維 DP 的狀態是 `dp[i][j]`，通常代表「走到第 i 行第 j 列的最佳值」或「考慮前 i 個元素、條件為 j 的最佳值」。

**遍歷順序原則**：計算 `dp[i][j]` 時，它依賴的狀態必須已經算好。

## 題目 1：Unique Paths（LeetCode 62）

**題目**：m×n 的網格，從左上角走到右下角，只能往右或往下，有幾種走法？

### 四個要素

```
狀態：dp[i][j] = 走到 (i,j) 的路徑數
轉移：dp[i][j] = dp[i-1][j] + dp[i][j-1]（從上方或左方來）
Base：dp[0][j] = 1（第一行只能從左走），dp[i][0] = 1（第一列只能從上走）
答案：dp[m-1][n-1]
```

```cpp
int uniquePaths(int m, int n) {
    vector<vector<int>> dp(m, vector<int>(n, 1));
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = dp[i-1][j] + dp[i][j-1];
    return dp[m-1][n-1];
}
```

## 題目 2：Minimum Path Sum（LeetCode 64）

**題目**：m×n 的網格，每個格子有非負數字，找從左上到右下的路徑使數字總和最小（只能往右或往下）。

```
狀態：dp[i][j] = 走到 (i,j) 的最小路徑總和
轉移：dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])
Base：dp[0][0] = grid[0][0]
     第一行：dp[0][j] = dp[0][j-1] + grid[0][j]
     第一列：dp[i][0] = dp[i-1][0] + grid[i][0]
```

```cpp
int minPathSum(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dp(m, vector<int>(n));

    dp[0][0] = grid[0][0];
    for (int j = 1; j < n; j++) dp[0][j] = dp[0][j-1] + grid[0][j];
    for (int i = 1; i < m; i++) dp[i][0] = dp[i-1][0] + grid[i][0];

    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1]);

    return dp[m-1][n-1];
}
```

## 題目 3：Edit Distance（LeetCode 72）

**題目**：給兩個字串 `word1` 和 `word2`，用最少幾次操作（插入、刪除、替換）把 `word1` 變成 `word2`。

### 狀態定義（最難的部分）

`dp[i][j]` = 把 `word1[0..i-1]` 變成 `word2[0..j-1]` 需要的最少操作數。

### 轉移

如果 `word1[i-1] == word2[j-1]`（最後一個字元相同）：
- 不需要操作：`dp[i][j] = dp[i-1][j-1]`

如果不同，有三種選擇取最小：
- **替換** `word1[i-1]`：`dp[i-1][j-1] + 1`
- **刪除** `word1[i-1]`：`dp[i-1][j] + 1`
- **插入** 一個字元到 `word1`：`dp[i][j-1] + 1`

```cpp
int minDistance(string word1, string word2) {
    int m = word1.size(), n = word2.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1));

    for (int i = 0; i <= m; i++) dp[i][0] = i;  // 刪除 i 個字元
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // 插入 j 個字元

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1[i-1] == word2[j-1])
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = 1 + min({dp[i-1][j-1], dp[i-1][j], dp[i][j-1]});
        }
    }
    return dp[m][n];
}
```

## 遍歷順序的重要性

網格路徑：從左上往右下遍歷，因為 `dp[i][j]` 依賴 `dp[i-1][j]` 和 `dp[i][j-1]`（左方和上方），這兩個在外層迴圈 `i` 從小到大、內層 `j` 從小到大的情況下都已算好。

若 `dp[i][j]` 依賴的方向不同（例如區間 DP 依賴區間長度），遍歷順序就要調整。

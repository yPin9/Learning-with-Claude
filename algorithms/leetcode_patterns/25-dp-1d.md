# Ch 25 — 一維 DP：爬樓梯、House Robber

> 目標：用兩道經典題練習「狀態 → 轉移 → 答案」的完整流程，建立一維 DP 的直覺。

## 題目 1：Climbing Stairs（LeetCode 70）

**題目**：爬 n 階樓梯，每次可以爬 1 或 2 階，有幾種爬法？

### 思維過程

站在第 n 階的前一步，你只可能從：
- 第 n-1 階跨 1 步來
- 第 n-2 階跨 2 步來

所以 `ways(n) = ways(n-1) + ways(n-2)`。

這就是 Fibonacci！

### 四個要素

```
狀態：dp[i] = 爬到第 i 階的方法數
轉移：dp[i] = dp[i-1] + dp[i-2]
Base：dp[1] = 1, dp[2] = 2
答案：dp[n]
```

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    vector<int> dp(n + 1);
    dp[1] = 1; dp[2] = 2;
    for (int i = 3; i <= n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    return dp[n];
}
```

## 題目 2：House Robber（LeetCode 198）

**題目**：一排房子，`nums[i]` 是第 i 間的錢。不能搶相鄰的房子，求最大總金額。

### 思維過程

對第 i 間房子，你有兩個選擇：
1. **搶它**：得到 `nums[i]`，但不能搶 i-1，最多拿 `dp[i-2] + nums[i]`
2. **不搶**：利益是 `dp[i-1]`

取最大值。

### 四個要素

```
狀態：dp[i] = 考慮前 i 間房子，能搶到的最大金額
轉移：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
Base：dp[0] = nums[0], dp[1] = max(nums[0], nums[1])
答案：dp[n-1]
```

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 1) return nums[0];

    vector<int> dp(n);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);

    for (int i = 2; i < n; i++)
        dp[i] = max(dp[i-1], dp[i-2] + nums[i]);

    return dp[n-1];
}
```

## 題目 3：House Robber II（LeetCode 213）

**題目**：房子排成一個圈（第一間和最後一間相鄰），求最大金額。

**關鍵觀察**：第一間和最後一間不能同時搶。所以拆成兩個子問題：
1. 只考慮 `nums[0..n-2]`（不搶最後一間）
2. 只考慮 `nums[1..n-1]`（不搶第一間）

取兩者最大值。

```cpp
int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 1) return nums[0];

    auto robLinear = [](vector<int>& nums, int lo, int hi) {
        int prev2 = 0, prev1 = 0;
        for (int i = lo; i <= hi; i++) {
            int cur = max(prev1, prev2 + nums[i]);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    };

    return max(robLinear(nums, 0, n-2), robLinear(nums, 1, n-1));
}
```

這裡已經用了 O(1) 空間的寫法（`prev1` 和 `prev2` 滾動）。

## 一維 DP 的通用模式

大多數一維 DP 的狀態轉移只依賴前幾個狀態（`dp[i-1]`、`dp[i-2]`），所以空間可以優化到 O(1)。

原則：只需要保留「轉移用到的幾個舊值」。

```cpp
// dp[i] = dp[i-1] + dp[i-2] 的 O(1) 空間版
int prev2 = base0, prev1 = base1;
for (int i = start; i <= end; i++) {
    int cur = prev1 + prev2;  // 或其他轉移
    prev2 = prev1;
    prev1 = cur;
}
return prev1;
```

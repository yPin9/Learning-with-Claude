# Ch 30 — DP 空間優化（滾動陣列）

> 目標：識別哪些 DP 可以壓縮空間，掌握滾動陣列的技巧。

## 為什麼要空間優化？

有些 DP 的空間是 O(N²) 或 O(N×W)，當 N 很大時，記憶體吃不消。

如果 `dp[i][j]` 只依賴「前一行」（`dp[i-1][...]`），就可以把二維壓縮成一維，空間從 O(N²) 降到 O(N)。

**判斷是否能優化的標準**：`dp[i][j]` 的計算只用到 `dp[i-1][...]`，不需要 `dp[i-2][...]` 或更早的行。

## 範例 1：LCS 的空間優化

原本 O(M×N)，壓縮成 O(N)。

```cpp
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    vector<int> dp(n+1, 0);

    for (int i = 1; i <= m; i++) {
        int prev = 0;  // 相當於 dp[i-1][j-1]
        for (int j = 1; j <= n; j++) {
            int temp = dp[j];  // 存下 dp[i-1][j]，下一格需要用
            if (text1[i-1] == text2[j-1])
                dp[j] = prev + 1;
            else
                dp[j] = max(dp[j], dp[j-1]);
            prev = temp;  // prev 更新為原來的 dp[i-1][j]
        }
    }
    return dp[n];
}
```

`prev` 的作用：在覆蓋 `dp[j]` 之前，先把舊值存起來，讓下一格的 `dp[i-1][j-1]` 能正確讀到。

## 範例 2：0/1 背包（Ch 27 已見過）

從右往左遍歷，因為 `dp[j]` 依賴 `dp[j - w[i]]`（左邊），從右往左更新保證左邊的值還是「更新前的」。

```cpp
for (int i = 0; i < n; i++)
    for (int j = W; j >= w[i]; j--)  // 從右往左
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);
```

## 範例 3：費波那契類問題（只需兩個變數）

當 `dp[i]` 只依賴 `dp[i-1]` 和 `dp[i-2]`，甚至不需要一維陣列，只要兩個變數。

```cpp
// House Robber 的 O(1) 空間版
int rob(vector<int>& nums) {
    int prev2 = 0, prev1 = 0;
    for (int x : nums) {
        int cur = max(prev1, prev2 + x);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

## 空間優化的通用思路

1. **確認依賴關係**：`dp[i][j]` 用到哪些格子？
   - 只用上一行 → 可壓縮成一維
   - 只用前兩格 → 可壓縮成兩個變數

2. **確認遍歷方向**：
   - 若依賴左邊（`dp[i][j-1]`）→ 從左往右（已更新的值就是「新一行的值」）
   - 若依賴左邊且要保留舊值（`dp[i-1][j-1]`）→ 需要 `prev` 變數暫存
   - 若不能讓左邊被覆蓋（0/1 背包）→ 從右往左

3. **邊界條件不變**：只是少了一個維度，base case 的邏輯不變。

## 何時不能空間優化？

- 區間 DP：`dp[i][j]` 依賴 `dp[i][k]` 和 `dp[k+1][j]`，同一行的不同格子互相依賴，無法壓縮
- 需要回溯路徑：如果要找出具體的最優方案（不只是最優值），必須保留完整的 dp 表

## 實戰建議

面試中：先寫二維版本確保正確，再口頭說「這可以優化到 O(N) 空間，方法是...」。

不要一開始就寫空間優化版，容易出錯，且面試官想先看你的思路是否正確。

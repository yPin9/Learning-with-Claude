# Ch 11 — 產業生命週期：四階段各看什麼

> 同樣一個產業，在它 1 歲、10 歲、50 歲、100 歲時，該問的問題完全不同。用「成熟期」的工具分析新興產業，會讓你錯過所有機會；用「成長期」的工具分析成熟產業，會讓你付天價買不值得的東西。這一章把產業的四個階段講清楚。

## 產業生命週期：四個階段

一個產業從誕生到消失，會經歷四個階段：

```
營收成長
    ↑
    │           ┌──────────────┐
    │          ╱                ╲
    │         ╱                  ╲
    │        ╱                    ╲
    │       ╱                      ╲
    │      ╱                        ╲___
    │     ╱                             ╲___
    │    ╱                                  ╲___
    │───╱────────────────────────────────────────
         早期      成長期         成熟期        衰退期
       (Emerging) (Growth)     (Mature)    (Declining)
         時間 →
```

這四階段的時間尺度可能很不同 — 某些產業 5 年就走完（科技類），某些產業 100 年才走一次（工業類）。

## 階段一：早期（Emerging）

### 特徵

- **產品形式還在變**：沒有公認的「標準產品」
- **玩家眾多**：幾十家甚至上百家新創競爭
- **技術還在迭代**：新技術不斷冒出
- **商業模式未確定**：大家在摸索怎麼賺錢
- **多數公司虧損**：還在燒錢搶市場
- **營收成長率高但基數小**：100% / 200% 的年成長率是常態
- **總市場規模不清楚**：大家爭論這個市場有多大

### 歷史範例

- **1990s 末的網路搜尋**：Yahoo、Lycos、AltaVista、Ask Jeeves、Google……十幾家搜尋引擎競爭
- **2010s 初的電動車**：幾百家電動車新創冒出，絕大多數消失
- **2015–2020 的 SaaS 工具**：無數垂直 SaaS 新創（銷售、HR、工程、財務每個子類都有數十家）
- **2022– 的生成式 AI 應用**：目前狀態

### 早期階段該問的問題

這階段**不能用傳統產業分析框架**（Porter 五力意義有限）。該問：

1. **這個產業的「標準產品」會是什麼？**
   - 搜尋引擎最後變成「有演算法 + 廣告模式」的那一種（Google 勝出）
   - 電動車目前主流是「鋰電池 + 直接銷售」模式
   - 雲端最後變成「IaaS + PaaS + SaaS」的分層

2. **勝出的商業模式會是什麼？**
   - 搜尋：廣告
   - SaaS：訂閱
   - 電動車：硬體 + 軟體訂閱（Tesla 模式）or 純硬體？未定

3. **「規模」的意義是什麼？**
   - 多少用戶是門檻？
   - 網絡效應何時會啟動？

4. **誰可能勝出？**
   - 通常不是最早的玩家
   - 是那些能**解決產品標準化 + 商業化的玩家**

### 早期階段的投資策略

**誠實地說**：早期階段很難賺錢（作為外部投資人）。

- **高風險**：大多數新創會死
- **估值扭曲**：市場給整個類別炒高，所有玩家的估值都離譜
- **資訊不足**：你很難判斷哪家會贏

**兩種比較可行的策略**：

**A. Pick-and-Shovel（賣鏟子）**：

- 淘金熱時，賣牛仔褲和鏟子的人（Levi's 的起源）比淘金者賺得多
- 早期 AI 熱潮：**不要猜哪家 AI 應用會勝出**，買 NVIDIA（賣 GPU 給所有人）
- 早期電動車：**不要猜哪家車廠會贏**，買台達電（賣充電模組給所有人）、寧德時代（賣電池給所有人）
- 這種策略叫「賣鏟子」

**B. 等成長期**：

- 等到產業「勝出者」開始浮現（市場份額初步穩定、標準產品出現），再進場
- 代價：錯過最早期爆發性的漲幅
- 好處：大幅降低「買到歸零股」的風險

多數散戶投資者該用 B 策略。

## 階段二：成長期（Growth）

### 特徵

- **產品已經標準化**：主流形式浮現
- **玩家數量開始下降**：弱者陣亡、強者整合
- **市佔率初步定型**：但仍有波動
- **營收成長率仍高**（20–40% 年成長）
- **獲利能力浮現**：領先者開始賺錢
- **總市場規模明確**：大家對 TAM 有共識

### 歷史範例

- **2005–2015 的 SaaS**：Salesforce 帶頭、HubSpot、ServiceNow 等陸續浮現
- **2015–2020 的雲端**：AWS 遙遙領先、Azure 快速追趕、GCP 專注特定領域
- **2010–2018 的手機 OS**：iOS + Android 雙霸，其他消失
- **2020–2024 的電動車（北美/歐洲）**：Tesla 明確領先、傳統車廠轉型中

### 成長期該問的問題

1. **滲透率在哪？** 離終極狀態還有多遠？
   - 滲透率 < 20%：還有很多成長
   - 滲透率 20–50%：加速期
   - 滲透率 50% +：減速期（接近成熟）

2. **勝出者開始定型了嗎？** 前三名市佔合起來 > 50% 嗎？
   - 是：競爭將趨理性
   - 否：還會有廝殺

3. **誰會成為下一輪的輸家？**
   - 技術落後的公司
   - 資本不足的公司
   - 商業模式有缺陷的公司

### 成長期的投資策略

**這是長期投資者的黃金區域**。

理由：

- 風險比早期低（勝出者輪廓清楚）
- 估值仍有上漲空間（市場還在消化成長故事）
- 複利效應最強（基本面成長 + 估值擴張）

**典型做法**：

- 挑領先者：通常前兩名佔產業報酬的 70% +
- 注意 **二次曲線**：早期領先不等於最後贏家（MySpace 輸給 Facebook、Yahoo 輸給 Google、Nokia 輸給 Apple）
- 看**單位經濟學**：一個客戶獲取花多少錢、留存多少年、產生多少利潤？

## 階段三：成熟期（Mature）

### 特徵

- **營收成長率放緩**（個位數或跟 GDP 一致）
- **市佔率高度集中**：前三名可能佔 70–90%
- **新進入者極少**：進入障礙已建立
- **獲利能力強而穩定**：毛利率、ROIC 都在高位穩定
- **配息、回購盛行**：公司賺的錢沒地方大規模再投資
- **管理層重視效率**：每個百分點的毛利率都計較

### 歷史範例

- **碳酸飲料**：可口可樂 + 百事佔全球 70% + 超過 50 年
- **信用卡網絡**：Visa + Mastercard 佔 90%
- **菸草（在多數先進國家）**：大型玩家穩定
- **啤酒（全球）**：AB InBev、Heineken、Carlsberg 主導
- **美國鐵路**：Union Pacific + BNSF + CSX + Norfolk Southern + Canadian Pacific 五家分西/東
- **大型百貨超市（美國）**：Costco、Walmart、Kroger、Target

### 成熟期該問的問題

1. **護城河有沒有被挑戰？**
   - 替代品（新技術、新商模）
   - 消費行為改變
   - 監管變動

2. **公司的資本配置合理嗎？**
   - 賺的錢用在哪：發股利？回購？亂投新業務（通常不好）？
   - ROIC 高的業務有在擴張嗎？

3. **估值合理嗎？**
   - 成熟期的公司是**最容易估值的** — 現金流可預測
   - 要用穩健的估值方法（DCF、配息模型）

### 成熟期的投資策略

**這是價值投資者的主場**。

巴菲特的經典投資（Coca-Cola、American Express、Apple 在 2016 年買的時候）都是成熟期公司。

典型做法：

- **選最強的幾家**
- **用合理（或低估）的估值進場**
- **長期持有**，享受配息與回購
- **注意結構性威脅**（替代品、顛覆）

**警告**：成熟期不等於「安全」。很多產業看似成熟，但其實正在被顛覆（見階段四）。

## 階段四：衰退期（Declining）

### 特徵

- **營收開始下降**（可能是絕對值下降或持續低於 GDP）
- **玩家退出或整併**：活不下去的關門，剩下的合併求生
- **獲利壓縮**：定價權被侵蝕、成本難控制
- **資本退出**：沒人願意新投資這個產業
- **管理層選擇**：轉型、清算、還是「收割」殘值

### 歷史範例

- **固網電話**：美國過去 30 年使用人數減半
- **紙本報紙**：美國訂戶 2000s 起快速下跌
- **傳統百貨**：Sears、JCPenney、Macy's 持續困境
- **錄影帶 / DVD 租賃**：Blockbuster 破產（2010）
- **桌上型 PC**：2008 達頂峰後緩慢下降
- **汽柴油車（部分國家）**：正在進入衰退期的前期

### 衰退期該問的問題

1. **衰退是短期（循環）還是結構性？**
   - 短期衰退：景氣循環（鋼鐵、航運）
   - 結構性衰退：被新技術/新行為永久取代（報紙、DVD）

2. **衰退的速度？**
   - 快速衰退（DVD）：不要碰
   - 緩慢衰退（菸草）：現金流其實很強大，但要抓對時間

3. **「收割」階段的機會**：
   - 一些成熟期轉衰退期的產業，有「收割者」策略的空間
   - 買低估值、拿高股息、等產業慢慢萎縮
   - 但要小心「價值陷阱」

### 衰退期的投資策略

**大多數衰退期產業該避開**。但少數有機會：

**A. 緩慢衰退 + 強現金流 = 高股息股**

典型：菸草公司（Altria、British American Tobacco）、一些公共事業

- 需求緩慢萎縮
- 但品牌強，定價權還在
- 公司把賺的錢大量發股利與回購
- 高 dividend yield 吸引收入型投資者

**B. 整併機會**

衰退中的產業，剩下的玩家可能併購、降低競爭 → 整併後獲利反而上升

**C. 最後的贏家**

有時衰退中的產業，最後的 1–2 個玩家能維持相對不錯的狀態（例如剩下的百貨公司）

## 跨階段比較：分析重點的差異

| 階段 | 最重要的問題 | 工具 |
|---|---|---|
| 早期 | 產品標準化、商業模式 | 情境分析、技術評估 |
| 成長期 | 滲透率、勝出者輪廓 | Cohort 分析、單位經濟學 |
| 成熟期 | 護城河、資本配置 | Porter 五力、DCF、競爭優勢分析 |
| 衰退期 | 衰退速度、現金流、整併機會 | 配息模型、清算價值分析 |

**用錯工具的代價**：

- 用「滲透率」分析成熟期產業（都滲透完了）→ 看不出機會
- 用「護城河」分析早期產業（還沒建立）→ 什麼都看不到
- 用「配息模型」分析成長期產業（還在燒錢）→ 錯過成長

## 一個重要的混淆：產業階段 vs 公司階段

公司和它所在的產業，可能處於**不同階段**。

**例**：

- **台積電**在一個**成長期產業**（晶圓代工）裡，自己是**成熟期公司**（市佔穩定、獲利穩健）
- **Tesla**在一個**成長期產業**（電動車）裡，是**成長期公司**（還在擴產能、擴市場）
- **IBM**在一個**成熟期產業**（企業 IT）裡，可能是**衰退期公司**（市佔流失給雲端、大型機業務萎縮）
- **一個新的 SaaS 新創**在一個**成熟期產業**（企業軟體）裡，是**早期公司**

**分析時要兩層都看**：

- 產業階段告訴你**天花板**在哪
- 公司階段告訴你**它現在在做什麼**

## 判斷產業當前階段的實用方法

不用做複雜分析，三個指標通常夠：

### 指標一：營收年成長率的長期趨勢

- > 30% 長期：早期或早成長期
- 15–30%：成長期
- 5–15%：成長中後期
- 0–5%：成熟期
- 負成長：衰退期

### 指標二：前三大市佔率（CR-3）

- < 20%：分散，可能早期
- 20–50%：成長期，整併中
- > 50%：成熟期寡佔
- 持續上升：在集中化
- 持續下降：可能被新玩家顛覆

### 指標三：產業內的活動類型

- 大量新創進入：早期
- IPO 浪潮：成長期
- 併購浪潮：成長後期 / 成熟前期
- 回購 + 配息：成熟期
- 關廠、破產重整：衰退期

## 一個隱藏的挑戰：生命週期會被打斷

不是所有產業都會循規蹈矩地走完四個階段。**科技變化會打斷週期**。

**例**：

- **傳統百貨產業**從成熟期被電商直接跳到衰退期（沒有「整併維穩」的機會）
- **傳統汽車產業**（內燃機）正從成熟期被電動車推向衰退期
- **傳統電視**被 OTT 串流跳越一個階段

所以做產業分析時不能只看當前階段，**要問：有沒有科技/政策變化正在把這個產業推到下一個（或提前跳到衰退期）？**

# Ch 3 — 財報速讀：三表的心智模型

> 財報是公司的體檢報告。看得懂，你能知道一家公司健不健康、賺不賺錢、會不會倒。看不懂，你做投資決策就是閉著眼睛走路。這一章把三大財報的心智模型建立起來 — 不追求會計精確度，追求**你知道每個數字在問什麼問題**。

## 為什麼是三張表

上市公司必須公布三張財務報表：

1. **損益表**（Income Statement / P&L）：**這段時間賺了多少錢？**
2. **資產負債表**（Balance Sheet）：**現在家底有多少？欠了多少？**
3. **現金流量表**（Cash Flow Statement）：**這段時間現金的進出如何？**

三張表看三個不同的問題。**三張都要看**，因為它們互相補充、互相驗證。

有的新手只看損益表（看淨利、EPS）就下判斷。這是危險的 — 因為損益表的「淨利」可以用會計手法美化。你必須三表一起看，才能交叉驗證公司真實的財務狀況。

## 表一：損益表（Income Statement）

### 它回答什麼問題

「這個月／這一季／這一年，公司賺了多少錢？」

### 基本結構

一份典型的損益表長這樣（簡化版）：

```
          營業收入 (Revenue)                  1,000
   減：   銷貨成本 (Cost of Goods Sold, COGS)  -600
   =      毛利 (Gross Profit)                   400      毛利率 = 40%
   減：   營業費用 (Operating Expenses)        -200
           - 銷售費用
           - 管理費用
           - 研發費用 (R&D)
   =      營業利益 (Operating Income / EBIT)    200      營業利益率 = 20%
   減：   利息費用 (Interest Expense)           -20
   減：   稅金 (Tax)                             -40
   =      淨利 (Net Income)                     140      淨利率 = 14%

   ÷ 股數 (Shares Outstanding, 10,000)
   =      每股盈餘 (EPS)                        0.014
```

### 每一層在說什麼

**營業收入**（Revenue / Sales / Top Line）
公司這段時間**賣了多少東西**。不是賺到多少，是賣到多少。台積電一年賣 2.16 兆新台幣的晶圓，就是它的營業收入。

**銷貨成本**（COGS）
生產那些賣出的東西**直接花了多少錢**。台積電的 COGS 就是晶圓廠的折舊、晶圓原料、廠房電費、作業員薪水等。

**毛利 / 毛利率**（Gross Profit / Margin）
毛利 = 營業收入 - 銷貨成本
毛利率 = 毛利 / 營業收入 = 40%

這是最能看出**一家公司定價權與生產效率**的數字。

台積電的毛利率約 53%，Apple 的毛利率約 45%，沃爾瑪（Walmart）的毛利率約 25%，航空公司毛利率可能只有 10% 甚至更低。

**為什麼差這麼多？** 因為不同產業的定價權不同。Ch 15 會專門談。

**營業費用**
跟生產沒直接關係但跟營運有關的費用：

- **銷售費用**（Sales & Marketing）：廣告、業務員薪水
- **管理費用**（G&A, General & Administrative）：CEO、財務、HR 薪水、辦公室租金
- **研發費用**（R&D）：做新產品的錢

**營業利益 / 營業利益率**（Operating Income / Margin）
營業利益 = 毛利 - 營業費用

這是**公司主業真正的獲利能力**。還沒算利息、稅金。

**淨利**（Net Income / Bottom Line）
扣掉利息與稅金後**最終歸屬股東的錢**。

**EPS（Earnings Per Share，每股盈餘）**
淨利 ÷ 流通股數。這是股東最直接關心的數字 — 你那一股賺了多少錢。

### 關鍵觀察點：毛利率、營業利益率、淨利率

這三個「率」比絕對金額更重要：

- **毛利率**：產品本身的定價能力
- **營業利益率**：主業的整體效率
- **淨利率**：最終股東能拿到多少

**看一家公司的三個率過去 5–10 年的趨勢**，比看任何單一季度的數字有用得多。

- 三個率穩定或上升 → 生意穩健
- 三個率下降 → 可能面臨競爭加劇、成本上升、或產品定價力流失

### 損益表的一個常見陷阱：非現金項目

損益表中有些費用**不代表真的有錢流出**。最典型的是：

**折舊（Depreciation）與攤銷（Amortization）**

一家半導體公司買了一台 10 億的機台。這 10 億不會一次性在損益表上變成費用。會計上會把這台機台的成本**分 10 年攤**，每年「折舊」1 億。

這 1 億是在損益表的 COGS 或營業費用裡扣的，它會讓淨利變少，**但這一年並沒有真的有 1 億現金流出**。錢在很多年前買機台時就付了。

這就是為什麼你光看「淨利」不夠 — 你要看**實際現金流**。這就要用到第三張表（現金流量表）。

## 表二：資產負債表（Balance Sheet）

### 它回答什麼問題

「這一刻，公司**擁有什麼**、**欠什麼**、**股東的淨資產是多少**？」

損益表是「一段時間的錄影」；資產負債表是「某一刻的快照」。

### 基本結構

資產負債表有一個核心公式：

```
資產 (Assets) = 負債 (Liabilities) + 股東權益 (Equity)
```

這叫「會計恆等式」— 永遠成立。一家公司擁有的所有東西（資產），要嘛是借來的（負債），要嘛是股東自己的錢和累積盈餘（股東權益）。

展開看：

```
資產 (Assets)                        負債與股東權益
─────────────────                    ─────────────────
流動資產                              流動負債
 - 現金                                - 應付帳款
 - 應收帳款                            - 短期借款
 - 存貨                                - 應付薪資
 - 其他                               非流動負債
非流動資產                             - 長期借款 (bonds)
 - 廠房、設備                          - 租賃負債
 - 無形資產（商譽、商標等）            股東權益
 - 長期投資                            - 股本
                                      - 保留盈餘 (retained earnings)
─────────────────                    ─────────────────
資產總計                              負債與股東權益總計
（兩側金額永遠相等）
```

### 左邊：資產（公司擁有的東西）

資產分兩類：

**流動資產（Current Assets）**：**一年內可以變現**的資產。

- **現金與約當現金**（Cash & Cash Equivalents）：最值錢、最安全的東西。
- **應收帳款**（Accounts Receivable）：客戶欠公司的錢（已經出貨但還沒收到錢）。
- **存貨**（Inventory）：未賣出的產品或原料。
- **其他**：預付費用、短期投資等。

**非流動資產（Non-Current Assets）**：**長期使用**的資產。

- **廠房與設備**（Property, Plant, and Equipment，PP&E）：工廠、機器、辦公室。台積電的大部分資產就是這個。
- **無形資產**（Intangibles）：專利、商標、版權等。
- **商譽**（Goodwill）：併購時付出超過目標公司淨資產的溢價。這是個會計概念，Ch 21 會再談。
- **長期投資**：持有其他公司的股份（不足以控制的）。

### 右邊上半：負債（公司欠的東西）

**流動負債（Current Liabilities）**：**一年內要還**的債。

- **應付帳款**（Accounts Payable）：欠供應商的錢。
- **短期借款**（Short-term Debt）：一年內到期的銀行貸款。
- **應付員工薪資、稅金** 等。

**非流動負債（Non-Current Liabilities）**：**一年後才要還**的債。

- **長期借款**（Long-term Debt）：銀行貸款、發行的公司債（bonds）。
- **長期租賃負債**：租 10 年的辦公室契約承諾。

### 右邊下半：股東權益（Equity）

這是股東的**帳面擁有權**。

- **股本**（Share Capital）：股東出資買入公司股票的錢。
- **保留盈餘**（Retained Earnings）：**歷年**賺的錢中**沒有以股利發給股東**、而是留在公司裡的。

保留盈餘是股東權益累積的主要來源。一家公司賺 100 億，發 30 億股利，70 億就進保留盈餘。

### 關鍵觀察點

**資產負債率（債務 / 資產）或 負債權益比（D/E）**

看公司**依賴借錢多不多**。

- 低（D/E < 0.5）：財務穩健，但可能資本效率沒充分發揮
- 中（0.5–1）：典型上市公司
- 高（D/E > 2）：槓桿大，危險性高（尤其景氣下行時）

**流動比率（流動資產 / 流動負債）**

看公司**短期償債能力**。健康公司通常 > 1.5。低於 1 代表公司短期內現金可能不夠支付到期債務。

**股東權益的趨勢**

股東權益逐年成長 = 公司在累積價值。這是投資人最想看到的長期趨勢。

### 資產負債表的一個常見陷阱：商譽

當 A 公司花 100 億併購 B 公司（B 公司帳面淨資產只有 60 億），多付的 40 億會以「商譽」（Goodwill）的形式計入 A 公司資產負債表。

商譽是**最容易欺騙人的資產**。它實際上不代表任何有形的東西，只代表「我多付了錢」。

如果之後 B 公司的生意變差，A 公司可能被迫做「商譽減損」（Goodwill Impairment）— 把商譽從資產負債表刪除，損益表計為一次性巨額虧損。

看一家公司的資產負債表時，**「無形資產 + 商譽佔總資產比例」如果超過 30%**，要特別警覺。這代表公司歷史上做過大型併購，而且可能還沒被檢驗。

## 表三：現金流量表（Cash Flow Statement）

### 它回答什麼問題

「這段時間**實際上有多少現金**流進流出公司？」

**這是三表中最重要的一張**。因為它**最不容易被會計手法做假**。

記住一句話：**Revenue is vanity（收入是虛榮），profit is sanity（利潤是理性），cash is king（現金才是王道）**。

### 基本結構

現金流量表分三塊：

```
營業活動現金流 (Operating Cash Flow, OCF)          +300
投資活動現金流 (Investing Cash Flow)                -200
融資活動現金流 (Financing Cash Flow)                -50
────────────────────
淨現金變動                                           +50
期初現金                                            1,000
期末現金                                            1,050
```

### 營業活動現金流（Operating Cash Flow, OCF）

**公司從主業賺到（或流出）的現金**。

計算方式（間接法）是從淨利開始調整：

```
淨利                                +140
+ 折舊與攤銷（非現金費用加回）        +100
+/- 營運資金變動
     - 應收帳款增加（客戶沒付錢）    -30
     + 應付帳款增加（延後付供應商）  +20
     - 存貨增加                      -10
+/- 其他調整                          +80
=  營業活動現金流                    +300
```

為什麼淨利 140 會變成 OCF 300？

**折舊 +100**：折舊是損益表的非現金費用 — 扣了淨利但沒流出現金。所以計算現金流時要加回來。

**應收帳款增加 -30**：你賣了東西計入營收，但客戶還沒付錢。帳上多賺 30 但現金沒進。現金流要扣掉。

這就是為什麼 OCF 與淨利常常不一樣 — **OCF 反映真實的現金進出**。

### 投資活動現金流（Investing Cash Flow）

**買/賣長期資產的現金進出**。

主要項目：

- **資本支出**（Capital Expenditure，CapEx）：買廠房、買機器、建設新廠的現金流出。這是負的。
- 出售舊資產（賣舊廠房、賣設備）的現金流入。
- 買賣其他公司股權。

**CapEx 是關鍵**。一家高 CapEx 的公司（如台積電）要持續投入資本維持競爭力。
一家低 CapEx 的公司（如 Microsoft 的 SaaS 業務）不用太多實體投資。

**自由現金流**（Free Cash Flow，FCF）的定義：

```
FCF = OCF - CapEx
```

這是投資分析的聖杯之一。它代表**公司真正可以自由運用的錢** — 可以發股利、可以回購股票、可以併購、可以還債。

### 融資活動現金流（Financing Cash Flow）

**跟股東與債權人往來的現金**。

主要項目：

- 借錢（+）、還債（-）
- 發新股（+）、回購股票（-）
- 發放股利（-）

### 三個現金流組合告訴你公司在做什麼階段

觀察三個現金流的正負組合，可以快速看出公司在什麼階段：

| OCF | Investing | Financing | 階段 | 例子 |
|---|---|---|---|---|
| + | - | - | **成熟穩健** | 成熟期的 Apple、Coca-Cola：主業賺錢、繼續投資、還股東 |
| + | - | + | **成長期** | 成長期公司：主業賺錢、投資更多、對外融資 |
| - | - | + | **早期虧損** | 新創：主業還在燒錢、投資建設、靠融資 |
| + | + | - | **衰退期收割** | 衰退產業：主業還有錢、變賣資產、還債 |
| - | + | + | **財務危機** | 變賣資產、借更多錢維持 |

這個檢查只花 30 秒，但能快速讀出一家公司的狀態。

### 現金流量表的最重要一件事：檢查 OCF 跟淨利的關係

健康的公司，**OCF ≈ 淨利 或 OCF > 淨利**（因為 OCF 要加回折舊）。

**警訊**：

- **淨利一直正，但 OCF 很小或為負**：公司「帳面賺錢」但沒收到現金。可能是客戶不付錢（應收帳款爆炸），或是會計手法把費用延後認列（典型會計舞弊）。
- **長年 OCF 為負，靠融資維持**：公司的主業根本不賺錢，靠外部錢撐。早期新創可以接受，但如果是一家「成熟」公司還這樣，要遠離。

## 三表的關聯：一個直覺圖

這三張表不是獨立的，它們互相流動：

```
損益表：這一年賺了 140 (淨利)
    │
    ↓（140 扣股利 30，保留 110）
保留盈餘 +110 → 資產負債表的股東權益
    │
    ↓（實際現金流入）
現金流量表：OCF 300，CapEx 200，淨增加 100
    │
    ↓
資產負債表的現金 +100
```

這是為什麼三表必須一起看：

- 如果淨利很高但 OCF 很低 → 會計手法有問題
- 如果 OCF 很高但保留盈餘沒增加 → 可能大量發股利或回購
- 如果總資產大幅上升但股東權益沒動 → 公司在借錢擴張

## 新手看財報的順序建議

第一次看一家公司的財報，不要一行一行讀。先抓幾個關鍵數字：

### 5 分鐘快速掃描

1. **營收** 過去 5 年的趨勢（成長、停滯、下滑？）
2. **毛利率** 過去 5 年的穩定度
3. **營業利益率** 過去 5 年的穩定度
4. **OCF** 是否穩定為正、是否成長
5. **FCF**（OCF - CapEx）是否穩定為正
6. **負債** 佔總資產比率
7. **保留盈餘** 是否逐年成長

這七個數字看完，你對這家公司的基本健康狀況已經有 70% 的把握。

### 要去哪看

- 美股：公司的 10-K（Item 8 是 Financial Statements）、或 macrotrends.net、stockanalysis.com
- 台股：公開資訊觀測站的「財務報告書」、Goodinfo
- 最快的方法：用 Google 搜 「公司名 10-K」或 「公司名 年報」

## 一個重要的警告：會計 ≠ 真實

這一章給你的是會計的心智模型。但要記住：**會計是一種紀錄方式，不是真實本身**。

- 同樣的經濟活動，不同的會計選擇會產生不同的帳面數字。
- 美國 GAAP 與國際 IFRS 有差異。
- 公司有很大空間做「激進」或「保守」的會計選擇。
- 極端的公司會故意做假（Enron、WorldCom、WireCard）。

看財報時要一直問：**這個數字代表的真實經濟活動是什麼？如果我不用會計術語，怎麼用白話描述這家公司的狀況？**

保持這個懷疑，你不會被會計數字騙。

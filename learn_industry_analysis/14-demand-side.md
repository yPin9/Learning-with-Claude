# Ch 14 — 需求面：終端驅動、彈性、週期性

> 供給告訴你「產業能產多少」，需求告訴你「市場會吸收多少」。把兩者對上，你才能判斷一個產業會不會賺錢。這一章教你拆需求：**誰在買、為什麼買、這個買的行為會怎麼變**。

## 需求分析的三個基本問題

分析一個產業的需求面時，你要問：

1. **誰是終端需求者**？
2. **需求是什麼驅動的**？（結構性、循環性、一次性）
3. **需求對哪些變數有彈性**？（價格、所得、利率、人口……）

這三題答對，你對這個產業的需求端就有扎實的理解。

## 追蹤到終端需求

### 核心觀念：每個產業都服務另一個需求

B2B 產業特別要注意：**你的客戶不是你的終端需求**。

**例：半導體設備（ASML）**

- ASML 賣光刻機給台積電
- 台積電把晶圓賣給 Apple、NVIDIA、AMD 等
- Apple 把 iPhone 賣給**消費者**
- NVIDIA 把 GPU 賣給**雲端業者 + 消費者**
- 雲端業者把**雲端服務**賣給**企業**（最終還是人類需求）

所以分析 ASML 時，你光看「台積電 Capex 會不會擴張」不夠。**真正的終端需求是「人類對智慧手機、AI 運算、雲端服務」的需求**。

如果那些需求變差，最終會穿透好幾層價值鏈影響到 ASML。

**這叫「追蹤到終端需求」** — 產業鏈分析的必做動作。

### 實例：追蹤到終端需求

**航運（貨櫃）**：

- 航運公司賺錢 ← 貨櫃運量 ← 全球貿易 ← 全球消費 + 全球製造

要分析航運，你不能只看貨運量，要看**全球消費與製造**的大趨勢。2022 年航運費率從高點崩 80%，本質原因是全球消費（尤其美國）從疫情高峰回落。

**商用房地產（辦公大樓）**：

- REIT 的租金 ← 辦公室出租率 ← 企業辦公需求 ← 白領就業 + 遠距工作比例

遠距工作這個**結構性變化**讓美國辦公大樓 REIT 過去 4 年股價跌 50% — 不是因為經濟衰退，是因為**終端需求改變**。

**化工（石化產品）**：

- 石化公司賺錢 ← 乙烯、丙烯、PX 等中間品價格 ← 下游塑膠、紡織、汽車、建材需求

要分析石化要知道下游的產業景氣。

### 追蹤到終端需求的技巧

問自己：

- 我賣東西給誰？→ **客戶 A**
- 客戶 A 賣東西給誰？→ **客戶 B**
- 一直問，直到看見**人類的最終消費** 或 **企業資本支出**（這是兩種最終的經濟終點）
- 問「終端需求的大趨勢是什麼」？

## 需求的三種型態

### 型態一：結構性需求（Structural Demand）

**長期、非循環、被某個大趨勢推動**。

例：

- **老齡化**：醫療、長照、製藥 — 只會越來越多
- **數位化**：雲端、SaaS、半導體 — 長期滲透率上升
- **電動化**：電動車、電池、充電 — 滲透率從 5% 往 50%+ 走
- **能源轉型**：再生能源、儲能 — 政策長期推動
- **新興市場消費升級**：品牌消費品在中國、印度、東南亞

結構性需求**最有投資價值**，因為它不依賴景氣循環。

### 型態二：循環性需求（Cyclical Demand）

**跟景氣循環綁在一起**。好時很好、差時很差。

例：

- **房地產 / 建材**：跟利率、所得、信心綁定
- **汽車（傳統）**：耐久財，景氣不好大家延後買車
- **工業設備**：企業 CapEx 是循環性的
- **餐飲連鎖**：跟 discretionary spending 綁定
- **航運 / 航空**：跟全球貿易與旅遊循環

循環性產業**在低點買、在高點賣**是標準劇本。但要小心 — 週期不會永遠按預期走，而且低點時常讓人恐懼到不敢買。

### 型態三：防禦性需求（Defensive Demand）

**不太受景氣影響的民生必需品**。

例：

- **食品飲料**：不管景氣多差，大家還是要吃喝
- **水電瓦斯**：剛性需求
- **必要性醫療**：生病就是要看病
- **菸草酒精**：上癮性產品需求穩定

防禦性產業的**報酬不會太爆發**，但**下跌也有限**。經濟衰退時是避風港。

### 三種型態的認識對投資很重要

- 景氣擴張期：循環性產業機會最大
- 景氣衰退前：防禦性產業避險
- 長期配置：結構性產業為主力

大多數散戶在**景氣最好的時候買循環股**（買在高點）、在**景氣最差的時候買防禦股**（買在高估值）。反其道而行才對。

## 需求的彈性（Elasticity）

彈性告訴你**當某個變數變 1%，需求變幾 %**。

### 主要的彈性類型

**價格彈性**（Price Elasticity）：當價格變 1%，需求變幾 %？

- 彈性 > 1：高彈性（漲價傷需求大，奢侈品除外）
- 彈性 = 1：單位彈性
- 彈性 < 1：低彈性（漲價也不太影響需求）

**所得彈性**（Income Elasticity）：當所得變 1%，需求變幾 %？

- > 1：奢侈品（所得上升時需求更快上升）
- 0 < x < 1：正常品
- < 0：劣等品（所得上升時需求下降 — 例如廉價泡麵）

**交叉彈性**（Cross Elasticity）：A 產品價格變 1%，B 產品需求變幾 %？

- > 0：替代品
- < 0：互補品

### 為什麼彈性對產業分析重要

彈性告訴你**需求的穩定性**：

- **低價格彈性**：產業可以漲價 → 定價權 → 好產業
  - 例：藥品、菸草、高端奢侈品
- **高價格彈性**：漲價就流失客戶 → 難漲價 → 不好產業
  - 例：消費電子、大宗商品

- **高所得彈性**：景氣好時爆發、景氣差時崩
  - 例：奢侈品、高端餐飲、娛樂
- **低所得彈性**：景氣影響小
  - 例：食品、電力、基本醫療

### 實例：疫情對不同產業的衝擊

2020 年新冠爆發，所得同時下降、消費模式突變：

**需求崩盤**（高所得彈性、被疫情直接衝擊）：
- 航空、郵輪、餐飲、零售服飾、線下娛樂
- 典型股票：Marriott、Carnival、Gap、AMC

**需求暴增**（低彈性 + 疫情加速）：
- 食品超市、家用品、遠距辦公軟體、娛樂串流、遊戲
- 典型股票：Costco、Clorox、Zoom、Netflix、Nintendo

**需求中性**（低彈性）：
- 公用事業、電信、菸草、必要性醫療

**這個例子顯示彈性分析的威力**。你理解產業的彈性結構，就能在任何衝擊事件下**大致預測誰會贏、誰會輸**。

## 循環性產業的分析

循環性產業是投資人的愛恨交織區域 — 賺大錢與賠大錢都可能。

### 循環的典型型態

```
需求
   ↑
   │    ┌─┐                ┌─┐
   │   ╱   ╲              ╱   ╲
   │  ╱     ╲            ╱     ╲
   │ ╱       ╲          ╱       ╲
   │╱         ╲________╱         ╲
   │           (低點)             
   └─────────────────────────────>  時間
      擴張   高峰   衰退   谷底   擴張
```

### 循環性產業的共同特徵

- **需求波動大**：景氣好時需求可能翻倍，景氣差時腰斬
- **供給僵固**：產能很難快速調整
- **價格敏感度高**：供需略失衡 → 價格劇烈變動
- **利潤放大**：需求小變，獲利大變

### 投資循環性產業的關鍵心法

**1. 忘記當前的 PE**

循環性產業在**高峰期**的 PE 看起來超低（例如 5 倍），但那是因為盈餘處在循環頂點。下一年盈餘可能腰斬。

**真正該看的是「循環平均盈餘」** — 過去一整個循環的平均盈餘是多少。

**2. 在悲觀時進場**

循環性產業的 PE、PB 在**谷底**時看起來超高（因為盈餘被壓縮）。但這是最好的買點。反之景氣頂點 PE 低反而是最差買點。

這叫「**inverse valuation**」— 循環性產業的估值邏輯跟成長股相反。

**3. 看實體指標**

循環性產業的實體指標（利用率、訂單、出貨、庫存）比財務指標敏感。財務指標滯後。

### 經典的循環性產業 + 關鍵指標

| 產業 | 關鍵實體指標 |
|---|---|
| 半導體記憶體 | DRAM spot price、Mws、庫存週數 |
| 鋼鐵 | 熱軋捲價、鐵礦石價、利用率 |
| 航運（貨櫃） | SCFI 運價指數、船隊數量 |
| 航空 | 客運 / 貨運量、載客率 |
| 化工（MEG、PX） | 價格、利差 |
| 石油 | 原油價、OPEC+ 產量 |

### 循環的不對稱

**下跌往往快於上升**。

需求突然下降時，產業馬上反應（價格跳水、訂單砍單、裁員、關廠）。
需求恢復時，供給已經被砍掉，恢復需要時間。

所以**好的循環性投資機會常在「大家還覺得慘」的時刻出現**。這時供給已經被砍到位，只要需求恢復一點，價格會迅速反彈。

## 需求分析的實用框架

做一個產業的需求分析，三步走：

### 第一步：界定終端需求

一層一層往下游問，直到看到「人的最終消費」或「企業的 CapEx 決策」。

### 第二步：判斷三種型態各佔多少

- 結構性需求：什麼？多大？
- 循環性需求：什麼？多大？
- 防禦性需求：什麼？多大？

通常一個產業是混合的。例如汽車既有循環性（耐久財）也有結構性（電動化取代內燃機）。

### 第三步：找關鍵的需求驅動變數

哪些**外部變數**會顯著影響這個產業需求？

- 利率？
- 所得 / GDP？
- 人口結構？
- 政策 / 補貼？
- 技術變化？
- 匯率？

**每個產業有 2–3 個主導變數**。找出來，就能預測需求的大致方向。

## 一個範例：住宅建築材料（全球水泥產業）

### 第一步：終端需求

水泥 → 建築業 → 住宅 + 商用 + 基建

**驅動住宅建築的根本**：人口、都市化、所得、利率。
**驅動基建的根本**：政府支出、經濟發展階段。

### 第二步：三種型態

- **結構性**：開發中國家的都市化（印度、非洲、東南亞）
- **循環性**：先進國家的住宅建築（跟利率循環）
- **防禦性**：基礎維修與更新（相對穩定）

### 第三步：驅動變數

- 新屋開工（housing starts）
- 建築許可（building permits）
- 利率（特別是 30 年抵押貸款利率）
- 政府基建支出

**投資含義**：

- 已開發國家的水泥廠是**循環性 + 低成長**。
- 開發中國家的水泥廠是**結構性成長 + 循環性波動**。
- 投資水泥，**應該看地區**：印度水泥廠未來 20 年仍有成長空間；美國水泥廠基本上是「跟著利率起伏」。

這就是需求分析怎麼影響你投什麼的實例。

## 一個進階：需求的「長尾」

某些產業的需求有**長尾**特徵 — 大部分需求集中在少數客戶。

**例：**

- **商用飛機**：Boeing + Airbus 的客戶都是幾大航空公司 + 航空租賃公司
- **半導體設備**：ASML 的客戶只有台積電、三星、Intel 等少數
- **高端醫療設備**：客戶是少數大型醫院集團
- **企業軟體（ERP）**：客戶是大企業

**長尾需求的特徵**：

- 單一客戶流失影響很大（敗掉 Apple 對高通是災難）
- 但客戶黏性高（建立關係要多年）
- 需求相對不隨一般消費者情緒變動

**投資含義**：研究這類產業，要**看最大幾個客戶的健康狀況**。如果大客戶出問題，整個產業會被拖下水。

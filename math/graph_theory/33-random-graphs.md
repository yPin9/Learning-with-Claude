# Ch 33 — 隨機圖與相變

> **目標**：理解 Erdős–Rényi 隨機圖 `G(n, p)` 的「演化」：邊的機率 p 慢慢變大時，圖的結構會在幾個臨界點突然改變。完整證明孤立點的閾值 `p = ln n / n`，用分支過程推出巨大連通分量的方程式 `1 − s = e^{−cs}`，並用固定 seed 的模擬把三條相變曲線（巨大分量、臨界尺度、連通性）量成表格，逐格對照理論。
>
> **環境**：Python 3.13.12、NetworkX 3.7，Windows 11。安裝：`pip install networkx==3.7 numpy==2.5.4 scipy==1.18.1 matplotlib==3.11.2`。

## 為什麼需要這個？

1959–1960 年，Erdős 與 Rényi 發表了兩篇論文，問了一個看似天真的問題：**一張「典型」的圖長什麼樣？**他們定義了隨機圖模型，然後發現一件驚人的事：很多性質不是隨著邊數平滑地變得更可能，而是在一個很窄的範圍裡從「幾乎不可能」跳到「幾乎必然」——就像水在 0°C 結冰。

這個現象叫做**相變**（phase transition），或在圖論裡叫**閾值現象**（threshold phenomenon）。對工程師，它有幾個直接的意義：

- **網路韌性**：一個網路隨機壞掉一部分連線，什麼時候會從「大部分還連著」崩潰成「碎成一堆小島」？巨大分量的相變就是這個問題最簡單的模型（滲流，percolation）。
- **P2P 與 gossip**：每個節點隨機連幾個鄰居，才能保證整個 overlay 連通？答案是 `ln n` 這個量級，正是連通性閾值。
- **空模型（null model）**：分析真實網路（社交、呼叫圖、依賴圖）時，「這個結構顯著嗎？」的標準問法是「和同樣邊數的隨機圖比」。不懂隨機圖長什麼樣，就無從判斷。
- **隨機實例的難度**：隨機 k-SAT 也有可滿足性的相變（Ch 31 提過門檻），求解器在門檻附近最慢；這是 SAT 基準測試設計的依據。

## 先建立直覺

想像 n 個人在一個空房間裡。每兩個人之間，以機率 p 牽一條線。從 p = 0 開始慢慢調高：

```text
p ≪ 1/n        零星的線段、小樹，最大的團塊只有 O(log n) 個人
p = c/n, c < 1 還是一堆小樹，每塊 O(log n)
p = 1/n        臨界：最大的團塊突然長到 n^{2/3} 這個奇怪的尺度
p = c/n, c > 1 出現一個「巨大分量」，包含常數比例 s(c)·n 的人；
               其他團塊仍然只有 O(log n)，而且第二大的那塊不會長大
p = ln n / n   最後幾個落單的人（孤立點）也被接上，整張圖連通
```

為什麼臨界點在 `p = 1/n`？因為那時每個人**平均**有 `p(n−1) ≈ c` 個朋友。從一個人出發往外探索，就像一個家族樹：每個人平均生 c 個「新」小孩。c < 1 時家族一定滅絕（樹很小），c > 1 時有正機率永遠延續（長成巨大分量）。這就是本章的核心心智模型：**分支過程**。

> 二階矩法在 [Ch 31 — 機率方法](./31-probabilistic-method.md) 的最後一節；它在那裡證明了三角形的閾值 `p = 1/n`。本章的生成樹計數會用到 [Ch 9 — 樹：等價定義、Cayley 公式、Prüfer 編碼](./09-trees-cayley-prufer.md) 的 Cayley 公式。

## 模型：G(n, p) 與 G(n, m)

- **`G(n, p)`**（Gilbert 模型；Erdős–Rényi 通常和它並稱）：n 個帶標號的點，`C(n,2)` 條可能的邊各自**獨立**以機率 p 出現。
- **`G(n, m)`**（Erdős–Rényi 原始模型）：在所有恰有 m 條邊的 n 點標號圖中均勻選一張。

兩者在 `m ≈ p · C(n,2)` 時對大部分「單調」性質給出相同的漸近答案。我們用 `G(n, p)`，因為邊的獨立性讓期望值與變異數好算。

**單調性質**：加邊不會破壞的性質（連通、含三角形、有巨大分量都是）。**閾值函數** `p*(n)`：當 `p/p* → 0` 時性質幾乎必不成立，`p/p* → ∞` 時幾乎必成立。Bollobás 與 Thomason（1987）證明**每個**非平凡的單調性質都有閾值函數。

**粗閾值 vs 尖閾值**：

| 性質 | 閾值 | 視窗寬度 | 型態 |
| --- | --- | --- | --- |
| 含三角形（Ch 31） | `1/n` | 和 p* 同量級：p = c/n 時機率 → `1 − e^{−c³/6}`，c 從 1 到 3 機率才從 0.15 爬到 0.99 | 粗（coarse） |
| 有巨大分量 | `1/n` | 在 `c = 1` 附近一個 `n^{−1/3}` 寬的視窗內完成 | 尖（sharp） |
| 連通 | `ln n / n` | `(ln n + c)/n`，c 只要跑幾個單位；相對於 p* 的寬度是 `O(1/ln n)` | 尖 |

直覺上，「局部」性質（看到一個固定的小子圖就成立）的閾值是粗的，「全域」性質是尖的。Friedgut（1999）把這個直覺做成了定理，本章不展開。

`nx.fast_gnp_random_graph(n, p, seed)` 用「幾何跳躍」法生成 `G(n, p)`：不逐一擲 `C(n,2)` 次硬幣，而是直接抽「下一條出現的邊在多遠之後」，期望時間 `O(n + m)`。`nx.gnp_random_graph` 則是逐對擲，`O(n²)`，稠密時比較快。兩者在相同 seed 下產生的圖**不同**（用的是不同的隨機數消耗方式），比較實驗結果時要用同一個函式。

## 相變一：孤立點與連通性

先證最乾淨的一個。

**定理 33.1（孤立點的閾值）**：令 X 為 `G(n, p)` 中孤立點的個數，ε > 0 固定。

- 若 `p = (1 + ε) ln n / n`，則 `P(X > 0) → 0`。
- 若 `p = (1 − ε) ln n / n`，則 `P(X > 0) → 1`。

**證明**：`X = Σ_v I_v`，`I_v` 是「v 的 n−1 條可能邊全都沒出現」，`P(I_v = 1) = (1 − p)^{n−1}`。

**上半（一階矩）**：`E[X] = n (1 − p)^{n−1} ≤ n e^{−p(n−1)}`（用 `1 − x ≤ e^{−x}`）。代入 `p = (1+ε) ln n / n`，`p(n−1) = (1+ε)(1 − 1/n) ln n`，所以 `E[X] ≤ n · n^{−(1+ε)(1−1/n)} = n^{−ε + (1+ε)/n} → 0`。由 Markov 不等式 `P(X ≥ 1) ≤ E[X] → 0`。

**下半（二階矩）**：先看 `E[X] → ∞`。對小的 p，`1 − p ≥ e^{−p − p²}`（`p ≤ 1/2` 時成立），所以 `E[X] ≥ n e^{−(p + p²)(n−1)}`；`p²n = O((ln n)²/n) → 0`，主項是 `n · n^{−(1−ε)} = n^ε → ∞`。

再算變異數。對 `u ≠ v`，`I_u I_v = 1` 要求 u 與 v 各自的 n−1 條邊都不出現；這兩組邊共用 uv 一條，總共 `2n − 3` 條，所以 `E[I_u I_v] = (1 − p)^{2n−3}`。

```text
Var(X) = E[X] + n(n−1)(1−p)^{2n−3} − n²(1−p)^{2n−2}
       ≤ E[X] + n²(1−p)^{2n−3} · (1 − (1−p))
       = E[X] + E[X]² · p/(1−p)
```

所以 `Var(X)/E[X]² ≤ 1/E[X] + p/(1−p) → 0`。由二階矩法（Ch 31），`P(X = 0) → 0`。∎

更精細地，`p = (ln n + c)/n` 時 X 趨近平均 `e^{−c}` 的 Poisson 分佈（本章不證），所以 `P(沒有孤立點) → e^{−e^{−c}}`。

**定理 33.2（連通性，Erdős–Rényi）**：`p = (ln n + c)/n` 時，`P(G(n,p) 連通) → e^{−e^{−c}}`。特別地，閾值是 `ln n / n`。

**這裡只給證明架構**。「連通」蘊含「沒有孤立點」，所以下半由定理 33.1 得到。上半要證：p 稍微超過 `ln n / n` 時，除了孤立點之外**也沒有其他小分量**。若圖不連通，必有一個大小 k（`2 ≤ k ≤ n/2`）的連通分量 C；C 有一棵生成樹，而且 C 與外面沒有邊。用 union bound：

```text
P(存在大小 k 的分量) ≤ C(n, k) · k^{k−2} · p^{k−1} · (1 − p)^{k(n−k)}
```

`k^{k−2}` 是 k 個標號點上的生成樹數——Ch 9 的 **Cayley 公式**（也是 Ch 28 矩陣樹定理在 `K_k` 上的值）。剩下的工作是證明這個和對 `k = 2..n/2` 加總後趨近 0：k 小時由 `(1−p)^{kn} ≈ n^{−k}` 壓住，k 大時由 `(1−p)^{k(n−k)} ≤ e^{−pkn/2}` 壓住。細節是一頁的不等式估計。結論是：在這個 p 的範圍內，**不連通幾乎等同於有孤立點**。

### 實測

```python
import math

import networkx as nx

n, trials = 2000, 300
print(f"n={n}, p=(ln n + c)/n, {trials} trials per row (seeds 0..{trials - 1})")
print(f"{'c':>5s} {'p':>8s} {'P(connected)':>12s} {'P(no isolated)':>14s} {'exp(-e^-c)':>10s} {'E[#isolated]':>12s}")
for c in (-2, -1, 0, 1, 2, 3):
    p = (math.log(n) + c) / n
    conn = noiso = 0
    for s in range(trials):
        G = nx.fast_gnp_random_graph(n, p, seed=s)
        iso = sum(1 for _, d in G.degree() if d == 0)
        noiso += iso == 0
        conn += nx.is_connected(G)
        assert not (nx.is_connected(G) and iso > 0)
    print(f"{c:5d} {p:8.5f} {conn / trials:12.3f} {noiso / trials:14.3f} {math.exp(-math.exp(-c)):10.3f}"
          f" {n * (1 - p) ** (n - 1):12.3f}")
```

   -1  0.00330        0.070          0.073      0.066        2.698

讀法：

- **連通 ≈ 沒有孤立點**：兩欄只在 c = −1 差 0.003，也就是 300 次中恰有 1 次「沒有孤立點卻不連通」（例如有一個孤立的 `K_2`）。這正是定理 33.2 的架構在說的事。
- **和 `e^{−e^{−c}}` 的吻合**：每一列差距 ≤ 0.011，在 300 次試驗的抽樣誤差（標準誤 ≤ 0.029）之內。
- **視窗很窄**：p 從 0.0028 到 0.0053 不到兩倍，連通機率從 0 走到 0.95。相對寬度 `O(1/ln n)` 就是「尖閾值」的意思。
- **E[#isolated] 欄**：`n(1−p)^{n−1}` 在 c = 0 時是 0.989，接近 `e^{−0} = 1`；有限 n 的修正讓它略小於 1。

工程上的翻譯：一個 2000 節點的 overlay，如果每對節點獨立以 p 相連，期望度數 `p(n−1)` 要到 `ln 2000 + 3 ≈ 10.6` 才有 95% 的機率連通；度數 5.6（c = −2）時幾乎一定有孤立節點。gossip 協定設定「每個節點聯絡 `O(log n)` 個隨機對象」，背後就是這個閾值。

## 相變二：巨大連通分量

### 分支過程推出 s(c)

固定 `p = c/n`。從一個點 v 出發做 BFS。v 的鄰居數服從 `Binomial(n−1, c/n)`，n 大時近似 `Poisson(c)`。BFS 早期，每個新點的「新鄰居」（還沒被探索過的）數目也近似獨立的 `Poisson(c)`——因為還沒探索的點幾乎是全部 n 個。所以 BFS 樹的早期近似一個 **Galton–Watson 分支過程**：每個個體獨立地生 `Poisson(c)` 個小孩。

**滅絕機率**：令 q 為「從一個個體開始，家族最終滅絕」的機率。根生了 K 個小孩，家族滅絕若且唯若 K 個子家族全部滅絕，各自獨立、機率 q：

```text
q = E[q^K] = Σ_k P(K = k) q^k = Σ_k e^{−c} c^k/k! · q^k = e^{−c} e^{cq} = e^{c(q − 1)}
```

令存活機率 `s = 1 − q`，得到

```text
1 − s = e^{−cs}
```

s = 0 永遠是解。函數 `f(s) = 1 − e^{−cs}` 在 0 的斜率是 c：

- **c ≤ 1**：f 是凹函數，斜率在 0 處 ≤ 1，`f(s) < s` 對所有 `s > 0`，唯一解是 s = 0——一定滅絕。
- **c > 1**：斜率 > 1，f 在 0 附近高於對角線，又 `f(1) < 1`，所以在 (0, 1) 中有唯一的正根 s(c)。滅絕機率是 `1 − s(c)`（可以證明正確的根是較大的那個）。

**定理 33.3（Erdős–Rényi 1960，巨大分量）**：`p = c/n`。

- `c < 1`：幾乎必然，最大分量大小是 `Θ(log n)`。
- `c = 1`：最大分量大小是 `Θ(n^{2/3})`（依分佈意義）。
- `c > 1`：幾乎必然，存在唯一一個大小 `(s(c) + o(1)) n` 的分量，其他分量都是 `O(log n)`。

**這裡只給證明架構**。分支過程只是啟發式：BFS 進行到後期，未探索的點變少，每個點的新鄰居數不再是 `Poisson(c)`。嚴謹的證明通常這樣做：

```text
1. 次臨界（c < 1）：用「BFS 探索過程」把分量大小上界到一個 Binomial(n, c/n) 分支過程，
   它的總人口有指數尾：P(總人口 > k) ≤ e^{−αk}，α = c − 1 − ln c > 0。
   取 k = (3/α) ln n，對 n 個起點做 union bound。
2. 超臨界（c > 1）：
   a. 小分量：同樣的上界論證，但只追蹤到 O(log n)：一個 BFS 要嘛在 O(log n) 內停住，
      要嘛「逃逸」到 n^{2/3} 這個尺度。
   b. 逃逸的點彼此相連：兩個大小 n^{2/3} 的團塊之間有 n^{4/3} 對可能邊，
      全部不出現的機率 (1 − c/n)^{n^{4/3}} = e^{−c n^{1/3}}，極小。所以大團塊只有一個。
   c. 逃逸點的比例：每個點逃逸的機率 → s(c)，再用二階矩法集中到 s(c) n。
3. 臨界（c = 1）：需要更細的鞅或隨機遊走論證，這是 Aldous（1997）等人的工作。
```

### 實測：巨大分量的曲線

我們自己寫 union-find 算分量大小，用 NetworkX 對拍一次，然後掃過 c：

```python
import math

import networkx as nx


def component_sizes(n, edges):
    """Union-find（路徑壓縮 + 依大小合併），回傳由大到小的連通分量大小。"""
    parent, size = list(range(n)), [1] * n

    def find(a):
        while parent[a] != a:
            parent[a] = parent[parent[a]]
            a = parent[a]
        return a

    for u, v in edges:
        ru, rv = find(u), find(v)
        if ru != rv:
            if size[ru] < size[rv]:
                ru, rv = rv, ru
            parent[rv] = ru
            size[ru] += size[rv]
    return sorted((size[r] for r in range(n) if find(r) == r), reverse=True)


def giant_theory(c):
    """解 1 - s = exp(-c s) 的最大根（c <= 1 時為 0），用不動點迭代。"""
    if c <= 1:
        return 0.0
    s = 1.0
    for _ in range(10_000):
        s = 1 - math.exp(-c * s)
    return s


# 先對拍一次：自刻 union-find vs NetworkX
G = nx.fast_gnp_random_graph(3000, 1.5 / 3000, seed=99)
mine = component_sizes(3000, G.edges())
ref = sorted((len(c) for c in nx.connected_components(G)), reverse=True)
assert mine == ref
print("union-find matches nx.connected_components:", mine[:3], "...")

n, trials = 20_000, 10
print(f"n={n}, p=c/n, {trials} trials per row (seeds 0..{trials - 1})")
print(f"{'c':>5s} {'L1/n sim':>9s} {'L1/n theory':>11s} {'L2/n sim':>9s}")
for c in (0.5, 0.8, 0.9, 1.0, 1.1, 1.2, 1.5, 2.0, 3.0):
    L1 = L2 = 0
    for s in range(trials):
        sizes = component_sizes(n, nx.fast_gnp_random_graph(n, c / n, seed=s).edges())
        L1 += sizes[0]
        L2 += sizes[1]
    L1, L2 = L1 / trials, L2 / trials
    print(f"{c:5.2f} {L1 / n:9.4f} {giant_theory(c):11.4f} {L2 / n:9.4f}")
```

輸出（本機約 6 秒）：

```text
union-find matches nx.connected_components: [1869, 11, 9] ...
n=20000, p=c/n, 10 trials per row (seeds 0..9)
    c  L1/n sim L1/n theory  L2/n sim
 0.50    0.0010      0.0000    0.0008
 0.80    0.0042      0.0000    0.0033
 0.90    0.0093      0.0000    0.0066
 1.00    0.0320      0.0000    0.0171
 1.10    0.1652      0.1761    0.0095
 1.20    0.3140      0.3137    0.0046
 1.50    0.5838      0.5828    0.0015
 2.00    0.7966      0.7968    0.0006
 3.00    0.9409      0.9405    0.0002
```

`L1` 是最大分量、`L2` 是第二大分量，都是 10 次的平均。

- **c ≥ 1.2**：模擬值和 `s(c)` 的差距在 0.001 以內。c = 1.5 時巨大分量吃掉 58% 的點，c = 3 時 94%。
- **c = 1.1**：模擬 0.165 對理論 0.176，差了 6%——這是**有限尺寸效應**：理論說的是 n → ∞ 的極限，而在臨界點附近收斂最慢。n = 20000 時臨界視窗寬度約 `n^{−1/3} ≈ 0.037`，c = 1.1 離臨界只有 3 個視窗寬。
- **c = 1.0**：理論極限是 0，模擬是 0.032（約 640 個點）。這不是巨大分量，是臨界尺度 `n^{2/3} ≈ 737`。
- **L2 欄**：c < 1 時 L1 與 L2 同量級（都是小樹）；c > 1 後 L2 反而**變小**——第二大的分量一旦變大，就會被巨大分量吞掉。這是「巨大分量唯一」的數值證據。

### 實測：三種尺度

定理 33.3 說最大分量在三個區間分別是 `log n`、`n^{2/3}`、`n` 的尺度。固定 c、讓 n 變大，看哪一個比值穩定：

```python
import math

import networkx as nx


def largest_component(n, p, seed):
    G = nx.fast_gnp_random_graph(n, p, seed=seed)
    return max(len(c) for c in nx.connected_components(G))


trials = 10
print(f"{trials} trials per cell, seeds 0..{trials - 1}")
print(f"{'n':>7s} | {'c=0.5: L1/ln n':>14s} | {'c=1: L1/n^(2/3)':>15s} | {'c=1.5: L1/n':>11s}")
for n in (1000, 4000, 16000, 64000):
    a = sum(largest_component(n, 0.5 / n, s) for s in range(trials)) / trials
    b = sum(largest_component(n, 1.0 / n, s) for s in range(trials)) / trials
    c = sum(largest_component(n, 1.5 / n, s) for s in range(trials)) / trials
    print(f"{n:7d} | {a / math.log(n):14.2f} | {b / n ** (2 / 3):15.2f} | {c / n:11.4f}")
```

輸出（本機約 8 秒）：

```text
10 trials per cell, seeds 0..9
      n | c=0.5: L1/ln n | c=1: L1/n^(2/3) | c=1.5: L1/n
   1000 |           1.62 |            1.04 |      0.5745
   4000 |           2.01 |            1.01 |      0.5851
  16000 |           2.16 |            1.01 |      0.5826
  64000 |           2.23 |            0.83 |      0.5815
```

- **c = 1.5**：`L1/n` 穩定在 0.58，對應 `s(1.5) = 0.5828`。
- **c = 1**：`L1/n^{2/3}` 在 0.83–1.04 之間擺動，沒有往 0 或無窮漂移。它不會收斂到一個常數——臨界時 `L1/n^{2/3}` 收斂到一個**非退化的隨機變數**，10 次平均仍然有明顯的抽樣波動。
- **c = 0.5**：`L1/ln n` 從 1.62 緩慢爬到 2.23。精確的漸近式是 `(ln n − (5/2) ln ln n)/α`（α = c − 1 − ln c），`ln ln n` 的修正項讓收斂非常慢；在可模擬的 n 範圍內看起來不是常數，但成長速度遠慢於任何 `n^ε`。

**注意這些表的統計意義**：每格只有 10 次試驗，數字代表「平均落在哪個量級」，不是精確估計。要做精確的有限尺寸分析，需要每格數百次試驗並報告信賴區間。

## 對比與取捨

| 模型 | 度數分佈 | 有巨大分量的條件 | 像什麼真實網路 |
| --- | --- | --- | --- |
| `G(n, p)`（本章） | Poisson(c) | 平均度數 c > 1 | 幾乎沒有；它是空模型 |
| 隨機 d-正則圖（Ch 30） | 全部是 d | d ≥ 3 時幾乎必連通 | 刻意設計的網路（Jellyfish） |
| 給定度數序列的 configuration model | 任意 | Molloy–Reed 條件：`Σ d(d − 2) > 0` 的加權版本 | 用來當「保留度數」的空模型 |
| 優先連結（Barabási–Albert） | 冪律 | 一直連通（每個新點都接上去） | 引用網路、網頁連結（爭議中） |

**為什麼真實網路不是 `G(n, p)`？** 真實社交網路有大量三角形（朋友的朋友是朋友）、度數分佈有重尾、有社群結構；`G(n, p)` 三者都沒有（c/n 時三角形期望只有 `c³/6` 個）。但這正是它當空模型的價值：「這張呼叫圖的三角形數是同邊數 `G(n,p)` 的 1000 倍」是一個有意義的陳述。

**為什麼不直接用 `G(n, m)`？** `G(n, m)` 的邊不獨立（總數固定），期望值與變異數的計算要處理超幾何分佈。兩者對單調性質漸近等價，所以先在 `G(n, p)` 裡證明，再轉回 `G(n, m)`。

## 踩雷集錦

1. **把閾值當成精確值**：「p > ln n / n 就連通」是錯的說法；`p = ln n / n` 時連通機率趨近 `e^{−1} ≈ 0.37`。閾值描述的是一個趨勢，具體機率要看 `(ln n + c)/n` 中的 c。
2. **在臨界點附近用小 n 驗證理論**：表中 c = 1.1 的 6% 誤差、c = 1 的 0.032 都是有限尺寸效應。要驗證漸近結果，至少要掃過幾個數量級的 n，看比值是否穩定。
3. **混用 `fast_gnp_random_graph` 與 `gnp_random_graph`**：同一個 seed 給出不同的圖。實驗要可重現，就固定用同一個函式並記錄 seed。
4. **對 c 很小或 p 很大用錯生成器**：`fast_gnp_random_graph` 是 `O(n + m)`，稀疏時好；p 接近 1 時 m ≈ n²/2，兩者都是 `O(n²)`，而 `gnp_random_graph` 的常數較小。
5. **以為分支過程是證明**：BFS 後期可用的點變少，分支近似失效；分支過程給出正確的方程式，但嚴謹證明要處理這個耗盡效應（架構第 2b、2c 步）。
6. **用平均值描述臨界行為**：c = 1 時最大分量的大小本身就有大的隨機波動，10 次平均的 0.83–1.04 擺動不是 bug。

## 進階：再往深一層

- **Kahn–Kalai 猜想（Park–Pham 定理）**：一個單調性質的閾值，和它的「期望值閾值」（讓某個見證結構的期望個數 ≈ 1 的 p）最多差一個 `O(log n)` 因子。2022 年 Park 與 Pham 用一個出奇簡短的論證證明了它；它解釋了為什麼本章和 Ch 31 的一階矩計算幾乎總是猜對閾值。
- **Hamilton 圈的閾值**：`G(n, p)` 有 Hamilton 圈的閾值也是 `ln n / n`，而且更精確地，「最小度數 ≥ 2」出現的那一刻，Hamilton 圈幾乎必然同時出現（hitting time 結果）。這和 Ch 8 的「Hamilton 是 NP-hard」形成有趣對比：最壞情況很難，隨機情況卻有極乾淨的答案。
- **色數與團數**：`G(n, 1/2)` 的團數集中在 `2 log₂ n` 附近的兩個值之一（二階矩法），色數約 `n / (2 log₂ n)`（Bollobás 1988，用 martingale 集中不等式）。
- **滲流（percolation）**：把「每條邊以機率 p 保留」放到格子圖或真實網路上，巨大分量出現的臨界 p 由網路結構決定。對度數重尾的網路，隨機故障幾乎打不散它，但針對高度數節點的攻擊很快讓它崩潰——這是網路韌性分析的標準論點，也是 Ch 39 攻擊圖「chokepoint」概念的機率版本。

## 動手練習

1. 改寫巨大分量實驗：固定 n = 20000，把 c 從 1.0 到 1.3 以 0.02 的間距掃過，每格 50 次試驗，用 matplotlib 畫出 L1/n 與 `s(c)` 的曲線。你會看到模擬曲線在 c = 1 附近被「抹平」，而 n 增大時（改跑 n = 80000）抹平的範圍變窄。
2. 證明 `1 − s = e^{−cs}` 在 c > 1 時恰有一個正根，並證明 c → 1⁺ 時 `s(c) ≈ 2(c − 1)`（提示：對 `e^{−cs}` 做二階泰勒展開）。用程式驗證 c = 1.01、1.05、1.1。
3. 在 `G(n, p)` 上用 Ch 28 的方法算 `λ_2`，觀察它在 `p = ln n / n` 附近如何從 0（不連通）變成正值。
4. 實作 `G(n, m)` 的生成（隨機抽 m 條相異邊，seed 固定），在 `m = n(ln n + c)/2` 下重做連通性實驗，和 `G(n, p)` 的表格對照。

## 本章重點整理

- `G(n, p)`：每條邊獨立以 p 出現；單調性質都有閾值，局部性質（三角形）閾值粗、全域性質（連通、巨大分量）閾值尖。
- 孤立點與連通性的閾值都是 `ln n / n`；`p = (ln n + c)/n` 時連通機率 → `e^{−e^{−c}}`，不連通幾乎等同有孤立點。證明 = 一階矩 + 二階矩 + Cayley 公式的 union bound。
- 巨大分量在 `p = c/n`、`c = 1` 出現；分支過程給出 `1 − s = e^{−cs}`；臨界時最大分量是 `n^{2/3}` 尺度。
- 模擬在 c 離臨界夠遠時和理論吻合到 0.001；臨界附近的有限尺寸效應要掃過多個 n 才看得清。

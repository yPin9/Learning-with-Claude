# Ch 22 — 技能 vs 知識：不同的學習邏輯

> Ch 20 區分了原理 vs 細節。這一章做另一個重要區分：**技能 vs 知識**。它們的**學習邏輯完全不同**。把技能當成知識來學，或把知識當成技能來學，都會失敗。

## 兩種截然不同的東西

### 知識（Knowledge）

**陳述性記憶**（Ch 3）：可以用語言表達的東西。

- 事實：「台積電 2024 年毛利率約 55%」
- 概念：「複利是什麼」
- 理論：「Porter 五力如何運作」
- 歷史：「1929 年大蕭條的成因」

**學習方式**：閱讀、討論、理解。

**測試**：能回答 / 解釋嗎？

### 技能（Skill）

**程序性記憶**（Ch 3）：做得出來的東西，難以用語言完整描述。

- **動作技能**：騎車、打字、彈琴、運動
- **認知技能**：寫程式、寫作、分析、解數學
- **社交技能**：對話、談判、演講

**學習方式**：練習、練習、更多練習。

**測試**：**能做嗎**？

## 兩者的學習曲線不同

### 知識的學習曲線

**相對平緩**，但有清晰階段：

```
理解 → 記憶 → 應用 → 遷移
```

你**今天讀了**就有部分成果。**持續間隔重複**維持。

### 技能的學習曲線

**漫長、不平均、有高原期**：

```
初學（快速進步）→ 高原期（感覺停滯）→ 突破 → 新高原 → ...
```

**技能學習有明顯的「plateau」（高原期）**。練了幾週感覺沒進步，然後**突然**跳一級。

**這個不平均讓很多人在高原期放棄**。以為自己「沒天分」。其實只是**技能學習的自然節奏**。

## 知識 vs 技能的時間投入

**極大差別**：

### 學一個知識

- 一個概念：幾小時到幾天
- 一個複雜理論：幾週到幾個月

### 學一個技能到「熟練」

- 打字：幾週
- 騎車：幾天到幾週
- 初階鋼琴：半年到一年
- 初階程式：半年到一年
- 流利新語言：1–3 年
- 職業級運動：10 年+
- 世界級專家：20 年+

**技能遠比知識花時間**。而且**沒有捷徑**。

**Cal Newport 說**：「我們崇拜天才，但天才的背後是大量的刻意練習」。

## 為什麼技能不能靠讀書學

**一個殘酷的事實**：**你不能靠讀書變會騎車、彈琴、程式、運動**。

**你可以靠讀書「知道」**這些事是什麼。**但「會做」需要親身練**。

### 為什麼

**神經科學的原因**：

- **知識**儲存在**海馬迴 + 新皮質**（陳述性記憶系統）
- **技能**儲存在**基底神經節 + 小腦**（程序性記憶系統）
- **兩個系統的運作方式不同**

知識可以**快速建立**（聽一次、讀一次就有初步形成）。
技能必須**慢慢雕塑神經迴路**（需要反覆做，讓神經連接固化）。

**沒有捷徑** — 你的大腦就是這樣運作。

## 一個常見錯誤：用學知識的方法學技能

這是我看過**最常見**的學習錯誤。

**症狀**：

- 讀很多關於 Python 的書、做很多筆記、看很多影片 → **還是寫不出程式**
- 讀很多投資的書、分析很多案例 → **還是不敢自己投資**
- 讀很多寫作的書 → **還是寫不好**
- 讀很多運動訓練的書 → **還是不健身**

**問題**：他們在**學知識**，但希望**得到技能**。

**這兩者不相通**。

### 解法

**技能必須練**。

- 想學 Python → 寫程式（很多很多）
- 想學投資 → 實際做投資決策（小錢也好）
- 想學寫作 → 寫（每天寫）
- 想練健身 → 真的去健身房

**讀書只是輔助**。讀書 + 不練 = 永遠不會。

## 技能學習的五個原則

### 原則 1：從簡單做起

**不要一開始挑戰最難的**。

- 學程式 → 先寫 Hello World，再寫小腳本，再做小專案，再做大專案
- 學鋼琴 → 先單手簡單曲，再雙手簡單曲，再複雜曲
- 學健身 → 先輕重量練正確姿勢，再慢慢增重量

**跳過基礎，後面會痛**。

### 原則 2：刻意練習（Ch 10）

**不是任何練習都有效**。要**針對弱點、有回饋、走出舒適區**。

**每次練習都要問**：我這次要改善什麼？

### 原則 3：重複到自動化

技能的終點是**自動化**（Ch 10）。

- 當基本動作自動化 → 工作記憶釋放 → 能處理更高層
- 寫程式的語法自動化 → 能思考設計
- 彈琴的指法自動化 → 能思考表達

**沒有自動化，永遠在基礎掙扎**。

### 原則 4：有回饋

**技能需要即時回饋**。

- 程式：能跑、能通過測試
- 音樂：聽得出錯音
- 運動：動作對不對

**最強的回饋**來自**更強的人**（老師、教練）。

**自學者的挑戰**：回饋從哪來？

- 社群 / 論壇（技術問題）
- 記錄自己（錄影、錄音）
- 對標：看專家做，對比自己

### 原則 5：耐心 — 高原期是正常的

**技能學習有高原期**。

- 練了幾週感覺沒進步
- 大腦在後台整合神經迴路
- 某天突然**質變**（突破）

**這不是你的問題，是技能的本質**。

**繼續練** — 大多數人在高原期放棄，**所以沒到突破**。

## 知識輔助技能：好的組合

**理想的學習**：**知識 + 技能並進**。

### 例 1：學 Python

**純知識方法**（會失敗）：
- 讀《Python for Beginners》
- 做筆記
- 看 YouTube 教學
- 不寫程式

**純技能方法**（也會失敗）：
- 不看書、不讀文件
- 只亂寫程式
- 不懂為什麼某些方法比別的好

**正確組合**：
- **讀書 / 看教學獲得知識**（「Python 有 list comprehension 這東西」）
- **立即動手寫 code** 應用（技能練習）
- **卡住時回來查知識**
- **練多了，某些知識自動內化成技能**

**知識是地圖，技能是實際走路**。兩者需要。

### 例 2：學投資

**純知識方法**（會停在愚人山）：
- 讀一堆投資書
- 看 YouTube 影片
- 但從沒實際投資

**純技能方法**（大賠錢）：
- 跳進股市就買
- 不懂基本原理
- 靠運氣

**正確組合**：
- **讀 Graham、Damodaran 等獲得知識**
- **實際用小錢投資**（幾千到幾萬，能承受損失的）
- **每次決策寫 thesis**（強迫整合知識與技能）
- **追蹤結果、反思**

**幾年下來**，知識與技能互相強化，你變成真正的投資人。

## 技能學習的「最低可行產品」

**一個有用的心態**：**先做出能動的東西，再改進**。

**寫程式**：先寫 **能跑的爛程式**，再 refactor。

**寫作**：先寫 **糟糕的初稿**，再修。

**學鋼琴**：先彈 **能聽的版本**，再 polish。

**新創**：**先做 MVP**，再迭代。

**為什麼**：

- **完美主義** 讓你永遠不敢出手
- **出手** 後你會遇到**真實的問題**
- **真實的問題** 教你的比想像的多

**多數人卡在「學還不夠，還不敢做」**。**正確**：**邊做邊學**。

## 一個嚴重的錯誤：收藏技能資源

我看過很多人的電腦 / 書架：

- 100+ 本程式書，看過 5 本
- 50+ 門線上課程，完成 3 門
- 幾十個 YouTube 播放清單，看過前兩集

**這些人有大量「關於技能的知識」，但沒有技能**。

**他們在做的事**：用**知識的方法**（收集、分類、閱讀）應對**技能的需求**（練習）。

**收集資源不等於擁有能力**。

**解法**：**丟掉 90% 的資源**，**選一門課 / 一本書 / 一個練習**，**認真做完**。做出一個實際的東西。然後才看下一個。

## 學習技能的長期心態

**技能學習要求**：

### 心態 1：接受時間尺度

**職業級技能 = 10 年**（Ericsson）。
**熟練水準 = 2–5 年**。
**入門 = 幾個月**。

**如果你期望 3 個月精通某個技能，你會失望、放棄**。

### 心態 2：每天一點點

**每天 1 小時 × 365 天 = 365 小時**。
**比「週末衝刺 10 小時」有效得多**。

**為什麼**：
- 技能需要**睡眠鞏固**（Ch 6）
- 技能需要**多次提取**（Ch 8）
- 每天少量 = 多次鞏固 + 多次提取

**衝刺 = 少次鞏固 + 少次提取**。

### 心態 3：過程導向

**享受過程本身**。

如果你只在意「什麼時候能精通」，你會**無法忍受**高原期、**錯過**過程中的細微進步、**放棄**太早。

**愛學習本身**，結果自然來。

## 技能學習的 3 個實用步驟

把本章的建議綜合成你可以立刻做的步驟：

### 步驟 1：選一個技能 + 承諾時間尺度

**挑一個**具體的技能（不要三個）。

**承諾**：我要花 **6 個月** 到熟練，**2 年**到職業初級水準。

**這個承諾阻止你中途換目標**。

### 步驟 2：拆成每天可做的

- 每天**練 30–60 分鐘**
- **不是一週一次 5 小時**

### 步驟 3：設計最低可行產出

**從今天開始做東西**，即使爛。

- 學程式 → 今天就寫一個 10 行的小程式
- 學寫作 → 今天就寫 200 字
- 學運動 → 今天就做 20 下

**邊做邊學**，不要等到「準備好了」。

# Ch 0 — 環境與工具

> 這一章是地基：工具、環境、時間分配。工具不是重點（真的不重要），但你的**學習環境設計**決定了你每天默認會發生什麼。把這個設計好，整門課的方法才能落地。

## 先講結論：工具其實不重要

這一章可能跟你期待的不一樣 — **沒有推薦一堆神奇的 app**。

理由：**學習工具的邊際效用極低**。

換一個更好的筆記軟體、換一個更花俏的 flashcard 工具、換一個新的閱讀 app — 這些動作**幾乎對你的學習成效沒影響**。

真正有影響的是：

1. **你每天實際花在「主動學習」的時間**
2. **你用什麼方法**（主動回憶 vs 被動閱讀）
3. **你能不能堅持幾個月以上**

這三個沒搞定，再好的工具都救不了。這三個搞定了，用便條紙 + 鉛筆也能學得很好。

**所以這章會盡量務實，不推銷工具**。

## 三樣你真正需要的工具

### 工具一：一個筆記系統（任何一個都行）

你需要一個地方存放：
- 主動產生的筆記（摘要、想法、疑問）
- 手抄的重要段落
- 你自己寫的解釋（費曼技巧用）

選項（按從輕到重排）：

**輕量：紙本筆記本**
- Moleskine、無印良品、一般筆記本
- 優點：不會被 app 的花俏功能分心；寫字的動作本身有助記憶（有研究支持）
- 缺點：搜尋不便、不能連結

**中量：簡單數位筆記**
- Apple Notes、Google Keep、OneNote
- 優點：設置簡單、可搜尋、跨設備
- 缺點：結構鬆散、難做長期知識庫

**重量：結構化知識管理**
- Obsidian、Notion、Roam Research、Logseq
- 優點：可做 Zettelkasten、可連結、可視覺化
- 缺點：學習曲線、容易陷入「整理系統」反而不學習

**建議**：如果你從沒用過這類工具，**從簡單數位筆記開始**。做兩三個月後，你會對自己的筆記習慣有感覺，再考慮升級。

**最大的陷阱**：花幾週研究「最好的筆記系統」，結果沒真的在學。**工具選擇不該超過一小時**。

### 工具二：一個間隔重複系統

這是**唯一值得認真選**的工具。因為 Ch 9 會告訴你，間隔重複是單一最重要的記憶技法。

選項：

**Anki**（免費開源）
- 桌面 + 手機都有
- 極強的客製化
- **介面醜、上手有門檻**，但一旦會用就受用一輩子
- **大多數嚴肅學習者的首選**

**RemNote**（部分免費）
- 筆記 + 間隔重複結合
- 適合同時做筆記與復習

**Quizlet**
- 入門友好
- 社群資源豐富（現成的 flashcard 組）
- 但演算法不如 Anki 嚴謹

**建議**：**認真學一個技術性主題的話，直接學 Anki**。忍耐第一週的介面不友善，你會感謝自己。

Ch 9 會詳細講怎麼用。

### 工具三：一個專注環境

這不是 app，是物理環境。

需求：

- **一個固定的學習位置**（桌子、圖書館、咖啡廳 — 任選一個固定的）
- **移走手機**（或至少關通知）
- **可以維持 45–90 分鐘不被打斷**

**為什麼固定位置重要**：神經科學有證據，**特定環境會觸發「學習模式」的腦態**。你每天在同一個位置學習，久了那個位置會成為「一坐下就進入學習」的觸發器。

這比任何 productivity app 有用。

## 不需要的東西

**不需要**花錢買：

- ❌ 付費的筆記軟體 pro 版（免費版通常夠用）
- ❌ 炫的 keyboard、顯示器、生產力配件
- ❌ 昂貴的線上課程（尤其是「how to learn」的課程，市場上大多是販賣焦慮）
- ❌ 所謂的「大腦訓練 app」（Lumosity、Elevate 等 — 研究顯示它們幾乎沒有遷移效果）

**不需要**追求：

- ❌ 完美的每日計畫表
- ❌ 美觀的筆記版面（bullet journal 等）
- ❌ 跟人比較「每天學了幾小時」

這些都是**生產力劇場**（productivity theater）— 看起來很努力，實際上在逃避真正的學習。

## 時間分配

### 每天實際學習時間

你可能看過網路上「頂尖學生每天 12 小時」的故事。大多數是假的或誤導的。

**科學證據顯示**：

- 高品質、深度專注的學習，**成人一天大概能維持 3–5 小時**
- 超過 5 小時，邊際效益急速下降
- 頂尖的科學家、數學家、作家，核心創造時間通常**每天只有 3–4 小時**

**所以你的目標**：每天 **2–4 小時**的**真正主動學習**。

「真正主動學習」不包括：
- 看 YouTube 教學影片（被動）
- 重複閱讀筆記（被動）
- 收集新資料、整理文件夾（拖延）
- 思考「該怎麼學」但沒真的學（元拖延）

### 每週節奏

建議的節奏：

- **週一到週五**：每天 2–4 小時主動學習
- **週六**：1–2 小時回顧整週學到的 + 做間隔重複
- **週日**：休息或輕鬆的閱讀

**關鍵**：**一定要休息**。Ch 6 會談為什麼睡眠與休息是學習的一部分，不是跟學習對立。

### 長期節奏

學一個嚴肅的主題（例如「學好 C++」「學懂投資」），時間尺度：

- **快速入門期**：1–3 個月（每天專注）
- **建立紮實基礎**：6 個月 – 1 年
- **進入熟練**：2–3 年
- **精通**：5–10 年

**短於這個時間的承諾都是不誠實的**。「30 天精通 Python」「一個月學會投資」都是騙人的。

這不是壞消息 — 這是**誠實地認識時間的代價**，讓你能做合理的規劃。

## 一個基礎流程：每週的學習循環

這是一個可以直接照做的流程：

### 每天（25–45 分鐘 × 3–4 次）

```
1. 今天要學什麼（具體到章節或問題）— 2 分鐘
2. 主動學習（閱讀 + 筆記 + 嘗試解釋）— 25–45 分鐘
3. 快速 active recall：合上書，寫下剛才學到的重點 — 5–10 分鐘
4. 間隔重複：做 Anki 或類似工具的今日排程 — 10–15 分鐘
```

### 每週（1–2 小時）

```
1. 回顧本週的筆記
2. 整理新加入的 flashcards
3. 寫一份「本週學到的 3 個關鍵 insight」
4. 計畫下週要處理的難點
```

### 每月（2–3 小時）

```
1. 檢視目前的學習進度 vs 當初的計畫
2. 更新長期計畫
3. 移除不再重要的筆記 / flashcard
```

這個流程看起來簡單，但**真的照做**的人極少。如果你能做到，你已經超過 90% 的學習者。

## 一個心態：工具服務方法，方法服務目標

很多人的學習順序是反的：

```
看到炫的工具 → 花時間學工具 → 希望用工具就能變會
```

正確的順序：

```
釐清目標（我要學什麼、為什麼） 
→ 選擇方法（主動回憶、間隔重複等）
→ 找能執行這些方法的最簡工具
→ 開始學
```

**工具只是方法的載體**。方法只是達成目標的手段。**最終重要的是你想成為什麼樣的人、想理解什麼、想做成什麼事**。

這門課從頭到尾會貫徹這個順序。

# Ch 26 — 動機、興趣、好奇心：學習的燃料

> 方法再好，沒有動機也不會做。這一章處理一個被學習科學書籍低估的議題：**什麼讓人持續學下去**。動機不是玄學，是有結構、可設計的。

## 兩種動機

心理學家 Edward Deci 和 Richard Ryan 的**自我決定理論**（Self-Determination Theory）區分兩種動機：

### 外在動機（Extrinsic Motivation）

**為了外部獎勵 / 避免懲罰而做**。

例：
- 為了分數讀書
- 為了薪水工作
- 為了父母期待而學
- 為了社會認可學某個領域

**特徵**：
- 獎勵消失 → 動機消失
- **容易短期有效，長期消耗**
- 產生「I have to」的感受

### 內在動機（Intrinsic Motivation）

**為了活動本身的滿足感而做**。

例：
- 因為好奇而讀書
- 因為有趣而寫程式
- 因為喜歡這個問題而研究
- 因為想變更厲害而練習

**特徵**：
- 不需要外部獎勵
- **可持續 — 幾年甚至幾十年**
- 產生「I want to」的感受

**長期學習需要內在動機**。外在動機作為輔助，但不能是主力。

## 內在動機的三要素

Deci & Ryan 的 SDT 說，**內在動機來自三個心理需求的滿足**：

### 要素 1：Autonomy（自主）

**你覺得是自己選擇做的，不是被迫**。

**強化自主**：
- **選擇**你真的想學的（而不是被推薦的）
- **決定**怎麼學（方法、時間、節奏）
- **定義**你自己的目標

**削弱自主**：
- 父母 / 公司強迫你學
- 跟隨別人的路徑
- 被死板的課程綁死

### 要素 2：Competence（勝任感）

**你看到自己在進步**。

**強化勝任感**：
- **看到具體進步**（這週做到上週做不到的）
- **挑戰剛好適中**（學習區，Ch 10）
- **獲得回饋**（知道自己對或錯）

**削弱勝任感**：
- 挑戰太難 → 永遠失敗 → 無力
- 挑戰太簡單 → 沒有進步感 → 無聊
- 沒有回饋 → 不知道自己在哪

### 要素 3：Relatedness（歸屬感）

**你覺得跟別人有連結**。

**強化歸屬**：
- 加入一個**學習社群**（有同樣目標的人）
- 跟**導師 / mentor** 有關係
- 對你的學習**對別人有價值**（教學、分享）

**削弱歸屬**：
- 完全孤立的學習
- 沒有人跟你討論、分享
- 感覺自己是唯一在做這件事

## 三要素的實踐

### 強化自主：選自己真的想學的

**一個測試**：如果沒有人知道你在學什麼，你還學嗎？

- **是** → 內在動機夠
- **否** → 多半是外在動機

**挑題目的方法**：

- 哪些東西你**會自己查**（不是被要求查）？
- 哪些書你**讀得下去**不用強迫？
- 哪些話題你**跟朋友聊起來會興奮**？

**這些是你真正想學的**。

**不要**只因為「市場熱」或「聽說有前途」就學。那是外在動機，撐不過幾個月。

### 強化勝任感：可見的進步

**每週記錄你的進步**：

- 這週學到什麼具體的新東西？
- 做到了上週做不到的什麼？
- 下週的具體目標？

**這個記錄**產生勝任感。

**數位工具**：
- 程式員的 GitHub contribution graph
- Anki 的 review 累積
- 部落格 / 寫作的字數累積
- 運動的數據記錄

**視覺化你的進步**。**看得見的累積是強大的內在動機來源**。

### 強化歸屬感：找或建社群

**孤獨學習極度困難**。

**加入一個社群**：
- Reddit 的相關 subreddit
- Discord 的學習群
- 本地的 meetup
- 線上的讀書會

**或者自己建**：
- 開一個部落格 / Substack
- 每週 tweet 學到的東西
- 邀朋友一起學

**你的學習**：

- 一個人做 vs 有 10 個人知道你在做
- 後者的堅持率**高 3–5 倍**

## 內在動機的大敵：過度外在獎勵

**一個反直覺的事實**：**給內在動機的活動加外部獎勵，會削弱內在動機**。

**經典實驗**：

- 一群兒童本來**自發地畫畫**（內在動機）
- 研究者開始**給畫畫獎勵**（貼紙、小禮物）
- 一段時間後，**取消獎勵**
- 兒童**不再畫畫**（比給獎勵前更不想）

**機制**：大腦把活動從「我想做」重新定義為「我為獎勵做」。獎勵沒了，動機也沒了。

**教育含義**：

- 不要**為了成績**而讀書（之後畢業你就不讀了）
- 不要**為了獎勵**而學興趣（你會失去興趣）
- **保護**你的內在動機

**對成人學習者**：

- 工作：別把賺錢當唯一動機（不然退休後會空虛）
- 寫部落格：別太早商業化（追 viewer 會壓扭真誠）
- 學新領域：別只看能不能賺錢（會失去深入的動機）

## 好奇心：最強的內在動機

**好奇心**是內在動機的最純形式。**看到某個謎就想懂**的那種感覺。

### 好奇心的兩種類型

**Diversive curiosity**（發散好奇）：隨便被新東西吸引。
- 滑 Reddit、看 YouTube shorts、隨意瀏覽
- 淺、短暫、不累積

**Epistemic curiosity**（探究好奇）：深入一個主題的渴望。
- 想真的搞懂一個領域
- 深、持久、累積

**這兩種都存在你身上**。你的日常是哪一種主導？

### 培養探究好奇

**好奇心不是固定的**。可以培養：

### 方法 1：讓自己面對「知道與不知道的邊界」

好奇心**在你覺得「我差一點就懂了」時最強**。

**太熟悉的東西** → 沒好奇心（你覺得你懂）
**完全陌生的東西** → 沒好奇心（你不知道在幹嘛）
**剛好在邊界** → **強烈好奇心**

**實用**：**挑略超過你理解**的東西閱讀、研究。

### 方法 2：問「為什麼」

**一個簡單動作**：**對你學到的每個事實，問「為什麼」**。

- 為什麼股票長期漲？
- 為什麼 Python 是動態型別？
- 為什麼人會有認知偏誤？

**連續問「為什麼」**會讓你進入真正的深度。

### 方法 3：找讓你「驚訝」的東西

**學習的火花**通常來自驚訝：

- 「咦，這個跟我以為的不一樣」
- 「原來 X 是這麼運作的？」
- 「這個跟 Y 竟然有關？」

**驚訝 = 現實與你的模型不符 = 學習機會**。

**刻意尋找**驚訝。讀跟你世界觀不同的書。

## 動機的不同階段

**學一個長期技能**的動機有階段：

### 階段 1：蜜月期（0–3 個月）

**新奇感驅動**。什麼都感覺新鮮。進步快。

**容易的陷阱**：以為「學習就該這麼簡單」。

### 階段 2：撞牆期（3–12 個月）

**新奇感消失**。進步變慢。碰到真實的困難。

**90% 的人在這放棄**。

**度過的關鍵**：**有內在動機**（不是新奇感）**支撐**。

### 階段 3：高原期（1–3 年）

**長期進步**。有時看不到進步，但累積中。

**這個階段**對很多人**無聊**。但大部分深度在這階段形成。

**需要的動機**：**享受過程本身**。

### 階段 4：精通期（3+ 年）

**能看到自己的領先**。獲得自信。
但也看到**自己不知道的有多少**（絕望谷）。

**這階段的動機**：**對領域的深愛**，以及**教別人、分享**的滿足。

**多數人永遠到不了這階段** — 因為沒度過階段 2。

## 一個實用的動機工具：Why 文件

**建議**：**為你每個重要的學習項目**，寫一份 **Why 文件**。

**內容**：

- **為什麼我要學這個？**（最深的理由）
- **這對我 5 年後的意義？**
- **如果 3 年後我精通這個，我會怎麼樣？**
- **當我累了想放棄時，我該想起什麼？**

**用法**：

- 開始學時寫一次
- **卡住、想放棄時**拿出來讀
- 每 3–6 個月**更新**

**這個文件**是你的動機錨。當熱情冷卻時它讓你**記起你為何開始**。

## 動機管理：每天的實踐

**動機不是一次性的**，是**每天管理**的。

### 每天的小儀式

- **早上確認**：今天我要做什麼學習？為什麼？
- **晚上回顧**：今天做到了什麼？明天什麼？
- **週末反思**：這週進步了嗎？方向對嗎？

### 處理低潮

**所有學習者都有低潮**。**預期它，處理它**：

**症狀**：
- 不想打開書
- 感覺「學了也沒用」
- 羨慕別人做別的

**處理**：

- **不要立刻放棄**。先 4–5 天看看（可能只是疲倦）
- **減量而非停止**（今天只學 15 分鐘，不是完全不學）
- **重新連結 Why**（讀你的 Why 文件）
- **換方式**（不同主題、不同工具）
- **休息**（如果真的累了，休息 1 週）

**你不會永遠在高動機狀態**。**有系統地處理低潮**是長期學習者的秘密。

## 害怕失敗：動機的殺手

**許多人的學習動機被「害怕失敗」殺死**：

- 不敢開始（怕失敗）
- 不敢挑戰難的（怕挫敗）
- 不敢公開（怕被笑）

**對抗方式**：

### 1. 重新定義失敗

**失敗 ≠ 你不好**。**失敗 = 你在嘗試超過現在能力的事**。

**真正的失敗**：**不嘗試**。

### 2. 擁抱「初學者的勇氣」

**所有專家都曾是笨拙的新手**。**寫爛程式、寫爛文章、彈爛曲子、投資賠錢** — 都是過程。

**新手勇敢 = 專家的搖籃**。

### 3. 跟自己比，不跟別人比

**網路讓你總是看到「比你強的人」**。

**這會破壞動機**：覺得自己永遠不夠好。

**正確視角**：**跟一年前的你比**。你進步了多少？

## 一個長期觀察：堅持 > 天分

**10 年尺度的學習者**，**堅持**比**天分**重要。

**一個天分 9 分但堅持 1 個月的人** → 最後進步小
**一個天分 5 分但堅持 10 年的人** → 最後深度驚人

**你看到的「神人」**（在領域內極強的人）通常不是**最聰明的**，是**最堅持的**。

**堅持**的本質 = 在**撞牆期**和**高原期****繼續做**。

**這需要的不是意志力**，是**動機的管理**（本章講的）。

## 一個心法：享受過程本身

最終的動機心法：**讓過程本身就是獎勵**。

**如果你只在意結果**，你會：
- 做得不開心
- 進度慢時失望
- 達成目標後空虛（下一個目標是什麼？）

**如果你享受過程**，你會：
- 每天的學習都是滿足
- 結果成為副產品
- 能持續幾十年

**學會享受學習本身**是最高的內在動機。

**怎麼學會**：
- **慢下來**（不追求快速）
- **注意細節**（看你學的東西的美）
- **感謝**你在學的事
- **跟同好分享**（放大樂趣）

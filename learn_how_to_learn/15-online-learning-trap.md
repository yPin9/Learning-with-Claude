# Ch 15 — 線上課程與 YouTube 學習的陷阱

> 2020 年後，線上學習平台爆發。Udemy、Coursera、YouTube 上的教學影片無窮無盡。很多人**收藏了幾百小時的課程卻什麼都沒學會**。這一章講為什麼 — 以及怎麼讓線上學習真的有效。

## 一個你可能認得的情境

你想學 Python。你：

1. 找一門評分高的 Python 課程（50 小時）
2. 買下來，或加入 watch later
3. 開始看第一節，覺得「講師講得真好」
4. 繼續看，邊看邊點頭
5. 幾集後開始跳過「我已經懂的部分」
6. 進入「感覺已經會了」的階段
7. 課程進度 40%，放著
8. **兩個月後回來**，發現**什麼都不會寫**

**這就是「tutorial hell」**（教學地獄）。

**它不是你的問題，是線上學習的結構性問題**。

## 為什麼線上課程容易無效

### 問題 1：被動消費的極致

看影片是**極低認知負荷**的動作：

- 你不用自己產生任何東西
- 講師已經把一切預處理好（順序、重點、例子）
- 你的大腦只需要**跟著走**

**這違反了 Ch 2 的核心原則**：學習的本質是提取，不是編碼。看影片 100% 是編碼、0% 是提取。

### 問題 2：流暢性錯覺的最大產生器

**看一個優秀講師解釋**某個概念：
- 他講得清楚
- 你能跟上
- 你覺得「懂了」

**但你沒做這件事**：**你自己從零開始解釋或實作這個概念**。

你以為懂了，其實只是**辨識**了這個概念。

關掉影片後讓你自己做 — 你做不到。

### 問題 3：進度假象

線上課程有進度條（已看 34%）、勾勾（已完成第 5 節）。

**這些指標衡量「觀看量」，不衡量「學習量」**。

你可以看完 100% 卻什麼都沒學會。你可以**只看 10%**（配合主動練習）卻真的掌握。

**進度條騙你**。

### 問題 4：「下一節」的拖延

看完一節，下一節自動播放。你**不停下來整理、做 blank page、做題**，直接進入下一節。

**整個過程中，沒有一次主動提取的機會**。

### 問題 5：節奏是講師的，不是你的

每個人需要的深度不同：

- 你 10 秒就懂的概念，講師講了 5 分鐘
- 你 10 分鐘才能消化的概念，講師 30 秒帶過

**你跟著講師的節奏 = 在**你不需要的地方花太多時間，**在你需要的地方不夠**時間。

## YouTube 學習的特殊問題

YouTube 更極端：

### 額外問題 1：無限滾動

看完一個影片，側邊 10 個推薦。你點一個、再一個、再一個...

**三小時過去，你「學」了十個主題**，但每個都沒深入。

這叫**「知識的糖水」**：感覺在學習，實際上只是娛樂。

### 額外問題 2：娛樂化的內容

YouTube 的演算法獎勵**留住注意力**的影片。結果：

- 吸引人的標題
- 戲劇化的敘事
- 快節奏剪輯
- 但**缺少深度**

**有深度的影片**通常不紅（因為慢、沈悶、需要專注）。

**你被推的多半是淺的**。

### 額外問題 3：偽專家

YouTube 任何人都能當老師。很多「教投資」「教程式」「教健康」的頻道，講的是**錯誤或過時的東西**，但因為影片製作精良而顯得權威。

**沒有認證機制**。你要自己判斷。

### 額外問題 4：看代替做

某些主題適合用影片學（例：visually 強的東西 — 解剖、物理、駕駛）。

**但大多數主題**（程式、寫作、分析）**必須你自己做**才能學會。

看影片 = 看別人做，不是你做。

## Tutorial Hell 的診斷

你是不是在 tutorial hell？檢查：

- 你有幾門**沒看完的**線上課程？（超過 2 門就是訊號）
- 你**看完**課程後能**自己**做類似的事嗎？
- 你**看完一章後**立刻打開下一章，還是會停下來做練習？
- 你在「學」但**實際上一年了還在入門階段**？

**如果以上多數指向「你一直在看但沒在做」** — 你在 tutorial hell。

## 讓線上學習有效的策略

不是不用線上資源。是**改用的方式**。

### 策略 1：看少，做多

**規則**：**每看 15–20 分鐘，必須停下來做 45 分鐘**。

「做」是什麼：

- 寫程式（如果是程式課）
- blank page（如果是知識課）
- 做習題（如果是數學）
- 費曼解釋（任何課）

**比例應該是看 25% / 做 75%**。大多數人是看 95% / 做 5%。

### 策略 2：選一門，完成它

**不要同時報名 10 門課**。選一門，認真看完（用策略 1 的方式）。

**一門真的學會的課 > 十門看了一半的課**。

### 策略 3：跳過你懂的部分

大多數課程**有重複或你已會的部分**。不要為了「完成度」看完。

**2 倍速**看過你懂的部分，**正常速**看新的。

這不是偷懶 — 是**把時間花在真正學習的地方**。

### 策略 4：做 Cornell / 費曼式筆記

看影片時**暫停**，寫自己的筆記（不是照抄）。

**結構**：

- **問題**：這段講什麼的問題？
- **關鍵概念**：用自己話寫（3–5 條）
- **我的理解**：我懂了嗎？有哪些不懂？
- **應用**：我要怎麼應用？

寫完這些再繼續。**這個 5 分鐘勝過 30 分鐘純看**。

### 策略 5：看完後做主動回憶

看完一節（或整個課程）後，**合上螢幕**：

- 寫下你學到了什麼
- 試著從零解釋這個主題
- 列出你還不確定的地方

**這是 Ch 8 的主動回憶應用到線上學習**。

### 策略 6：立刻應用

**看完一個技能型課程後**，**馬上做一個實際的東西**：

- 學 Python 的 class → 立刻寫一個 class 解決你的問題
- 學 SQL → 立刻查詢你的資料
- 學繪圖工具 → 立刻做一張圖

**沒有立刻應用，看過等於沒看**。

### 策略 7：用 YouTube 的右邊選擇

YouTube 是雙面刃。**有深度好內容**，也有**糖水**。

**選擇右邊**：

- **長影片**（30 分鐘以上的深度分析，通常比 10 分鐘的好）
- **特定的頻道**（而不是演算法推的）
- **不是 trending**（熱門多半是熱度優先）

**好頻道的特徵**：
- 有 references、連結到論文或原典
- 不用噱頭的縮圖
- 不製造焦慮、不賣速成
- 訂閱數相對少（數百萬訂閱的多半是淺的）

**建議**：建立自己的「高品質頻道清單」，只看這些。不看演算法推的。

## 線上課程 vs 書本：哪個好？

**粗略的經驗**：

### 線上課程的優勢

- **視覺化強**：難用文字描述的東西（動畫、互動）
- **手把手指導**：步驟示範
- **有人聲陪伴**：孤單時比較友好
- **最新的內容**（書出版慢）

### 書本的優勢

- **你的節奏**：看得快看得慢都你決定
- **密度**：一本好書的深度 > 一個小時的影片
- **回查方便**：跳到特定章節、劃線、記憶（紙本）
- **被動地誤用較難**：你必須主動處理字

**建議**：

- **入門期**：用線上課程（快速看完全景）
- **深入期**：轉到書本（深度）
- **複習 / 延伸**：兩者都用

**最常見的錯誤**：一輩子只用線上課程，從不讀書。

## 一個例子：學 Python

**低效做法**：買一門 50 小時的 Python 課程，從頭看到尾。

**高效做法**：

1. **看一本入門書**（例：Zed Shaw 的《Learn Python the Hard Way》或官方 tutorial）
2. **跟著做每個例子**
3. **做完一章後，寫一個自己的小程式**用這章的概念
4. **遇到具體問題時**，查特定的影片或 Stack Overflow
5. **做一個實際專案**（見 Ch 24 Project-First）
6. **需要特定主題深入時**，找一個好的線上課程**針對性**地看

**這不是單一資源能解決**。需要**書 + 練習 + 專案 + 針對性影片** 的組合。

## 一個警告：品牌化的學習產品

市場上有**很多**販賣學習焦慮的產品：

- 「30 天成為資料科學家」
- 「一個月精通 React」
- 「被動收入速成班」

**這些幾乎全部是騙人的**。

**學習的時間尺度是年，不是月**（Ch 0 就講過）。

**付錢買這些產品的人**，多半是為了**感覺自己在學**，不是真的學會。

**如何判斷**：

- **有真實成就感示例**（學生真的做出了什麼）— 可能有用
- **只有勵志與「你也可以」** — 多半是行銷
- **定價高於書的 50 倍** — 通常是品牌溢價，不是內容溢價

**免費的 MIT OpenCourseWare、Coursera 的免費課程，品質往往比付費的「速成班」好**。

## 一個現實：影片時代的深度危機

近年一個文化現象：**短影片、TikTok 式內容**正在影響人的注意力模式。

很多人**已經無法專注看超過 10 分鐘的單一影片**，更不用說讀一本書。

**這是認知能力的萎縮**。而且它**隱形地發生**：

- 你不會注意到自己無法深入了
- 你會合理化為「現代生活節奏快」
- 你會覺得「我不需要深度，快速吸收就好」

**但學複雜的東西需要深度**。沒有深度注意力，你學不會複雜東西。

**對抗方式**：

- **限制短影片**（設時間上限）
- **定期讀長篇文章、書**（訓練長注意力）
- **看長影片而非短的**（30 分鐘的深度 > 30 個 1 分鐘的淺的）

這是**你的基礎認知能力的投資**，比任何具體課程更重要。

# Ch 8 — marks / folds / 捲動：大檔定位

> **目標**：掌握在**單一大檔**內定位的三組工具——**marks（標記攻堅點反覆回來）、folds（折疊看大結構）、捲動對齊（把當前行置中/頂/底看上下文）**。前面幾章讓你在檔裡快速移動；這章讓你**主動組織一個大檔**：標下你關心的幾個點、把不看的部分收起來看骨架、把在讀的那行擺到最舒服的位置。這是 Part 1 的收尾——motion 是「怎麼到」，這章是「怎麼在一個 2000 行的檔裡不迷失」。

> **環境**：Neovim v0.12.4，WSL2。範例用 Lua 的 `lvm.c`（1978 行，`luaV_execute` 主迴圈在 1204 行、長達好幾百行的 switch）。

## 為什麼需要這個？

讀 `lvm.c` 的 `luaV_execute`——一個 1204 行起、內含 86 個 `vmcase` 的巨型 dispatch 迴圈。你在讀 `OP_ADD` 的 handler，但要不時回去看迴圈開頭的變數宣告（`ci`、`base`、`pc`），又要跳去看 `OP_FORLOOP` 對照。這一趟你會反覆造訪三四個定點。

問題：這三四個點你怎麼「記住」並快速回去？`Ctrl-O`（jumplist）能退回**線性路徑**，但你要的是「反覆跳到我標的那幾個定點」，不是沿路退。這就是 **marks**——你手動釘幾個書籤，`` `a `` 一鍵飛過去。

另一個問題：`luaV_execute` 太長，你想先看它的「骨架」——有哪些 case、大結構長怎樣——不想被幾百行細節淹沒。這是 **folds（折疊）**：把 block 收起來只看標題，看清大結構再展開你要的那塊。

第三個問題：`1204G` 跳到函式，游標落在螢幕最上面，你看不到它上面的 context（函式簽名前的註解）。`zz` 把當前行拉到螢幕正中央，上下文一次看好看滿。這是**捲動對齊**。

三者都在解同一件事：**在一個大到裝不進一屏的檔裡，怎麼組織你的視野與定點**。

## 先建立直覺：三者是「定點 / 視野 / 對齊」三個維度

前面幾章的 motion 都在回答「怎麼**到**一個位置」。這一章換一個維度——你人已經在大檔裡，問題變成「怎麼**管理**這個大檔的視野」：

```
    一個 1978 行的 lvm.c，你的螢幕只看得到 ~40 行：

    ┌─ marks（定點）───────────────────────────────┐
    │  在檔裡釘幾個書籤，隨機存取地飛回去            │
    │    ma → OP_ADD    mb → 迴圈入口    mc → OP_FOR │
    │    `a `b `c 任意跳，不管中間隔幾百行           │
    ├─ folds（視野的縮放）─────────────────────────┤
    │  把不看的收起來，只留骨架                      │
    │    zM 全折 → 每個函式/case 收成一行標題        │
    │    za 展開你要細看的那一塊                     │
    ├─ 捲動對齊（視野的定位）──────────────────────┤
    │  游標不動，把它在螢幕上擺到最佳位置            │
    │    zz 置中（上下文對稱）  zt 頂  zb 底         │
    └───────────────────────────────────────────────┘
```

心智模型三句話：**mark 是「我要反覆回來的點」，fold 是「我現在想看多細」，捲動對齊是「把在讀的行擺哪」。** 三者正交——你可以同時用（折疊看骨架、mark 標幾個 case、跳過去 `zz` 置中細讀）。它們和前面的 motion/jumplist 也正交：jumplist 記你走過的路（自動、線性），mark 記你選的定點（手動、隨機），兩套堆疊各管一件事。

## 核心一：marks——手動標記攻堅點

mark 是你在檔裡釘的**書籤**。設一個、跳過去：

- `m<字母>`：在當前位置設一個 mark。`ma` 設 mark `a`
- `` `<字母> ``（反引號 + 字母）：跳到 mark 的**精確位置**（行 + 欄）
- `'<字母>`（單引號 + 字母）：跳到 mark 所在**行的行首**
- `:marks`：列出所有 mark

小寫 vs 大寫的關鍵差別：

- **小寫 mark（`a`–`z`）**：**buffer-local**——`ma` 只在當前檔有效，換檔後 `` `a `` 無意義
- **大寫 mark（`A`–`Z`）**：**全域、跨檔**——`mA` 記「哪個檔的哪一行」，`` `A `` 從任何檔跳過去，還跨 session 保存

讀碼實戰（讀 `luaV_execute`）：

```
    1204G           跳到 luaV_execute 開頭
    ma              設 mark a（迴圈入口 = 我的錨點）
    /OP_ADD<CR>     搜到 OP_ADD handler
    mb              設 mark b
    /OP_FORLOOP<CR> 搜到 OP_FORLOOP
    mc              設 mark c
    ── 現在 `a `b `c 三鍵在三個攻堅點間任意飛 ──
```

`` `a `` 回迴圈入口看變數宣告、`` `b `` 回 OP_ADD、`` `c `` 去 OP_FORLOOP。**這比 jumplist 適合「反覆造訪固定幾個點」**——jumplist 是路徑（線性、自動），mark 是定點（隨機存取、手動）。

**大寫 mark 跨檔標攻堅點**：追一條橫跨 `lvm.c` / `lapi.c` / `lgc.c` 的路徑時，在每個檔的關鍵函式設 `mA` `mB` `mC`，之後 `` `A `` `` `B `` `` `C `` 在三個檔的三個定點間跳——不管你現在在哪個檔。這是跨檔攻堅的「傳送點」。

**自動維護的特殊 mark**（Ch 5 提過，這裡歸位）：

- `` `. ``：上次**修改**的位置
- `` `^ ``：上次**離開 insert** 的位置
- `` `` ``：上次**跳轉前**的位置（兩點來回）
- `` `[ `` / `` `] ``：上次被 yank/貼上 的區域起訖
- `` `< `` / `` `> ``：上次 visual 選取的起訖

## 核心二：folds——折疊看大結構

fold（折疊）把一段行收合成一行摘要，讓你看「骨架」而非「全文」。

**折疊方法（foldmethod）**——先決定「怎麼判斷該折哪裡」：

- `indent`：依縮排折（簡單、零設定，適合掃結構）
- `syntax`：依語法折
- `expr` + treesitter：**依真正的語法樹折**（最準，Part 3 會設；折 function/block 剛好對）
- `manual`：你手動框選要折的（`zf`）

讀碼建議用 treesitter 的折疊（Part 3 Ch 13/14 接上），能精準折到「每個函式收成一行」。這章先用內建方式建立操作直覺。

**折疊操作鍵**（zf 系列，`z` 像折起來的紙）：

| 按鍵 | 作用 |
|---|---|
| `zf<motion>` | 建立折疊（fold）。`zfi{` 折當前 block、`zfap` 折一段 |
| `za` | **toggle** 當前折疊（開↔關，最常用） |
| `zo` / `zc` | 打開（open） / 關閉（close）當前折疊 |
| `zR` / `zM` | 打開**全部** / 關閉**全部**折疊（Reduce / More folding） |
| `zj` / `zk` | 跳到下一個 / 上一個折疊 |
| `zd` | 刪掉當前折疊（delete fold，manual 模式） |

讀碼實戰：打開 `lvm.c`，`zM`（全折）——整個檔收成一列列折疊標題，每個函式一行。你一眼看到「這檔有這些函式」的骨架（配合 treesitter 折得最漂亮）。想細看 `luaV_execute`？游標移過去 `zo`（或 `za`）展開它，其他仍折著。**這就是「先看大結構、再展開你要的那塊」**——`reading_code` 掃讀階段的視覺化利器。

在 `luaV_execute` 內部：`zM` 把每個 `vmcase` block 折成一行，你看到「86 個 case 的清單」，鎖定 `OP_ADD` 那行 `za` 展開細讀。折疊讓你在一個幾百行的 switch 裡不被淹沒。

## 核心三：捲動對齊——把當前行擺到最佳位置

跳到一個位置後，游標落在螢幕哪裡影響你能看到多少上下文。這三個鍵**重新捲動螢幕、但不動游標邏輯位置**：

- `zz`：把當前行捲到**螢幕正中央**（上下文對稱看）
- `zt`：把當前行捲到**螢幕頂端**（往下看，適合「從這函式開始往下讀」）
- `zb`：把當前行捲到**螢幕底端**（往上看）

讀碼實戰：`1204G` 跳到 `luaV_execute`，游標落在螢幕頂——你看不到函式簽名上面的註解。按 `zz`，函式定義行移到正中央，上面的註解 + 下面的函式體同時可見。**「跳過去 + `zz`」幾乎是一組連招**：`1204Gzz`、`/OP_ADD<CR>zz`。

`zt` 適合「我要從這一行開始往下細讀整個函式」——把它頂到最上面，下面留最大空間給函式體。

**`scrolloff`（Ch 0 設了 `= 8`）**是相關設定：游標上下永遠保留 8 行 context，你不會捲到游標貼著螢幕邊緣、看不到接下來幾行。這是「捲動時永遠留一點前後文」的自動版，讀碼很重要——你追一行 code 時總看得到它的鄰居。

## 對比與取捨

| 你想做的事 | 工具 | 動作 |
|---|---|---|
| 反覆造訪同檔的幾個定點 | mark | `ma`/`mb` 設，`` `a ``/`` `b `` 跳 |
| 跨檔的傳送點 | 大寫 mark | `mA`/`mB` 設，`` `A ``/`` `B `` 跳 |
| 追一趟路徑再退回 | jumplist（Ch5） | `Ctrl-O`/`Ctrl-I` |
| 最近兩點來回 | `` `` `` | 反覆按 |
| 看大檔骨架（有哪些函式） | fold | `zM` 全折看標題 |
| 只看某函式細節 | fold | 游標移過去 `za` 展開 |
| 跳過去後看到完整上下文 | 捲動對齊 | 跳完接 `zz` |

**mark vs jumplist vs harpoon（Part 6 Ch 26）** 的完整分工：jumplist 是**自動、線性**的路徑（追一趟退回）；mark 是**手動、隨機存取**的定點（反覆造訪固定幾點）；harpoon 是 mark 的升級——選單化、跨 session、`<leader>1`/`<leader>2` 直接跳到「我釘的第 1/2 個檔」，解決「大寫 mark 只有 26 個字母、要記哪個字母是哪」的痛點。這章先把原生 mark 練熟，它是 harpoon 的概念地基。

## 踩雷集錦

1. **搞混 `` ` ``（反引號）和 `'`（單引號）跳 mark**。`` `a `` 跳到精確位置（行+欄），`'a` 只跳到那行行首。讀碼要精確落點通常用反引號 `` ` ``。反引號難按，很多人把它綜合綁到別的鍵，但先知道差別。
2. **小寫 mark 換檔後失效還以為壞了**。小寫 mark（`a`–`z`）是 **buffer-local**——`ma` 只在設的那個檔有效。要跨檔跳用**大寫** mark（`mA`，全域）。這是設計，不是 bug。
3. **`zf` 建了折疊，重開檔案就沒了**。manual 折疊不會自動保存。要保存得靠 `:mkview`/`viewoptions`（或設 `foldmethod=expr`+treesitter 讓折疊由語法自動算出，重開就在）。讀碼建議走 treesitter 自動折疊（Part 3），不手動 `zf`。
4. **`zc` 折不起來，說 "No fold found"**。當前 `foldmethod` 沒在這行算出折疊。內建預設 `foldmethod=manual` 你沒手動建過就沒得折。先 `:set foldmethod=indent`（或上 treesitter）才有東西可折。
5. **`zz` 和 `ZZ` 打錯**。`zz`（小寫，兩個 z）是捲動置中；`ZZ`（大寫）是**存檔並退出**！讀碼手滑打成 `ZZ` 會直接關掉。看清大小寫。
6. **設太多小寫 mark 記不住哪個是哪**。`a` `b` `c` 三四個還行，設到 `m` `n` `x` 就忘了各是啥。這正是 harpoon（Part 6）要解決的——與其硬記字母，不如用選單。原生 mark 適合「當下這趟、少數幾個」。

## 進階：再往深一層

- **mark 進 jumplist 且能配 operator**：`` `a `` 是一個 motion——`d`a` 從當前刪到 mark a、`y'a` 複製到 mark a 那行（linewise）。讀碼少用，但知道 mark 是 motion 有助理解它的正交性。設 mark 也會讓某些跳轉進 jumplist。
- **`:delmarks`**：清 mark。`:delmarks a` 清 mark a、`:delmarks!` 清所有小寫 mark。攻堅完一個函式，清掉舊 mark 換下一批。
- **折疊的 `foldlevel` / `foldtext`**：`foldlevel` 控制「一打開檔就折到第幾層」（`zm`/`zr` 逐層增減折疊深度，比 `zM`/`zR` 細緻）；`foldtext` 客製折疊標題長什麼樣（顯示函式簽名 + 行數，讓折疊標題更有資訊）。Part 3 上 treesitter 折疊時可調。
- **`gv`**：重選上次 visual 選取（用 `` `< `` `` `> `` 那對 mark）。讀碼時「剛剛選中那段我想再看一次」用 `gv` 一鍵重選，不用重框。
- **view / session**：`:mkview` 存單檔的折疊狀態 + 游標位置，`:loadview` 還原。整組佈局的保存是 session（Part 6 Ch 27）。攻堅跨天時，這讓你隔天回到一模一樣的折疊與定點。

## 本章重點整理

- **marks 是手動釘的定點**：`ma` 設、`` `a `` 跳，適合「反覆造訪同檔幾個攻堅點」；**小寫本檔、大寫全域跨檔**（跨檔傳送點）。與 jumplist（自動線性路徑）互補。
- **folds 折疊看大結構**：`zM` 全折看骨架（每函式一行）、`za` 展開要看的那塊——掃讀階段的視覺利器。讀碼建議走 treesitter 自動折疊（Part 3）而非手動 `zf`。
- **捲動對齊**：跳過去後接 `zz`（置中）/`zt`（頂）/`zb`（底），把在讀的行擺到最佳位置看上下文；`scrolloff=8`（Ch 0）自動留前後文。
- 三者共同解決「一個大到裝不進一屏的檔裡怎麼組織視野與定點」。mark 是 Part 6 harpoon 的地基。

# 華語辯論競賽全攻略：從零到新國辯冠軍

> 給完全沒有比賽經驗、目標是 2027 新加坡國際華語辯論賽（新國辯）冠軍的選手。

這套教材從「辯論是什麼」開始，走完立論、攻防、自由辯、結辯、辯題研究、名局拆解，最後落地到完整備賽計劃。不是辯論學理論書，是競賽訓練手冊——每一章都有可以拿去練的東西。

## 為什麼從零能打新國辯？

- **新國辯看的是體系，不是天賦**：頂尖隊伍贏的是框架清晰、攻防配合，不是誰嘴皮子快
- **兩年時間夠用**：2025–2027，系統訓練一年半，後半年衝刺，有人更短時間做到過
- **教材比帶隊教練更可靠的地方**：你可以反覆翻、隨時對照，帶隊教練不一定有時間

## 學習方式建議

1. **每章讀完立刻說出來**：對著鏡子或錄音，用自己的話重述核心概念，說不出來就再讀一遍
2. **練習題不要跳**：立論工坊（練習 A）是後面所有章節的地基，跳掉後面會空轉
3. **看真實比賽影片對照**：每讀完一個 Part，找一場新國辯的影片，用這 Part 學到的眼光重新看一遍

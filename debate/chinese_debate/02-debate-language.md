# Ch 2 — 辯論語言入門

> 目標：建立一套統一的辯論術語，讓你讀後面的章節時不用反覆查字典，也讓你和隊友溝通有共同語言。

## 一場辯論的四層結構

每一方的主張，都可以分解成四層：

```
立場（Position）
  └── 標準（Criterion）
        └── 論點（Argument）
              └── 例證（Evidence / Example）
```

**立場**：你方的整體主張。就是辯題裡你支持的那一側。「科技讓人更幸福」或「科技讓人更不幸福」。

**標準**：用來評判「誰說的對」的尺子。我方認為衡量這道題應該看「長期社會影響」，而不是「個人主觀感受」——這就是標準。

**論點**：在這個標準下，你為什麼說你對。「科技讓資訊傳遞效率提升，降低了決策成本，長期來看提升整體社會幸福感。」

**例證**：讓論點變得具體可信的材料。數據、案例、類比、歷史事件。

## 核心術語表

| 術語 | 定義 | 常見誤用 |
|------|------|----------|
| **辯題** | 本場比賽要討論的命題 | 不要和「論點」混用 |
| **立場** | 你方在辯題上的整體態度（正/反）| — |
| **框架（Frame）** | 你方對這場比賽「該在哪個維度討論」的主張 | 常被誤以為等同「立論」 |
| **標準（Criterion）** | 評判勝負的尺子；你希望裁判用什麼衡量 | 不是「論點」，是「論點的評判規則」 |
| **論點** | 在框架和標準下支持你方立場的一個推論 | 不要把例證當論點 |
| **例證** | 支撐論點的具體材料（數據 / 案例）| 例證本身不能替代論點 |
| **立論** | 正式比賽中的開場陳述；包含框架、標準、論點、例證 | 不等同於「論點」 |
| **質詢** | 問問題環節；一方向另一方問 | 不是辯論；問問題不是說立場 |
| **自由辯論** | 雙方自由交鋒的環節；不固定發言順序（依賽制而定）| — |
| **結辯** | 最後陳述；梳理整場比賽的得失，給裁判最終印象 | 不是「再說一遍立論」 |
| **回應（Response）** | 針對對方論點的反駁或解釋 | 不是「忽視對方後繼續說自己的」 |
| **拆論** | 攻擊對方論點的邏輯或例證，讓它失效 | — |
| **讓步（Concession）** | 承認對方某個點有道理，但說明它不影響大局 | 適當讓步不是失分，是高手表現 |
| **攻擊線（Attack Line）** | 你打算從哪個角度攻擊對方；賽前就要想好 | — |
| **必爭點（Clash Point）** | 雙方立場必然衝突的核心爭議；這裡輸了就整體輸了 | — |

## 「論點」和「例證」的差別——新手最容易混淆

**論點**：一個推論，有邏輯結構的主張。

> 「AI 輔助醫療診斷降低了誤診率，讓更多患者得到正確治療，因此科技提升了社會整體健康水平。」

**例證**：讓上面那個推論更可信的材料。

> 「根據 2023 年 Nature Medicine 的研究，AI 診斷某類皮膚癌的準確率達 94.5%，高於平均皮膚科醫師的 86.6%。」

沒有論點只有例證：你說了很多故事，裁判不知道你要主張什麼。
沒有例證只有論點：你說的聽起來有道理，但裁判無法相信你。

## 什麼是「框架」

框架是比標準更上一層的東西——它決定「這場比賽在什麼維度上討論」。

辯題：「科技的發展讓人類更幸福」

可能的框架競爭：

| 框架 | 你在主張什麼 |
|------|-------------|
| 個體主觀感受框架 | 幸福是個人感覺，要看個人說不說自己幸福 |
| 社會整體福祉框架 | 幸福應以客觀指標衡量（預期壽命、基尼係數等）|
| 長期 vs 短期框架 | 要看百年尺度的趨勢，不是當下的感受 |

正反方爭框架，贏的那方等於「在自己最熟悉的賽場上打比賽」。**定義戰（Ch 25）的核心就是搶框架。**

# 用 AI agent 帶來被動收入（passive income with AI）

> 這個分類跟其他分類不一樣：它**不是教學課程**，是一組**可操作的 playbook ＋ 腳本**——拿來就能照著做、把腳本接起來跑的作業手冊。

## 先講清楚：「被動」是理想，不是現實

這裡所有項目的共同前提，先說在前面：

- **這些是「會累積的資產 / 流量水龍頭」，不是「印鈔機」。** 前期都是純付出，要花時間建立、且要持續維護。真正能省力的是「AI 砍掉重複勞動」那一段，不是「躺著就有錢」。
- **沒有保證數字。** 任何跟你保證「月入 X 萬」的都在唬你——市面上很多「教你被動收入」的內容，本身就是靠賣那套教學賺錢。本分類給的是**把每一步做到位的方法與工具**，數字得你用自己的真實數據算。
- **合規與真實價值是底線，不是選配。** 平台（Google、蝦皮、Meta）都在懲罰「大量、低價值、操弄性」的內容與行為。**唯一長久的做法是真的對讀者/消費者有用、且照規矩揭露。** 想走捷徑量產垃圾的，這裡幫不了你（而且那條路本來就會被演算法埋掉）。

## 共用的設計原則

每個項目都遵守這幾條（很多直接借用本 repo 的 [harness_engineering](../ai/harness_engineering/README.md)）：

1. **把流程當 agent harness**：選題/選品 → AI 產內容 → **品質閘** → 發佈 → 追蹤 → 數據回饋。
2. **品質閘不可繞過、且是地板不是天花板**：AI 草稿一律先過閘（合規、價值訊號）再上線；別為了過閘作弊——平台的演算法比你的閘嚴得多，最後是它替你打真分數（Goodhart）。
3. **用真實數據而非感覺**：每個項目都有 tracker，用「漏斗轉換 + ROI」決定什麼該留、什麼該砍。
4. **誠實**：腳本不爬違反 ToS 的資料、不杜撰數字、認識論誠實（不確定就標示）。

## 項目

### ⭐ [threads_shopee_affiliate](./threads_shopee_affiliate/README.md) — Threads × 蝦皮分潤（主力）
近年台灣做蝦皮分潤**很常見的起步通路**：短社群貼文衝互動、把分潤連結放第一則留言、靠 Threads 的陌生人流量擴散。包含兩種用法：
- **拆解別人**：蒐集＋判讀別人的爆文「哪些有流量、為什麼」的框架（`collection_sheet.csv` + `post_teardown.py`）。
- **自己產**：選品 → AI 產鉤子貼文 → 過閘 → 發佈（內文＋留言連結）→ 追蹤的半自動 pipeline。

### [seo_shopee_affiliate](./seo_shopee_affiliate/README.md) — SEO 內容站 × 蝦皮分潤（長線輔助）
另一條較慢、較長線的通路：寫評測/選購指南，靠 Google 自然搜尋帶流量，文章內嵌分潤連結。和 Threads 互補——**Threads 是會沉的流量水龍頭，SEO 是養得久的累積性資產**。包含關鍵字選題打分、AI 產文、上線前品質閘、連結與成效追蹤。

> 兩個項目都針對「蝦皮分潤」這個變現方式，差別在**通路**（社群即時流量 vs 搜尋長尾流量）。建議先從 Threads 起步（回饋快、門檻低），有餘力再用 SEO 養長線資產。

## 開始前：註冊蝦皮分潤計畫 + 產生連結（兩個項目共用的第 0 步）

要有「分潤」，得先加入蝦皮的官方計畫、拿到你的推廣連結。下面是流程概述，**細節與條款一律以蝦皮官方當期說明為準**（會改）：

1. **申請**：到官方頁 [affiliate.shopee.tw](https://affiliate.shopee.tw) 點「開始使用」，用蝦皮帳號登入；或在蝦皮 App【我的 → 蝦皮分潤計畫 → 進入】。填基本資訊、合作類型選「**部落客／社交媒體**」、連結你的社群帳號後送出。
2. **審核**：蝦皮審核資格，通過後你才是正式推廣夥伴。
3. **產生推廣連結**：兩種方式——(a) 蝦皮 **App 的商品「分享」功能**直接產；(b) **分潤計畫後台（電腦版）**產。**自己拼的連結不算分潤，一定要用官方產的。**
4. **分潤率**：各商品不同、在商品資訊頁可見，官方標示範圍大約 **0.5%–30%**（高比例多為加碼活動，且常有上限與排除項）。**別預設「都很高」，以後台與商品頁為準。**
5. **官方資源**：蝦皮幫助中心有「蝦皮分潤計畫介紹／如何註冊」專文，照官方步驟走最準。

> 兩個項目的腳本（Threads 的 `tracker.py`、SEO 的 `shopee_link.py`）都假設你**已經有官方連結**；它們負責的是追蹤、正規化與對應，不是替你產官方連結。
>
> ⚠️ **先做一次追蹤實測**：先看後台的「點擊數」會不會在你點自己連結後增加（測點擊歸因）；要測到「成單分潤」歸因，**請有真實購買需求的朋友（非同住、無利益交換）透過你的連結下單**——**別自己買來測**，自買/自我推薦多數計畫禁止（self-referral，以蝦皮當期條款為準）。目的是排除「導購/開 App 跳轉覆蓋追蹤」的陷阱，確認連結真的算得到，再大量發。

## 之後可能擴充的方向

同樣的「AI 半自動內容 → 變現」骨架可以換通路/換變現方式（例如 YouTube Shorts 導購、電子報聯盟、數位商品）。每個都會是獨立項目，共用上面的設計原則。

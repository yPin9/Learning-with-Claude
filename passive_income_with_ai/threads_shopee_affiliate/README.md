# Threads × 蝦皮分潤：用 AI 半自動經營（含「拆解別人爆文」的判讀框架）

> **這份是什麼**：本分類的**旗艦項目**。本 playbook 聚焦 **Threads**（短社群貼文 + 留言放連結）這條通路——近年它是台灣做蝦皮分潤很常見的起步管道（門檻低、有陌生人流量），跟 SEO 部落格那條互補（那份在 [`../seo_shopee_affiliate`](../seo_shopee_affiliate/README.md)，當作另一條較慢、較長線的通路參考）。
>
> 它有**兩種用法**：
> - **用法 A — 拆解別人**：蒐集、判讀別人的貼文「哪些有流量、為什麼」，把可複製的打法學起來。（`collection_sheet.csv` + `post_teardown.py`）
> - **用法 B — 自己產**：把「選品 → 產貼文 → 過閘 → 發佈（內文＋留言連結）→ 追蹤」做成半自動 pipeline。（`hook_generator.py` + `post_qa.py` + `tracker.py`）
>
> 🚀 **想直接開工？先看 [QUICKSTART.md](./QUICKSTART.md)**——從註冊蝦皮分潤、選利基、到發出前 10 篇的第一週逐日行動清單。本 README 是原理與細節，QUICKSTART 是「今天就做什麼」。
> 第 0 步「**註冊蝦皮分潤計畫 + 產生官方連結**」見 [分類 README](../README.md)。
> 長期怎麼運轉（發文節奏/A-B/挖爆文/迭代）見 [workflow.md](./workflow.md)；想**一鍵照著跑**用 Claude Code 技能 `/shopee-threads-ops`（[SKILL](../../.claude/skills/shopee-threads-ops/SKILL.md)）。

## 先把醜話講在前面（讀完再做）

1. **演算法細節是「創作者與行銷圈歸納出來的」，不是官方公開規格，而且會變。** 本文寫的互動權重、留言觸及佔比等，是多方一致的觀察與實測心得，**當成假設去驗證，不要當成保證**。Threads/Meta 隨時會調。
2. **我（AI）無法替你量測 Threads 的真實觸及。** 沒有開放 API、要登入、爬它違反 ToS。所以「用法 A」的判讀是**啟發式**——根據貼文打中哪些演算法訊號推估「為什麼會紅」，**不是量到的數字**。要真數據，得你自己看後台/體感，或把你觀察到的讚/留言數餵給 `post_teardown.py`。
3. **不是躺賺。** 蝦皮佣金多在 **1–10%、且很多商品只有 1%**，私人賣場常無分潤，cookie 歸因視窗約 7 天。心得文落差極大：有人四個月賺幾百元，也有人宣稱月入數萬——**月入數萬是少數＋長期高頻經營的結果，「躺著賺」是賣課話術**（市面上「Threads×蝦皮分潤攻略」電子書本身就是一門生意）。
4. **一個會讓你白做的追蹤陷阱**：創作者回報，**用「導購／搜尋跳轉開蝦皮 App」型態的連結，可能覆蓋掉你的分潤追蹤**——點了有進 App、但分潤算不到你頭上。連結型態要用對、並**務必實測**（先看後台點擊數有沒有增加；要測成單就請有真實需求的朋友透過你的連結下單——**別自己買，self-referral 多數計畫禁止**）。
5. **合規不能省**：留言放連結時要**揭露分潤關係**；不得買假讚假留言（違反 Meta 規範、也騙不過長期演算法）；不得自買套利、不得誤導（違反蝦皮條款，會被收回分潤甚至停權）。**以蝦皮分潤計畫當期條款與 Threads 平台規範為準。**

## 一、為什麼 Threads 是現在的主場

- **陌生人流量**：Threads 會主動把貼文推給不認識你的人，**零追蹤也可能單篇觸及上萬**。對素人最友善，這是它打敗「要養半年才有自然流量」的部落格 SEO 的關鍵。
- **門檻低、回饋快**：純文字 + 手機就能做，發完幾小時內就知道有沒有起來，不像 SEO 要等 Google 收錄與排名。
- **代價**：壽命短（貼文紅一兩天就沉）、要持續高頻發、且高度受演算法擺布。它是「流量水龍頭」，不是「會累積的資產」——這點和 SEO 正好互補。

## 二、核心機制：為什麼有些貼文會有流量

這節就是「用法 A」要判讀的東西，也是「用法 B」要打中的訊號。**再次提醒：以下是創作者圈一致的觀察與實測歸納，不是 Meta 官方公開的演算法規格，當「操作假設」用、並自己驗證。**

1. **連結放「第一則留言」，不放內文（主要適用於意見/評測型內容）。** 創作者圈普遍觀察到：意見/評測型貼文若把外連放內文會壓低觸及，放**第一則留言**則不會（先當建議照做、自己比較）。**但有個反直覺的例外**：純「折扣碼/情報」型帳號通常**直接把 `s.shopee.tw` 連結放內文**也照樣經營得起來——因為對那種讀者來說，連結本身就是他要的價值（見 [`case_studies.md`](./case_studies.md) 案例 4）。**所以這條要看內容類型，不是無腦套用。** 不論如何，「第一則留言有沒有蝦皮連結」仍是辨識評測型分潤貼文的關鍵特徵。
2. **留言區是主戰場。** 有創作者回報 **過半觸及來自「會去看留言的人」**（個案說法、非官方指標）。方向上合理：連結放留言不只是避懲罰，留言區本身就是大半互動的所在。
3. **互動權重被認為有高低：留言 ＞ 轉發（小飛機）＞ 複製連結 ＞ 愛心**（創作者歸納、非官方權重）。所以爆文都在**逼留言**：提問、選邊站、留爭議鉤子、「想要連結的留言 +1」。
4. **停留時間（dwell time）。** 讓人停下來讀完內文、又往下讀留言，演算法判定「有興趣」，就繼續推給更多人。長一點、有資訊密度、留言區熱鬧的貼文吃這個紅利。
5. **去商業化／不像廣告。** 太像業配的會被埋。能紅的是**短句觀點、微案例、開箱心得、團購清單、迷因哏**——蝦皮官方帳號自己就是範例（社畜哏、圖文不符）。
6. **承接頁**：連結變多時，用 **Portaly（傳送門）** 這類 link-in-bio 工具把多個分潤連結集中成一個個人主頁，留言放那一頁、或放單一商品連結。

> 一句話判讀：**一篇貼文會不會紅，看它有沒有「鉤住人停下來 + 逼出互動（留言，或讓人想分享/轉發）」；是不是蝦皮分潤貼文，看它第一則留言有沒有 `shopee.tw` / `s.shopee.tw` / `shp.ee` 或 Portaly 連結。**（爆文不只一條路：有的靠逼留言、有的靠高分享，見 [`case_studies.md`](./case_studies.md) 案例 1。）

## 三、用法 A：拆解別人的貼文（判讀框架）

這是你最初要的：**蒐集別人的做法、判斷哪些有流量、為什麼。** 已經先幫你拆好一批真實案例（附連結與數據）在 [`case_studies.md`](./case_studies.md)——含一個「連結放內文 vs 沒放內文」的天然對照、以及高分享型 vs 逼留言型的不同擴散路徑。先看那份，再用下面的流程蒐集你自己的。

**Step 1 — 邊滑邊蒐集。** 開 `templates/collection_sheet.csv`，滑到一篇疑似蝦皮分潤的貼文就填一列：帳號、貼文 URL、內容形態（開箱/觀點/清單/迷因…）、用了什麼鉤子、**第一則留言有沒有放分潤連結**、你體感/看到的讚與留言數、你猜它為什麼紅。**先求量**，蒐 30–50 篇再找規律。

**Step 2 — 逐篇拆解。** 把一篇貼文的內文（和你觀察到的數字）餵給 `post_teardown.py`：

```bash
# 只給文字：偵測鉤子、有沒有把連結放內文（放內文是扣分）、互動訊號強度
python scripts/post_teardown.py post.txt

# 連同你看到的讚/留言/轉發數一起給：多算「留言/讚 比」這個演算法友善度指標
python scripts/post_teardown.py post.txt --likes 1200 --comments 340 --reposts 60
```

它會輸出：偵測到的鉤子類型、連結位置檢查、互動訊號啟發式分數、以及（給了數字的話）**留言/讚比的判讀**——這比就是「為什麼有流量」最可量化的線索：**高留言/讚比 = 演算法最愛、最容易被推爆**。記住這是啟發式，不是 Threads 後台真值。

**Step 3 — 歸納可複製的點。** 蒐集表填滿後，看「高互動的那些貼文共用了哪幾個鉤子、什麼形態、什麼選品」。那就是你「用法 B」要照抄結構（不是抄字）的模板。

## 四、用法 B：自己產（半自動 pipeline）

把整條流程當成一個 agent harness（見 [harness_engineering](../../ai/harness_engineering/README.md)）：

```
  選品 ──▶ 產貼文(LLM) ──▶ ┌─ 貼文 QA 閘 ─┐ ──▶ 發佈 ──▶ 追蹤 ──▶ 回饋
  蝦皮後台   hook_generator   post_qa         內文＋第一則    tracker  （數據回頭
 （人工選）  （多個鉤子變體）  沒過退回改       留言放連結              修選品/鉤子）
```

- **Step 1 選品**：到蝦皮分潤後台挑有分潤、且適合社群開箱/推薦的商品；產生官方分潤連結（**並實測它沒被追蹤覆蓋**，見第五節）。
- **Step 2 產貼文**：先準備商品檔（`cp templates/products.example.json products.json` 改成你的選品），再跑
  `python scripts/hook_generator.py --topic "通勤耳機" --product products.json --n 5 --dry-run`。它產 N 個內文變體（不同鉤子）＋ 一則「第一則留言」文案（含分潤連結佔位 + 揭露）。AI 給草稿，**你要挑一個、改成自己的口吻、補真實心得**——千篇一律的 AI 貼文在 Threads 一樣會被埋。（`--dry-run` 只印 prompt、不需金鑰；拿掉它並設好 `ANTHROPIC_API_KEY` 才會真的產草稿。）
- **Step 3 過閘**：把內文存成 `body.txt`、第一則留言（含分潤連結與揭露）存成 `comment.txt`，跑
  `python scripts/post_qa.py body.txt --comment comment.txt`。**不可繞過的閘**：內文**不准有外部連結**（連結只能在留言）、要有鉤子/CTA、長度合理、業配感不過重；**揭露檢查只在你有傳 `--comment` 時才會跑**——所以正式發佈前一定要連留言一起過。沒過不准發。
- **Step 4 發佈**：內文照貼，**分潤連結放第一則留言**，留言裡帶揭露（例：「分潤連結放留言👇 透過它在蝦皮買我會有少量回饋、不影響你價格」）。
- **Step 5 追蹤**（在 `threads_shopee_affiliate/` 目錄下執行，CSV 會寫在當前目錄）：
  `python scripts/tracker.py add --post bt-01 --hook 痛點 --topic 通勤耳機 --product B款`，
  之後 `python scripts/tracker.py update --post bt-01 --reach 18000 --likes 1200 --comments 340 --clicks 95 --commission 60`，
  再 `python scripts/tracker.py report`。用真數據決定哪種鉤子、哪類選品值得繼續。

> **和 SEO 那條共用的鐵律**：QA 閘是地板不是天花板，別為了過閘硬塞鉤子或灌互動；買假互動短期或許騙得過表面指標，但騙不過演算法的長期分發，也違反平台規範（Goodhart，見 harness 課 Ch 34 §七）。

## 五、合規、平台規範與追蹤陷阱（細節）

- **揭露**：含分潤連結的留言/貼文**通常需要揭露**分潤關係（以當期法規與蝦皮條款為準）。`post_qa.py` 在你傳 `--comment` 時，會檢查留言裡有沒有揭露字樣。
- **Threads/Meta 規範**：不得買假帳號互動、不得操弄性 spam、不得大量重複洗版；過度自動化發文可能被限流或停權。本專案的腳本只到「產草稿 + 過閘 + 記錄」，**發佈請手動或用合規工具，不要做帳號農場**。
- **蝦皮條款**：不得自買套利、不得誤導點擊、品牌字與連結用法有規範；佣金率與歸因以後台當期公告為準。**做之前讀條款，定期回看（會改）。**
- **追蹤陷阱（重要）**：用對連結型態，並做一次成單實測（**請有真實需求的朋友透過你的連結下單，別自己買——self-referral 多數計畫禁止**）確認後台有記到分潤——「導購/開 App」型態的跳轉據報可能蓋掉分潤歸因。
- **詐騙生態，別碰也別被當同類**：Threads 上常見的詐騙型態包含假「免費領養／免費送」「加 LINE 領好康」實則騙個資/卡號（請自行查證，可參考 165 反詐騙專線/官方反詐資訊）。你要做的是**正當分潤**——絕不要求加 LINE 領、不要個資、不導去可疑賣貨便網站；做法越透明，越不會被讀者跟平台當成詐騙同類。

## 六、收入現實與 KPI

`tracker.py report` 給你每篇貼文的互動與分潤、加上各鉤子的累計分潤；要比「哪種鉤子/選品/主題最好」用 `tracker.py ab --by hook|product|topic`。判讀：

- **看分群**：賺錢的通常是少數幾種選品 × 鉤子組合，別被總發文數迷惑。
- **連結點擊率 ＞ 讚數**：一篇兩千讚但沒人點留言連結，對分潤是零。要盯的是「觸及 → 留言連結點擊 → 下單」。
- **務實期待**：穩定後多數人是月入幾百到低四位數台幣的副業級；要更多得靠「選品準 + 高頻 + 長期 + 找到會轉換的利基」。

## 七、踩雷集錦

1. **把分潤連結放內文**：創作者圈普遍觀察會壓低觸及。連結放第一則留言（先照做、自己比較）。
2. **連結型態錯，分潤沒記到**：最痛的雷——辛苦導流卻零分潤。用對連結 + 實測（請朋友真實下單，別自買）。
3. **沒揭露**：通常需要揭露（以當期法規與蝦皮條款為準）；少了可能違規被停權，也傷讀者信任。
4. **買假讚假留言衝數據**：違反 Meta 規範、騙不過長期分發、還可能被砍號。
5. **AI 貼文直接發、千篇一律**：去商業化是 Threads 的命門，罐頭味會被埋。AI 出草稿，你補真人觀點與心得。
6. **變成「分潤蟑螂」**：用盜片/盜圖/盜文、爭議洗流量去洗分潤連結，是這圈子被公開鄙視的做法（有創作者直接造詞「分潤蟑螂」罵，也有人教大家用關鍵字過濾掉所有蝦皮分潤貼文）。除了違反著作權、會被檢舉下架，也毀帳號信譽。**只用你自己的內容與真實心得**（見 [`case_studies.md`](./case_studies.md) 案例 6）。
7. **只看讚數不看連結點擊/分潤**：讚 ≠ 錢。盯轉換漏斗。
8. **自買套利**：幾乎所有計畫都禁止，被抓收回分潤甚至停權。
9. **把它當會累積的資產**：Threads 貼文壽命短，停更就沒流量。想要累積性資產，搭配 SEO 那條長線。

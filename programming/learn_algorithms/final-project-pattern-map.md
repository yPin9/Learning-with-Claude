# Final Project — 建立你自己的「訊號 → 演算法」對照表

> 目標:整理一份**屬於你個人**的速查表。面試前 30 分鐘看它,比刷 10 題有用。

## 為什麼是這個 Final Project

整門課讀完,你已經累積大量 pattern。但**讀過的 pattern 不是你的**——寫成自己的一張速查表,才真的內化。

別人的 cheatsheet 你看不懂。自己做的、用自己的話寫的、含自己踩過的坑的——那才是你的工具。

---

## 交付物

兩份東西:

### 1. `my-pattern-map.md`(你的速查表)

格式建議:

```markdown
# 我的題目辨識速查表

## Array / String

### 訊號 1: sorted array + 找 target / pair
- 候選: 雙指針(相向)、binary search
- 模板位置: [連結到你自己的 snippet,或直接寫在裡面]
- 我踩過的坑: 忘了 l < r 的 strict less than
- 範例題: LC 167, LC 15

### 訊號 2: subarray 連續 + 和 / 長度
- 候選: sliding window(若單調)、前綴和 + hash(有負數)
- 我踩過的坑: 看到 subarray 就衝 sliding,結果有負數 TLE
- 範例題: LC 3, LC 560

[... 依此類推,每個訊號一段 ...]
```

### 2. `30-problems-verified.md`(你驗證過這張表的 30 題)

挑 30 題(從 Practice A–D 裡選或自己選),**每題做完**記:

```markdown
## Problem: [題目連結]

- 我看到什麼訊號?
- 我對照表找到什麼解法候選?
- 實際解法是?(是否跟候選一致)
- 如果不一致,速查表需要什麼補充?
- 我寫的 bug?
- 複雜度:
```

這 30 題的過程,會把你的速查表**修正成真的能用**。

## 寫作建議

### 用自己的話

**不要抄這門課的章節**。把章節的內容用你自己的語言重寫。

抄來的東西你記不住。你用自己的話寫過的東西,面試當下才會浮現。

### 加個人味

記錄你踩過的坑、你的直覺記法、你的誤會。

範例:

> **我的誤會**:以為「sliding window」跟「雙指針」是同義詞。實際上前者視窗有意義、後者找兩個點。
> **我踩過的坑**:Two Sum 忘了邊掃邊查,先建完 hash 對重複元素出錯。

### 模板 code 要用「你的風格」

同樣的 BFS,你可能用 `queue.append / popleft` 寫,別人可能用 `collections.deque` 加別的 alias。**挑一套你用得順的,寫在表裡**。面試當下重現才快。

### 定期更新

每刷 10 題 review 一次:

- 有沒有新的訊號要加?
- 有沒有原本的訊號其實不準?
- 有沒有 typo?

這張表是活的。直到你 onsite 前一天,都還在更新。

## 建議的大架構

先寫骨架,再填血肉。骨架建議:

```
1. Array / String
   1.1 Sorted + 找 pair / triplet
   1.2 Subarray 連續問題
   1.3 Subsequence 不連續問題
   1.4 K 個最大 / 最小 / 頻率
   1.5 Anagram / Palindrome
   1.6 Rotate / Reverse / Transform

2. Linked List
   2.1 反轉 / 拷貝
   2.2 快慢指針
   2.3 合併

3. Tree
   3.1 遍歷 / 深度 / 路徑
   3.2 BST 特有
   3.3 序列化 / 重建
   3.4 樹形 DP

4. Graph
   4.1 連通 / 分量
   4.2 最短路
   4.3 拓撲 / 依賴
   4.4 MST
   4.5 2D grid

5. 演算法範式
   5.1 Binary Search(含二分答案)
   5.2 Greedy
   5.3 Backtracking
   5.4 DP(一維 / 二維 / 區間 / 樹形 / 狀壓)

6. 雜項
   6.1 Bit
   6.2 Intervals
   6.3 字串進階
   6.4 數學

7. 面試流程 cheatsheet
   7.1 Clarify 問題清單
   7.2 常用話術
   7.3 自己的 bug 日誌前 10 名
```

## 驗收標準

以下每項都要做到才算完成 final project:

- [ ] `my-pattern-map.md` 至少 3000 字,涵蓋 20+ 訊號 pattern
- [ ] 每個 pattern 有至少一題範例
- [ ] 至少三分之一的 pattern 含「我踩過的坑」或「我的誤會」
- [ ] `30-problems-verified.md` 確實做完 30 題並記錄
- [ ] 整份 markdown 用你自己的話寫,沒有整段抄這門課

**最後一項是關鍵**。如果整份就是把課程章節複製過來,等於沒做。

## 怎麼用這份速查表

### 面試前一週

每天睡前過一遍。不是精讀,是複習。

### 面試前一天

重點看「訊號 → 演算法」那段。讓自己對題目的第一反應快起來。

### 面試前 30 分鐘

只看「面試流程 cheatsheet」那段:clarify 問題、常用話術、bug 日誌前 10 名。

不要看解法細節——當天再背只會慌。

### 面試中(心裡)

面試官講題的時候,腦中掃這張表:「他在講什麼輸入形狀?什麼關鍵字?n 多大?」

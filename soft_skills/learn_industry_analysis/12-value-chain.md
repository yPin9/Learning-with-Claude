# Ch 12 — 價值鏈：錢從哪進、哪出、誰抽成

> 一個產業是由多層玩家串起來的鏈條。**每一層創造的價值不同，能留住的利潤也不同**。產業分析最常見的盲點，是把所有玩家當成「這個產業」的公司，其實他們的經濟學天差地別。這一章教你拆解價值鏈、找到真正賺錢的那一層。

## 價值鏈是什麼

**價值鏈**（Value Chain）：一個產品從原料到最終消費者手上，經過的所有生產與流通環節。

每一個環節是一層玩家，他們各自有：

- 自己的**投入**（從上一層買什麼）
- 自己的**加工**（做什麼價值轉換）
- 自己的**產出**（給下一層什麼）
- 自己的**利潤**（能留下多少）

**關鍵洞察**：**一條價值鏈裡，不同層級的玩家賺的錢可能差一個量級**。

## 一個經典例子：iPhone 的價值鏈

看 iPhone 的價值鏈（簡化版）：

```
原料礦 → 晶圓代工 → 晶片設計 → 零組件 → 組裝 → Apple → 通路 → 消費者
(礦商)  (台積電) (Apple/高通) (各家)  (鴻海) (Apple) (電信/Apple Store)
```

看每一層的 take（以一台 $999 iPhone 為例，粗略數字）：

| 環節 | 玩家 | 營收 | 毛利率 | 實際毛利貢獻 |
|---|---|---|---|---|
| 原物料 | 礦商 | 少 | 低 | $5 |
| 晶圓代工 | 台積電 | $50 | 55% | $27 |
| 晶片設計 | Apple 自有 + 高通 | $100 | 60–75% | $60–75 |
| 記憶體 | Samsung、Micron | $30 | 20–40% | $6–12 |
| 顯示器 | Samsung、LGD、JDI | $70 | 15–25% | $10–17 |
| 相機模組 | Sony、LG | $30 | 25% | $8 |
| 電池 | ATL、LG | $5 | 15% | $1 |
| 其他零件 | 眾多 | $60 | 15–25% | $10 |
| 組裝 | 鴻海、立訊 | $15 | 5–6% | $1 |
| **總硬體成本** | | **~$370** | | |
| **品牌/設計/軟體/通路** | **Apple** | **$629** | | **大部分** |
| 通路 | 電信商、Apple Store | | | |
| **零售價** | | **$999** | | |

**看到什麼了嗎**：

- **Apple** 拿走這台 iPhone 最大一份的利潤（> $300）
- **Apple 的晶片設計**（A 系列晶片）貢獻了高毛利
- **台積電** 以 $50 的營收賺 $27，毛利率高但絕對值不算大
- **鴻海**（組裝）$15 營收只賺 $1，毛利率 5%，最艱苦的工作

**同樣一台 iPhone，Apple 賺 $300、鴻海賺 $1**。

### 為什麼差這麼大

這就是價值鏈分析的核心問題：**為什麼有些環節賺得多，有些賺得少**？

**Apple 賺最多**，因為：
- 品牌（消費者願意付 iPhone 溢價，而非「某台手機」）
- 設計（產品差異化）
- 軟體生態（iOS + App Store）
- 通路控制（Apple Store、Apple 品牌）

**台積電賺很好**，因為：
- 技術壟斷（先進製程）
- 高進入障礙

**鴻海只賺一點點**，因為：
- 組裝是大宗化工作
- 買家只有少數（Apple、Samsung 等）
- 可被中國本土 OEM 替代（立訊、比亞迪）

**原則**：在價值鏈中，**能差異化、有議價權、有進入障礙的環節**賺得多。大宗化、可替代的環節賺得少。

## 價值鏈分析的核心問題：誰抽成？

當你做一個產業分析時，這是最根本的問題：

1. **這個產業的**總蛋糕**有多大**？（TAM — Total Addressable Market）
2. **這個蛋糕是怎麼切的**？（每一層分多少）
3. **哪一層能留住最多價值**？
4. **這個切法未來 5 年會怎麼變**？

如果你看錯了層，你就投錯了公司。

## 一個反面例子：電動車價值鏈

電動車產業的價值鏈分布，跟傳統車有很大不同：

**傳統汽車**（內燃機車）：
- 整車廠（Toyota、VW、GM）是最大玩家，毛利率 5–10%
- 零件供應商也賺（Bosch、Continental、Denso），毛利率 10–20%
- 燃油供應（石油公司、加油站）穩賺
- 分布相對平衡

**電動車**：

```
礦 → 電池材料 → 電池芯 → 電池Pack → 整車廠 → 充電 → 使用者
```

看每層的毛利狀況（2024 年前後）：

| 環節 | 代表 | 毛利率 | 結構性定位 |
|---|---|---|---|
| 礦（鋰） | Albemarle、贛鋒鋰業 | 高度波動（20–50%） | 供應循環、寡佔 |
| 電池材料 | 當升科技、正極負極材料廠 | 15–25% | 競爭激烈 |
| 電池芯 | **寧德時代、LG、SK、Samsung SDI** | 20–25% | 集中度高 |
| 整車廠 | Tesla、比亞迪、各傳統車廠電動部門 | 10–25% → **壓縮中** | 競爭極激烈 |
| 充電基礎設施 | Tesla Supercharger、ChargePoint、EVgo | 看規模 | 早期 |

**看到了沒**：

- **電池供應商**賺得比整車廠多（寧德時代毛利率 23% vs 某些車廠 10%）
- **整車廠之間的價格戰讓整車環節利潤被壓縮**
- **充電基礎設施**有潛力成為「通行稅」

**投資含義**：在電動車這個產業，**不要直接買整車廠**（除非 Tesla 這種有品牌溢價的），而要買：

- 上游（電池材料、部分礦業）
- 基礎設施（充電網絡）
- 關鍵零件（功率半導體、充電模組 — 例如台達電）

**這就是為什麼「我看好電動車、所以我買電動車股」這個邏輯常常是錯的**。

## Porter 的價值鏈框架

Porter 把公司**內部**的價值鏈拆成幾個活動：

**主要活動**：

1. 進料後勤（Inbound Logistics）
2. 生產（Operations）
3. 出貨後勤（Outbound Logistics）
4. 行銷與銷售（Marketing & Sales）
5. 服務（Service）

**支援活動**：

1. 公司基礎設施（General management）
2. 人力資源
3. 技術發展
4. 採購

做產業分析時，這個「內部價值鏈」的拆解有助你理解：**一家公司的競爭優勢來自哪一環？**

- Costco 的優勢在「採購」（大量採購壓低成本）
- Apple 的優勢在「技術發展」與「行銷」
- Tesla 的優勢在「生產整合」與「行銷（品牌）」
- Walmart 的優勢在「進料後勤」（物流系統）

**但對投資分析而言**，**產業間的價值鏈**（跨公司、上下游）比公司內部的價值鏈更重要。

## 垂直整合 vs 水平專精

公司在價值鏈上有兩種策略：

### 垂直整合（Vertical Integration）

一家公司做**多個**價值鏈層級。

**例**：

- **Tesla**：設計 + 電池（部分自製） + 整車 + 自營通路 + 充電網絡 + 自動駕駛軟體。幾乎全價值鏈。
- **三星**：設計 + 晶片（自產）+ 螢幕（自產）+ 整機 + 通路
- **Apple**：設計 + 自研晶片 + 軟體 + 通路 + 服務
- **Zara（Inditex）**：設計 + 生產（大部分自有工廠）+ 通路（自營店）

**優點**：
- 控制整個體驗（產品一致性）
- 獲取整條價值鏈的利潤
- 不被某個單一環節掐住

**缺點**：
- 需要大量資本
- 每個環節都要做好很難
- 失去「專注」帶來的效率

### 水平專精（Horizontal Focus）

一家公司只做價值鏈的**一層**，但做到極致。

**例**：

- **台積電**：只做晶圓代工。不設計、不封測（基本上）、不做消費品。
- **ASML**：只做光刻機（一個設備類別）
- **Visa / Mastercard**：只做卡片網絡。不發卡、不做商戶服務。
- **Salesforce**：只做 CRM 軟體

**優點**：
- 專注帶來規模經濟
- 建立深厚的技術/規模壁壘
- 簡單的商業模式

**缺點**：
- 依賴其他層級的健康（台積電依賴 fabless 客戶的健康）
- 如果這一層被顛覆，沒有 fallback

### 兩者都對，看情境

兩種策略沒有絕對好壞。**關鍵是跟產業結構配合**：

- **網絡效應或技術壟斷**強的層，做水平專精往往更好（Visa、台積電、ASML）
- **品牌與消費者關係**主導的產業，垂直整合可獲取更多價值（Apple、Tesla）

## 一個重要概念：價值鏈的「瓶頸」位置

在一條價值鏈中，通常有一個**瓶頸**位置 — 這個位置控制了整條鏈的流動。

瓶頸位置通常是最賺錢的。

**半導體價值鏈的瓶頸**：

- 以前：製程（Intel 領先時代）
- 現在：**EUV 光刻機**（ASML 獨家）與**先進晶圓代工**（台積電）
- 未來：可能是某種新架構（3D 封裝、光子運算）

**電動車價值鏈的瓶頸**：

- 以前：電池
- 現在：電池 + 軟體
- 未來：可能是 L4/L5 自動駕駛系統

**辨識瓶頸的問題**：

- 哪一層沒了就沒有下一層？
- 哪一層的供給最緊？
- 哪一層新進入者最難打進？

答案就是瓶頸，也往往是最該投資的地方。

## 價值鏈分析的實用流程

做一個新產業的價值鏈分析時：

### 步驟一：畫出價值鏈

從最上游（原料）到最終消費者，列出每一層。

### 步驟二：列出每一層的主要玩家

- 3 個最大的公司
- 它們的市佔

### 步驟三：估算每一層的經濟表現

- 營收規模
- 毛利率
- 成長率

### 步驟四：辨識瓶頸與高價值層

- 哪一層最賺錢？
- 為什麼？是規模？技術？品牌？網絡效應？

### 步驟五：預測未來 5 年的變化

- 哪一層會被壓縮？
- 哪一層會變成新瓶頸？

這五步做完，你不只知道產業的結構，你知道在這個產業投資該投哪一層。

## 具體示範：雲端產業的價值鏈

```
資料中心基建 → 半導體（GPU/CPU）→ 雲端 IaaS → 雲端 PaaS → 雲端 SaaS → 企業 / 消費者
(Equinix、Digital Realty) (NVIDIA、AMD)  (AWS、Azure、GCP) (Snowflake、MongoDB) (Salesforce、ServiceNow)
```

### 每一層的經濟

| 層 | 主要玩家 | 毛利率 | ROIC | 判斷 |
|---|---|---|---|---|
| 資料中心 REIT | Equinix、Digital Realty | 45% | 10% | 穩定，不驚艷 |
| GPU 晶片（AI 時代） | NVIDIA | 75% | 50% + | **當前最賺錢** |
| IaaS | AWS、Azure、GCP | 60–65%（AWS） | 25% + | 非常賺 |
| 資料庫 PaaS | Snowflake、MongoDB | 65–75% | 負（還在成長階段） | 潛力高 |
| 企業 SaaS | Salesforce、Adobe、ServiceNow | 80% + | 15–25% | 成熟穩定 |

**2024 觀察**：NVIDIA 是當前最大贏家，因為所有想訓練 AI 模型的人都要買 GPU。這是**階段性瓶頸** — 10 年前瓶頸在 CPU + 伺服器（Intel + Dell + HP），未來可能轉回下層（如果 ASIC 取代部分 GPU）或往上（如果 AI 應用層出現贏家）。

### 投資含義

- 短期（2023–2026）：NVIDIA 是價值鏈最大受益者
- 中期（2026–2030）：可能轉向某些 AI 基礎設施平台（Databricks、Snowflake）或應用層
- 長期（2030+）：AI 應用層會出現大贏家，但現在還太早判斷

價值鏈分析告訴你：**不要只買「AI 股票」，要精確買 AI 價值鏈當前的瓶頸層**。

## 一個警告：價值鏈會變

價值鏈不是靜態的。**瓶頸會移動**。

典型例子：

- **手機產業**：2000s 瓶頸是作業系統（Symbian、Palm），2010s 後變成生態系（iOS、Android），底層晶片長期由高通主導，但 Apple 自研後重新定義。
- **PC 產業**：1990s 瓶頸是 CPU（Intel），2000s 後變成作業系統（Windows）與應用（Office），2010s 後連 CPU 都被 Apple M 系列晶片改寫。

**做分析時**：問自己「這個瓶頸未來 10 年會移到哪？」

通常會移到：

- 新的技術節點（下一代技術的控制者）
- 新的整合層（把零散功能整合起來）
- 新的互動介面（用戶怎麼使用這個產業的產品）

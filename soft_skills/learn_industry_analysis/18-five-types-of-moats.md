# Ch 18 — 護城河的五種型態

> 「護城河」（economic moat）是巴菲特發明的詞，指一家公司的**結構性、可持續的競爭優勢**。這個概念的強大在於：**它把抽象的「競爭力」變成可拆解的五種具體機制**。這一章教你辨認這五種護城河，以及如何判斷真假。

## 護城河為什麼重要

**沒有護城河的公司**會被這個規律宰割：

```
公司賺錢 → 吸引競爭者 → 競爭壓低價格/利潤 → 報酬回到平均
```

這叫「**均值回歸**」（mean reversion）。大多數公司會被這個規律吞沒。

**有護城河的公司**可以抵抗這個過程。

巴菲特在 1999 年《Fortune》說：

> *"The key to investing is not assessing how much an industry is going to affect society, or how much it will grow, but rather determining the competitive advantage of any given company and, above all, the durability of that advantage."*

翻譯：投資的關鍵不是評估一個產業對社會的影響有多大、會成長多少，而是**評估某家公司的競爭優勢，以及這個優勢的持久性**。

關鍵詞是「持久性」。護城河不只要存在，要能**持續多年甚至幾十年**。

## 兩個主要框架

最常用的護城河框架有兩個：

- **Morningstar 的五種護城河**（Pat Dorsey 整理）
- **Hamilton Helmer 的 7 Powers**

這一章用 Morningstar 的五種，是業界最常引用的。這五種是：

1. **無形資產**（Intangible Assets）
2. **轉換成本**（Switching Costs）
3. **網絡效應**（Network Effect）
4. **成本優勢**（Cost Advantage）
5. **有效規模**（Efficient Scale）

## 護城河一：無形資產（Intangible Assets）

### 定義

**法律或心理上的資產，阻止對手進入或取代**。

### 三個子類

#### 1a. 品牌

消費者願意為這個名字多付錢。

**例**：

- **Coca-Cola**：世界最有價值的品牌之一。同樣是糖水加氣，Coca 比自有品牌貴 2–3 倍，人們還是買
- **Apple**：iPhone 比同等規格 Android 貴 30%+
- **Ferrari、Porsche、Rolls-Royce**：品牌 = 客戶

**品牌護城河的強度測試**：

- 如果這家公司的產品用別的名字賣，消費者願意付同樣的價格嗎？
- 可口可樂換成「某糖水」? 顯然不行 → 極強品牌
- 某家銀行換名字? 客戶多半不在意 → 弱品牌

#### 1b. 專利

法律保護的技術獨占權。

**例**：

- **製藥**：一個新藥，專利期內（通常 20 年）幾乎壟斷。藥效好的專利藥是極強護城河。
- **半導體**：特定技術的專利（ARM 的指令集、高通的基頻通訊專利）
- **工業**：某些 know-how 受智慧財產保護

**專利護城河的限制**：

- **有時限**：20 年後失效 → 學名藥廠湧入，原藥價格崩
- **可能被繞過**：競爭者可能發明類似但不侵權的技術

#### 1c. 政府授予的牌照 / 許可

法規限制進入。

**例**：

- **銀行牌照**：不是想開就能開
- **電信頻譜**：國家拍賣給少數玩家
- **賭場**：特定城市的牌照有限
- **航線授權**：國際航線要政府間協議

這類護城河的缺點：**政府是他們的依靠也是風險** — 法規變了就不一樣了。

### 無形資產護城河的實例對比

| 公司 | 無形資產 | 強度 | 持久性 |
|---|---|---|---|
| Coca-Cola | 全球品牌 | 極強 | > 100 年 |
| Apple | 品牌 + 設計 | 強 | 20–30 年（但在變化中） |
| Pfizer | 藥品專利 | 強 | 限於專利期內 |
| 中國某銀行 | 政府牌照 | 中 | 政策可變 |
| 某家新創 | 商標註冊 | 弱 | 名字還沒人知道 |

## 護城河二：轉換成本（Switching Costs）

### 定義

**客戶要換掉這家公司的產品，要付很高的代價**（金錢、時間、心力、風險）。

### 例子

#### 企業 ERP / CRM

**SAP、Oracle、Workday、Salesforce**：

- 導入一次動輒幾百萬美元、幾年時間
- 員工要重訓
- 既有流程要重新設計
- 風險大（萬一新系統出問題）
- 結果：**客戶換供應商極少，續約率 95%+**

這種高轉換成本讓這些公司能**漸進漲價** — 客戶反正走不掉。

#### 企業銀行帳戶 & 支付系統

- 大企業的主要銀行帳戶通常用了幾十年
- 換銀行要重新 set up 所有自動付款、薪資、供應商匯款
- 客戶關係（信貸額度、客戶經理）要重建
- 結果：**企業銀行業務黏性極高**

#### 工業設備

- 工廠用了一套 ABB 的自動化控制器，20 年配件 / 維護都綁定 ABB
- 要換 Siemens = 整廠停工改造
- 結果：**安裝基礎 = 持續營收**

#### 個人的「習慣」類別

- 軟體：你習慣用 Photoshop，換 GIMP 要重學
- 遊戲平台：你的遊戲庫在 Steam，不會輕易換到 Epic
- 金融：主要信用卡用了 10 年、累積點數，不會為了一點折扣換

### 怎麼量化轉換成本

**流失率（Churn Rate）** 是最好的指標：

- 企業 SaaS 年流失率 < 5% → 高轉換成本
- 消費 SaaS 年流失率 10–20% → 中轉換成本
- 零售年流失率 > 30% → 低轉換成本

大公司通常會在年報或法說會揭露流失率或 **續約率**（Retention Rate = 1 - Churn Rate）。

### 轉換成本 + 漲價能力

高轉換成本的真正威力：**可以慢慢漲價**。

**例**：Autodesk（CAD 軟體）從傳統 perpetual license 轉成 subscription 模式，2015–2024 每年漲價 5–8%，客戶的流失率只有 5%。結果 ARR（Annual Recurring Revenue）持續上升。

這是為什麼**軟體股長期表現好**— 一旦客戶進來，就不走，而且越來越值錢。

## 護城河三：網絡效應（Network Effect）

### 定義

**一個產品/服務的價值，隨使用者數量增加而增加**。

### 經典例子

#### 電話 / 即時通訊

- 一個人用電話：無用
- 全世界用電話：極有用

早期的電話公司因為這個效應，最後整合成 AT&T 這樣的壟斷。

#### 信用卡網絡

- Visa / Mastercard 的價值來自**雙邊網絡**：
  - 越多商家接受 → 越多消費者願意用
  - 越多消費者用 → 越多商家願意接受
- 這個正向循環讓新進入者（Discover、American Express 以外的）幾乎不可能打進來

#### 社群平台

- Facebook、LinkedIn、微信、IG、TikTok
- 你用 Facebook 不是因為它的介面最好，是因為**你朋友都在上面**
- 新社群 app 要起來極難 — 甚至 Google 的 Google+ 也失敗了

#### 交易所

- NYSE、CME、HKEX
- 流動性吸引流動性：一個市場交易量大 → 價差小 → 更多人來交易 → 交易量更大
- 新交易所很難取代既有交易所

#### 出行平台

- Uber、滴滴、Grab
- 雙邊網絡：司機 vs 乘客
- 一個城市如果 Uber 的司機 / 乘客密度高，新玩家很難從零建立

### 網絡效應的種類

**直接網絡效應**：用戶數直接增加價值
- 例：社群、通訊

**間接網絡效應**（雙邊 / 多邊）：一邊的增加對另一邊有價值
- 例：信用卡（商家 + 消費者）、叫車（司機 + 乘客）、商場（商店 + 消費者）

**數據網絡效應**：更多用戶 → 更多數據 → 更好的服務 → 更多用戶
- 例：Google（更多搜尋 → 更好演算法）、推薦系統（Netflix、Amazon）

### 網絡效應的測試

- 這個產品用的人越多，對既有用戶越有價值嗎？
- 新進入者從零開始，要到什麼規模才能提供同等價值？
- 有沒有 **臨界規模** 的概念？

### 網絡效應的強度等級

**極強**：信用卡網絡、交易所、某些社群平台（Facebook、微信）
**強**：主流社群（LinkedIn、Twitter）、叫車（在城市內）
**中**：電商（Amazon、eBay）— 實際上是規模效應 + 弱網絡效應
**弱**：很多公司宣稱有網絡效應，其實是規模效應

**投資人要小心**：很多科技公司宣傳「網絡效應」，但仔細看其實只是「有很多用戶」。**真網絡效應的測試是：新進入者要成功，必須先達到類似規模**。

## 護城河四：成本優勢（Cost Advantage）

### 定義

**結構性地比對手成本低**。注意是「結構性」— 不是暫時的運氣。

### 四個子類

#### 4a. 規模優勢

大規模帶來低單位成本。

**例**：
- **Walmart**：美國最大的零售商，採購量大，拿到最好的供應商價格
- **Costco**：靠超大規模 + 會員費模式壓低毛利率還能賺
- **Amazon**：雲端、電商的物流都有巨大規模

**判斷**：
- 如果你規模是第二名的 3 倍以上，通常有顯著成本優勢

#### 4b. 地點 / 地理優勢

資源靠近市場 = 運輸成本低。

**例**：
- **水泥廠**：水泥運輸成本高（運費是水泥本身價格的 30%），所以每個區域的水泥業是地理壟斷
- **汽油 / 天然氣**：靠近大型消費市場的煉油廠有優勢
- **餐飲**：開在高流量位置的餐廳有流量優勢

#### 4c. 獨特的資源

擁有別人沒有或難以複製的資源。

**例**：
- **低成本礦**：Saudi Aramco 的原油成本每桶 $10，遠低於其他地方
- **水資源**：某些飲料公司擁有特定水源
- **獨特基礎設施**：大型港口、鐵路樞紐

#### 4d. 製程 / 技術優勢

製造方法比對手有效率。

**例**：
- **台積電**：良率比三星代工高，意味著每顆晶片的「實際成本」低
- **Toyota 的 lean manufacturing**：長期把生產效率提高到世界一流
- **GEICO**：車險的直接銷售模式（不透過經紀人）讓 Buffett 持有的這家公司長期成本低於傳統車險

### 成本優勢的測試

- 比較這家公司的**毛利率 / 營業利益率** vs 產業平均
- 持續 5–10 年顯著高於平均 → 有結構性成本優勢
- 只在某幾年高於平均 → 可能是運氣或短期因素

### 一個警告：成本優勢會消失

成本優勢**不是永恆的**。要小心：

- **新技術**：Toyota 的 lean 曾經是護城河，現在全世界製造業都學了
- **匯率**：台灣很多製造業的成本優勢來自台幣 / 人力成本，這些都可變
- **規模追平**：Walmart 的規模優勢現在被 Amazon 追上甚至超越

## 護城河五：有效規模（Efficient Scale）

### 定義

**這個市場的規模，只能容納少數幾家玩家理性共存**。新玩家進來的結果是大家一起虧錢。

### 經典例子

#### 區域基建壟斷

- 一個小鎮的水電瓦斯
- 一條城際鐵路
- 一個地方的機場

**邏輯**：需求量有限，但基建成本巨大。已經有一家在做，第二家進來會發現需求不夠分，兩家都賺不到錢。所以第二家理性地不會進來。

#### 細分工業市場

某些小眾 B2B 市場只有 1–3 家公司：

- 某種特殊化學品
- 某種專業醫療設備
- 某種細分軟體（例：律師事務所管理軟體）

**例**：Moody's、S&P Global、Fitch 三家信評機構。整個全球信評市場大致上被這三家瓜分。為什麼沒有第四家？因為**一個新的信評機構要被市場信任需要幾十年，但市場只需要 3 家**。

#### 火車 / 鐵路

美國的鐵路已經高度整併。現在的 5 家鐵路公司把北美大致分成幾個 zone，彼此不太侵入對方地盤 — 因為進入對方地盤的成本 > 搶到的業務。

### 有效規模的識別

- 這個市場的需求能支撐幾家公司？
- 如果多一家，大家會一起虧嗎？
- 過去 20 年有多少新玩家成功進入？

### 有效規模 vs 寡佔

這兩者很像但有差別：

- **寡佔**：市場結構是少數玩家，但不一定表示「只能容納這麼多」
- **有效規模**：市場結構**數學上**只能容納這麼多，新玩家理性不該進入

**有效規模是寡佔的一種**，但不是所有寡佔都是有效規模。

## 五種護城河的綜合分析

多數真正有護城河的公司有**複合護城河** — 超過一種機制。

### 實例：Visa

- **網絡效應**（主要）：商家 + 消費者雙邊網絡
- **無形資產**：品牌（消費者信任）
- **成本優勢**：全球運作的規模
- **轉換成本**（次要）：對商家而言，不能不接受 Visa

### 實例：Apple

- **無形資產**：極強品牌、設計
- **轉換成本**：iOS 生態系（iMessage、App Store、iCloud）
- **網絡效應**（弱）：iMessage 的同溫層效應
- **成本優勢**（部分）：全球供應鏈管理

### 實例：台積電

- **成本優勢**（技術）：先進製程的良率領先
- **無形資產**：技術 know-how 的累積
- **規模優勢**：最大的代工廠，採購設備議價
- **轉換成本**（客戶端）：客戶 tape-out 一次就綁定

複合護城河**遠比單一護城河穩固**。如果一個機制被削弱，其他還能支撐。

## 怎麼判斷護城河的真假

市場上很多公司**自稱**有護城河但其實沒有。測試方法：

### 測試一：長期 ROIC

真護城河 = 長期 ROIC 高（超過資金成本，通常 > 15%）且穩定。

ROIC 10%、忽高忽低 → 不是護城河。

### 測試二：過去 10 年的市佔變化

真護城河 = 市佔穩定或上升。

市佔持續流失 → 護城河被侵蝕或根本沒有。

### 測試三：毛利率趨勢

真護城河 = 毛利率穩定或上升。

毛利率持續下降 → 定價權流失 = 護城河被侵蝕。

### 測試四：新玩家的進入與存活

真護城河 = 過去 10 年沒有新玩家成功進入前五。

如果有新玩家輕易擠進前五 → 進入障礙不夠高。

**這四個測試過一次**，你對這家公司有沒有真正的護城河就有清楚判斷。

## 護城河的動態：擴張 vs 被侵蝕

護城河**不是靜態**的。

### 擴張

有些公司的護城河隨時間**變深**：

- **Costco**：會員數增加 → 採購量增加 → 成本更低 → 吸引更多會員
- **Amazon**：規模增加 → 物流效率更高 → 更多客戶
- **Visa**：全球化延伸 → 網絡更廣 → 新興市場都想加入

**這是複利最強的狀態**。

### 被侵蝕

有些公司護城河**被侵蝕**：

- **傳統電視廣告**：過去幾家電視台寡佔，被 Google + Facebook 的數位廣告吃掉
- **傳統銀行零售**：被 fintech 逐步侵蝕
- **Intel**：x86 CPU 的護城河被 Apple（自研 M 系列）、AMD（追上）、ARM 架構（雲端伺服器）侵蝕

**投資時要問**：這個公司的護城河，**未來 10 年是擴張還是被侵蝕**？

## 一個警告：沒有永恆的護城河

Munger 說過：

> *"Competitive advantage will always be eroded by competition, but some companies have a wider moat that resists longer."*

翻譯：所有競爭優勢都會被競爭侵蝕，只是有些公司的護城河更寬，抵抗得更久。

**結論**：

- 不要以為買了護城河股票可以永遠不管
- 要定期檢查護城河是否仍然存在
- 當護城河開始被侵蝕，趁早退出（在股價崩跌前）

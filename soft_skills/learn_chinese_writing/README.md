# 中文寫作心法：敘事散文與小說

> 給已能寫通順中文、但文字卡在「及格」與「漂亮」之間的寫作者。
> 不談議論文、不談應用寫作、不談考試。
> 重心只在兩件事：**敘事散文** 與 **小說**。

這不是一套教你「如何起承轉合」的教材。那種東西國中就學過了，學了又不會寫得更好，就是證據。

這門課的預設：你已經寫得出文從字順的中文，但你讀張愛玲會嘆氣、讀契訶夫會沮喪、讀自己兩週前寫的東西會皺眉。你知道問題存在，但你說不出來它在哪。

這門課要做的事，就是把那個「說不出來」拆成可操作的幾十個點。

## 學完你應該能

- 認出自己的文字哪裡「不夠漂亮」— 並且知道所謂「漂亮」其實是四件事的合成詞：**準確、節奏、意外、克制**。
- 用動詞寫，而不是用形容詞寫。
- 感受到句子的長短是一種呼吸，標點是節拍器。
- 寫出有重量的描寫 — 不靠堆辭藻，靠具體。
- 控制敘事的視角、距離、速度；知道哪裡該放慢、哪裡該跳過。
- 看出一段對白的潛台詞、一段場景的留白、一個結尾的餘韻 — 並且寫得出來。
- 有一張自己的作家地圖，知道誰的文字該偷、偷哪裡、偷多少。

## 為什麼要學這個？

- **寫作沒有底線**：工程師寫程式有「能跑」這個底線，寫作沒有。一段文字堪用與絕妙之間，差的是一輩子可以走的路。
- **中文寫作的病大同小異**：太想寫得美、翻譯腔、形容詞成癮、節奏僵硬、show 不出來只會 tell。這些病都有具體成因，也有具體藥方。
- **這是一門耳朵的工夫**：你能聽出一個句子哪裡卡，才能修它。這門課有一半是教你怎麼聽。
- **你的文字就是你**：寫作風格不是裝飾，是一個人看世界的方式。把風格磨出來，你對世界的感知也會變細。

## 使用方式

- **不含練習**。每一章只有兩件事：**心法** 與 **例子**。照著讀，每讀完一章，去翻你自己寫過的一段文字，拿這一章的放大鏡照一次。
- **例子會混中文與英文**。卡佛、海明威、契訶夫的英文我會給原文對照，因為翻譯會吃掉節奏。其他大多數引文是華語原典。
- **不追求全面，追求對**。我不會假裝這是一本文學概論。這是一份**偏見清單** — 偏袒克制、偏袒具體、偏袒刪除。

## 參考取樣

這份課不是文學史，引例只挑適合拆解的片段。主要取樣來自：

- **華語現代**：魯迅、沈從文、汪曾祺、張愛玲、錢鍾書、白先勇、朱天文、朱天心、木心、駱以軍、吳明益、賴香吟、黃錦樹、胡淑雯、董啟章
- **翻譯文學**：契訶夫、托爾斯泰（短篇）、海明威、卡佛（Raymond Carver）、福克納、波赫士、卡爾維諾、馬奎斯、芥川龍之介、川端康成、太宰治、村上春樹、石黑一雄
- **詩與文論**：王國維《人間詞話》、錢鍾書《談藝錄》、余光中〈中文的常態與變態〉、Strunk & White《The Elements of Style》、Ursula Le Guin《Steering the Craft》

## 一個告誡

學完這 24 章不會讓你變成作家。會寫的人寫了十幾二十年才成形。這門課能給你的，是一張診斷書 — 讓你看自己寫的東西時，能指著某一行說「問題在這」。

剩下的，只能靠手。

# Ch 5 — 遺忘其實是學習的朋友

> 這一章的主題反直覺到讓人起疑：**遺忘幫助學習**。這不是心靈雞湯，是認知科學的重要發現。理解這件事會徹底改變你對學習的心態 — 你會開始擁抱遺忘，而不是對抗它。

## 一個反直覺的實驗

Nate Kornell 和 Robert Bjork（UCLA）2008 年做了個實驗。

給學生學各種鳥類圖片與品種名。兩組：

- **A 組**：看 10 張 bluebird，再看 10 張 sparrow，再看 10 張 cardinal（blocked 集中學習）
- **B 組**：bluebird、sparrow、cardinal 混著看，每種散 30 張（interleaved 交錯學習）

**學習過程中**：
- A 組自評「我學得比較好」（感覺熟悉）
- B 組自評「我學得比較差」（感覺混亂）

**幾天後的測驗**：
- B 組的辨識準確率**顯著高於** A 組
- **而且 B 組自己不知道**自己學得比較好

**這個實驗反映一個定律**：**感覺上更難的學習，通常實際上學得更好**。

這個發現背後的深層原理：**有益的遺忘**。

## Bjork 夫婦的突破

Robert Bjork 和 Elizabeth Bjork（加州大學洛杉磯分校的記憶研究者）提出了**新的記憶理論**，顛覆了傳統認知：

### 傳統觀念（錯的）

```
記憶強度 = 儲存強度 = 提取強度
記憶是一維的變數，越強越好
```

### Bjork 理論（對的）

記憶有**兩個獨立維度**：

1. **Storage Strength（儲存強度）**：這個記憶有多穩固
2. **Retrieval Strength（提取強度）**：現在有多容易調出這個記憶

**這兩者可以獨立變動**。

### 四個象限

```
                     提取強度高
                         ↑
              (B) 剛學過    │    (A) 掌握透
                         │
                 ────────┼──────── 儲存強度
              (D) 完全忘     │    (C) 一時想不起
                         │
                         ↓
                     提取強度低
```

**四種狀態**：

- **(A) 儲存強 + 提取強**：你能快速用的核心知識（母語、騎車）
- **(B) 儲存弱 + 提取強**：剛學過，但還沒鞏固（流暢性錯覺的來源）
- **(C) 儲存強 + 提取弱**：多年沒用的知識，但想一想能回來
- **(D) 儲存弱 + 提取弱**：真的忘光的東西

### 關鍵洞察

**Bjork 理論最反直覺的部分**：

> **提取一個「提取強度低」的記憶（需要努力回想的東西），會顯著增加它的儲存強度**。

換句話說：**你越費力想起一個東西，記得越牢**。

### 實例

**情境 A**：你剛讀完一段內容，立刻複習一次。
- 提取強度：高（剛讀過）
- 費力程度：低
- 儲存強度增加：少

**情境 B**：你讀完一段，隔了一週才回來複習。
- 提取強度：低（快忘了）
- 費力程度：高
- 儲存強度增加：**多**

**情境 B 的學習效果比 A 好**。因為你「努力想起來」的過程就是學習在發生。

## 為什麼「遺忘是朋友」

現在你能理解標題了：

**小量的遺忘 → 下次提取時更費力 → 提取的過程強化儲存 → 長期記得更牢**

**如果你從不忘**（每小時複習一次），你的提取不費力，學習效果反而弱。

**如果你完全忘光**，你也學不到，因為你根本提取不到。

**最佳狀態**：**在記憶的遺忘曲線上，你快忘但還沒忘光的時候去提取**。

這就是間隔重複的科學核心。

## 一個實用的類比：肌肉訓練

**肌肉訓練的原則**：

- 舉重讓肌肉纖維**微損傷**
- 恢復期肌肉**修補**、變更強
- 如果不給時間恢復就再舉，肌肉反而沒機會變強

**記憶也類似**：

- 提取一個快忘的記憶讓這個記憶**被挑戰**
- 挑戰後的「修補」讓記憶**更穩固**
- 如果不給時間遺忘就再複習（一直重讀），記憶沒機會「修補變強」

**肌肉需要「重量 + 恢復」的循環，記憶需要「提取 + 遺忘」的循環**。

## 兩個常見迷思的破解

### 迷思一：「我忘了，是我沒學好」

**錯**。遺忘是記憶過程的正常部分。**有意識地**忘了某個東西，再成功想起來，比從沒忘過學得更好。

真正的失敗是**沒提取練習**，而不是「忘記」。

### 迷思二：「我要趁記憶最清楚時複習」

**錯**。這就是前面的實驗 — 剛學完立刻複習感覺有效，但長期效果弱。

**正確**：**等你開始遺忘、但還沒完全忘的時候複習**。

## 遺忘的最佳時機

**實務上，什麼時機複習最好**？

Bjork 實驗室多年研究得出的大致建議：

- **第一次複習**：學完的 **第 2–3 天**（已經開始遺忘但還能想起大部分）
- **第二次複習**：第一次複習的 **1 週後**
- **第三次複習**：第二次的 **2–3 週後**
- **第四次複習**：**1–2 個月後**
- 之後：**3 個月、6 個月、1 年...**

**間隔倍增**是大原則。每次成功提取後，下次可以拉得更長。

Anki 和其他間隔重複軟體自動算這個。你不用手動管理。Ch 9 細講。

## 「提取困難度」的調整

Bjork 夫婦還有一個洞察：**提取時感覺到的困難度本身是可調整的**。

你可以讓同樣一個提取變得更困難或更簡單：

### 讓提取變困難（建議，效果更強）

- **徹底合上書再想**（不要偷看）
- **用自己的話說**（不要照著記）
- **寫下來**（不要只在腦中想）
- **解釋給別人聽**（強迫完整化）

### 讓提取變簡單（效果弱，但感覺好）

- **邊讀書邊默念**
- **看答案再「確認」**
- **讀一遍就算複習**

**高手的選擇**：寧可提取困難，也不要偽裝成提取的輕鬆複習。

## 一個關鍵：不要怕忘記

這一章要內化的心態：**不要怕忘記**。

多數學生的心態：

- 忘記 = 我不夠好
- 忘記 = 我必須更多次複習
- 忘記 = 浪費時間

**正確心態**：

- 忘記 = 自然的過程
- 忘記 = 下次提取會更有效的機會
- 忘記 = 大腦在做篩選（如果反覆忘，代表這個資訊可能真的不重要，或者你的編碼不夠深）

**面對忘記的三步**：

1. **不自責**（這是正常的）
2. **試著自己想起來**（提取練習）
3. **想不起來再查，然後重新編碼（這次更深）**

這個循環做幾次，資訊就真的內化了。

## 應用：如何把「遺忘是朋友」用到學習

### 應用一：不要立刻複習

讀完一章，**不要馬上重讀**。等 2–3 天。那時你已經忘一些，然後合上書試著回想 — 這一輪提取比剛讀完時的「複習」強十倍。

### 應用二：間隔重複的紀律

用 Anki（Ch 9）或類似工具。**當 Anki 跳出一張卡片，第一反應是「我忘了」**。這時不要沮喪，**專注於努力想起來**。想出來了就是強化，想不出來就看答案再記 — 都比你從沒忘過學得更深。

### 應用三：不要一直留在舒適區

如果學習一直感覺很順，你可能在重讀 / 再看一遍熟悉內容。**主動把自己放到遺忘的邊緣** — 學新的、做新問題、往難的方向走。

### 應用四：接受「學習曲線是波浪」

你會感覺自己「進步又退步又進步」。**這是正常的**。長期來看你在前進，但每一輪複習時你會經過「不太記得」的低谷，然後提取後又「知道了」的高峰。

## 一個實驗性的想法：「生產性失敗」

Manu Kapur（ETH Zürich）提出「**生產性失敗**」（Productive Failure）：

- 學習新主題時，**故意先嘗試自己解決**（幾乎一定會失敗）
- 失敗後再學標準方法
- 這比先看答案再做題**學得更深**

**原理**：失敗的嘗試讓你**真正理解問題的困難**，當標準方法出現時，你會真正懂為什麼是這樣做。

**實務應用**：讀一本新領域的書時，**先不看解答地試著自己推理關鍵問題**。錯了沒關係。然後讀書時你會 get 到更深的東西。

這也是「遺忘是朋友」的延伸 — **困難是朋友**。

## 一個提醒：不要過度

這一章說「遺忘是朋友」，但不代表**完全忘光是好的**。

- 完全忘光（Bjork 象限 D）= 學習效果接近零
- 快要忘但沒忘（B 接近 D）= 效果最佳
- 完全記得（A）= 複習價值低

**甜蜜點**是「提取困難但能做到」。太難 = 挫敗放棄；太簡單 = 學習效果弱。

好的間隔重複演算法（Anki）就是在尋找每個人每張卡片的甜蜜點。

# Ch 29 — 怎麼知道自己學會了？

> 這是本課最後一章。我們回到一個**根本的問題**：**你怎麼真的知道自己學會了一個東西？** 不是「感覺」學會了、不是「考試及格」了、不是「別人誇你」了 — 怎麼**確定**你真的會？這一章給你一個**終極的自我檢測框架**。

## 一個殘酷的開場

**多數人不知道自己會不會**。

**Ch 16 的能力錯覺**：大部分人**以為自己會**，但真的被考驗時**不會**。

這不是智力問題，是**缺乏檢測框架**。

**本章教你**：**一套系統性的、誠實的方法**來檢測你真的會不會。

## 四個層次的掌握

**一個概念 / 技能的「會」** 有層次：

### 層次 1：能辨認（Recognition）

**你看到就認得**。

- 「這個是 Python 的 decorator」
- 「這是護城河」
- 「這是 deliberate practice」

**最低層次**。**選擇題考得過**，但不能實作。

### 層次 2：能解釋（Explanation）

**你能用自己的話說出是什麼**。

- 能用白話解釋 decorator
- 能說出護城河的類型與例子
- 能講 deliberate practice 是什麼

**這是費曼技巧的目標**。懂，但不一定會用。

### 層次 3：能應用（Application）

**你能在實際情境中用**。

- 能寫出用 decorator 的 Python code
- 能分析一家公司的護城河
- 能設計一個 deliberate practice 計畫

**這是「會」的開始**。但還限於熟悉的情境。

### 層次 4：能遷移（Transfer）

**你能在新情境中用、能組合、能創新**。

- 寫一個你沒看過的問題的 decorator 解法
- 在陌生產業中辨認新型護城河
- 為你自己獨特的學習需求設計 deliberate practice

**這是真正的掌握**（Ch 21 的遠遷移）。

**多數人停在層次 1 或 2。**
**少數人達到層次 3。**
**極少數達到層次 4。**

你的目標應該是 3 或 4，不是 1 或 2。

## 五個檢測方法

**怎麼檢測自己到了哪個層次**？五個方法：

### 方法 1：費曼測試

**合上所有資料**，用白話對一個假想外行解釋這個概念。

**卡住的地方**：你不懂的地方（低於層次 2）。
**流暢**：至少達到層次 2。

**但這只驗證「懂」，不驗證「會用」**。

### 方法 2：Blank Page 測試

**拿白紙**，寫下你對某主題記得的一切。

**看漏洞**：你以為會但寫不出的地方。

**進階版**：**寫下這個主題的 10 個關鍵問題** 並回答。

### 方法 3：空白問題測試

**找一個這個主題的新問題**（你沒見過的），試著解。

- 解得出 → 層次 3 或 4
- 解不出 → 層次 1 或 2

**你不能自己出題**（你會自然挑簡單的）。**找別人出的題**：

- LeetCode（程式）
- 面試題
- 真實世界的問題

### 方法 4：教學測試

**教一個真人**（或嘗試教）。

**觀察**：
- 你能**完整地**教嗎？
- 對方的問題你能**回答**嗎？
- 對方理解嗎？

**教得好 = 你懂得透**。

### 方法 5：時間測試

**3 個月後再做測試**。

**如果你 3 個月後還能**：
- 解釋
- 應用
- 回答問題

**這才是真的「會」**。**短期會但長期忘 = 沒真正掌握**。

**這就是為什麼 Anki 重要**：它幫你**長期維持**你學會的東西。

## 一個實用的自我檢測流程

給你一個具體的流程。**學完任何東西後**，依序做：

### 階段 1：立即檢測

- [ ] **合上書做 blank page**（5 分鐘）
- [ ] **用自己話解釋**（費曼，5–10 分鐘）
- [ ] **標記漏洞**：你發現不懂 / 記錯的

### 階段 2：應用檢測（當天或隔天）

- [ ] **解一個新問題**（用剛學的東西）
- [ ] **觀察卡點**：哪裡需要回去查？

### 階段 3：隔一段時間

- [ ] **1 週後**：再做 blank page
- [ ] **1 個月後**：再做一次
- [ ] **3 個月後**：做完整測試（費曼 + 應用）

### 階段 4：遷移檢測

- [ ] **3–6 個月後**：**在完全不同的情境**用這個概念
- [ ] 如果還能用 → 層次 4

**做過這整個流程的人**，**真的掌握**了這個主題。

## 一個常被忽略的指標：教學能力

**衡量自己「會不會」的最強指標**：**你能不能教**。

**不是隨便教**，是**系統性地**教 — 寫部落格、講解給新人、寫教材（像這門課）。

**教的過程暴露**：

- 你解釋卡的地方
- 你不知道答案的問題
- 你以為懂但其實沒懂的地方

**所以這門課本身的存在**是作者對「怎麼學」這個主題的**掌握證明**。

**對你的意義**：**選一個你以為會的主題，寫一篇 5000 字的完整教學**。

**做得出來** = 你真的會。
**做不出來** = 還有漏洞要補。

## 自我檢測的陷阱

### 陷阱 1：自己出簡單的題

**自測時**，你會**不自覺**選你會的題。

**解法**：**找外部的題**（LeetCode、考試題、真實問題）。

### 陷阱 2：選擇性記憶

**你記得你答對的，忘記你答錯的**。

**解法**：**寫下所有結果**。追蹤率不要只追「懂」，也追「錯」。

### 陷阱 3：把「做過一次」當成「會」

**做過一次** ≠ **會**。

**會 = 能多次重複地、在不同情境做出來**。

**解法**：**多次、間隔、不同情境**。

### 陷阱 4：只檢測知識，不檢測技能

**你可能懂 Python** 的理論，但**寫不出好程式**。

**解法**：**以產出檢測**。**做出什麼 > 知道什麼**。

## 一個終極測試：你能做什麼

**最誠實的檢測**：**你能做什麼**？

- 你學投資 → 你管理了多少錢、報酬多少？
- 你學程式 → 你做出了什麼？部署了什麼？
- 你學寫作 → 你發表了什麼？有多少讀者？
- 你學運動 → 你達成了什麼？體能數據？

**真實世界的產出 = 最終的測試**。

**沒有產出的「會」** = 可能還在層次 2 或 3，沒達到 4。

## 對外部認可的警惕

**小心**：很多人用**外部認可**當自我檢測：

- 「我有證書，所以我會」
- 「我在大學畢業，所以我會這個領域」
- 「我的老闆信任我，所以我會」

**這些不是真正的測試**。

- **證書**：測過去的考試，不測當下能力
- **學位**：測**平均**能力，不測真正深度
- **老闆信任**：可能只是**平均 + 會 present**

**真正的測試**：**你能做真實的事情嗎**？

## 一個建議的習慣：定期的「能力盤點」

**每年一次**，做一個**誠實的能力盤點**：

**寫下你認為自己會的主題**。

**每個主題**，誠實評分：

- **4 分**：能教 / 能遷移 / 能創新
- **3 分**：能獨立應用
- **2 分**：能解釋，但不能獨立做
- **1 分**：能辨認，但做不到
- **0 分**：不會（別誆自己）

**多數人高估**自己。

**誠實的盤點**讓你**看到真實**。

**然後**：

- **給自己 4–8 個重點**（不是所有主題）
- **其他主題誠實承認「我不會」**
- **計畫**如何把 2–3 提到 3–4

**這個盤點**比任何「我很棒」的自我感覺強 10 倍。

## 能力與身份的區分

**一個重要的心態**：**能力 ≠ 身份**。

**你是一個不斷進步的人**，不是「我會什麼」的靜態身份。

**避免**：
- 「我是程式員」→ 不動了，不學新的
- 「我是投資達人」→ 不能承認自己有盲點
- 「我是寫作者」→ 不能接受寫得不好

**接受**：
- 「我在學程式」→ 一直可以進步
- 「我在學投資」→ 永遠有東西學
- 「我在學寫作」→ 接受這週寫得差

**「我在學」的心態**讓你永遠開放。**「我會」的心態**讓你停止成長。

## 最終的自我檢測

**如果這門課你認真讀完了**，做最後一次測試：

**合上這個文件**，試著：

1. **用白話解釋**這門課的核心 — 給一個沒聽過的人聽。
2. **列出 5 個你會開始用的方法**。
3. **寫下你對「自己以前如何學習」的新理解**。
4. **具體寫下**：未來一個月，你會做什麼不同的事？

**如果做得到** → 你真的吸收了這門課。
**如果做不到** → 回去重讀重要章節，真的做各章的自我檢核。

**這門課的價值 0% 在讀過、100% 在你之後怎麼做**。

## 結語

這門課從 Ch 0 到 Ch 29，**系統性地**講了學習的：

- **理論**（記憶、遺忘、注意力）
- **方法**（主動回憶、間隔重複、費曼、interleaving、刻意練習）
- **陷阱**（重讀、劃線、tutorial hell、能力錯覺）
- **系統**（閱讀、筆記、心智模型、遷移）
- **技能 vs 知識**（不同邏輯、ultralearning、project-first、技術自學）
- **過程**（動機、卡住、長期計畫、自我檢測）

**整門課的精髓**可以濃縮成**五個原則**：

1. **主動勝過被動**（Ch 8）：提取比輸入重要
2. **困難合意**（Ch 13）：感覺難 = 學習中
3. **時間分散**（Ch 9）：間隔重複勝過集中
4. **產出勝過吸收**（Ch 24）：做出東西 > 讀很多
5. **長期累積**（Ch 28）：3 年 > 3 個月

**這五個原則**如果你真的內化，你未來的**所有**學習都會加速。

**知道** ≠ **會**（回到 Ch 16）。

**那時候**，你比 95% 的學習者強。

# 如何學習：meta-learning 的系統工法

> 所有 learn_* 系列的「前置課程」。學會這一套，你後面每門課都會快 3–5 倍。

這門課的假設：**你讀過學校，但學校從來沒教過你「如何學習」這件事**。

這是一個荒謬的教育漏洞。學校要求你吸收各種科目的知識，卻從來沒有一堂課教你**大腦是怎麼記住東西的、什麼方法有效、什麼方法是浪費時間**。

結果就是大多數人用「重複閱讀 + 劃線 + 複習筆記」這套**幾乎完全無效**的方法學了 16 年（甚至更久），然後覺得自己學不好是「不夠聰明」「天分不足」。

**不是的**。是**方法錯了**。

過去 50 年認知心理學累積了大量關於學習的實驗證據。好消息是：**這些知識可以操作、可以實踐、而且效果驚人**。壞消息是：這些知識幾乎沒有進入主流教育系統。

這門課要做的事，就是把這些知識濃縮成可用的工法。

## 學完你應該能

- 知道**為什麼**多數人的學習方法是錯的 — 不只是知道「不要這樣做」，而是知道背後的大腦機制。
- 有一套**具體的、可操作的**學習方法（主動回憶、間隔重複、刻意練習、費曼技巧等）。
- 能**辨認自己的學習幻覺**（最大的敵人是「以為學會了但其實沒有」）。
- 能**設計一個長期學習計畫**（3 年、5 年尺度），不只是短期衝刺。
- 能判斷**什麼時候該學、什麼時候該放棄**（這兩個都是技能）。
- 知道**技能學習**與**知識學習**是不同的事，各自有自己的邏輯。
- 能針對**技術自學**（程式、工程、自學型知識）做出專屬的學習系統。

## 為什麼要學這個？

- **學習是元技能**：你一生會學很多東西。把「學習」本身學好，會放大你所有其他學習的投資報酬。
- **自學已是基本功**：現代世界變化快，學校教的知識 10 年後大部分過時。會自學的人能持續更新，不會的人被淘汰。
- **認知科學有確定的答案**：不像心理勵志書靠個人經驗說話，學習科學有 50 年的實驗證據。這些知識是**可重複驗證**的。
- **你的學習方法，決定你能學到什麼**：你可以用一輩子的時間讀書，但如果方法錯了，你得到的東西非常有限。

## 使用方式

- **從頭讀**。Ch 0–2 是必讀的地基，尤其是 Ch 2（編碼與提取）。整門課圍繞這兩個字展開。
- **邊讀邊應用**。這門課不是知識性的（讀完就沒事），是**操作性**的。每讀一章，選一兩個方法試用到你當下正在學的東西上。
- **不含練習**。但 Ch 8、Ch 11、Ch 25 等章裡會明確給「你該做什麼」的指示，等於是嵌在心法裡的實作指南。
- **讀完一次後每半年重讀一次**。學習科學的知識你第一次讀會覺得懂了，但實際應用會踢到很多坑。半年後重讀，你會發現新的層次。

## 一個告誡

學習的方法你可以一週內讀完。但**把它變成習慣**需要幾個月甚至幾年。

大多數人讀完這類書後，**還是回到舊習慣**。原因是新方法在短期內感覺更痛苦（主動回憶比重讀難、間隔重複需要紀律、費曼技巧會讓你發現自己原來不懂）。

**這個痛感是對的**。它就是學習正在發生的訊號。

你的選擇：要嘛接受這個痛、把方法變成習慣、看到一年後的巨大進步；要嘛回到舒服但低效的舊方法、繼續覺得自己不夠聰明。

沒有第三條路。

# Ch 18 — 筆記系統：Zettelkasten、Cornell、個人知識庫

> 好的筆記不只是「抄寫」。好的筆記是**你思考的外化**、**未來的你能查詢的介面**、**跨時間的知識累積**。這一章介紹三種主流的筆記方法，以及怎麼選適合自己的系統。

## 先講結論

**多數人不需要複雜的筆記系統**。簡單的方法做好，勝過複雜系統做差。

但**某些類型的學習者**（研究者、寫作者、大量跨領域學習者）可以從更高階的系統中獲益。

這章會從**最簡單**講到**最複雜**，你依自己需求選。

## 筆記的三個功能

好的筆記系統要滿足三個功能：

### 功能 1：捕捉（Capture）

**你遇到有意思的東西時，有地方寫下來**。

- 讀到的金句
- 突然的想法
- 聽到的 insight
- 疑問

**如果沒地方捕捉**，這些會**消失**。你大腦的工作記憶很快清空（Ch 3）。

### 功能 2：處理（Process）

**捕捉的東西不是終點**。要**處理**：

- 用自己話重寫
- 連結到其他筆記
- 打標籤、歸類
- 做成可複習的 flashcard

**不處理的筆記 = 數位垃圾**。

### 功能 3：提取（Retrieve）

**未來你需要這個知識時找得到**。

- 搜尋功能
- 組織結構
- 連結網絡

**找不到的筆記 = 沒有筆記**。

**三個功能都要滿足**。多數人只做到捕捉，忽略處理和提取。

## 方法 1：Cornell Notes（康乃爾筆記法）

**1950 年代康乃爾大學發展的**。用於課堂或閱讀筆記。

### 結構

把一張紙分成三區：

```
┌──────────┬──────────────────────┐
│          │                      │
│  Cue     │     Notes            │
│  (關鍵詞) │     (主要內容)        │
│          │                      │
│          │                      │
│          │                      │
├──────────┴──────────────────────┤
│                                 │
│         Summary                 │
│         (摘要)                   │
│                                 │
└─────────────────────────────────┘
```

### 使用

1. **上課 / 讀書時**：在右邊大區域寫主要內容
2. **事後（當天或隔天）**：
   - 在左邊寫 **關鍵詞 / 問題**（未來複習用的 cue）
   - 在下方寫**整頁的摘要**（一兩句話）
3. **複習時**：遮住右邊，用左邊的 cue 測試自己（主動回憶！）

### 為什麼有效

- **強迫「處理」**（左邊、下方的摘要都是事後加的）
- **內建主動回憶**（左邊的 cue 設計為測試用）
- **寫摘要是強迫理解整體**

### 適合誰

- 學生（課堂筆記）
- 正在讀一本書的人
- 剛開始建立筆記習慣

### 限制

- **以紙本為主**（數位版有但較不自然）
- **按時間順序**，不擅長跨筆記連結
- **不適合大量知識的長期累積**

## 方法 2：Zettelkasten（卡片盒）

**德國社會學家 Niklas Luhmann 發展**，他靠這個方法寫了 70+ 本書和 400+ 篇論文。

### 核心概念

**每個「想法」是一張卡片**。卡片間**互相連結**，形成一個**知識網絡**。

**跟 Cornell 不同**：Cornell 的筆記是**以來源組織**（這個筆記來自哪一章）。Zettelkasten 的筆記是**以想法組織**（這個筆記是一個獨立的想法）。

### 結構

每張卡片有：

1. **唯一 ID**（日期 + 時間，例：202411230845）
2. **標題**（這張卡的核心想法）
3. **內容**（**一個**想法，用自己的話寫）
4. **連結**（這個想法跟哪些其他卡片相關）
5. **標籤 / 分類**

### 範例

**卡片 A**（ID: 202411230901）

```
標題：流暢性錯覺 vs 真正的理解

內容：流暢性錯覺是把「熟悉」誤認為「掌握」。這是重讀學習無效的主要原因 — 你讀第三次時感覺熟悉，大腦誤判為理解，但其實沒建立可提取的記憶。

區分：
- 熟悉 = 認出文字
- 理解 = 能用自己話解釋  
- 掌握 = 能在新情境應用

連結：
- → [202411230845] 主動回憶是解法
- → [202411220530] Bjork 的儲存 vs 提取強度
- → [202411231020] 能力錯覺的機制
```

**這張卡**：
- **獨立**（不需要其他 context 就能讀）
- **用自己話**寫
- **有連結**到其他卡片
- **有具體 ID**

### 特色：連結與 emergence

Zettelkasten 的威力**不在單張卡片**，在**卡片之間的連結**。

**你寫卡片時**，會發現：

- 「啊，這個想法跟前天寫的卡片 X 有關」 → 建立連結
- 「這跟 A 和 B 兩張卡都有關，它們之間也有關」 → 形成三角
- 幾個月後，**某個主題周圍自然形成密集的網絡**

**這個網絡**本身就是你正在形成的思想。

**你要寫一篇文章 / 論文時**，看哪裡卡片密集 → 那就是你已經累積的知識 → 直接拿來用。

### 實作：數位 vs 實體

**實體版**：Luhmann 用**真實的紙卡**，存在木盒裡，用編號系統連結。

**數位版**（當代主流）：

- **Obsidian**：免費、本地檔案、支援 markdown、強連結
- **Roam Research**：付費、強連結、雙向連結的原創
- **Logseq**：開源、類似 Roam
- **Notion**（較弱）：可以做但不是為 Zettelkasten 設計

### 適合誰

- 長期累積知識的人（研究者、寫作者、博士生）
- 跨領域學習者
- 想寫書 / 長文的人
- 對知識的「連結」有興趣

### 不適合誰

- 只想**臨時記點東西**的人
- 時間短暫的學習（只學一門課 3 個月）
- 覺得這個系統太重的人

**老實說**：**Zettelkasten 是高投入高回報**。如果你沒打算長期（幾年以上）用，不需要學它。

## 方法 3：個人知識庫（Personal Knowledge Base / PKM）

**最寬鬆的方式**：一個數位空間，混合各種筆記、想法、資料。

### 特色

- **不強制結構**（你可以用資料夾、標籤、連結混合）
- **各種類型**（簡短備忘、長篇文章、清單、todo、專案筆記）
- **融合工作與學習**

### 典型工具

- **Notion**：最流行、介面好、模板多
- **Obsidian**：更 local、更 hackable
- **Apple Notes**：極簡、與蘋果生態整合
- **OneNote**：微軟生態

### 一個簡單架構

```
/Knowledge Base/
  /Daily Notes/         ← 每天的流水帳
  /Books/               ← 每本書一個筆記
  /Topics/              ← 主題性的長期筆記
    /投資/
    /學習方法/
    /Python/
  /Projects/            ← 進行中的專案
  /People/              ← 重要的人、聯絡資訊
  /Resources/           ← 收藏的文章、連結
```

### 適合誰

- 剛開始建筆記習慣
- 不想學複雜系統
- 想要靈活多元的記錄

### 限制

- **容易亂**（如果不時時整理）
- **不強制處理**（你可能只捕捉不處理）
- **長期下來找不到東西**（搜尋依賴標題）

## 選哪個系統？

實用的決策樹：

### 如果你現在沒有筆記系統

從**簡單的**開始：

- **Apple Notes** 或 **Google Keep**
- 做 Cornell 式的筆記結構
- 用 **3 個月** 看自己需要什麼

**不要一開始就學 Zettelkasten**。那是進階工具。

### 如果你寫有需要記很多跨主題的知識

- 升級到 **Notion** 或 **Obsidian**
- 用**資料夾 + 標籤** 組織

### 如果你是研究者 / 寫作者 / 深度學習者

- **Obsidian 或 Logseq**
- **嘗試 Zettelkasten 方法**（慢慢建立，不急）

### 如果你有特定項目（例：這門課）

- **一個資料夾裝所有相關筆記**
- **整合到既有系統**（不要為每個項目開新工具）

## 筆記的核心原則（不論系統）

**無論你用什麼系統**，這些原則都適用：

### 原則 1：用自己的話寫

**最重要的原則**。

- 抄書 = 沒有理解
- 用自己話重寫 = 強迫理解 = 真正的學習

如果你不能用自己話重寫，代表**你還沒懂**。回去重讀。

### 原則 2：筆記要能獨立

**未來的你不記得當時的 context**。

所以：

- 每個筆記**自己能看懂**
- 不要寫「上面說的 X」（一週後你不記得上面是什麼）
- **完整句子**，不要只寫關鍵詞

### 原則 3：連結到既有知識

**新資訊如果不跟既有連結，會被遺忘**。

- 這個跟我上週讀的 X 有什麼關係？
- 這個跟我工作的 Y 有什麼連結？
- 這個跟我已經知道的 Z 哪裡不同？

**連結是記憶的黏著劑**（Ch 2 的深度編碼）。

### 原則 4：定期回頭看

**筆記不是寫完就丟**。

- 每週看上週的筆記
- 每月看上月的筆記
- 重要的筆記要反覆看

沒回頭看的筆記 = 資訊墓園。

### 原則 5：拒絕「完美主義」

**不要為排版、顏色、分類糾結**。

**內容 > 形式**。花時間寫好內容，不是調格式。

## 做筆記的三大陷阱

### 陷阱 1：只收藏不閱讀

**Read Later 變成 Never Read**。你收藏 100 篇文章，讀過 3 篇。

**解法**：**不收藏，直接讀**。如果現在沒時間讀，**多半以後也沒時間**。

### 陷阱 2：筆記多但沒連結

一堆獨立的筆記。沒有跨筆記的連結或思考。

**解法**：寫每個筆記時問：**這跟我已經寫過的哪些有關？**

### 陷阱 3：只做筆記不學習

**做筆記**本身不是學習。筆記是**支援**學習的工具。

**解法**：筆記 + 主動回憶 + 實踐 — 不要把筆記當成學習的全部。

## 一個實用建議：start small

如果你從來沒有系統性做筆記，**不要一次建大系統**。

**第一階段（1–2 個月）**：
- 用最簡單的 app（Apple Notes 或類似）
- 強制自己「每讀完一章就做筆記」
- 用 Cornell 格式

**第二階段（3–6 個月）**：
- 如果你發現自己有了習慣
- 升級到 Notion / Obsidian
- 建立主題性的筆記

**第三階段（一年以上）**：
- 如果你真的在長期累積
- 考慮 Zettelkasten
- 建立你的知識網絡

**每一階段的升級**都根據你**真實的需求**，不是因為看到別人的推薦。

## 一個有爭議的觀點：工具焦慮

網路上很多人**痴迷於筆記工具**。他們會花幾週研究 Obsidian vs Roam、Zettelkasten 的各種流派、不同 plugin 的組合。

**但他們的實際筆記很少**。

**警訊**：

- 你花在**研究工具**的時間 > 花在**寫筆記**的時間
- 你一直**重構筆記系統**（每幾個月全部重整）
- 你擁有多個筆記系統，每個都半吊子

**這叫 tool obsession / productivity porn**。它是一種**逃避真正工作**的方式。

**治療**：

- **選一個工具，用 6 個月**，不要換
- **內容 > 工具**
- **寫一篇短文** > 研究十個新功能

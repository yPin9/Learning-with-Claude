# Ch 14 — 重複閱讀與劃線的幻覺

> 這是本課最殘酷的一章：**你從小到大最依賴的學習方法，幾乎是最無效的**。重複閱讀、劃線、做漂亮筆記 — 這些被學校與家長鼓勵的動作，科學上的證據是：**幾乎沒有長期學習效果**。這一章把這件事講到讓你不再願意用它們。

## 先給證據

前面 Ch 1 提過 John Dunlosky 2013 的綜覽研究。再提一次，因為這是最重要的證據：

### Dunlosky 2013 的評估

| 方法 | 效果 | 常用度 |
|---|---|---|
| **Practice Testing（測驗）** | **高** | 極低 |
| **Distributed Practice（間隔）** | **高** | 低 |
| Elaborative Interrogation | 中 | 低 |
| Self-Explanation | 中 | 低 |
| Interleaved Practice | 中 | 極低 |
| **Summarization（摘要）** | **低** | **高** |
| **Highlighting（劃線）** | **低** | **極高** |
| Keyword Mnemonic | 低 | 中 |
| Imagery for Text | 低 | 低 |
| **Rereading（重讀）** | **低** | **極高** |

**看出模式了嗎**：

- **高效方法 = 低常用度**
- **低效方法 = 高常用度**

這不是巧合。低效方法因為**感覺良好**而被大量使用。高效方法因為**感覺困難**而被迴避。

這是**教育體系的集體系統性失敗**。

## 我們來一個一個拆

### 拆解 1：重複閱讀（Rereading）

**為什麼感覺有效**：

- 第二次讀時，內容變**熟悉**
- 熟悉 → 大腦誤判為「掌握」
- 第三次讀更熟悉 → 更有信心
- 這就是 **流暢性錯覺**（Ch 1）

**為什麼實際無效**：

- 熟悉 ≠ 能提取
- 你沒做任何「主動調出記憶」的動作
- 資訊只是**流過**工作記憶，沒真正進入長期記憶

**實驗證據**：

Callender & McDaniel (2009) 研究：

- 讓大學生讀教科書章節，一組讀一次、一組讀兩次
- 之後測驗

**結果**：讀兩次的**沒有顯著優於**讀一次。

**第三次、第四次讀**：效果遞減。**讀 4 次 vs 讀 2 次** 幾乎沒差。

### 一個比較

**A 方案**：讀 4 次，花 80 分鐘
**B 方案**：讀 1 次（20 分鐘）+ 主動回憶 3 次（共 30 分鐘）= 總 50 分鐘

**長期記憶的比較**：B 方案顯著強於 A，而且只花 62% 的時間。

**多出的 30 分鐘**拿去做別的學習、休息、或吃飯 — 都比第 2、3、4 次重讀好。

### 當重複閱讀是 OK 的

公平地說，**少量**重讀不是完全沒用：

- **第一次讀沒讀懂**：可以再讀一次
- **幫助你理解結構**：第二次讀時看到整體架構
- **校對錯誤**（寫作時）

**但超過這個**，重讀是在浪費時間。

**替代方案**：第一次讀完，**不重讀，做主動回憶**。卡住的地方再回去查那個具體段落。

## 拆解 2：劃線 / 螢光筆（Highlighting）

**為什麼感覺有效**：

- 劃的動作**感覺在做事**
- 劃完後感覺「這本書我處理過了」
- 書本上的顏色視覺上**豐富**

**為什麼實際無效**：

- 劃線是**極低認知負荷**的動作（幾乎不用思考）
- 你只是在**判斷「這句重要」**，沒有處理內容
- 劃完後你**不會真的回去讀那些劃線**（多數人不會）
- 更糟：劃線**提供安全感**，阻止你真的學習

**研究證據**：

Peterson 1992 年的研究：

- 兩組學生讀同一篇文章
- A 組：允許劃線
- B 組：不許劃線
- 之後測驗

**結果**：**劃線組沒有顯著優於不許劃線組**。

**甚至**：**某些研究顯示劃線組表現略差**。

原因：劃線讓他們**以為自己學了**，放棄了真正的學習動作。

### 劃線唯一合理的用法

**如果你真的要劃線**：

- 劃線作為**未來主動回憶的 cue**
- 讀完一節後，**合上書**
- 拿劃線的位置當提示，**回想那段內容**
- **如果你不做這個回想動作，劃線就是浪費**

**99% 的人劃了線就結束了**。劃線 → 感覺有學習 → 闔上書 → 從未回頭。

這些劃線幾乎沒有價值。

## 拆解 3：漂亮的筆記

**為什麼感覺有效**：

- 整齊、彩色、看起來像在學習
- 滿足某種秩序感
- 可以在 Instagram 分享

**為什麼實際無效**：

- 漂亮的筆記 = **優秀的抄寫員**，不是學習者
- 花 1 小時寫筆記 vs 15 分鐘寫筆記 + 45 分鐘主動回憶 — 後者效果高很多
- 有漂亮筆記的人通常**不會真的回去看**（因為已經「學過了」）

**研究**：

有個實驗讓學生用兩種方式做筆記：

- A 組：**詳細地抄**講師的內容
- B 組：**簡短地寫關鍵詞**，之後用自己的話重建

**結果**：B 組學得更好。

**為什麼**：A 組在做**轉抄**（低認知）。B 組在做**理解 + 重建**（高認知）。

### 筆記的正確用法

**不是**「把講師說的全寫下來」。
**是**「用自己的話寫關鍵洞察」。

一頁漂亮筆記 vs 半頁費曼式筆記 → 後者有效 10 倍。

**簡短、用自己話、帶問題**的筆記才有價值。

## 拆解 4：做摘要（Summarization）

**為什麼感覺有效**：

- 比重讀多了一個「生成」動作
- 會逼你處理內容

**為什麼實際效果有限**：

- **如果只是抄寫原文關鍵句**：跟劃線差不多，沒有深度處理
- **如果是真的用自己話重寫**：有效，但這其實是費曼技巧的一種（有效），不是「摘要」本身有效

**關鍵差別**：

- **壞摘要**：照抄原文 = 低認知
- **好摘要**：用自己話重組 = 接近費曼技巧 = 有效

大多數人做的是**壞摘要**。

## 為什麼這些方法持續存在

**既然這些方法無效，為什麼學校還在教？**

### 原因 1：教師也沒被教過學習科學

多數老師從自己的老師那學到怎麼教。**傳統延續下來**。很多老師**不知道**這些方法無效。

### 原因 2：考試設計獎勵這些方法

選擇題、配對題的考試，依賴「辨識」記憶。**重讀已經足夠應付**。

所以重讀在**這些考試**上是有效的 — 但學生考完就忘，學不到應用的能力。

**考試制度設計錯了，方法配合錯了**。

### 原因 3：家長的加成

家長看到孩子「在劃線、做漂亮筆記」會稱讚「很用功」。

家長看到孩子「閉著眼睛在沙發上想」會覺得「在發呆」。

**外部獎勵錯的動作，懲罰對的動作**。這會塑造下一代的學習習慣。

### 原因 4：書商的行銷

彩色筆、筆記本、螢光筆 — 這些產業的商業利益與低效方法綁在一起。**它們會繼續推廣**這些方法。

## 一個真實的故事：聰明的失敗者

很多名校學生從小成績好。他們用傳統方法（重讀 + 劃線 + 詳細筆記）成功。

**但到了大學或職場**，他們會失敗 — 因為：

- 大學 / 職場需要**真正的理解與應用**（不只是辨識）
- 傳統方法**沒有建立深度掌握**
- 他們過去成功來自「**認真的重讀**」 + 部分天分
- 當內容太多或太難，重讀不夠用

**這些人**意識到自己的方法錯了，往往已經大學三年級。他們**之前的「好成績」**讓他們以為方法對，反而阻礙了更早的調整。

**如果你現在是學生**：不要被「看起來用功」的方法迷惑。早點轉成有效方法。

**如果你已經出社會**：現在轉還不晚。一年的正確方法勝過十年的錯誤方法。

## 一個重要的區分：短期 vs 長期表現

**傳統方法（重讀、劃線）的「優勢」在短期**：

- 短期測驗（讀完當天）：重讀組有小優勢
- **長期測驗**（一週後）：主動回憶組大勝
- **應用到新情境**：主動回憶組遠遠勝出

**學習的價值 99% 在長期與應用**，不在短期。

**所以傳統方法的「優勢」幾乎沒有真實價值**。它們只是幫你**通過下週的考試**，沒幫你學到永久的知識。

## 一個情感難處：放棄舊習慣

**放棄這些方法心理上很難**。原因：

- **慣性**：你已經用了 15 年
- **身份**：「我是勤奮的學生」綁在這些動作上
- **不安全感**：沒做筆記 / 沒劃線感覺「什麼都沒學」
- **社會證據**：大家都這樣

**如何轉換**：

1. **先接受證據**：Dunlosky 研究是實驗性的、可複製的。不是觀點。
2. **試一個月**：完全不劃線、不重讀，改用主動回憶 + 間隔重複
3. **對比結果**：一個月後你會發現記得比過去多很多
4. **一旦嘗到新方法的效果**，舊方法的吸引力會自然消失

這需要**幾週的決心**。之後你自己會想換。

## 一個溫和的路徑：過渡期

**如果完全放棄舊方法讓你焦慮**：

**過渡方式**：**保留少量舊動作，但強制加新動作**。

- 仍然劃線，**但**每章讀完後強制**合上書做 blank page**
- 仍然做摘要，**但**一週後強制**不看摘要做主動回憶**
- 仍然重讀，**但**每次重讀前強制**先試著回憶**

這個過渡期**新舊並存**。幾週後你會發現**新動作才是真正讓你進步的**。舊動作可以自然放掉。

## 一個總結：時間重分配

**假設你一週有 10 小時學習時間**。

**傳統分配**：

- 讀書：4 小時
- 劃線 / 做筆記：3 小時
- 重讀 / 複習筆記：3 小時

**結果**：讀很多、記得少。

**有效分配**：

- 讀書：3 小時
- **主動回憶（blank page / Anki）：4 小時**
- **費曼 / 解題 / 應用：2 小時**
- 間隔重複維護：1 小時

**一樣 10 小時，效果 3–5 倍**。

**主要的轉換**：從「輸入型」動作（讀、劃、抄）轉到「輸出型」動作（回憶、解釋、應用）。

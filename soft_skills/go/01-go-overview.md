# Ch 1 — 圍棋全貌與段級制度

> 目標：建立整門課的 mental map。知道圍棋怎麼分段、學棋路線怎麼走、AI 時代要避開哪些坑。

## 圍棋是什麼（30 秒版）

兩個人輪流在 19x19 棋盤交叉點放黑白棋子，**目標是圈出比對方多的「地」**。最後數子或數目，多的勝。

唯一的取子規則：**沒有「氣」的棋子被提走**。「氣」= 棋子上下左右相連的空點。一塊棋只剩 1 口氣 = 「打吃」、0 口氣 = 被提。

跟西洋棋對比：

| 項目 | 西洋棋 | 圍棋 |
|---|---|---|
| 棋盤 | 8x8 | 19x19 |
| 棋子 | 6 種，從 32 顆減少 | 1 種，從 0 開始放 |
| 規則複雜度 | 中（吃子、王車易位、過路兵、升變...） | 極簡 |
| 變化空間 | ~10^120 | ~10^170 |
| 頂尖 AI 出現 | 1997 (Deep Blue) | 2016 (AlphaGo) |
| 一盤平均手數 | 40-80 | 200-300 |

圍棋規則 5 分鐘能教完，但精通要一輩子。**這種規則簡單但策略無窮的遊戲，正是它迷人的原因**。

## 段級制度

圍棋的強度量化是「段位 / 級位」。從弱到強：

```
 30k → 25k → 20k → 15k → 10k → 5k → 1k →
 1d → 2d → 3d → 4d → 5d → 6d → 7d (業餘高段) →
 1p → 2p → ... → 9p (職業)
```

| 段級 | 強度約略 | 達到時間（成人認真學） |
|---|---|---|
| 30k | 剛學會規則 | Day 1 |
| 15k | 9x9 能下完不亂 | 1-2 個月 |
| 10k | 19x19 能下完，知道圍地 | 3-6 個月 |
| 5k | 死活基本不錯，會手筋 | 1 年 |
| 1k - 1d | 業餘中段，能對殺、會佈局 | 1-2 年 |
| 3d | 強業餘 | 2-4 年 |
| 5d - 7d | 業餘高段 | 5-10 年（且要對局量充足） |
| 1p+ | 職業段位，童子功 | 不可能成年才開始 |

**「k」= kyu = 級**（弱），**「d」= dan = 段**（強）。1k 的下一級是 1d，**沒有 0 段**。

職業段位（1p-9p）跟業餘段位**完全不同尺度**：業餘 7d 對職業 1p 通常需要讓 3-4 子。

不同平台的段位略有出入：

- **OGS**：通膨較少，rank 比實際略高一些
- **KGS**：傳統校準，最接近真實水平
- **野狐 / Tygem**：通膨較重，野狐 5d 約 KGS 2d
- **Fox / 弈城**：韓國強手集中，rank 嚴

**段位不是目標，下棋的快樂才是目標**。但有個量化指標確實能驅動學習。

## 圍棋的「三大支柱」

幾百年來圍棋訓練法都圍繞這三件事：

1. **死活（Life and Death / 詰碁）**：判斷一塊棋活還是死。**這項弱 = 上不去**
2. **手筋（Tesuji / 手筋）**：在小範圍內找最強的一手
3. **形（Shape / 形）**：直覺判斷哪些棋形好、哪些壞

這三項佔上手強度的 80%。**佈局、定石、棋史，都是次要**。Part 4-6 整整 12 章在打這三項。

## AI 時代怎麼學棋

2016 年 AlphaGo 之前，圍棋學習鏈是：「看書 / 老師 → 跟強過自己的人下 → 復盤 → 再下」。問題：

- 強者老師難找、貴
- 復盤靠記憶，講者主觀
- 一盤要等對手願意配合復盤
- 大多數錯手沒人指出

**KataGo 把這套全部解掉**。它能：

- 24/7 陪你下、任何 rank 都調得到
- 即時告訴你「這手丟了多少目」（mistake highlight）
- 給推薦變化、解釋為什麼
- 全自動復盤上百盤都不抱怨

**現代學棋的「正確姿勢」**：

```
 你下棋 (OGS / 野狐) ──────► 棋譜
                                │
                                ▼
                         KataGo 復盤
                                │
                                ▼
              標出 mistakes + 建議手 ──► 你看
                                          │
                                          ▼
                                 死活 / 手筋題複習
                                          │
                                          ▼
                                     再下棋
```

這個循環一週跑 5-7 次，半年保證升 5 級以上。

**沒這個循環的話**：背定石 200 個、看名局 100 盤、讀理論書 10 本，不如 KataGo 復盤 10 盤實戰。

## 一個常見誤解：「圍棋很難因為規則複雜」

圍棋規則**比西洋棋簡單**。難的不是規則，是**搜尋空間大到無法靠記憶**。西洋棋大師背 1 萬個開局變化能用一輩子；圍棋背完所有定石還是只能應付佈局，中盤跟收官完全靠當下計算 + 棋感。

**圍棋的難在「決策的廣度」，不在規則的深度**。

## 一個常見誤解：「先看書，理論扎實再開始下」

新手最大的學習誤區。圍棋是**體感遊戲**，純讀理論不會 internalize。正確順序：

```
 規則熟練 (1 天) → 馬上下棋 → 卡住 → 找書 → 再下 → 卡住 → 再找書
```

不是：

```
 看完厚厚一本理論書 → 開始下 → 發現書裡的東西用不出來
```

**Ch 2 規則章節讀完，立刻去 OGS 下一盤 9x9**，再回來繼續讀後面章節。

## 一個常見誤解：「定石要背很多才能上」

**錯**。職業棋手知道 200+ 定石；業餘高段 30 個就夠。**每個定石的「為什麼這樣下」比背順序重要**。

AI 時代更是這樣 — KataGo 讓很多傳統定石被推翻（如三三入侵在現代成主流）。背 5 年前的定石可能反而下出「不是當前最佳」的棋。Ch 24 詳細講。

## 一個常見誤解：「死活我會了再來下」

死活是**永遠學不完的**。等你「全會了」這天不會來。**邊下邊練，遇到死活問題就回頭做題**，這比連做 1000 題再下棋實用。

死活題不是課程作業，是日常練習。**每天 30 題**比「集中三天做 500 題」有效 100 倍。

## 動手練習

**1. 確認段級認知**

去 OGS / 野狐看 5 個高段棋手的棋譜（搜「7d」），跟 5 個入門棋手的對局（搜「20k」）。看 5 分鐘對比 — 不為理解內容，只為形成「強跟弱差多少」的直覺。

**2. 看 AlphaGo vs 李世乭第二局**

YouTube / Bilibili 搜「AlphaGo Lee Sedol Game 2 第 37 手」。第 37 手是 AI 史上最有名的一步。**看不懂沒關係**，記住這個畫面 — 後面 Ch 24 會回來解釋為什麼這手震驚當代棋界。

**3. 規則自我檢測（為下一章預熱）**

你能不能講出：

- 「氣」是什麼？
- 「打吃」是什麼？
- 提一個子的條件？
- 為什麼「禁入點」存在？
- 什麼是「劫」？

不能完整答 → 沒關係，Ch 2 會詳細教。能答對 → 很好，Ch 2 用來確認細節。

**4. 訂出你的對局頻率**

寫下自己的承諾：「我每週至少下 X 盤、做 Y 題死活」。**寫下來貼螢幕邊**。圍棋的進步跟頻率高度相關。

我建議入門期最少：
- 對局：每週 3-5 盤（先 9x9，後 19x19）
- 死活題：每天 10-30 題

進階期：
- 對局：每週 10+ 盤
- 死活題：每天 30-50 題

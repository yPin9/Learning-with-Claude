# Final Project — 50 盤升段挑戰

> 目標：把整套課程學的東西黏起來。50 盤實戰，每 10 盤一個 milestone 復盤。完成後你應該到業餘 1d/1k 線。

## 任務規格

| # | 項目 | 內容 |
|---|---|---|
| 1 | 對局數 | 50 盤 19x19（OGS / 野狐 / KGS） |
| 2 | 對手 | 真人（不對 AI），rank 接近你 |
| 3 | 復盤 | 每 10 盤 1 個 milestone 詳細復盤 1 盤 |
| 4 | 戰報 | 每 milestone 寫 500+ 字戰報 |
| 5 | 升段驗證 | 50 盤後對比起點段位，目標升 1+ 級 |
| 6 | 時間 | 大約 1-2 個月 |

## 為什麼是 50 盤

少於 50 盤：太少對局形成不了 pattern 改善  
多於 50 盤：戰報跟不上 → 無效對局

**50 盤是業餘升段的「最低有效量」**。配合死活 + 手筋訓練更佳。

## 平台選擇

| 平台 | 優點 | 缺點 |
|---|---|---|
| **OGS** | 英文友善、free、可下載 SGF | 對手品質參差 |
| **野狐圍棋** | 高水平棋手多 | 中文介面、廣告 |
| **KGS** | 老牌、社群緊密 | 介面老 |
| **Tygem / Fox** | 韓國強手 | 高段才友善 |

**推薦**：OGS 為主、野狐為輔。

## 50 盤的節奏建議

### 階段 1：第 1-10 盤（適應期）

- 找你目前 rank 的對手
- 大量輸（適應真人）
- **不必每盤詳細復盤**，1-2 盤詳細即可

第 10 盤 milestone：詳細復盤 + 寫戰報

### 階段 2：第 11-20 盤（穩定期）

- 勝率約 50%
- 開始識別自己的高頻 pattern

第 20 盤 milestone：詳細復盤 + 跨前 20 盤的 pattern 分析

### 階段 3：第 21-30 盤（突破期）

- 應用 pattern 改善
- 勝率穩定在 55%+
- 平台給你升級提示

第 30 盤 milestone：升 1 級慶祝 + 復盤升級對局

### 階段 4：第 31-40 盤（鞏固期）

- 在新 rank 適應
- 可能短暫掉回原 rank
- 繼續死活訓練

第 40 盤 milestone：對比 1-10 盤跟 31-40 盤的棋力差異

### 階段 5：第 41-50 盤（衝刺期）

- 目標升到 1d/1k 線
- 最後 milestone 詳細復盤

第 50 盤 milestone：完整總結 50 盤

```markdown

## 階段總結
- 對局範圍：第 (N-9) - N 盤
- 整體勝率：?
- 段位變化：起點 X → 現在 Y
- 最高 rating：?

## 詳細復盤對局（這 10 盤中最具代表性的 1 盤）
（按 Ch 34 完整復盤模板）

## 累積 pattern 變化
- 之前 milestone 的 pattern 1：是否消失？
- 之前 milestone 的 pattern 2：是否消失？
- 新出現的 pattern：

## 死活 / 手筋訓練量
- 這 10 天死活題：N 題
- 平均答對率：?
- 手筋題：N 題
- 平均答對率：?

## 對比過去
- 跟前 10 盤比，哪些方面有進步？
- 哪些方面沒進步？

## 下個階段重點
- 1 個要改的 pattern
- 1 個要加強的訓練
- 1 個對局心態調整
```

每個 milestone 寫 500-800 字。**5 個 milestone × 1 hour = 5 小時投入**，加上對局 50 hour = **總投入 60 小時**。

## 配套訓練

對局之外：

- **每天死活 30 題**（持續 60 天）
- **每天手筋 10 題**
- **每週看 1 盤名局**（用 Ch 36-37 列的）
- **每週 1 次 KataGo 深度復盤**

50 盤對局 + 完整訓練 = 1-2 個月升 1-2 段。

## 期望結果

| 起點 | 預期目標 |
|---|---|
| 30k - 20k | → 15k - 10k（升 5-10 級） |
| 15k - 10k | → 5k - 1k（升 5-10 級） |
| 10k - 1k | → 1d - 3d（升 1-2 段） |
| 1d - 3d | → 3d - 5d（升 1-2 段） |
| 5d+ | → 5d+1（少數人能升）|

**業餘高段 5d+ 後升段非常慢**，可能 1 年只升半段。50 盤對 5d+ 不夠。

如果你起點是 30k，50 盤後到 15k 是合理的。**升段速度跟你的「死活練習量」高度相關**。

## 常見錯誤

| 症狀 | 修 |
|---|---|
| 對局太頻繁、沒復盤 | 強制每 10 盤暫停做 milestone |
| 對手太強連敗 | 降 rank，找你水平的 |
| 對手太弱連勝 | 升 rank，挑戰高一段 |
| 50 盤後沒升段 | 對局 + 死活訓練量都不夠，再加 50 盤 |
| 寫戰報太累放棄 | 縮短到 200 字 + 1 個 pattern |

# 練習 D — 中盤判斷題 + 對局復盤

> 目標：用 5 盤完整中盤對局練「形勢判斷 + 急所大場 + 攻擊收益」三合一。

## 任務規格

| # | 項目 | 內容 |
|---|---|---|
| 1 | 對局數 | 5 盤完整 13x13 或 19x19 對局 |
| 2 | 形勢判斷 | 每盤手 50 / 100 / 150 各做 1 次（共 15 次） |
| 3 | KataGo 復盤 | 每盤完整復盤 + 對形勢判斷比對 |
| 4 | 急所識別 | 每盤找出 3 個急所場合 |
| 5 | 攻擊分析 | 每盤分析 1 次攻擊：殺 / 逼活 / 取厚 / 換手 |

## 工作流程

### 對局前

設定 KaTrain 對 AI（你的等級）：

- 13x13 或 19x19（以 13x13 開始）
- 不開即時分析（讓自己練）

### 對局中

每手前自問 5 步思考順序（Ch 25）：急所 → 大場 → 弱塊 → 厚薄 → 先後手。

每手 50 / 100 / 150 暫停做形勢判斷：

```markdown
## 手 50 形勢判斷
- 黑實地：?
- 黑準地：?（折扣 ?%）
- 白實地：?
- 白準地：?（折扣 ?%）
- 加贴目，差距：?
- 策略：穩 / 激 / 平
```

### 對局後

KataGo 復盤：

1. 看 score lead 的實際變化曲線
2. 對比你的 3 次判斷跟 AI 真實值
3. 找最大失誤手 (-5 目以上) 5 個
4. 對每個失誤手分析：

```markdown
## 失誤 3：手 N
- 我下：X
- AI 推薦：Y
- score loss：N 目
- 為什麼錯：
  - 沒看到急所？
  - 沒做好形勢判斷？
  - 攻擊方向錯？
- 改善計畫：
```

5. 找出當盤你的「攻擊類型分析」：

```markdown
## 本盤攻擊分析
- 我攻擊了對方哪塊？（中央 / 角 / 邊）
- 攻擊類型：殺 / 逼活賺地 / 取厚 / 換手
- 收益：N 目
- 失敗點：
```

## 期望結果

5 盤完成後，你應該：

1. 形勢判斷誤差：從 ±20 目降到 ±15 目
2. 急所識別率：從 50% 升到 65%
3. 攻擊有計畫率：從 30% 升到 50%
4. KataGo 評估失誤手：從 8-10 個 / 盤 降到 5-6 個 / 盤

## 常見錯誤

| 症狀 | 原因 |
|---|---|
| 形勢判斷誤差 > 30 目 | 模樣折扣給太高 / 沒算贴目 |
| 對 KaTrain 連敗 | rank 設太高，降 5 級 |
| 5 盤都沒實踐入侵 | 故意設定「至少 1 次入侵」目標 |
| 攻擊沒方向 | 攻擊前先決定類別（殺 / 逼活 / 取厚 / 換手） |

## 進階挑戰

**A. 連 5 盤形勢判斷誤差 < 10 目** → 升 1 個棋力小段。  
**B. 找一個棋友交換對局報告** → 互相檢查盲點。  
**C. 看一盤職業棋自己做形勢判斷** → 跟解說員對比。

# Ch 30 — 收官的價值計算

> 目標：學會精算每個收官手的目數價值，按價值順序執行 — 收官決定 5-10 目，常常是勝負關鍵。

## 為什麼收官重要

中盤結束後雙方領土雛形定、剩 30-50 個小手。每手價值 0.5-5 目。

**新手收官**：隨意下、看哪邊空就下哪邊  
**業餘 1d 收官**：粗算大小、優先大者  
**業餘高段收官**：精算到 0.5 目、無誤

收官常常**勝負差 5-10 目**，業餘 1d 收官好可以勝業餘 3d 一盤。

## 收官手的「大小」分類

| 類別 | 一手價值 | 何時收 |
|---|---|---|
| 大官子 | 5-15 目 | 第 1 批 |
| 中官子 | 2-5 目 | 第 2 批 |
| 小官子 | 1-2 目 | 第 3 批 |
| 半目官子 | 0.5 目 | 最後 |

按大小**從大到小**收。新手反過來 → 大虧。

## 「先手 / 後手」對價值的影響

每個官子手有「先後手」屬性：

- **先手**：你下完對方必須應 → 你拿先手再下別處
- **後手**：你下完對方可不應 → 你失主動

「**先手 5 目**」實質上 = **5 目 + 你拿到的下一手價值**。

例：

```
 A 點：先手 5 目
 B 點：後手 8 目
```

哪個大？要看 A 之後你下的「下一手」價值。如果下一手 4 目以上，A 加總 = 9+ 目，超過 B 的 8 目。

公式：

```
 先手手實際值 ≈ 後手手目 × 2
```

也就是：「**先手 3 目** ≈ **後手 6 目**」。

## 「逆官子」的價值

「逆官子」 = 你對方該收的後手手，你先下了。

對方先手後手的價值差 = 5 目，你逆下 = 你拿到 + 對方失去 = **加倍**。

例：

```
 A 點對黑：後手 5 目
 A 點對白：先手 3 目（白下時黑必應）

 如果白先收 A：白賺 3 + 後續 5 = 8 目
 如果黑逆收 A：黑賺 5 + 對方失 3 = 黑領先 8 目
 兩種差 16 目！
```

「逆官子」常是收官最大手段。

## 收官順序的算法

每個收官手按 **( 自己賺 ) + ( 對方失 )** 排序：

1. **雙先**（你下對方必應，對方下你必應）→ 最大
2. **逆官子**（搶對方該下的後手）→ 次大
3. **單先**（你下完對方應）→ 中
4. **後手大**→ 中
5. **後手小**→ 末

## KataGo 的收官精準度

KataGo 收官手手精算，誤差 < 0.5 目。

業餘新手收官誤差 5-15 目。**這就是輸的原因**。

## 一個常見誤解：「收官手手細，沒差」

**錯**。收官 50 手，每手平均錯 0.2 目 = 10 目誤差。一盤 = 一個大角的差。

「收官精算」是上手必修課。

## 一個常見誤解：「先手手都該優先」

**部分對**。先手手通常優先，但**不是無腦先手**。

「先手 1 目」 vs 「後手 10 目」 → 後手大。先手再帶 5 目價值的下一手，總 6 目，仍小於 10 目。

## 一個常見誤解：「逆官子是新手陷阱」

**錯**。逆官子是收官最強招。「對方該下而我先下」 → 等於拿到雙倍。

新手不下逆官子 = 失多目。

## 動手練習

**1. 收官手分類**

KaTrain 復盤你最近 5 盤的收官階段。對每個你下的收官手，標：

- 先手 / 後手 / 雙先 / 逆官子
- 估算目數
- 對比 KataGo

**2. 收官順序測試**

對 KaTrain 從中盤結束開始下 5 盤。每盤目標：

- 收官部分 score loss 平均 < 5 目（中等水平）
- 然後降到 < 3 目（業餘 1d 水平）

**3. 觀察李昌鎬的收官**

李昌鎬以「收官神」聞名 — 收官精算到 0.5 目以下。YouTube 找李昌鎬對局，注意他收官順序。

**4. 「逆官子」識別**

對 KaTrain 對局，凡是 KaTrain 推薦但你下別處的手，看是否「逆官子」。

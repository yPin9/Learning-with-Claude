# Ch 16 — 能力錯覺：知道 vs 懂 vs 會

> Ch 14–15 講了具體的無效方法。這一章講它們的**共同根源**：**能力錯覺**（Illusion of Competence）。理解這個錯覺，你就能在任何學習情境中自我檢測、避免被騙。

## 三個層次：知道 vs 懂 vs 會

先釐清三個常被混用但完全不同的狀態：

### 知道（Know about）

**你聽過、讀過、有印象**。

例：

- 我「知道」什麼是 Python（聽過名字）
- 我「知道」Warren Buffett 是誰
- 我「知道」自由現金流的存在

**這是最淺的層次**。幾乎沒有實質能力。

### 懂（Understand）

**你能解釋、有心智模型**。

例：

- 我「懂」Python 的 list comprehension（能解釋為什麼、怎麼用）
- 我「懂」Buffett 的投資哲學（能講出主要原則）
- 我「懂」自由現金流 = OCF - CapEx，以及為什麼它重要

**這是中層**。你有概念，但不一定能實際做。

### 會（Can do）

**你能獨立完成，解決實際問題**。

例：

- 我「會」用 Python 寫一個 web scraper
- 我「會」用 Buffett 的方法**實際**分析一家公司的護城河
- 我「會」從一家公司的 10-K **實際**算出自由現金流並判斷健康度

**這是最深的層次**。真正的能力。

## 三者的鴻溝

這三個狀態**差距巨大**：

```
知道 → 懂：需要深度編碼、主動思考
懂 → 會：需要大量的刻意練習、實戰
```

**大多數人卡在「懂」**。他們讀了書、看了影片、聽懂了 — 但從沒真的做過。

**要從「懂」到「會」**，需要動手、犯錯、修正、再試 — 這個過程**辛苦**，大多數人放棄在途中。

## 能力錯覺：把低層誤認為高層

**能力錯覺** = **把「知道」誤認為「懂」，把「懂」誤認為「會」**。

**常見錯覺**：

- 讀了一本關於 Python 的書 → 以為自己「會 Python」（其實只「知道」）
- 看完一個投資分析影片 → 以為自己「會分析」（其實只「懂了」一點）
- 聽了一個關於健康的 podcast → 以為自己「會照做」（其實只「知道」原理）

**這種錯覺的代價**：

- 你停止真正的練習（反正「會了」）
- 你到實際要做時才發現不會（尷尬、挫敗）
- 你學了很多「主題」但沒有真正的能力累積

## 能力錯覺的來源

幾個心理機制產生這個錯覺：

### 機制 1：流暢性錯覺（Ch 1 的老朋友）

**看熟 ≠ 懂**。你對一段內容熟悉，大腦誤判為掌握。

### 機制 2：辨識 vs 提取

你能**認出**一個概念（「哦，這個我聽過」），但不能**從零重建**它。

- 辨識：看到答案選對 → 簡單
- 提取：從零想出答案 → 難

**大腦會把「認出」誤判為「會用」**。

### 機制 3：被動模仿的假象

看別人做（影片、書的範例），你覺得「我也做得到」。

**但你從沒自己做過**。真的試時會發現無數卡點。

### 機制 4：Dunning-Kruger 效應

**能力低的人，高估自己的能力**。
**能力高的人，低估自己的能力**。

為什麼？因為**要辨認自己不會，需要某種程度的能力**。完全的新手**看不出來自己不會**。

## 三個具體的診斷問題

**如何分辨你的真實水準**？問這三個問題：

### 問題 1：能教嗎？

**你能把這個概念教給一個完全外行、並讓他真的懂嗎？**

**如果做得到**：你至少「懂」了。
**如果做不到**：你只是「知道」。

這就是費曼技巧（Ch 11）的核心測試。

### 問題 2：能生成嗎？

**合上所有資料，你能從零重建這個東西嗎？**

- 寫一個 Python 函式：你能不看範例寫出來嗎？
- 分析一家公司：你能不看分析報告寫出你的判斷嗎？
- 解一道題：你能不看答案解出來嗎？

**如果生成得出來**：你至少「懂」，可能「會」。
**如果不能**：你只是「知道」或淺「懂」。

### 問題 3：能在新情境應用嗎？

**把這個概念用到一個你沒見過的情境** — 做得到嗎？

- 你學 Python 的 decorator — 現在請你用 decorator 解決你工作中一個具體問題
- 你懂 Porter 五力 — 現在請你分析一個你沒看過的產業
- 你會微積分 — 現在請你用微積分解一個現實生活問題

**能做到**：你真的「會」了。
**做不到**：你還在「懂」的層次。

## 為什麼錯覺這麼危險

錯覺讓你**停止練習**。

流程：

```
讀完一個主題 → 感覺「懂了」 → 停止處理 → 進入下一個主題
```

**你沒有進入「會」的練習**。幾個月後：
- 累積了一堆「知道」和「懂」的主題
- 沒有**一個**真正「會」的能力
- 面對實際問題：無能為力

**廣 + 淺 的學習 = 看起來學了很多，實際上什麼都不會**。

反過來：**深 + 窄 的學習 = 看起來只懂幾件事，但真的能做**。

**後者在真實世界有價值，前者沒有**。

## 如何破除能力錯覺

### 方法 1：強制「生成」測試

**每學一個概念後**，強制自己：

- 合上書
- 用自己話解釋
- 實際做一個例子

**你會當場發現自己的錯覺**。

### 方法 2：定期實際應用

**不要停留在「學習模式」**。**定期把學的東西用在實際問題上**。

- 學程式 → 寫真實的小工具
- 學投資 → 分析你真的感興趣的公司
- 學語言 → 用這個語言實際對話

**真實應用會暴露錯覺**。

### 方法 3：被挑戰

**讓懂這個主題的人挑戰你**：

- 面試（程式員最好的能力測試）
- 向老師 / 前輩解釋並回答問題
- 加入討論社群，接受批評

外部人的視角**看到你看不到的漏洞**。

### 方法 4：長期回頭

**學完一個主題後**，**3–6 個月回來測驗自己**。

**你多半會發現**：「咦，我以為會了，原來忘了」或「咦，我以為懂了，現在看發現當時沒懂」。

長期的回顧是對抗錯覺的最強工具。

## Dunning-Kruger 的四個階段

Dunning-Kruger 效應的完整曲線：

```
自信 ↑
     │              ╱──────────────  專家
     │             ╱    │
     │            ╱
     │           ╱ ← 平原期（長期慢慢累積）
     │ ╱╲      ╱
     │╱  ╲    ╱ 
     │    ╲  ╱ ← 啟蒙
     │     ╲╱   （意識到自己不會）
     │     ↑
     │     絕望谷（知道越多、越知道自己不會）
     │
     │─╱ 愚人山（我什麼都懂了！）
     │╱   （剛入門的錯覺）
     └──────────────────────→ 經驗（真實能力）
```

**四個階段**：

### 階段 1：愚人山（Peak of "Mount Stupid"）

剛接觸一個主題，**自信爆表**。

- 「我看了幾篇文章，懂投資了」
- 「我寫了第一個 Python 程式，會程式了」

這個階段的人**最危險** — 他們**沒意識到自己不會**。

### 階段 2：絕望谷（Valley of Despair）

接觸更多後，**發現自己根本什麼都不懂**。信心暴跌。

- 「靠，投資原來這麼難」
- 「程式的深度遠超我想的」

**這個階段**很多人**放棄**。

### 階段 3：啟蒙期（Slope of Enlightenment）

**熬過絕望谷**的人，開始真正建立能力。**慢慢地、一步一步**，看得見進步。

### 階段 4：專家平原（Plateau of Sustainability）

**多年累積後**，成為真正的專家。**依然謙虛**，因為知道自己不懂的還很多。

## 識別自己在哪個階段

**你在愚人山**：
- 對新主題**自信**
- 覺得「這不難」
- 尚未遇到真實的挑戰

**你在絕望谷**：
- 原本的自信崩盤
- 想放棄
- 覺得「我不是這塊料」

**你在啟蒙期**：
- 接受「這很難但能進步」
- 看到每週的微小進步
- 能自我評估自己知道什麼、不知道什麼

**你在專家期**：
- 謙虛（因為知道自己不知道的有多少）
- 能教別人也繼續學習
- 能辨認「誰是真的懂、誰是裝懂」

## 一個殘酷但重要的建議

**大多數成年學習者在愚人山**：

- 讀了很多書但沒實際做過
- 看了很多影片但沒產出過東西
- 有「知識」但沒「能力」

**承認自己在愚人山是進步的第一步**。

**方法**：

1. 選一個你「以為會」的技能
2. **實際做**一個非教學範例的應用
3. **你會發現**很多卡點
4. **那些卡點就是你真正要學的東西**

**這個過程**讓你**從愚人山跌入絕望谷**。很痛，但是**真正學習開始的地方**。

## 一個文化現象：「我知道」vs「我會」

當代網路文化鼓勵「淺薄的知識」：

- 看了一個 TED talk 就覺得「懂了這個領域」
- 讀了一本書就覺得「掌握了這個主題」
- 聽了一個 podcast 就覺得「了解這個產業」

**這些都是「知道」的層次**。幾乎沒有實質能力。

**當代社會對「廣 + 淺」的人過度獎勵**（talking heads、KOL、評論家），對「窄 + 深」的人獎勵不足（真正的專家）。

**但實際世界的問題需要「窄 + 深」的能力解決**。

**你的選擇**：要嘛成為**愚人山的 Instagram 知識分子**，要嘛成為**真正能做事的人**。

後者需要的是**在一個領域走過絕望谷、進入啟蒙期**。

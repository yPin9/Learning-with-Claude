# Ch 9 — 間隔重複：Anki 與非 Anki 的實作

> **主動回憶**告訴你「怎麼練」，**間隔重複**告訴你「什麼時候練」。兩者結合，是認知科學對「長期記憶」提供的最強工具。這一章講間隔重複的原理、Anki 的實作、以及不想用工具時的手動方法。

## 一個簡單的事實

Ch 5 講過：**在快忘的邊緣複習，效果最好**。

**間隔重複系統**（Spaced Repetition System，簡稱 SRS）就是**自動化這個時機**的工具。

基本邏輯：

- 學一個東西後，**隔一段時間**再複習
- 如果你還記得 → **下次間隔拉長**
- 如果你忘了 → **間隔縮短，幾天後再試**
- 這個循環無窮重複

**結果**：每個資訊**按你個人的遺忘速度**被複習，效率最大化。

## 為什麼需要「系統」

如果只是偶爾複習，你不會系統性地管理幾百個 / 幾千個小資訊。

**想像你學一個語言**：
- 5000 個單字
- 幾十個文法規則
- 幾千個慣用搭配

**手動管理這些的複習時程？不可能**。

**間隔重複軟體解決這個**：它替你管理每張卡片的下次複習時間，你每天只要打開做「今天到期的」。

## Anki：事實上的標準

**Anki** 是間隔重複的主流工具。免費、開源、跨平台（桌面 + 手機）。

**為什麼要認真學 Anki**：

- **演算法最完整**（基於 SuperMemo 的 SM-2 + 改進）
- **完全客製化**（格式、間隔、排程全可調）
- **擴充生態系**大（數千個 add-on）
- **一輩子可用**（你建的卡片庫會累積）

**缺點**：

- **介面醜**（像 90 年代的軟體）
- **學習曲線**：第一週困惑
- **需要自己建卡片**（現成 deck 品質參差）

**權衡**：花一週學 Anki，用 10+ 年。這是划算的交易。

## Anki 基礎：一張卡片長什麼樣

**最簡單的形式**：一個正面 + 一個反面。

正面（Question 題目）：

```
工作記憶的容量是多少？
```

反面（Answer 答案）：

```
約 4±1 個單位（Miller 1956 估 7±2，更新研究認為 4±1）。

意義：一次能同時處理的資訊單位極少，
這是 chunking 為什麼重要的原因。
```

**複習時**：

1. Anki 顯示正面
2. 你**在腦中想答案**（主動回憶）
3. 點「Show Answer」看正確答案
4. **評分**：
   - Again（忘了）→ 1 分鐘後再看
   - Hard（勉強）→ 短間隔
   - Good（正常）→ 標準間隔
   - Easy（很輕鬆）→ 長間隔

**Anki 根據你的評分自動算下次複習時間**。

## Anki 間隔的數字感

給你一個感覺：

新卡片的演進：

- 第 1 次答對 → 1 天後
- 第 2 次答對 → 3 天後
- 第 3 次答對 → 7 天後
- 第 4 次答對 → 15 天後
- 第 5 次 → 30 天
- 第 6 次 → 60 天
- 第 7 次 → 4 個月
- 第 8 次 → 8 個月
- ...
- 幾年後 → 每 2–3 年看一次

**如果你答錯**：間隔大幅縮短（例如從 30 天回到 1 天）。

**結果**：一個你真正記得的事實，每年可能只需要看幾次就能持續記得。

## Anki 的威力：百張 vs 千張 vs 萬張

**一個你可能低估的事實**：

- 每天 **10 張新卡片 + 50 張複習**：約 20 分鐘
- 一年：3,600 張新卡片
- **5 年：18,000 張**

18,000 個事實、概念、連結存在長期記憶裡。這是什麼量級？

- 一個流利第二外語的**詞彙量**（約 10,000–15,000）
- 一個領域專家的**核心知識點**
- 醫學院學生學的**一門課的詳細內容**

**這些人 5 年後還記得這 18,000 個東西** — 因為間隔重複自動維持。

**沒用 Anki 的人，讀過再多書都無法維持這個記憶量**。

## 建立好卡片的原則

卡片的品質決定 Anki 的效果。爛卡片會讓你浪費時間。

### 原則 1：最小資訊原則（Minimum Information Principle）

**每張卡片只測一個東西**。

**壞卡片**：

```
正面：工作記憶是什麼？
反面：工作記憶是你當下意識到、正在處理的資訊，
     容量 4±1 個單位，持續幾秒到幾十秒，
     跟長期記憶相對，需要 chunking 才能處理複雜任務。
```

這張卡包了**太多東西**。你答的時候會大量遺漏。

**好卡片**（拆成幾張）：

```
卡 1：工作記憶的容量大約是多少？  →  4±1 個單位
卡 2：工作記憶的持續時間大約？    →  幾秒到幾十秒
卡 3：什麼機制讓工作記憶處理複雜任務？→ chunking
卡 4：工作記憶 vs 長期記憶，主要差別是什麼？→ 容量、持續、主動意識
```

**每張卡一個具體問題**。答對或答錯都很清楚。

### 原則 2：具體問題，不是「解釋概念」

**壞**：「解釋 Bjork 理論」
**好**：「Bjork 理論的兩個獨立維度是什麼？」→ 儲存強度、提取強度

具體問題讓答案明確。模糊問題讓你不知道要答什麼。

### 原則 3：用自己的話

**不要複製教材的句子**。用你自己理解的語言寫。

為什麼？

- **強迫你先真正理解**（能自己說才能寫卡片）
- **貼合你的思維習慣**
- **避免記住一串你不懂的字**

### 原則 4：加上 context / example

純定義的卡片**容易變空洞**。加上例子或 context。

**無 context**：

```
問：什麼是「流暢性錯覺」？
答：把熟悉誤認為理解的現象。
```

**有 context**：

```
問：什麼是「流暢性錯覺」？在實際學習中怎麼出現？
答：把熟悉誤認為理解。
例：讀一段教材第三次，覺得很熟，以為掌握了，
    但實際上只是認出文字、沒真正記住內容。
    測試會揭露這個錯覺。
```

後者的記憶更紮實。

### 原則 5：用圖、用程式、用例子

Anki 支援圖片、音訊、程式碼。

- **程式語言**：正面程式碼片段，反面解釋它做什麼
- **醫學 / 生物**：解剖圖標記特定結構
- **語言學習**：單字 + 例句 + 音訊（複習時聽）

**多媒體的 cue** 讓記憶更強（因為多個感官連結）。

## 什麼該放 Anki，什麼不該

### 適合 Anki 的內容

- **事實、定義、數字**（容量 4±1、CIA triad、某公司 ROIC）
- **語言**（單字、文法、慣用語）
- **分類、清單**（Porter 五力的五個、記憶的三個階段）
- **視覺辨認**（鳥類、植物、人物）
- **程式語法、API、熱鍵**

### 不太適合 Anki 的內容

- **高度情境化的判斷**（這段程式的設計模式好不好？— 這需要脈絡）
- **長篇的文章內容**（如果一張卡是一段文字，Anki 不對）
- **技能動作**（騎車、彈琴 — 這需要實際練）
- **非常少用的冷門知識**（你一輩子用不到一次的，不值得維護）

**原則**：**Anki 裡的東西應該是你希望「一輩子記得」的核心**。

**不要把 Anki 變成「我看過所有東西」的記錄**。這樣卡太多、太雜，一下就放棄。

## 每天的 Anki 節奏

**建議**：

- **每天 15–30 分鐘**（早上或通勤時）
- **新卡片上限 10–20 張 / 天**（你可以加更多，但要累積得動）
- **不要跳過一天**（連續 5 天不複習 → 卡片大量到期 → 你會崩潰放棄）

**實務小提示**：

- **手機 app 複習很方便**（排隊、坐車、等人時做）
- **桌面版做新卡片**（比手機做卡片好）
- **sync 好桌面 + 手機**（AnkiWeb 免費）

## 一個常見的 Anki 失敗模式

新手常犯的錯：

### 錯誤 1：下載別人的 deck

「網路上有 10,000 卡的 Python deck，我下載來用」。

**問題**：
- 別人的卡片**格式不適合你**
- 別人理解後寫的，跟**你不理解**狀況不同
- 你會跳過一堆、慢慢累積壓力
- 幾週後放棄

**正確**：**自己建立卡片**。慢但有效。

### 錯誤 2：加太多卡片

「我今天讀了一章，加 100 張卡片」。

**問題**：
- 明天複習壓力暴增
- 幾天後到期卡片數 >> 能複習數
- 失控、放棄

**正確**：**每天新卡 10–20 張上限**。讀到的東西**選關鍵的**放 Anki。其他讓它過。

### 錯誤 3：不複習就加新的

「今天不想複習，明天就好」。

**問題**：
- 連續幾天不複習 → **幾百張卡到期**
- 下次打開 Anki **瞬間崩潰放棄**

**正確**：**每天複習是第一優先**。加新卡片是次要。如果時間緊，**只複習、不加新的**。

## 沒 Anki 怎麼做間隔重複（手動版）

如果你不想學 Anki（可以理解 — 介面真的勸退），手動方法也可行，效果略差但還是比沒有好。

### 方法：Leitner 盒子（實體 flashcard）

- 準備 5 個盒子（或 5 個資料夾）
- 新卡片放盒子 1
- **每天**檢查盒子 1：答對移到盒子 2，答錯留在 1
- **每 3 天**檢查盒子 2：答對移到盒子 3，答錯回到 1
- **每週**檢查盒子 3：...
- **每兩週**檢查盒子 4
- **每月**檢查盒子 5

這是 Anki 演算法的極簡類比版。

### 方法：筆記本 + 日曆

用紙本筆記本記重點，標記「1 / 3 / 7 / 30」。

- 每個重點寫一個日期
- 每天看今天該複習的
- 回想後記「記得」或「忘了」
- 忘了的重新排程

**不如 Anki 好用，但比什麼都沒有好**。

## 一個進階：間隔重複用在技能

前面主要講**陳述性知識**的間隔重複。但某些**技能**也可以。

**例**：

- **學鋼琴**：一個曲子練會後，不要放棄，每週彈一次 → 每兩週 → 每月 ...
- **程式語言語法**：寫一個特殊語法，之後**定期**用它（而不是忘了）
- **運動動作**：學一個動作後，按間隔重複的時程 review

**但要注意**：技能的間隔重複要**做完整動作**，不只是想一下。這叫**肌肉記憶的複習**。

## 一個警告：Anki 不是萬能

這章介紹了 Anki 的威力，但要平衡一下：

### Anki 不能做到的

- **不能給你理解**（如果你沒搞懂的東西，記住也沒用）
- **不能替代實踐**（記住程式語法不等於會寫程式）
- **不能替代深度思考**（Anki 是記憶工具，不是思考工具）
- **不能替代應用**（記住投資理論不等於能投資）

### Anki 的角色定位

**Anki 應該是你學習系統的「記憶層」**，不是全部。

完整的學習應該是：

1. **理解**（讀書、聽課、討論）
2. **整合**（寫摘要、建立心智模型）
3. **實踐**（做題、寫程式、應用）
4. **記憶**（Anki 把核心知識永久化）

**Anki 負責第 4 層**。沒有前三層，Anki 也救不了你。

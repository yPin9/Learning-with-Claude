# Ch 20 — 原理 vs 細節：兩種記憶該分開處理

> 很多人把所有要學的東西混在一起處理。但**原理**和**細節**是兩種不同的記憶，**需要不同的學習方法**。搞混兩者，你會在原理上花太少、在細節上花太多（或相反）。這一章把這個區分講清楚。

## 什麼是原理 vs 細節

### 原理（Principles）

**少量、通用、穩定**的核心概念。

- **少量**：一個領域可能只有 20–50 個核心原理
- **通用**：應用到這個領域的幾乎所有情境
- **穩定**：10 年、50 年都適用

**例子**：

- **程式設計**：抽象、模組化、DRY、關注點分離、錯誤處理模式
- **投資**：複利、風險報酬、定價權、護城河、均值回歸
- **寫作**：清楚、準確、節奏、編輯（刪）、結構
- **數學**：證明、極限、抽象、對稱、變換

**原理要徹底內化**，要**理解為什麼**，不只是知道。

### 細節（Details）

**大量、特定、會變**的具體資訊。

- **大量**：一個領域可能有幾千、幾萬個細節
- **特定**：只在特定情境中用
- **會變**：可能 2–5 年就過時

**例子**：

- **程式設計**：特定語言的語法、特定 API 的參數、特定函式庫的用法
- **投資**：某年某產業的 ROIC 數字、特定公司的財務、市場某時期的估值
- **寫作**：特定語言的用法細節、某個流派的慣例
- **數學**：特定公式、特定題型的解法

**細節要記住**（或能快速查到），但**不需要「理解」它們 — 它們就是這樣**。

## 兩種記憶的學習方法

這兩類**需要不同的學習方法**：

### 原理：深度理解 + 長期應用

**方法**：

- **費曼技巧**（能用自己話解釋）
- **跨例子泛化**（用多個具體例子證實）
- **持續應用**（每次遇到相關情境時用）
- **長期累積**（原理之間互相強化）

**時間尺度**：**幾個月到幾年**掌握一個原理。

**測試**：**能向新手解釋嗎？能用到新情境嗎？**

### 細節：間隔重複 + 必要時查詢

**方法**：

- **Anki / 間隔重複**（如果需要記）
- **查詢系統**（如果不需要記，只需要能查）
- **熟練度練習**（重複到自動化）

**時間尺度**：**幾天到幾週**掌握一個細節。

**測試**：**需要時能 recall 或快速查到嗎？**

## 一個核心洞察：不是所有細節都要記

**這一章最重要的一點**：

> **大多數細節不值得背 — 值得建立查詢系統**。

### 例子：程式語法

**該記的細節**（值得 Anki）：
- `for` loop 的基本結構（寫了一千次了）
- 常用的 string 操作（split、join、format）
- 常用的 list/dict 操作

**不該記的細節**（該查詢）：
- 特定 library 的完整 API
- 特定 regex 的語法規則
- 特定錯誤訊息的解決方法

**為什麼**：後者太多、查得到、而且常變。

### 例子：投資分析

**該記的細節**（值得 Anki）：
- 三大財報的基本結構
- 核心估值倍數的公式（PE、PB、EV/EBITDA）
- 幾個核心產業的典型 ROIC 範圍

**不該記的細節**（該查詢）：
- 特定公司某季的財務數據
- 特定產業某時期的市佔數據
- 每個股票的歷史股價

**為什麼**：前者太多、查得到、每個投資人都能查。

## 但原理必須內化

**相對地**：**原理不能靠查詢**。

**為什麼**：

- 原理**應用時你沒時間查**。當你看一家公司，你不會查「護城河是什麼」 — 你已經知道。
- 原理**互相連結**。你面對一個問題時，**多個原理同時作用**。查詢模式太慢。
- 原理**變化緩慢**。投資花幾年內化「複利」的原理，值得 — 因為它 50 年都適用。

**實用原則**：

- **把時間花在原理**上（深度理解）
- **把細節放在查詢系統**（適度 Anki + 文件 / Google）

## 一個常見錯誤：搞反了比例

多數學習者的時間分配**搞反**：

- **花 80% 時間記細節**（具體數字、語法、事實）
- **花 20% 時間理解原理**（抽象概念）

**結果**：他們記住很多細節但不懂背後的原理。**應用時**：
- 細節很快過時或用不到
- 原理沒理解好，無法推理新情境

**應該反過來**：

- **80% 理解原理**
- **20% 記必要的細節**

**這樣的學習者**：
- 細節過時了沒關係（查就好）
- 遇到新情境能**從原理推理**

## 範例：學 Python 的正確比例

**錯誤做法**：把時間花在**背語法細節**。

- 每個內建函式的完整參數表
- 每個標準庫的完整 API
- 特定語法的邊界條件

**正確做法**：**先掌握原理**：

- Python 是動態型別、解釋執行、object-oriented 語言
- 一切是 object
- List comprehension 是 functional 思維的應用
- Decorator 是 function-as-first-class-citizen 的應用
- Generator 是 lazy evaluation

**這些原理掌握後**，細節查就好：

- 「`zip()` 怎麼用？」→ 查
- 「這個 library 的這個函式？」→ 查
- 「這個錯誤訊息？」→ 查

**真正的程式專家不是記最多細節，而是掌握原理 + 有好的查詢系統**。

## 範例：學投資的正確比例

**錯誤做法**：記每家公司的財務、每個產業的數字。

**正確做法**：掌握原理：

- 為什麼好產業 > 好公司 > 好估值（順序）
- 護城河的五種類型
- Porter 五力的邏輯
- DCF 的內在邏輯
- 週期 vs 結構性成長的區分

**這些原理掌握後**，遇到任何公司 / 產業：

- 快速套用原理
- 需要具體數字時查（網站、年報）
- 做出判斷

**這比試圖記「所有公司」的細節有用 100 倍**。

## 什麼情況下細節也需要內化

**少數情況下，細節必須內化不能查**：

### 情境 1：動作速度關鍵

**外科醫生不能查「盲腸在哪」**。動作必須**自動化**。

- 程式員的核心語法（快速寫）
- 鋼琴家的手指位置
- 運動員的動作

**這些細節必須從「懂」到「會」（自動化，Ch 10）**。

### 情境 2：考試不許查

**很多考試不許查資料**。在這種情境下，你必須記。

- GMAT、GRE、某些證照考試
- 大學期末考的部分

**對這些考試**：Anki + 間隔重複是你的朋友。但考完後，多數細節可以讓大腦忘。

### 情境 3：核心概念的關鍵細節

有些「細節」其實是**核心概念的關鍵**。

- 學 Python 不需要記每個 library 的 API，**但要記 Python 的執行順序、作用域規則**（這些「細節」其實是原理的一部分）
- 學投資不需要記每家公司的股價，**但要記 PE、PB 等估值倍數的計算**（這些是基礎）

**判斷**：這個「細節」是否**頻繁被其他東西依賴**？如果是 → 記下；如果不是 → 查就好。

## 一個實用策略：「記憶階梯」

給不同類型的資訊**不同的記憶策略**：

### 階梯 1：深度內化（長期記憶 + 自動化）

- 核心原理
- 頻繁用的基本技能
- 你領域的核心概念

**方法**：費曼、實際應用、多年反覆

### 階梯 2：Anki 化（主動記憶）

- 需要時能 recall 的重要事實
- 常用但不是反射的細節

**方法**：間隔重複

### 階梯 3：筆記化（認識但不記憶）

- 重要但不常用的資訊
- 未來可能查到的資源

**方法**：個人知識庫、筆記系統

### 階梯 4：外部查詢（不記不內化）

- 大量、變化快的細節
- 網路 / 文件能快速查到

**方法**：Google / Stack Overflow / 文件

### 階梯 5：忽略

- 不相關的細節
- 過度專業化的內容

**方法**：忽視，不要焦慮於「記不住」

**把每個資訊放到對的階梯**，你的學習效率會大幅提升。

## 一個工具化的建議

**為自己建立一個分類習慣**：

**每次學到新東西，問**：「這個應該在哪個階梯？」

- 「複利」的概念 → 階梯 1（深度內化）
- 「Python 的 list comprehension 語法」 → 階梯 2（Anki 化，用幾次後自動化）
- 「Numpy 的完整 API」 → 階梯 3（筆記 / 文件）
- 「某個特定錯誤訊息的解法」 → 階梯 4（查）
- 「某個過度 niche 的工具細節」 → 階梯 5（忽略）

**這個分類本身**就是一種深度編碼。它強迫你**判斷這個資訊對你的意義**。

## 一個現代的提醒：搜尋 + AI 是你的盟友

2024 後，**搜尋與 AI 工具改變了「記細節」的價值**。

**過去**：你可能需要記很多技術細節（沒網路時代）。

**現在**：
- Google 幾秒鐘查到
- GPT / Claude 即時回答問題
- Stack Overflow 有解答

**這意味什麼**：**細節的價值進一步下降，原理的價值進一步上升**。

**因為**：

- 細節 AI 能幫你
- **原理 AI 不能替你理解**（AI 能給你答案，但你需要自己能判斷答案合理性）

**在 AI 時代，贏家是掌握原理、能判斷、能問對問題的人**。記細節的人會被 AI 替代。

這是你學習優先順序的另一個理由：**原理 > 細節**。

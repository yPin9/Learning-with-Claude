# Ch 0 — 工具箱設定

> **目標**：在讀任何一句英文之前，先把一整套學習環境裝好、調順。裝完這一章的清單，你之後每天的閱讀與記憶都有現成的工具接住，不會因為「還要找字典」「文章版面太亂」而卡住。

> **環境**：一台能裝軟體的電腦（Windows / macOS 皆可）＋一支手機（iOS 或 Android）。全部工具都有免費版本足夠用。整章裝完約 30–40 分鐘。

---

## 為什麼需要這個？

大多數人學英文閱讀失敗，不是因為不夠努力，而是因為**摩擦力（friction）太高**。所謂摩擦力，是指「從『我想讀』到『我真的開始讀』之間的每一個小障礙」：字典要另外開分頁、生字記在便利貼上下次找不到、文章擠在滿是廣告的網頁裡讓人不想看。每一個小障礙都在偷偷勸退你。

我們這門課的核心信念是：**讓英文閱讀從「解碼苦工」變成「理解本身」**。而降低摩擦力，是達成這件事的第一步，也是最務實的一步。這一章不談任何理論，只做一件事——幫你把工作台（workbench）搭好，讓「查一個字」「記住一個字」「找一篇能讀的文章」都變成三秒鐘的動作。

工具本身不會讓你變強，**每天用工具讀對的東西**才會。但如果工具很難用，你根本撐不到「每天」那一步。所以我們認真對待這一章。

---

## 先建立直覺

把你的英文閱讀學習想成一間工作坊。裡面有四個工作站，缺一不可：

```
   ┌─────────────────────────────────────────────┐
   │            你的英文閱讀工作坊                  │
   │                                               │
   │   [1] 記憶站          [2] 查詢站              │
   │   Anki               字典 + 瀏覽器擴充         │
   │   (把生字變長期記憶)   (三秒查到意思)           │
   │                                               │
   │   [3] 閱讀站          [4] 材料站              │
   │   Reader mode        分級材料來源             │
   │   (乾淨版面)          (找到你讀得動的文章)      │
   └─────────────────────────────────────────────┘
```

- **記憶站（Anki）**：你查過的生字如果不主動複習，幾天後就忘光。Anki 負責把「查過」變成「記住」。這是全課最重要的單一工具。
- **查詢站（字典 ＋ 瀏覽器擴充）**：讀到不懂的字，要能在原地、三秒內查到——而且查到的是**能幫你真正學會這個字**的解釋，不只是一個中文對應詞。
- **閱讀站（Reader mode）**：把新聞網頁的廣告、側欄、彈窗全部剝掉，只留文字，讓你的注意力（attention）不被瓜分。
- **材料站（分級材料來源）**：你現在讀不動 BBC，不代表無路可走。有一整條從「超簡單」到「BBC 原文」的材料階梯，這一站先讓你知道它們在哪。

接下來一站一站裝。

## 工作站 1：Anki（記憶站，最重要）

### Anki 是什麼

**Anki** 是一套免費、開源的**間隔重複（spaced repetition）**閃卡（flashcard）軟體。間隔重複的意思是：軟體會依據你對每張卡的熟悉程度，自動算出「下一次該在何時複習」——快忘記的字明天就再考你，記得很牢的字可能一個月後才出現。這樣你把複習的力氣**只花在快要忘記的字上**，效率遠高於土法煉鋼一遍遍全部重看。

（間隔重複背後的科學，我們留到 Ch 5 講透。這裡你只要知道：它是有紮實記憶研究支撐的方法，不是行銷話術。）

### 為什麼 Anki 是全課最重要的工具

閱讀能力的最大瓶頸是詞彙量（我們在 Ch 1 會用數字證明這件事）。而詞彙量沒有捷徑：你必須把大量生字**搬進長期記憶**。人腦會遺忘，這是生理事實，對抗遺忘唯一有效的方法就是「在對的時間點複習」——這正是 Anki 做的事。

換句話說：**這門課教你的方法，最後都要靠 Anki 這個引擎日復一日地跑，才會累積成真正的能力。** 其他工具都可以替換，Anki 不行。

### 怎麼裝

Anki 是**桌面版免費、手機版依平台不同**，先裝桌面版：

1. **桌面版（Windows / macOS / Linux）**：到官網 <https://apps.ankiweb.net/> 下載並安裝。這是完全免費的。
2. **註冊 AnkiWeb 帳號**：到 <https://ankiweb.net/> 免費註冊。這個帳號負責把你的卡片在**桌面與手機之間同步（sync）**——你在電腦上建的卡，通勤時用手機就能複習。
3. **手機版**：
   - **Android**：裝 **AnkiDroid**，Google Play 上完全免費。
   - **iOS / iPadOS**：官方 App 叫 **AnkiMobile**，是**付費**的（一次性買斷，用來支持開發）。若不想付費，iPhone 使用者可以先只用桌面版，或改在瀏覽器登入 AnkiWeb 網頁版複習（功能較陽春但免費）。

裝好後三邊（桌面 / 手機 / AnkiWeb）都用同一組帳號登入，按同步鈕，卡片就會流通。

### 基本操作：先跑一次最小循環

不用一開始就懂全部功能。先建立肌肉記憶，跑完這個最小循環就夠了：

1. 開啟 Anki 桌面版，點左下 **Create Deck（建立牌組）**，命名為 `English Reading`。牌組（deck）就是一疊卡片的分類。
2. 點上方 **Add（新增）**，選到剛建的牌組。
3. 在 **Front（正面）** 打上你想記的英文字或整個句子，在 **Back（背面）** 打上意思、例句。按 `Ctrl+Enter`（Mac 是 `Cmd+Enter`）存檔，繼續加下一張。
4. 回主畫面點牌組名稱，按 **Study Now（開始學習）**。看到正面時先在心裡回想答案，再按空白鍵翻到背面。
5. 對照答案後，依實際熟悉度選 **Again（忘了）/ Hard（勉強）/ Good（記得）/ Easy（太簡單）**。Anki 會依你的選擇排下一次複習時間。

**最重要的紀律：每天打開 Anki 把當天到期的卡複習完。** 就算只有五分鐘、就算只有十張卡。斷掉一天，隔天到期的卡會堆積，堆積會讓你更不想開——這是最常見的失敗模式。

（我們在 Ch 5 與練習 A 會教你如何做出**好的卡片**——不是背中英對照，而是帶語境的卡。現在先把工具跑起來就好。）

## 工作站 2：字典策略（查詢站）

字典的選擇，關係到你「查一個字之後，能不能真正把它學起來」。這裡有一個對初學者違反直覺、但非常關鍵的觀念。

### 雙語字典 vs 單語 learner's dictionary

- **雙語字典（bilingual dictionary）**：英中對照，例如 Yahoo 奇摩字典、劍橋英漢。它給你一個中文對應詞。
- **單語學習者字典（monolingual learner's dictionary）**：用**受控的簡單英文**來解釋英文字，專門為英語學習者設計。兩大權威是：
  - **Longman Dictionary of Contemporary English（LDOCE）**：<https://www.ldoceonline.com/>
  - **Oxford Learner's Dictionaries**：<https://www.oxfordlearnersdictionaries.com/>

這兩本的關鍵特色是：它們的**釋義只用大約 2,000–3,000 個最常見的字**寫成。所以就算你程度還不高，也讀得懂它的解釋。而且它們附大量**自然例句**與**搭配詞（collocation，指某些字習慣跟哪些字連用，例如英文說 "make a decision" 不說 "do a decision"）**。

### 為什麼要往單語過渡

雙語字典有個隱形陷阱：一個英文字給你一個中文詞，你以為「懂了」，但其實你只學到「這個英文字約等於那個中文詞」，沒學到它**真正的用法邊界**。

看一個具體例子。英文字 **afford**，雙語字典常給「負擔得起」。於是你可能造出這種句子：

- ✗ *I can afford this problem.*（想表達「我能承受這個問題」——錯）

但翻開 Longman，它會告訴你 afford 幾乎總是用在**金錢或時間**上，且常與 can/could 連用：*I can't afford a new car.* / *We can't afford to lose this deal.*（我們輸不起這筆交易）。看過這幾個自然例句，你才真正抓到它的邊界。**單語字典教你的是「這個字怎麼活著用」，雙語字典只給你一個標籤。**

我們的建議很務實，不搞原教旨主義：

- **現在**：兩本都裝著。遇到抽象、難懂的字，先看雙語快速抓大意，**再翻單語看例句**確認用法。
- **目標**：隨著程度上升，逐漸把重心移到單語字典。這件事本身就是絕佳的閱讀練習——你在讀「用簡單英文寫的解釋」。

### 瀏覽器彈出式字典擴充

要把「查字」的摩擦力壓到最低，裝一個**彈出式字典（pop-up dictionary）**瀏覽器擴充。它讓你在網頁上把游標移到、或雙擊某個字，就地跳出小視窗顯示意思，不用切分頁。

- **Google 翻譯官方擴充（Google Translate extension）**：Chrome 線上應用程式商店可裝，雙擊單字即顯示翻譯，最無腦、最快上手。
- **進階選項**：市面上有數款能**一鍵把查到的字送進 Anki** 的彈出式字典擴充（例如整合 AnkiConnect 的擴充）。這類工具設定稍複雜，等你 Anki 用順了、確定要長期投入時再研究，現在不必急。

**原則**：讓「查一個字」變成三秒的動作。摩擦力越低，你越讀得下去。

## 工作站 3：Reader mode（閱讀站）

現代新聞網站塞滿了廣告、自動播放影片、訂閱彈窗、側邊欄推薦。這些東西不只煩，還會**實際降低你的閱讀理解**——你的注意力頻寬有限（這點 Ch 1 會細講），花在忽略干擾上的每一分，都是從理解那邊挪走的。

**Reader mode（閱讀模式）／readability 工具**會把整頁只留下文章本體：純文字、乾淨背景、可調字級，其餘一律隱藏。

- **瀏覽器內建**：
  - **Safari**：網址列左側有「閱讀器」圖示，點下去即可。
  - **Firefox**：網址列右側有閱讀器視圖圖示。
  - **Chrome / Edge**：內建有「閱讀模式／沉浸式閱讀工具」，可在設定或右鍵選單開啟；若找不到，裝一個 readability 類擴充即可達到同樣效果。
- **加分功能**：許多閱讀模式支援調整字級、行距、背景色。字調大一點、行距鬆一點，長時間閱讀眼睛比較不累。

養成習慣：**打開一篇要認真讀的文章，先按 reader mode。** 這個一秒的動作，會顯著改善你的專注度。

## 工作站 4：材料來源（材料站）

你現在讀不動 BBC 原文，這是正常的、也是有解的。關鍵在於**找到你此刻讀得動的材料**，站穩了再往上爬。這一站先讓你認識整條材料階梯上有哪些來源，Part 4（Ch 14–16）會教你怎麼系統性地爬。

由易到難：

- **Simple English Wikipedia**（<https://simple.wikipedia.org/>）：用受控的簡單英文重寫的維基百科。同一個主題，這裡的版本句子短、用字淺。**技術背景的人特別適合**——查你熟悉的主題（例如某個演算法、某個城市），內容你懂，只是換簡單英文說一遍。
- **News in Levels**（<https://www.newsinlevels.com/>）：同一則新聞提供三種難度版本（Level 1 最簡單到 Level 3 接近原文），還附朗讀。可以先讀 Level 1 抓故事，再挑戰 Level 3。
- **BBC Learning English**（<https://www.bbc.co.uk/learningenglish>）：BBC 官方的**英語學習**頻道，注意它不同於 BBC News。文章刻意為學習者寫，難度適中，且大量講解字彙與用法。是通往 BBC News 原文的最佳中間站。
- **Graded readers（分級讀本）**：專為學習者改寫的整本書，依詞彙量分級（例如「1000 字級」「2000 字級」）。找法：搜尋 "graded readers"、各大出版社的分級書系（如 Oxford Bookworms、Penguin Readers），或到 **ER-Central / M-Reader** 這類分級閱讀資源網站。圖書館與二手書市也常有。
- **BBC News**（<https://www.bbc.com/news>）：這是我們的**攻頂目標**，不是起點。現在先知道它在哪就好，不要現在硬啃。

原則一句話：**寧可輕鬆讀懂十篇簡單的，不要痛苦啃半篇難的。** 這條原則貫穿全課。

## 兩個之後會用到的診斷工具（先認識，先別急著跑）

下一章之後我們會做自我診斷，這裡先預告兩個工具，讓你有印象：

- **Test Your Vocabulary**（<https://testyourvocab.com/>）：花幾分鐘勾選你認識的字，它幫你**估算目前的英文詞彙量**。Ch 2 會帶你正式跑一次。
- **Lextutor VocabProfile**（<https://www.lextutor.ca/vp/>）：把**任何一篇英文文章**貼進去，它會算出這篇文章由哪些難度層級的字組成、以及你的詞彙量能覆蓋其中多少。這是全課最強的自我診斷利器，Ch 2 會教你怎麼用它找出「你到底卡在哪一層字」。

現在不用跑，知道它們存在就好。

## 機制小節：為什麼「降低摩擦力」這件事值得一整章

你可能覺得「不就是裝幾個軟體，有必要當一章寫嗎？」——有必要，而且理由是行為科學的：

一個習慣能不能持續，關鍵往往不在意志力，而在**啟動成本（activation cost）**：開始做這件事需要跨過多少個小障礙。閱讀是一場數月的持久戰（Ch 2 會誠實地講清楚時間尺度），能不能撐下去，決定於每天那一刻你「想不想開始」。而「想不想開始」高度受制於摩擦力：

- 字典要開分頁 → 少查一個字 → 讀得更吃力 → 更不想讀。
- 生字沒地方存 → 查了就忘 → 覺得沒進步 → 放棄。
- 版面很亂 → 讀得累 → 縮短閱讀時間。

反過來，當查字三秒、生字自動進 Anki、版面乾淨，每一次閱讀的體感都變好，你就更可能明天再來。**這一章搭的不是工具，是「讓你撐得下去」的基礎建設。**

## 踩雷集錦

1. **錯誤直覺：「Anki 之後再裝，先開始讀就好。」**
   → 正確認識：從第一天就掛上 Anki。你在沒有 Anki 的情況下讀的每一篇，查過的生字幾乎都會流失，等於白讀。工具先到位，閱讀的產出才留得下來。

2. **錯誤直覺：「用雙語字典比較快，單語字典看不懂何必自找麻煩。」**
   → 正確認識：雙語字典只給你一個中文標籤，教不了你「afford 只能用在錢和時間上」這種用法邊界。單語字典的釋義只用最常見的 2,000–3,000 字寫成，你讀得懂，而且讀它本身就是閱讀練習。不必一步到位，但要開始並逐步過渡。

3. **錯誤直覺：「先讀 BBC 原文，讀不懂就多查字典硬撐。」**
   → 正確認識：一篇文章若生字太密（Ch 1 會講清楚密到什麼程度就讀不動），查字典查到你不想讀，那是**材料選錯了**，不是你不夠努力。降階到讀得動的材料不丟臉，硬撐才是浪費時間。

4. **錯誤直覺：「iPhone 的 Anki 要付費，那我不用 Anki 了。」**
   → 正確認識：桌面版永遠免費，AnkiWeb 網頁版也免費可在手機瀏覽器複習。付費的只有 iOS 原生 App，那是體驗升級，不是使用門檻。別讓這個誤解擋掉全課最重要的工具。

## 進階：再往深一層

當你 Anki 用順了（大概是跑完練習 A 之後），有兩個進階方向值得研究，但**現在不必碰**：

- **一鍵造卡流水線**：把「彈出式字典查字 → 自動抓釋義與例句 → 送進 Anki」串成一條龍。這通常靠 AnkiConnect（Anki 的一個外掛，開放本機 API 讓其他程式跟 Anki 溝通）加上支援它的字典擴充達成。造卡摩擦力歸零，你會願意存下更多生字。
- **句子挖空卡（cloze deletion）**：Anki 支援一種卡型，把句子中的目標字挖成空格，讓你在**完整語境**裡回想那個字，而非孤立背單字。這對「記住字的用法」比中英對照卡有效得多。Ch 5 會深入。

這些都是「錦上添花」。地基是：每天打開 Anki、把到期卡複習完。這件事做到了，進階功能才有意義。

## 動手練習

跟著做，做完你的工作台就搭好了：

1. **裝 Anki 桌面版**，並註冊 AnkiWeb 帳號。手機裝對應的 App（Android 裝 AnkiDroid；iOS 先用網頁版亦可）。三邊登入同一帳號，按一次同步確認相通。
2. **建立牌組 `English Reading`**，手動加 5 張卡（隨便找 5 個你今天想記的英文字），跑完一次 Study Now，感受一下 Again / Hard / Good / Easy 的節奏。
3. **書籤兩本單語字典**：Longman LDOCE 與 Oxford Learner's。用它們各查一次 `afford` 這個字，讀它的例句，感受「單語字典怎麼教一個字」。
4. **裝一個彈出式字典擴充**（先裝 Google 翻譯官方擴充即可），在任一英文網頁上雙擊一個字，確認彈窗跳得出來。
5. **開一篇任意英文文章，按下 reader mode**，感受版面清乾淨後的差別。
6. **開三個材料來源網站各逛一分鐘**：Simple English Wikipedia（查一個你熟的技術主題）、News in Levels、BBC Learning English。記下哪個看起來你現在讀得動。

## 本章重點整理

- 閱讀學習失敗常敗在**摩擦力太高**，不是不夠努力。這一章的任務是把工具搭好、把摩擦力壓到最低。
- **四個工作站**：Anki（記憶）、字典＋彈出式擴充（查詢）、Reader mode（乾淨閱讀）、分級材料來源（找到讀得動的東西）。
- **Anki 是全課最重要的工具**：對抗遺忘唯一有效的方法是在對的時間複習，而這正是間隔重複做的事。桌面版免費，每天複習到期卡是不可斷的紀律。
- **字典要從雙語逐步過渡到單語 learner's dictionary**：單語字典用最常見的字寫釋義、附自然例句，教你用法邊界，不只給一個中文標籤。
- **Reader mode 剝掉干擾**，把有限的注意力全留給文字。
- **材料由易到難**：Simple English Wikipedia → News in Levels → BBC Learning English → graded readers → BBC News（攻頂目標）。寧可輕鬆讀懂十篇，不要痛苦啃半篇。

## 延伸閱讀

- **[Anki 官方使用手冊](https://docs.ankiweb.net/)** — 讀「Getting Started」與「Studying」兩節就夠起步；等你想調整每日新卡數量、複習上限時，再回頭讀「Deck Options」。這是理解 Anki 一切行為的權威來源。
- **[Longman Dictionary of Contemporary English（LDOCE）線上版](https://www.ldoceonline.com/)** — 直接拿它查幾個你以為懂的常用字（get / take / run），讀它的例句與搭配詞，你會發現這些「簡單字」其實用法很深。這是你之後每天都會用到的查詢站主力。
- **[BBC Learning English](https://www.bbc.co.uk/learningenglish)** — 逛「6 Minute English」與「News Review」兩個單元，它們專門把新聞英文拆給學習者看，是連接本課 Part 4「攻頂 BBC」的最佳中間站。

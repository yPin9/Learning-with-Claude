# Ch 16 — 攻頂：BBC News 與新聞英文的慣用語

> **目標**：站上階梯頂端，把 BBC News 特有的**新聞英文（journalese）** 一條條拆開，讓你從「有人陪讀的新聞語言」正式跨進「獨自順讀原生 BBC」。這是 Part 4 的原理深挖章，我們要攻克五道最會絆倒學習者的坎：**標題體（headlinese）** 的省略文法、**倒金字塔（inverted pyramid）** 的結構、**消息來源歸屬（attribution）** 的語氣密碼、新聞愛用的**片語動詞與慣用語**、以及**避險語言（hedging）**。最後給你一條從分級材料橋接到真 BBC 的具體路線。攻下這章，頂階對你就不再是隔牆的城堡，而是可以天天散步的公園。

## 為什麼需要這個？

你按著 Ch 14 的階梯、用 Ch 15 的資源一路爬上來，現在站在頂階門口。但你會發現一件事：**就算你的詞彙量夠了、拆句也會了，第一次讀原生 BBC News 還是會卡。**

卡在哪？不是生字，也不完全是句構——是**新聞這種文體自成一套的慣用語言**。新聞英文（有個帶點貶義但實用的名字叫 **journalese，新聞腔**）有一堆「只有新聞這樣寫」的慣例：標題會省掉冠詞和 be 動詞、用現在式講過去的事；每篇的資訊排列有固定套路；「誰說的」用哪個動詞藏著記者的態度；充斥著特定的片語動詞和避險說法。**這些慣例，前面所有階的教學化材料都沒完整教你**——因為它們是真新聞才有的「野生」特徵。

這就是為什麼很多人詞彙、文法都到位了，卻還是覺得「BBC 讀起來怪怪的、抓不到那個調」。**他們缺的是這一章：新聞文體的專屬使用手冊。** 一旦你認得這些慣例，BBC 的「怪」會瞬間變成「熟」——你會發現它其實高度規律、甚至比技術文好預測。

Ch 10 已經給過你「新聞 vs 技術句構指紋」的宏觀對照，這章是**把新聞那一半放大、鑽到底**：Ch 10 告訴你新聞有 attribution、有 headlinese，這章告訴你它們**具體長什麼樣、每種變體傳達什麼、你該怎麼讀**。這是你攻頂前的最後一塊拼圖。

## 先建立直覺

新聞英文的每一個怪癖，追根究柢都來自**同一個約束：新聞必須在最小的空間、最短的時間裡，把最重要的資訊送進讀者腦裡。**

想想新聞的生產與消費現場：
- 標題只有一行、字數有限（尤其是紙媒年代的遺產、以及現在的手機小螢幕）→ 於是發展出**省到極致的標題文法**。
- 讀者可能只讀第一段就滑走 → 於是把最重要的塞最前面（**倒金字塔**）。
- 新聞必須交代資訊來源、又要維持「客觀」的姿態 → 於是發展出一整套**歸屬語言**，還在動詞選字裡偷渡態度。
- 新聞常在事實未定時就得報導、又怕被告 → 於是大量用**避險語言**來保護自己。

所以這一章的五道坎，**不是五個要死背的規則清單，而是同一個約束（極致的資訊效率 + 自我保護）長出來的五種適應。** 你只要記住這個底層邏輯，每一種慣例都變得可推理、可預測：

```
                    ┌─ 標題要極短      → headlinese（省略文法）
   極致資訊效率 ────┼─ 讀者只讀開頭    → inverted pyramid（倒金字塔）
                    └─ 密度要高        → 片語動詞、慣用語（省字又生動）
                    ┌─ 要顯得客觀      → attribution（歸屬 + 動詞偷渡態度）
   自我保護 ────────┤
                    └─ 事實未定怕被告  → hedging（避險語言）
```

看懂這張圖，你讀 BBC 時就不是「一條條對規則」，而是**「我知道新聞為什麼要這樣寫，所以我預期它會這樣寫」**——預期一旦建立，理解速度就飛起來。

## 坎一：headlinese（標題體）——被省到骨架的文法

**標題（headline）自成一套語法**，跟正文的文法不一樣。為了在一行內塞進最多資訊，它砍掉一切可省的東西。不懂這套語法，你會覺得標題「文法都是錯的」——其實它是另一套規則。以下是 headlinese 的核心規則，每條配一個示意結構（用貼近真實 BBC 風格的標題示範，僅示意）：

### 規則 1：省略冠詞（a / an / the）

標題幾乎不用冠詞。

```
標題：Minister resigns over scandal
還原：A minister resigns over a scandal.
      （補回被省的 a / a）
```

讀法：看到標題裡名詞前面「缺冠詞」，**心裡自動補回 a/the**，別以為句子壞了。

### 規則 2：省略 be 動詞

`is / are / was / were` 常被整個砍掉。

```
標題：Talks under way to end strike
還原：Talks ARE under way to end the strike.
      （補回被省的 are）

標題：Two arrested after protest
還原：Two [people] WERE arrested after a protest.
      （這裡連被動的 were 都省了 → 見規則 4）
```

讀法：標題若「名詞 + 直接接形容詞/介系詞片語/過去分詞」而少了動詞，**多半省了 be 動詞**，補回去就通。

### 規則 3：用現在式表達「已經發生的過去事件」（historic present）

這是最會誤導人的一條。新聞報導的多半是**剛發生的過去事件**，但標題用**現在式**，因為現在式短、又有臨場的即時感。

```
標題：Earthquake hits southern region
實際：An earthquake HIT the southern region.（是已發生的事）
      標題用 hits（現在式）不是 hit（過去式）
```

讀法：**標題的現在式，內容通常指剛發生的過去**。別被現在式騙成「這是正在發生/常態」——去讀正文，正文會用正常的過去式講清楚時態。

### 規則 4：省略被動的助動詞（只留過去分詞）

被動語態（Ch 10）在標題裡常只留過去分詞，把 `be` 助動詞省掉。

```
標題：Suspect charged with fraud
還原：A suspect [has been / was] CHARGED with fraud.
      （只留 charged，省了 has been / was）
```

讀法：標題若「名詞 + 過去分詞（-ed / 不規則分詞如 charged, arrested, found, killed）」，**這是省了助動詞的被動**——是「某人被起訴/被逮捕/被發現/被殺」，不是那人自己做了什麼。**這條特別重要，搞錯主被動意思會完全相反。**

### 規則 5：用不定詞（to + 動詞）表達「即將發生的未來」

標題用 `to + 原形動詞` 表示「將要、計畫要」。

```
標題：PM to visit Washington next week
還原：The PM IS GOING TO visit Washington next week.
      （to visit = 將要造訪）
```

讀法：標題出現 `名詞 + to + 動詞`，**這是講未來計畫**（= is going to / will / is set to），不是不定詞當受詞那種用法。

### 規則 6：名詞堆疊（noun pile-up）

標題把一長串名詞疊在一起當形容詞用（Ch 8 的名詞堆疊，在標題裡密度更高），省掉介系詞和關係子句。

```
標題：Hospital data breach probe launched
拆解：一項調查（probe）被啟動（launched），
      關於「醫院（Hospital）資料（data）外洩（breach）」
還原：A probe into the hospital data breach HAS BEEN launched.
```

讀法：遇到一長串名詞疊在一起，**從最後一個名詞（核心）往前讀**（Ch 8 的心法），前面的都是修飾它的。這是標題最容易讓人「每個字都認識、合起來看不懂」的地方。

### 一張 headlinese 速查表

| 標題現象 | 實際意思 | 你該補回 |
|---|---|---|
| 名詞前沒冠詞 | 正常名詞 | a / an / the |
| 名詞後直接接形容詞/介系詞，缺動詞 | 省了 be | is / are / was |
| 用現在式（hits, resigns） | **通常是剛發生的過去** | 讀成過去式 |
| 名詞 + 過去分詞（charged, arrested） | **被動**（被…） | has been / was + 分詞 |
| 名詞 + to + 動詞 | **未來計畫**（將要…） | is going to / will |
| 一長串名詞疊在一起 | 名詞堆疊 | 從最後一個往前拆 |

**攻克 headlinese 的總心法：標題是「壓縮檔」，正文是「解壓縮後」。** 讀標題卡住時，別硬解標題——**直接看第一段正文**，正文用完整文法把標題的意思講一遍，你對照著就懂了。標題的作用是「勾你進去」，不是「讓你在那卡住」。

## 坎二：倒金字塔（inverted pyramid）——最重要的在最前面

**倒金字塔**是新聞報導的標準結構：**把最重要的資訊放最前面，越往後越次要。** 這和你熟悉的「起承轉合、鋪陳到高潮」的敘事順序**完全相反**——新聞把「高潮」（結論、最重要的事實）直接擺開頭。

```
   ┌─────────────────────────────┐
   │  導言（lead / lede）          │  ← 最重要：誰、做了什麼、
   │  第一段，通常一兩句           │     何時、何地、（為何/如何）
   ├───────────────────────────┤       = 5W1H 的核心
   │  重要細節、背景、引述         │  ← 次要：補充、消息來源說法
   ├─────────────────────────┤
   │  更多背景、周邊資訊           │  ← 更次要
   ├───────────────────────┤
   │  最不重要的細節              │  ← 可有可無（早年紙媒為排版可直接砍尾段）
   └─────────────────────┘
```

### 這對你「怎麼讀」的三個直接影響

1. **讀第一段（導言）就能抓到全文重點。** 導言（lead，英式常拼 lede）通常一兩句話就把 **5W1H（who, what, when, where, why, how）** 的核心塞好。**你光讀導言，就知道這則新聞在講什麼。** 這是新聞比小說好讀的地方——它不藏。

2. **你可以合法地「讀到不想讀就停」。** 因為越往後越不重要，讀累了、時間不夠了，**讀完前幾段停下來，你不會漏掉重點**。這對還在攻頂、耐力有限的你是天大的好消息——**你不必逼自己讀完整篇**，讀導言 + 前兩三段，重點已到手，這完全是合理的讀法（呼應 Ch 19 要講的 skimming）。

3. **它讓 skimming（略讀）變得極有效率。** 想快速掃一批新聞抓大意？**只讀每則的標題 + 導言**就夠了。倒金字塔結構讓「只讀開頭」成為一種可靠的策略，不是偷懶。

**攻克倒金字塔的心法：讀 BBC 新聞，先把導言（第一段）讀懂、確認抓到 5W1H，這是地基。之後每一段都是在給地基加細節，你按需要往下讀多深由你決定。** 這徹底翻轉了「一定要從頭讀到尾」的壓力。

## 坎三：attribution（消息來源歸屬）——動詞裡藏著態度

新聞必須交代「這是誰說的」，這叫 **attribution（歸屬）**。它是新聞維持「客觀」姿態的手段——記者不直接斷言「事情是這樣」，而是說「某某人**說**事情是這樣」。attribution 遍布每一篇新聞，形式有三大類：

```
① 動詞式：X said / claimed / added ...        （最常見）
② 介系詞片語式：according to X, ...           （據 X 表示）
③ 消息來源標籤：officials said / sources told the BBC / a spokesperson said
```

### 關鍵：attribution 動詞是「語氣密碼」

Ch 10 點過這件事，這章鑽到底。**記者選哪個動詞來 attribute，偷偷傳達了他對這句話可信度的態度。** 這是讀新聞「言外之意」最核心的技能。把常見的 attribution 動詞按「中立 → 帶立場」排開：

| attribution 動詞 | 語氣 | 記者暗示什麼 |
|---|---|---|
| **said** | 完全中立 | 純粹轉述，不表態（BBC 最愛用、最安全） |
| **added / noted / explained** | 中立偏正面 | 補充、澄清；explained 微微暗示「這是對的說明」 |
| **stated / announced** | 中立、正式 | 官方、正式的宣布 |
| **according to** | 中立，但把責任推給來源 | 「這是 X 說的，不是本報認定」 |
| **claimed** | **暗示存疑** | 「X 這樣說，但**未必是真的/本報不背書**」 |
| **alleged** | **暗示指控未證實** | 「這是指控，尚未證實」（法律敏感時用） |
| **insisted** | 暗示「講了不只一次、或有人不信」 | 帶點「硬要這麼說」的意味 |
| **admitted / conceded** | 暗示「這對說話者不利」 | 承認了對自己不利的事 |
| **denied** | 中立轉述否認 | X 否認（常暗示先前有相反指控） |
| **warned** | 中立偏嚴肅 | 警告，強調事態嚴重 |

**讀新聞時的動作：看到 attribution 動詞，先讀「說了什麼」，再看「用哪個動詞說的」——動詞就是記者對這句話的隱形註解。**

實例對照（同一件事，換動詞，語氣天差地別）：
```
The company said the data was secure.
  → 中立轉述，記者不表態。

The company claimed the data was secure.
  → 記者暗示：公司這樣講，但我對此存疑（也許後面就有反證）。

The company admitted the data was not secure.
  → 記者暗示：公司承認了對自己不利的事（先前可能否認過）。
```

**這三句的字面「公司對資料安全的說法」大同小異，但記者對可信度的態度完全不同——差別全在那一個動詞。讀不出這個，就只讀到字面、漏掉新聞真正的訊息層。**

### attribution 的其他門道

- **具名 vs 不具名**：`the minister said`（具名，可信度高、要負責）vs `a source said / officials said`（不具名，可信度較低、來源受保護）。BBC 常見 `sources told the BBC`——這是「本報有內線消息但不透露是誰」，可信度看 BBC 信譽背書。
- **放句首 vs 句尾**：attribution 放句首（`Officials said the measure would...`）會讓「誰說的」更突出；放句尾（`...the measure would be reviewed, officials said.`）則讓「說的內容」先進讀者腦、來源當附註。位置本身就是一種強調的操作。
- **attribution 是「標籤」不是「主菜」**：讀的時候，先抓「說了什麼」（主菜），再回頭看「誰說的、用什麼動詞、具不具名」（標籤上的資訊）。別讓一堆 `officials said / according to the report` 打斷你抓主要內容。

## 坎四：新聞愛用的片語動詞與慣用語

新聞英文為了**又省字又生動**，大量使用**片語動詞（phrasal verb，動詞 + 介副詞，如 carry out）** 和**慣用語（idiom，字面加起來不等於實際意思的固定說法）**。這是很多學習者的痛點——因為片語動詞和慣用語**「每個字都認識，合起來卻猜不到意思」**。

### 新聞高頻片語動詞（先認得這批）

這些在 BBC 出現的頻率極高，且意思往往和字面差很遠。**先把這批當生字背起來**（丟 Anki，Part 1 習慣），你的新聞閱讀會立刻順很多：

| 片語動詞 | 新聞裡的意思 | 例句結構 |
|---|---|---|
| **carry out** | 執行、進行（攻擊、調查、手術） | carry out an attack / investigation |
| **step down** | 辭職、下台 | The CEO stepped down. |
| **call for** | 呼籲、要求 | Campaigners called for a ban. |
| **crack down (on)** | 嚴厲打擊、取締 | Police cracked down on protests. |
| **roll out** | 推出、逐步實施 | The government rolled out the scheme. |
| **look into** | 調查、研究 | Officials are looking into the claims. |
| **rule out** | 排除（可能性） | Police have not ruled out arson. |
| **set out** | 闡述、提出（計畫） | The minister set out the plan. |
| **step up** | 加強、加大（力度） | The army stepped up its offensive. |
| **turn out** | 結果是、原來是 | It turned out to be a false alarm. |
| **hand over** | 移交、交出 | Suspects were handed over to police. |
| **draw up** | 擬定、草擬 | Lawyers drew up the agreement. |

### 新聞常見慣用語 / 固定說法

慣用語更麻煩，因為完全不能從字面推。新聞裡有一批高頻的：

- **in the wake of ...** = 在…之後（尤指某事件之後，帶「作為後果」的意味）。`In the wake of the scandal, ...`
- **amid ...** = 在…的背景/氛圍中（新聞超愛用，比 during 更帶「動盪環境」感）。`resigned amid mounting pressure`
- **come under fire** = 遭到抨擊。`The policy has come under fire.`
- **at odds (with)** = 與…不合、相左。`The two ministers are at odds.`
- **in the pipeline** = 在籌備/進行中。`More reforms are in the pipeline.`
- **a U-turn** = 政策大轉彎、髮夾彎。`The government made a U-turn on the tax.`
- **spark** = 引發（當動詞，比 cause 生動）。`The remarks sparked outrage.`
- **grapple with** = 費力應對、苦於。`The city is grappling with flooding.`

**攻克心法：片語動詞和慣用語沒有捷徑，只能「認得就記、記了就熟」。** 但好消息是——**它們高度重複**。新聞來來去去就那幾百個高頻片語動詞和慣用語，你把最常見的這兩三批吃下來（丟 Anki 反覆），覆蓋率會急速上升。**這是投資報酬率極高的一批「生字」**，因為每一個都會在往後的每一篇新聞裡不斷回來找你。

## 坎五：hedging（避險語言）——新聞為什麼講話這麼「軟」

**避險語言（hedging）** 指用來**弱化斷言、保留餘地、不把話說死**的詞語。新聞大量用它，原因是坎的底層邏輯之一：**新聞常在事實未完全確定時就得報導，說死了萬一錯了要負責（甚至被告）。** 於是記者用 hedging 給自己留後路。

常見的避險手段：

| 避險手段 | 例子 | 效果 |
|---|---|---|
| 情態動詞 | may / might / could / would | 「可能」而非「一定」 |
| 副詞 | reportedly, allegedly, apparently, seemingly | 「據報/據稱/看來」，保留餘地 |
| 動詞 | suggest, indicate, appear (to) | 「顯示/看來」而非「證明」 |
| 模糊量詞 | some, several, a number of, many | 不給精確數字 |
| 條件語氣 | if confirmed, if true | 「若屬實」，明擺著還沒確定 |
| 歸屬（本身就是避險） | X claimed / according to | 把責任推給來源（見坎三） |

實例：
```
The attack may have been carried out by a state-backed group,
sources suggest.

├─ may have been           ← 情態動詞避險（可能，不確定）
├─ carried out             ← 新聞片語動詞（執行，見坎四）
├─ a state-backed group    ← 名詞堆疊
└─ sources suggest         ← attribution + suggest（避險動詞）+ 不具名來源

整句的「確定性」被層層調低：這只是「消息來源暗示的、可能的」說法，
記者一個字都沒把話說死。
```

**讀 hedging 的關鍵：分辨「記者在陳述事實」還是「記者在保留餘地」。** 一句沒有 hedging 的話（`The minister resigned.`）是記者確認的事實；一句滿是 hedging 的話（`The minister may be about to resign, sources suggest.`）是**還沒確定、記者不背書**的推測。**把這兩層分開，你才讀得出「哪些是新聞確定的、哪些只是風聲」**——這是讀新聞不被帶風向的核心能力。

## 對比與取捨

把新聞英文的五道坎，連同「它為什麼存在」「你該怎麼讀」整理成一張總表，這是本章最該內化的：

| 坎 | 新聞為什麼這樣寫 | 具體特徵 | 你該做的動作 |
|---|---|---|---|
| headlinese | 標題空間極小 | 省冠詞/be、現在式表過去、分詞表被動、to 表未來、名詞堆疊 | 卡住就跳讀第一段正文（解壓縮） |
| 倒金字塔 | 讀者只讀開頭 | 最重要的在導言，越後越次要 | 先讀懂導言抓 5W1H，之後按需往下 |
| attribution | 要顯客觀、要交代來源 | said/claimed/admitted、具不具名、位置 | 先抓「說什麼」，再讀動詞的語氣密碼 |
| 片語動詞/慣用語 | 又省字又生動 | carry out, step down, in the wake of... | 當高頻生字丟 Anki，投報率極高 |
| hedging | 事實未定、怕擔責 | may/reportedly/suggest/if confirmed | 分辨「確認的事實」vs「保留的推測」 |

取捨與心法：

- **這五道坎全是「新聞文體的規律」，不是「英文的例外」。** 一旦你認得它們，BBC 從「怪」變「熟」，甚至比技術文更好預測——因為新聞的套路比技術文更固定。**攻克新聞英文，本質是攻克一套規律，不是攻克無限的例外。**
- **五道坎的投報率不同，按此排優先順序**：先攻 **headlinese + 倒金字塔**（結構性的、一學就大幅提升，且讓你能「讀導言就抓重點」），再攻 **片語動詞/慣用語**（高頻、丟 Anki 累積），最後細品 **attribution 語氣 + hedging**（進階的「讀言外之意」，需要多讀才培養出手感）。
- **前四道坎讓你「讀懂字面」，第三、五道（attribution 語氣、hedging）讓你「讀懂新聞如何被建構」。** 前者是攻頂的門檻，後者是頂階之上的批判性閱讀能力——不必一次到位，先讀懂字面，語氣與避險的敏感度會隨閱讀量自然長出來（Part 5 精讀 BBC 時會實地練）。

## 踩雷集錦

1. **把標題的現在式讀成「正在發生 / 常態」。**
   標題 `Earthquake hits southern region`，讀成「地震正在襲擊/常襲擊南部地區」。
   → 正解：**標題的現在式（historic present）通常指剛發生的過去事件**——是「（剛剛）發生了地震」。標題用現在式只為求短和臨場感。**去讀第一段正文，它會用過去式把時態講清楚。**

2. **把標題「名詞 + 過去分詞」的被動讀成主動，意思完全相反。**
   標題 `Suspect charged with fraud`，讀成「嫌犯（主動）指控詐欺（別人）」。
   → 正解：這是**省了助動詞的被動**——「嫌犯**被**以詐欺罪起訴」。標題裡「名詞緊接過去分詞（charged/arrested/killed/found）」幾乎都是被動。**主被動搞反，整則新聞的意思就反了，這是 headlinese 最危險的坑。**

3. **逼自己從頭到尾讀完每一篇新聞，讀不完就有罪惡感。**
   以為「認真讀就該讀完整篇」，一則長新聞讀到累還硬撐。
   → 正解：**倒金字塔結構下，越後面越不重要**——讀懂導言 + 前幾段，重點已到手，之後按需要往下讀多深由你決定，**讀到不想讀就停是合理的**，不會漏重點。硬讀完整篇既累又浪費耐力，還可能因此放棄整個習慣。

4. **把 attribution 動詞全當成中性的「說」，讀不出語氣。**
   `The company claimed the data was secure` 讀成「公司說資料是安全的」，和 `said` 版本讀成一樣。
   → 正解：**claimed 暗示記者存疑、admitted 暗示對說話者不利、according to 把責任推給來源**——動詞就是記者的隱形註解。**把 claimed 讀成 said，你就漏掉了記者偷偷告訴你「別全信」的訊號。** 讀新聞先抓「說什麼」，再品「用哪個動詞說」。

5. **卡在片語動詞/慣用語，硬用字面拆。**
   讀到 `in the wake of the scandal`，苦苦思考「醜聞的『尾流/醒來』是什麼」；讀到 `step down`，想成「往下走一階」。
   → 正解：**片語動詞和慣用語的意思不等於字面加總**（in the wake of = 在…之後、step down = 辭職）。**別硬拆字面，把它們當「一個整體的生字」記住**（丟 Anki）。這批高頻、重複出現，記一次受用無數次，投報率極高。

6. **把滿是 hedging 的推測，讀成新聞確認的事實。**
   `The minister may be about to resign, sources suggest` 讀成「部長要辭職了」（當成確定的事去轉述給別人）。
   → 正解：**may + sources suggest 是層層避險**——這是「有風聲、可能、未證實」，記者一個字都沒說死。**把「hedging 過的推測」和「沒 hedging 的事實」分開**，是讀新聞不被誤導、不傳謠的核心能力。看到 may/might/reportedly/allegedly/suggest/if confirmed，就知道記者在保留餘地。

## 進階：再往深一層

- **「journalese」這個詞本身帶著新聞界的自我批判。** 新聞腔（journalese）指的不只是這些慣例，也常帶點貶義——指那些「只有新聞才會用、日常沒人這樣講」的陳腔（例如 `slam` 代替 criticize、`probe` 代替 investigation、`bid` 代替 attempt）。這些是新聞為了短和聳動發展出的專屬詞彙。**對讀者的意義**：你會在新聞裡讀到一批「日常英文很少見、但新聞超常見」的字（slam, probe, bid, row, blast, mull, eye 當動詞用…）。它們是新聞的「行話」，你把它們當「新聞專用生字」收進 Anki 即可，別因為「日常沒學過」就慌——它們只在新聞這個文體裡高頻。BBC 官方甚至有一份公開的 **[BBC News Style Guide（新聞寫作風格指南）](https://www.bbc.co.uk/newsstyleguide)**，記載記者被要求怎麼寫（用詞、標題、attribution 規範）——**讀它就是「反推你該怎麼讀」的權威捷徑**：知道記者被教怎麼寫，你就知道文本為什麼長這樣。

- **attribution 與 hedging 合起來，構成新聞的「認識論框架」。** 往深一層看，一篇好新聞其實在對你**分層標示每個資訊的確定性**：哪些是記者親眼確認的（直接陳述、無 hedging）、哪些是可靠來源說的（具名 attribution）、哪些是未證實的風聲（不具名 + hedging + claimed）。**老練的讀者讀新聞時，腦中會自動幫每句話貼上一個「確定性標籤」**——這句是事實、這句是官方說法、這句是猜測。這是從「讀懂新聞說什麼」升級到「評估新聞每句話多可信」的關鍵一步，也是媒體素養（media literacy）的核心。你不必馬上做到，但知道有這一層，你讀 BBC 就會開始不自覺地留意「這句記者有多確定」。

- **倒金字塔正在被「新型態」侵蝕，但仍是硬新聞的骨架。** 傳統倒金字塔是「硬新聞（hard news，即時事件報導）」的標準結構，至今 BBC 的即時報導仍嚴格遵守。但你也會遇到不走倒金字塔的類型：**特稿/長篇報導（feature）** 可能用故事化開頭（anecdotal lead，先講一個人的故事再帶到主題）、**分析/評論** 可能用論證結構。**辨認文類，套對結構預期**：看到 BBC News 一般報導，用倒金字塔讀法（先抓導言）；看到 The Conversation 那類深度分析，預期它更像論說文（有鋪陳、有論證、重點可能在中後段）。這呼應 Ch 10 「先判文體、套對讀法」的宏觀心法——在新聞內部，還要再細分文類。

- **英式 BBC 英文與美式新聞英文有系統性差異。** 你的目標是 BBC，屬**英式英文（British English）**——拼法（`organise` 不是 `organize`、`labour` 不是 `labor`、`defence` 不是 `defense`）、用詞（`row` = 爭吵/爭議、`sacked` = 被解僱、`whilst` = while、`MP` = 國會議員）、乃至集合名詞的動詞一致（英式常把 `the government / the team` 當複數：`The government are considering...`）都和美式不同。**讀 BBC 前先有「這是英式」的預期**，遇到這些差異就不會誤判為錯誤。這也是為什麼你的階梯選 BBC Learning English 當第 4–5 階特別合適——它從一開始就餵你英式語感，一路上來無縫接軌 BBC News。

## 動手練習

1. **拆 5 個真實 BBC 標題**：去 [BBC News 官網](https://www.bbc.com/news) 抓 5 個當天標題，對每個：(a) 找出用了哪幾條 headlinese 規則（省冠詞？現在式表過去？分詞表被動？to 表未來？名詞堆疊？）；(b) 把它「解壓縮」成完整文法的句子；(c) 再讀第一段正文，對照你解壓縮得對不對。**特別檢查有沒有「名詞 + 過去分詞」的被動，確認你沒讀反主被動。**

2. **只讀導言抓 5W1H**：抓 3 則 BBC 短新聞，**只讀第一段（導言）**，寫下你抓到的 who / what / when / where / why / how。然後讀完整篇，檢查「只讀導言」漏了哪些重點——你會發現多半沒漏，這就是倒金字塔的威力。

3. **attribution 語氣偵測**：在一篇 BBC 報導裡，把所有 attribution（said / claimed / according to / admitted...）圈出來，對每一個判斷：這個動詞是中立還是帶立場？記者暗示了什麼？來源具名嗎？做完你會發現，同一篇新聞裡，記者對不同說法的「背書程度」其實不一樣。

4. **建你的「新聞高頻片語動詞 + 慣用語」Anki 牌組**：把本章「坎四」的兩張表全部做成 Anki 卡（正面片語動詞、背面新聞裡的意思 + 一個例句）。之後每讀一篇 BBC，新遇到的片語動詞/慣用語就加進這副牌。目標：這副牌養到 100+ 張時，你的新聞閱讀會明顯變順。

5. **hedging 分層練習**：找一篇報導「還在發展中的事件」的 BBC 新聞（這種最多 hedging），把每一句標記成「① 記者確認的事實（無 hedging）」或「② 保留餘地的推測（有 hedging）」。數一數兩類各幾句，體會新聞是怎麼一句句調節確定性的。

6. **橋接實作（承接 Ch 15 的第③步）**：挑一則你在 News in Levels（Level 3）或 News Review 讀過背景的新聞主題，去 BBC News 讀原生報導。因為有背景加持，用本章五道坎的心法去讀，記錄：哪道坎最卡你？把最卡的那道當成接下來一週的專攻重點。

## 本章重點整理

- **新聞英文的所有怪癖，都來自同一約束**：極致的資訊效率 + 自我保護。認得這底層邏輯，五道坎全都可推理、可預測。
- **坎一 headlinese**：標題自成一套語法——省冠詞/be、**現在式表剛發生的過去**、**名詞+過去分詞=被動（別讀反）**、to+動詞=未來、名詞堆疊。卡住就跳讀第一段正文（解壓縮）。
- **坎二 倒金字塔**：最重要的在導言，越後越次要。**先讀懂導言抓 5W1H**，之後按需往下讀，**讀到不想讀就停是合理的**（不漏重點）。
- **坎三 attribution**：先抓「說什麼」，再品動詞的**語氣密碼**——said（中立）/ claimed（存疑）/ admitted（不利）/ according to（推責給來源）；並留意具不具名、放句首句尾。
- **坎四 片語動詞/慣用語**：carry out / step down / crack down / in the wake of / amid / come under fire... **當高頻生字丟 Anki，投報率極高**（重複出現）。
- **坎五 hedging**：may / reportedly / suggest / if confirmed... 是避險。**分辨「記者確認的事實」vs「保留餘地的推測」**，是不被帶風向的核心。
- **優先順序**：先攻結構性的 headlinese + 倒金字塔，再攻高頻的片語動詞/慣用語，最後細品 attribution 語氣 + hedging。前四道讓你讀懂字面，第三、五道讓你讀懂新聞如何被建構。
- **BBC 是英式英文**：拼法、用詞、集合名詞一致性都和美式不同，先有預期就不誤判。

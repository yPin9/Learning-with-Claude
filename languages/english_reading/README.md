# 英文閱讀流暢度：從「硬讀技術文」到「輕鬆讀懂 BBC」

> 給能靠領域知識硬啃技術文、卻讀不動一整篇長文的工程師。目標不是考試分數，是**讓讀英文從「解碼苦工」變成「理解本身」**。

這不是一本文法書，也不是單字書。這是一本**薄手冊 + 每日練習系統**：手冊講清楚你為什麼讀不動、以及怎麼有效率地把地基補起來；系統給你一套每天照跑的菜單和一條從現在爬到 BBC 的材料階梯。真正讓你變強的是「每天讀對的東西」，不是讀這本手冊——所以它刻意做薄。

## 為什麼學這個？

- **你讀技術文能過關，是假象**：你靠的是領域知識 + 關鍵字 pattern matching + 翻譯工具，不是真的在讀英文。一換到非技術長文（新聞、評論、文件的敘事段落）就露餡。這門課補的是真正的底層閱讀能力。
- **閱讀是所有輸入的地基**：聽力、寫作、口說都建立在「腦中有大量正確的英文輸入」之上。閱讀是最可控、最高效的輸入來源。把閱讀練順，其他技能才有養分。
- **這是可以自學到底的技能**：閱讀不需要對練夥伴、不需要開口的勇氣。只要方法對、材料選對、量夠，一個人就能練到很遠。這門課就是要把「方法」和「材料階梯」交到你手上。

## 先修知識

- 國中程度的基礎文法與單字（大約 TOEIC 400+）——你能看懂簡單句子，只是撐不住長文
- 願意每天投入 20–40 分鐘，持續數月（這是硬需求，閱讀是肌肉不是知識）
- 一台能裝 Anki、能開瀏覽器的電腦或手機
- **不需要**：任何語言學背景、任何考試目標

## 學習方式建議

1. **手冊快、練習慢**：Ch 0–19 你可以一兩週讀完，但別以為讀完就結束了——真正的功夫在 Final Project 那套每日系統，那要跑好幾個月。
2. **邊讀邊建 Anki**：從 Part 1 開始就把 Anki 掛起來，之後每天餵它。這是全課最重要的單一習慣。
3. **誠實選 level**：讀到「查字典查到不想讀」就是材料太難了，往下降一階（見 Part 4）。降階不丟臉，硬撐才是浪費時間。
4. **量重於質**：extensive reading 的核心是「讀很多」。寧可輕鬆讀十篇，不要痛苦啃一篇。

## 精選資料庫

整門課最值得反覆參照的資源，各章「延伸閱讀」會指向更具體的部分。

### 必讀基礎

- **Paul Nation, *Learning Vocabulary in Another Language*（2nd ed., Cambridge, 2013）**
  - 詞彙教學與二語習得的權威。本課 Part 1 的覆蓋率理論、word family、學習策略都源自這裡
- **[New General Service List Project](https://www.newgeneralservicelist.org/)**
  - 高頻詞清單的權威來源（NGSL / NAWL / TSL / BSL），本課詞彙階梯的骨幹

### 推薦論文

- **[Nation, "How Large a Vocabulary Is Needed For Reading and Listening?"（2006）](https://www.lextutor.ca/cover/papers/nation_2006.pdf)**
  - 建立了「98% 覆蓋率 = 獨立閱讀門檻」「書面文字需 8,000–9,000 word families」的基準，本課 Ch 1 的地基
- **[Coxhead, "A New Academic Word List"（TESOL Quarterly, 2000）](https://onlinelibrary.wiley.com/doi/abs/10.2307/3587951)**
  - AWL 的原始論文，570 word families 佔學術文本約 10%，本課 Ch 4 的依據

### 推薦部落格 / 工具

- **[Lextutor VocabProfile](https://www.lextutor.ca/vp/)** — 把任何文本貼進去，算出它的高頻詞/AWL/難詞覆蓋率。全課的自我診斷利器
- **[Test Your Vocabulary](https://testyourvocab.com/)** — 快速估你的英文詞彙量，Part 0 診斷用

### 讀完本課之後

- **Stephen Krashen, *The Power of Reading*（2nd ed., 2004）** — 把「大量自由閱讀」的證據講到底，讀完本課後給你繼續下去的信念與更深的理論

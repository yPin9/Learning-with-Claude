# Ch 6 詞根詞綴與技術英文詞彙

> **目標**：學會用構詞學（morphology）拆解生字——認識常見的希臘/拉丁字根（root）、前綴（prefix）、後綴（suffix），把一個沒見過的長字拆成「已知零件」來猜意思；同時搞懂「結合語境猜字」的正確做法與它的極限。接著我們把矛頭轉向你的主場：**為什麼你這個技術背景讀者會覺得技術英文「好讀」**——領域窄、術語重複、大量同源詞（cognate）、名詞化（nominalization）——並教你怎麼把這個優勢用在爬向 BBC 的階梯上。最後拆兩個陷阱：假朋友（false friends）與「認得字面、卻不懂術語專義」。

## 為什麼需要這個？

前三章我們用覆蓋率地圖（Ch 3、4）和記憶方法（Ch 5）解決了「哪些字值得學、怎麼記住」。但無論你背多少字，真實閱讀裡永遠會撞到**沒背過的字**——尤其在往 98% 爬的長尾階段，off-list 的低頻字是常態。

這一章給你兩把在「當場遇到生字」時能用的武器：

1. **拆解（decoding）**：很多英文長字不是不可分割的整體，而是由**可辨認的零件**拼成的。學會拆，你能把一個沒見過的字化簡成「已知前綴 + 已知字根 + 已知後綴」，當場猜出八九不離十的意思——**不必查、不必背，靠結構就破解**。
2. **語境推斷（contextual inference）**：靠句子周圍的字，圈出生字的大致意思。

這兩把武器合起來，能大幅降低你對字典的依賴，讓你在「還沒背到那個字」時也能滑過去、維持閱讀的流暢。

更重要的是，這一章要揭穿並利用你身上一個已經存在的優勢。本課從第一章就一直說「你讀技術文能過關是假象」——那是要你別自滿。但這一章要換個角度：**那個「假象」背後，其實有一部分是貨真價實的優勢，而且可以移植。** 技術英文之所以對你好讀，有幾個結構性的原因（不只是你懂那個領域），搞懂這些原因，你能把同一套讀技術文的順手感，慢慢延伸到更廣的文本上。

## 先建立直覺

先看一個字，感受「拆」的威力。假設你從沒見過 `intractable` 這個字。

不會拆的人：一個長長的、陌生的、只能查字典的整體。

會拆的人看到的是三塊：

- **`in-`**：前綴，表「不、非」（同 `invisible` 的 in-）。
- **`tract`**：字根，源自拉丁文 `trahere`（拉、牽引）——你其實已經在 `tractor`（拖拉機）、`attract`（吸引，向自己拉）、`extract`（抽取，往外拉）裡見過它。
- **`-able`**：後綴，表「可……的」（同 `readable`、`portable`）。

拼起來：`in-`（不）+ `tract`（拉、牽引、駕馭）+ `-able`（可……的）= **「不可駕馭的、棘手的、難處理的」**。查字典的定義正是「difficult to control or deal with」。**你沒背過這個字，卻靠三塊已知零件當場猜對了。**

這就是構詞拆解的核心直覺：**英文（尤其正式/學術/新聞的第二圈字）有巨大比例是拉丁/希臘零件的排列組合。** 你不必記住每一種排列（那是無限多的），你只要記住那**有限的一批零件**——幾十個高頻字根、幾十個常見前後綴——就能像認識化學元素一樣，去解開由它們組成的成千上萬個「化合物」。

這對你這個技術背景讀者尤其甜：你已經在術語裡見過大量這些零件（`extract`、`compress`、`transmit`、`asynchronous`……全是拉丁/希臘零件），你只是沒意識到它們是「零件」、可以拆下來用在別的字上。這一章就是把這個潛在能力顯性化。

## 前綴：改變意思的方向

**前綴（prefix）**加在字根前面，通常**改變意思的方向**（否定、方位、程度、時間），較少改變詞性。它們是拆字時最先看的一塊，因為最好認、最穩定。挑對閱讀正式文本最有回報的一批：

**否定 / 相反類**（讀新聞評論極常見，關乎句子的正負向）：
- `un-`：不、未。`unprecedented`（前所未有的）、`undeniable`（不可否認的）。
- `in- / im- / il- / ir-`：不、非（in- 在 b/p/m 前變 im-、在 l 前變 il-、在 r 前變 ir-）。`incapable`、`impossible`、`illegal`、`irregular`。
- `dis-`：相反、除去。`disagree`、`disorganize`、`disconnect`。
- `non-`：非。`nonprofit`（非營利的）、`nonexistent`。
- `anti-`：反對。`antibody`（抗體）、`anti-government`。
- `mis-`：錯誤地。`misinterpret`（誤解）、`misconduct`（不當行為）。

**方位 / 方向類**：
- `sub-`：下、次。`submarine`（潛水艇）、`subordinate`（下屬）、`subset`（子集，你的領域字）。
- `super- / sur-`：上、超。`supervise`（監督）、`surpass`（超越）。
- `trans-`：跨、越。`transport`（運輸）、`transmit`（傳送）、`transnational`（跨國的）。
- `inter-`：之間。`international`、`interact`、`intervene`（介入）。
- `pre-`：之前。`predict`（預測）、`precedent`（先例）。
- `re-`：再、回。`review`、`reconstruct`、`retract`（縮回，又見 tract）。

**程度 / 數量類**：
- `over- / under-`：過度 / 不足。`overestimate`、`underfunded`（資金不足的）。
- `co- / con- / com-`：共同、一起。`cooperate`、`construct`（一起堆起來）、`compress`（一起壓，你的領域字）。

看前綴時，一個實用的判斷：**否定前綴會把整個字的正負向翻過來**。讀新聞時，`the deal is not without precedent` 和 `unprecedented` 意思天差地別——沒看清 `un-` 就會把句子讀反。**前綴雖小，常是句子語意的開關。**

## 後綴：改變詞性

**後綴（suffix）**加在字尾，主要功能不同於前綴——它**改變詞性**（把動詞變名詞、名詞變形容詞……），對意思方向的改動較小。認後綴的最大用處是：**看字尾就能判斷這個字在句子裡是什麼角色（名詞？形容詞？動詞？）**，這對 Part 2 拆長句時「找主詞、找動詞」極有幫助。

**變成名詞的後綴**：
- `-tion / -sion / -ation`：動作或其結果。`organization`、`decision`、`implementation`。**這是學術/新聞文本密度最高的後綴之一**（名詞化的主力，下面會專門講）。
- `-ment`：動作或結果。`government`、`development`、`agreement`。
- `-ness`：狀態、性質。`awareness`（意識）、`willingness`。
- `-ity / -ty`：性質、狀態。`ability`、`security`、`complexity`（你的領域字）。
- `-ism`：主義、學說。`capitalism`、`mechanism`（機制）。
- `-er / -or / -ist`：執行者。`developer`、`operator`、`analyst`。

**變成形容詞的後綴**：
- `-able / -ible`：可……的。`readable`、`intractable`、`accessible`。
- `-al`：關於……的。`political`、`technical`、`functional`。
- `-ous`：充滿……的。`dangerous`、`ambiguous`（模稜兩可的）。
- `-ive`：有……傾向的。`effective`、`competitive`、`recursive`（你的領域字）。
- `-ic`：關於……的。`economic`、`systematic`、`asynchronous`（a- + syn- + chron 時間 + -ous，你的領域字）。

**變成動詞的後綴**：
- `-ize / -ise`：使成為。`organize`、`optimize`（你的領域字）、`prioritize`。
- `-ify`：使成為。`clarify`（澄清）、`simplify`、`verify`（你的領域字）。
- `-en`：使變得。`strengthen`、`weaken`。

**變成副詞的後綴**：
- `-ly`：以……方式。`significantly`、`subsequently`。

實務上，後綴給你的第一層情報往往不是「精確意思」，而是**詞性**——這已經很值錢。當你在長句裡看到 `the implementation of these measures constitutes a significant shift`，就算 `constitutes` 你不確定，`-s` 加動詞位置告訴你它是動詞、`implementation`（-tion）是名詞當主詞、`significant`（-ant）是形容詞修飾 `shift`。**光靠後綴辨認詞性，你就已經能把句子的骨架搭起來**——這是 Part 2 的先修技能。

## 字根：意思的核心

**字根（root）**是字的意思核心，多數源自拉丁文或希臘文。這是拆字裡最需要累積、也回報最複利的一塊——因為**一個字根往往生出一大群字**，你認得一個根，就等於同時鬆動了一整族的字。挑幾個高產、且你在術語裡早就見過的：

- **`tract`**（拉、牽引，拉丁 trahere）：`attract`（吸引）、`extract`（抽取）、`contract`（合約 / 收縮）、`retract`（縮回）、`intractable`（難駕馭的）、`abstract`（抽象的，「往外拉離具體」）。
- **`spect / spec`**（看，拉丁 specere）：`inspect`（檢視）、`respect`（尊重，「回頭看」）、`prospect`（前景，「往前看」）、`spectator`（觀眾）、`perspective`（觀點）、`speculate`（推測）。
- **`port`**（攜帶，拉丁 portare）：`transport`（運輸）、`export / import`（出/進口）、`portable`（可攜的）、`support`（支持，「從下托住」）、`report`（回報，「帶回來」）。
- **`dict`**（說，拉丁 dicere）：`predict`（預測，「事先說」）、`dictate`（口述 / 命令）、`contradict`（反駁，「反著說」）、`verdict`（裁決）、`dictionary`（字典）。
- **`struct`**（建造，拉丁 struere）：`construct`（建造）、`destruct`（破壞）、`structure`（結構）、`instruct`（指示，「在裡面建起」）、`infrastructure`（基礎設施）。
- **`vert / vers`**（轉，拉丁 vertere）：`convert`（轉換）、`reverse`（反轉）、`introvert`（內向者）、`controversy`（爭議，「轉向相對」）、`version`（版本）、`divert`（轉移）。
- **`mit / miss`**（送，拉丁 mittere）：`transmit`（傳送）、`submit`（提交，「往下送」）、`emit`（發出）、`mission`（任務）、`permission`（許可）、`dismiss`（解散，「送走」）。

希臘源的則大量集中在科學技術術語（這對你更是主場）：`tele-`（遠：telephone、television）、`photo-`（光：photograph）、`graph`（寫/畫：graph、paragraph、autograph）、`chron`（時間：chronological、synchronize、asynchronous）、`morph`（形：morphology 構詞學、polymorphism 多型——你的領域字）、`log / logy`（言說/學問：logic、biology、technology）。

看出來了嗎？**你的技術詞彙庫，本身就是一座拉丁/希臘零件的礦。** `polymorphism` = poly（多）+ morph（形）+ ism（現象）；`asynchronous` = a（非）+ syn（共同）+ chron（時間）+ ous（的）。你早就會這些字，只是沒把零件拆出來、意識到它們能重組去解別的字。**這一節真正要你做的，不是死背字根表，而是養成「看到長字先找熟零件」的反射**——而你的術語庫給了你比一般學習者厚得多的零件底子。

## 三個完整拆解示範

把前綴、後綴、字根合起來實戰。看三個字怎麼被當場拆開。

**示範一：`intractable`**（前面看過，複習一次完整流程）
- 掃前綴：`in-` = 不。
- 掃後綴：`-able` = 可……的。
- 剩中間：`tract` = 拉、牽引、駕馭（你從 tractor/extract 認得）。
- 組合：不 + 可駕馭 + 的 = **難駕馭的、棘手的**。
- 語境驗證：`an intractable dispute between the two countries`（兩國間一場棘手/難解的爭端）——通順，猜對。

**示範二：`disorganization`**
- 掃前綴：`dis-` = 相反、除去。
- 掃後綴：`-tion`（實為 `-ation`）= 名詞、狀態。
- 剩中間：`organ`（→ organize 你認得，「組織」）。
- 組合：除去 + 組織 + （名詞）= **無組織、混亂（的狀態）**。
- 注意詞性：`-tion` 告訴你這是**名詞**，所以句中它會當主詞或受詞，不是動詞。

**示範三：`irreversible`**
- 掃前綴：`ir-`（in- 在 r 前的變體）= 不。
- 掃後綴：`-ible` = 可……的。
- 剩中間：`re-`（再/回）+ `vers`（轉）= reverse（反轉）你認得。
- 組合：不 + 可反轉 + 的 = **不可逆的**。
- 語境驗證：`irreversible damage to the ecosystem`（對生態系不可逆的破壞）——通順，猜對。

三個示範的共同流程，記下來當 SOP：**先剝前綴 → 再剝後綴（順便定詞性）→ 看剩下的字根認不認得 → 組合猜義 → 拿句子語境驗證是否通順。** 拆解不是玄學，是這五步的機械操作。

## 結合語境猜字：做法與極限

拆解處理「字的內部結構」，語境推斷處理「字的外部環境」。兩者互補：拆解給你字的**大致方向**，語境幫你**收斂到精確意思、並驗證你的拆解沒錯**。

**語境推斷怎麼做？** 遇到生字別馬上查，先問句子周圍給了什麼線索：

- **定義 / 同位語線索**：正式文本常自己解釋難字。`Photosynthesis, the process by which plants convert light into energy, ...`——逗號後面直接把 photosynthesis 定義了。看到生字後面跟著逗號、`which`、`that is`、破折號，八成是在替它解釋。
- **對比線索**：`Unlike his gregarious brother, he was quiet and withdrawn.`——`Unlike`（不同於）+ 對面是 quiet，推得 gregarious 意思相反，約等於「外向、愛社交」。
- **例子線索**：`Predators such as lions, wolves, and hawks ...`——`such as` 後面舉的例子（獅、狼、鷹）告訴你 predators 是「掠食動物」。
- **因果 / 邏輯線索**：`The bridge was so dilapidated that it had to be closed.`——「破到必須關閉」推得 dilapidated ≈「破敗失修」。

**拆解 + 語境合擊的威力**：碰到 `The negotiations reached an intractable deadlock.`，你用拆解得到 intractable ≈「難駕馭/棘手」，再用語境（deadlock 僵局、negotiations 談判）確認方向對——兩把武器互相印證，比單用任一把都穩。

**但語境推斷有真實的極限，必須講清楚，別過度神話它：**

1. **它需要你認得周圍的字。** 語境線索是「用已知字推未知字」——**如果周圍也一堆生字（覆蓋率不到 95%），就沒有可靠的線索可用**，推斷會變瞎猜。這正是 Ch 1 講的覆蓋率門檻的另一面：**覆蓋率不夠，連猜都猜不動。** 所以語境推斷不是取代背字，而是建立在足夠字彙基礎上的加值技能。
2. **很多語境根本沒給線索。** 研究上，真實文本裡能靠上下文清楚推出生字義的比例，遠低於一般人的樂觀想像；更常見的是「句子沒提供足夠線索」或「你推出一個似是而非的錯義還不自知」。**別假設每個生字都能靠語境破解。**
3. **推斷是機率，不是確定。** 你猜出的是「大致方向」，可能對、可能偏。對 extensive reading（大量泛讀，Ch 11）夠用——方向對就能繼續讀；但對 intensive reading（精讀，Ch 13）或關鍵句，方向對不夠，該查就查。

所以務實的原則是：**優先用拆解 + 語境滑過非關鍵生字（維持流暢），但對「反覆出現、或明顯是句子關鍵、或推不出來」的字，果斷查、並做成卡片（回 Ch 5）。** 猜字是為了不打斷閱讀節奏，不是為了逞強不查。

## 技術英文為什麼「好讀」——並怎麼利用

現在回到這一章對你最有價值的一節。本課一直提醒你「讀技術文過關是假象」，但那假象裡有真材料。我們拆開來看，**技術英文對你好讀，有四個結構性原因**——搞懂它們，才知道哪些能移植到 BBC、哪些不能。

**原因一：領域窄，話題可預測。** 一篇講 TCP 壅塞控制的文，主題被鎖死在一個很窄的範圍裡，反覆講同一組概念。你的**領域知識（domain knowledge）**替你補足了大量沒明講的背景——作者不必解釋什麼是封包，你已經知道。**這部分是真優勢，但它綁死在你的領域**：換到一篇講中東政治的 BBC 長文，你的領域知識歸零，這個優勢跟著消失。這解釋了為什麼你「技術文可以、新聞不行」。

**原因二：術語重複率極高。** 技術文為了精確，同一個概念會用**同一個字**反覆指涉（`buffer` 從頭到尾都叫 buffer，不會為了文采換成別的說法）。而 BBC 新聞為了避免單調，會**刻意變換用字（elegant variation）**——同一個人第一句叫 `the president`、第二句叫 `Mr. Biden`、第三句叫 `the 46th commander-in-chief`。**技術文的用字重複讓你越讀越輕鬆（生字第一次撞到、之後都認得），新聞的用字變換讓你越讀越多陌生說法。** 這是新聞比技術文累的一大結構原因。

**原因三：大量同源詞（cognate）與可拆的長字。** 技術術語壓倒性地由拉丁/希臘零件構成（`compression`、`transmission`、`asynchronous`、`polymorphism`），也就是本章前半教你拆的那種字。**你讀技術文時其實一直在做拆解，只是太熟練到沒意識到。** 好消息：這個拆解能力**完全可以移植**——BBC 第二圈的學術/正式字（`constitute`、`implementation`、`unprecedented`）跟技術術語是同一批零件做的。**你把讀術語練出來的拆字反射，直接就能用在新聞的正式字上。這是四個原因裡最值得、也最能移植的一個。**

**原因四：名詞化（nominalization）風格你已習慣。** 技術與學術英文愛把動作寫成名詞——不說 `we implemented the system, which reduced errors`，而說 `the implementation of the system resulted in a reduction of errors`（系統的實作導致了錯誤的減少）。這種**把動詞/形容詞塞進名詞（`implement`→`implementation`、`reduce`→`reduction`）、讓句子由一串名詞片語堆成**的風格，就叫**名詞化（nominalization）**。它讓句子資訊密度高、抽象、正式——技術文和 BBC 新聞**都**大量使用。你讀技術文早就習慣了名詞化，**這個習慣同樣可移植到新聞**。（名詞片語怎麼堆疊、怎麼拆，是 Ch 8 的專題。）

把四個原因分類，策略就清楚了：

- **不可移植（綁死領域）**：原因一的領域知識。讀領域外新聞時它幫不上忙，別指望。
- **反而變難（新聞特性）**：原因二的用字變換。這是新聞比技術文累的地方，要有心理準備，Ch 16 會專門教你應付 elegant variation。
- **完全可移植（真正的槓桿）**：原因三的拆字能力、原因四的名詞化習慣。**這兩個是你讀技術文練出來、可以直接搬去讀 BBC 的真本事。**

所以，「利用技術英文優勢爬向 BBC」的具體意思是：**認清你的真本事是「拆字」和「習慣名詞化」這兩項可移植技能，刻意把它們用在新聞的正式字與長句上；同時清醒地知道「領域知識」這根拐杖到了新聞就沒了，得靠廣泛認字（Ch 3–5）和拆句（Part 2）補上。**

## 假朋友與「認得字面、不懂術語專義」

拆解和猜字很強，但有兩個陷阱會讓它們反過來害你。

**陷阱一：假朋友（false friends）。** 這詞原指「兩種語言裡長得像、意思卻不同的字」（例如對母語含拉丁詞根的人，英文 `actually` 不是「目前」而是「其實」）。對你這個中文母語者，更相關的變體是**「英文內部長得像、意思卻不同的字」**，以及**「你以為的意思其實是錯的」**：

- `sympathetic` 不是「有同情心」那麼窄，常指「贊同、支持（某立場）」：`sympathetic to the cause`。
- `sensible`（明智的）vs `sensitive`（敏感的）——長得像、意思差很遠。
- `economic`（經濟的）vs `economical`（省錢的）——同根不同義。
- `literally`（字面上地）常被誤用/誤解為強調詞。

假朋友的教訓：**拆解和「看起來像」只能給你假設，不能給你確定。** 當拆出來的意思代進句子**讀不通**，別硬凹，那可能就是假朋友——回去查。拆解是加速器，不是免查金牌。

**陷阱二：認得字面、卻不懂術語專義（這對你這個技術讀者是最兇的陷阱）。** 大量技術術語是用**普通日常字**當招牌，但在領域裡有**專門的、和字面不同的意思**。你「認得每個字」，卻完全不懂它在講什麼：

- `thread`（線）→ 程式的「執行緒」。
- `heap`（一堆）→ 記憶體的「堆積區」，一種特定資料結構。
- `garbage collection`（收垃圾）→ 自動記憶體回收機制。
- `race condition`（賽跑條件？）→ 「競態條件」，並行程式的一種 bug。
- `daemon`（惡魔）→ 背景執行的「守護行程」。

換到新聞領域也一樣，普通字帶專義：`table`（動詞，英式=提出議案）、`address`（處理，不是地址）、`subject to`（使遭受）——這正是 Ch 4 講的「熟字生義」。

這個陷阱的可怕在於：**它不會觸發你的「生字警報」。** 遇到 `intractable` 你知道自己不會、會停下來拆或查；但遇到 `race condition`，每個字你都認得，警報不響，你**自以為讀懂了，其實完全誤解**——這比遇到明顯生字危險得多。

破解之道：**當「每個字都認得、整句卻怪怪的、或代入常識講不通」時，警覺這可能是一個帶專義的術語 / 熟字生義，而不是你理解有誤。** 這種句子要慢下來，懷疑那個「你以為懂」的字，去查它在**這個領域 / 這個語境**下的專門意思。認字面不等於懂意思——這是整章最後、也最反直覺的一課。

## 踩雷集錦

**雷 1：硬拆規則不規則的字、或拆出來硬套。** 不是每個字都乾淨可拆，也有拆得出零件卻意思飄移的（`awful` 不是「充滿敬畏」而是「糟糕」）。**拆解給的是假設，一定要拿語境驗證**；代進句子讀不通，就別信你的拆解，回去查。把拆解當「必對的公式」是誤用。

**雷 2：把語境推斷當萬能、拒絕查字典。** 迷上猜字後，連關鍵句、反覆出現的字都硬猜不查，猜出一個似是而非的錯義還沾沾自喜。**語境推斷是為了滑過非關鍵生字、維持流暢**；關鍵字、常出現的字、推不出來的字，該查就查並做卡。猜字是節省，不是逞強。

**雷 3：以為覆蓋率不夠也能靠猜字撐。** 語境推斷靠「用已知字推未知字」，**周圍一堆生字時根本沒線索可用**。有人拿「反正能猜」當藉口跳過 Ch 3–5 的建字彙——結果材料太難、生字成群、猜全變瞎猜。**猜字建立在覆蓋率夠（≥95%）之上，不能取代它。**

**雷 4：忽略前綴而讀反句子。** `un- / in- / dis- / non-` 這些否定前綴是句子正負向的開關，漏看一個 `un-` 就把 `unprecedented`（前所未有）讀成「有先例」，整句意思翻掉。**拆字第一步永遠先掃前綴**，尤其是否定前綴。

**雷 5：栽進假朋友——「看起來像」就當「意思是」。** `sensible` 當 `sensitive`、`economic` 當 `economical`、`sympathetic` 只想到「同情」。長得像不代表意思同。**拆出來或聯想到的意思，代進句子讀不通時，那八成是假朋友，回去查。**

**雷 6：認得每個字就以為讀懂了術語 / 熟字生義（最兇的雷）。** `race condition`、`garbage collection`、`table（提案）`、`address（處理）`——字全認得，警報不響，你自以為懂其實誤解，還比遇到明顯生字更危險。**「每字都認得、整句卻怪 / 代常識講不通」時，懷疑那是帶專義的術語或熟字生義，慢下來查它在這個領域/語境的專門意思。**

**雷 7：死背字根表當單字背。** 抱著一本「500 個拉丁字根」從頭背——這又犯了 Ch 5 的「背表」大忌，孤立、無語境、忘得快。**字根該在拆解真實生字的過程中一個個累積**（「喔 intractable 的 tract 就是 tractor 那個」），而不是脫離語境硬背表。你的術語庫已經給你大量零件，從那裡認起最自然。

## 進階：再往深一層

**構詞學（morphology）是語言學的一個正式分支，拆字只是它的入門應用。** morphology 研究的是**詞素（morpheme）**——語言中最小的有意義單位。`intractable` 有三個 morpheme（in / tract / able）；`cats` 有兩個（cat / -s，後者是表複數的「屈折詞素」inflectional morpheme）。前綴、後綴、字根都是 morpheme。知道這個框架的好處是：你會理解「拆字」不是零散技巧，而是在辨認語言的**組合規則**——英文（尤其其拉丁/希臘層）是高度「組合性」的，這正是為什麼有限的零件能生出近乎無限的字，也是為什麼拆解如此高槓桿。想深入的話，構詞學是條清楚的進階路。

**同源詞（cognate）的雙面性：對你既是禮物也是陷阱。** cognate 指「同源、跨語言或跨領域長得像意思也近」的字。對你，最大的 cognate 寶庫是**你的技術術語 ↔ 新聞的正式字**（同一批拉丁/希臘零件）——這是禮物，讓拆字能力可移植。但 cognate 玩到極端就變成假朋友（同源卻意思漂移了），這是陷阱。健康的心態：**把 cognate 當「高機率正確的假設」——先信它、快速前進，一旦語境打臉就立刻改口去查。** 這正是「快速泛讀」和「該精讀時慢下來」之間的平衡（Part 3 主題）。

**技術英文的優勢有天花板，別誤把它當「英文好」。** 最後回扣本課的核心誠實：你讀技術文順，是「領域知識 + 可移植的拆字/名詞化技能 + 術語重複」多重因素疊加的結果，其中**只有拆字和名詞化是真正的英文閱讀能力**，領域知識和術語重複是外掛。把這三者分清楚很重要——否則你會誤判自己的英文程度，選了太難的新聞材料而挫敗。**準確的自我認知是：我有一套可移植的拆字/長句直覺（值錢，Part 2 會繼續放大它），但我的通用詞彙覆蓋率和領域外背景知識還不夠，這才是讀 BBC 卡住的真因。** 認清這點，你就會把力氣正確地押在「補通用字彙 + 練拆句」上，而不是繼續躲在技術文的舒適圈裡自我感覺良好。

## 動手練習

1. **拆五個字**：用「先剝前綴 → 剝後綴定詞性 → 認字根 → 組合 → 語境驗證」的 SOP，親手拆解 `incomprehensible`、`transnational`、`counterproductive`、`interdependence`、`irreplaceable`。每個字寫下三塊零件、猜的意思、和一句驗證用的例句。

2. **從你的術語挖零件**：列 5 個你領域的英文術語（如 `compression`、`asynchronous`、`polymorphism`、`recursive`、`throughput`），把每個拆成零件，並找出**至少一個含相同零件、但不屬於你領域的字**（例：compression 的 press → `impressive`、`express`）。體驗「術語庫是零件礦」。

3. **語境推斷四線索**：找一段 BBC 短新聞，圈出 3 個你不確定的字，先**不查**，判斷各自屬於哪種語境線索（定義 / 對比 / 例子 / 因果 / 或「無線索」），寫下你的推斷，最後再查、對照你猜得準不準。特別記下「無線索、猜不動」的那幾個——那就是語境推斷的極限。

4. **技術 vs 新聞用字重複度**：拿一篇技術文和一篇 BBC 新聞，各挑一個「主角」（技術文的核心概念、新聞的主要人物），數這個主角在文中被用**幾種不同說法**指涉。親眼看到技術文的重複 vs 新聞的 elegant variation。

5. **抓熟字生義 / 假專義**：找 3 個「每個字都認得、整句卻怪」的例子（可從你讀技術文的經驗撈，如 `race condition`、`starve a thread`、`orphan process`），寫下字面意思 vs 領域專義的差別。

## 本章重點整理

- **構詞拆解**：英文（尤其第二圈正式字）大量由拉丁/希臘零件組成。記住有限的**前綴 / 後綴 / 字根**，就能當場破解無數沒背過的字。
- **前綴**改意思方向（否定 `un-/in-/dis-`、方位 `sub-/trans-/inter-`、程度 `over-/co-`）；**否定前綴是句子正負向的開關**，第一步先掃。
- **後綴**主要改**詞性**（`-tion` 名詞、`-able` 形容詞、`-ize` 動詞、`-ly` 副詞）；認後綴幫你在長句裡定角色（Part 2 先修）。
- **字根**是意思核心且高產（一根生一族：tract / spect / port / dict / struct / vert / mit）。**你的術語庫就是一座零件礦。**
- **拆解 SOP**：剝前綴 → 剝後綴定詞性 → 認字根 → 組合猜義 → 語境驗證。
- **語境推斷**用四類線索（定義 / 對比 / 例子 / 因果）；**但有極限**：需覆蓋率夠、很多語境無線索、只是機率不是確定。**滑過非關鍵字用它，關鍵字/常見字/推不出的字該查。**
- **技術英文好讀的四個原因**：領域窄（不可移植）、術語重複（新聞相反、更難）、同源詞可拆（**可移植**）、名詞化習慣（**可移植**）。真正的槓桿是後兩者。
- **兩大陷阱**：假朋友（長得像≠意思同，讀不通就回查）；**認得字面卻不懂術語專義 / 熟字生義**（不觸發生字警報，最兇；「每字都認得卻怪」時要懷疑並查）。

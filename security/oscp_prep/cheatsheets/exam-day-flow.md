# 考試當天流程（一頁）

> 搭配 [Ch 40 考試策略](../40-exam-strategy.md)。考試**禁用 AI/LLM**；Metasploit 僅限一台機器。

## 開賽 0–30 分：全面佈局

```
1. 連 VPN，確認能 ping 到所有目標
2. 建立筆記結構（每台一個資料夾：scans/ loot/ screenshots/）
3. 對「所有」目標同時開跑枚舉：
   sudo autorecon <所有IP>    # 背景跑，不受 MSF 限制
4. 等掃描時：讀題目說明、記下 AD 鏈的目標與獨立機器
```

## 時間分配（24 小時滲透）

```
總分 100，及格 70（2026-12-01 起改 100–500 分級分，400 及格）

建議節奏：
├─ 0–1h    全目標枚舉佈局 + 讀題
├─ 1–8h    AD 三機鏈（40 分，最高 CP 值，優先攻）
├─ 8–16h   獨立機器 ×3（各拿初始立足 → 再回頭提權）
├─ 16–20h  回頭啃卡住的機器 / 補提權
├─ 20–22h  確認每台 local.txt + proof.txt 都有截圖
└─ 22–24h  補截圖、整理筆記、睡覺前對帳
```

## 單機決策流程

```
          ┌─ 全埠 nmap -p- + UDP top100
          ▼
    每個開放服務逐一枚舉（換憑證就重枚舉）
          ▼
   找到版本漏洞? ──是──► searchsploit → 手動改 exploit（Ch17）
          │
          否
          ▼
   Web? ──► 目錄爆破/vhost/SQLi/上傳/LFI（web 速查）
          ▼
   拿到初始 shell ──► 升 TTY ──► 跑 linPEAS/winPEAS
          ▼
   提權（linux/windows 速查）──► proof.txt + ipconfig 截圖
```

## 卡關止損規則

```
單一入口卡 45 分鐘沒進展 → 換下一台（標記回頭再戰）
提權卡 30 分鐘 → 重跑枚舉，一定漏了東西
整體卡住 → 回到「枚舉 > 一切」：哪個服務/憑證還沒深挖？
禁止：死磕一台到天亮、跳過全埠掃、忘記換憑證重枚舉
```

## 截圖紀律（不截 = 沒分）

```
每台必截：
  □ 初始立足的關鍵步驟（漏洞利用當下）
  □ local.txt 內容 + hostname + ip a / ipconfig 同畫面
  □ 提權的關鍵步驟
  □ proof.txt 內容 + whoami（root/SYSTEM/administrator）+ ip
每個用到的指令貼進筆記
```

## Metasploit 使用（想清楚再用）

```
整場只能對「一台」機器用 MSF 模組（exploit/auxiliary/post 擇一台）
→ 留給最難手動利用的那台，其餘全手動
→ meterpreter 也算，想好要花在哪
```

## 報告（滲透後 24 小時）

```
□ 用官方模板（Ch 41）
□ 每台：摘要 → 步驟（含截圖+指令）→ 可重現
□ local.txt / proof.txt 雜湊貼上
□ 交檔前檢查：截圖清楚、IP/hostname 可見、步驟連貫
```

## 一句話
**分數在 AD 鏈和「每台至少拿初始立足」。先廣後深，截圖隨手，卡住就換，枚舉到底。**

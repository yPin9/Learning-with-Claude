# Ch 40 — OSCP 24 小時考試策略：時間分配與心態

> 目標：制定一個現實的考試計劃，在 24 小時內最大化得分，並維持清醒和高效的工作狀態。

## 考前準備（考試前一週）

### 技術準備

```
□ 確認 Kali VM 能正常啟動，更新套件
□ 準備工具目錄 ~/tools/（linpeas, winpeas, chisel, PowerUp, nc.exe, etc.）
□ 準備筆記模板（每台機器一個目錄結構）
□ 準備截圖工具（Flameshot 或 Greenshot）
□ 測試 VPN 連線，確認 tun0 能用
```

mkdir -p ~/exam/{machine1,machine2,machine3,ad_chain}/{nmap,exploit,loot,screenshots}

### 其他準備

```
□ 充足睡眠（考前一晚早睡）
□ 準備足夠的咖啡和水
□ 告訴家人/室友這 24 小時不要打擾
□ 準備健康的點心（不要讓血糖波動影響集中力）
```

## 考試當天的時間規劃

### 建議時間表

```
H+0    考試開始。下載考試 VPN，連線，截圖確認連線
H+0.5  枚舉所有 5 台機器（並行跑 nmap -p- --min-rate 5000）
H+1    所有機器有基本 port 清單，開始詳細枚舉
H+2    選一台「看起來最有機會」的機器開始打
H+4    目標：拿到第一台機器（初始立足）
H+5    提權第一台
H+7    開始打 AD 鏈（如果第一台 AD 機器拿到了）
H+10   目標：AD 鏈至少兩台
H+12   截圖整理，喝水，短暫休息 15–20 分鐘
H+13   繼續打剩下的機器
H+20   停止打機器，開始整理筆記和截圖
H+22   完成截圖整理，開始思考報告結構
H+24   考試結束
```

**這只是建議。每個人的節奏不同，重要的是不要在一台機器上死磕太久。**

## 時間管理規則

### 45 分鐘換方向法則

同一個思路超過 45 分鐘沒進展：

```
1. 記錄你試過什麼（不要丟失進度）
2. 換另一台機器
3. 或換一個完全不同的思路
```

不是放棄，是「先走開，等等再看」。新的角度往往能找到突破口。

### 低垂果實優先

```
考試時選擇下一台機器的標準：
1. 有明顯已知漏洞的版本（nmap 已掃出）
2. Web 應用（通常入口多）
3. 枚舉信息最豐富的機器
4. 不要選「什麼都沒開的」當第二台
```

### 截圖時機

```
每次有突破就截圖，不要等到最後：
□ 拿到初始 shell：whoami + ifconfig + cat local.txt
□ 提權成功：whoami (root/SYSTEM) + ifconfig + cat proof.txt
□ AD 橫向：每台機器拿到後截圖
□ AD DCSync 成功：截圖 hash 輸出（含機器 IP）
```

**proof.txt 的截圖格式：**

```cmd
# Windows
type C:\Users\Administrator\Desktop\proof.txt && ipconfig

# Linux
cat /root/proof.txt && ifconfig
```

必須要有：flag 內容 + 機器 IP（ifconfig / ipconfig 輸出）

## 心態管理

### 考試必然會卡住

OSCP 考試設計就是讓你卡住的。關鍵是：

```
卡住了不代表你不夠資格
卡住了 = 還沒找到正確的枚舉方向

問自己：
  "我有沒有枚舉所有 port？"
  "Web 目錄爆破跑完了嗎？"
  "每個服務都有仔細看版本嗎？"
  "有沒有 UDP port？"
```

95% 的「打不進去」是枚舉沒做完。

### 不要對比進度

考試中不要想「別人現在可能打到幾台了」。你只能控制自己的進度。

### 適時休息

```
每 4–5 小時：15 分鐘強制休息
  站起來走走、喝水、吃點東西
  讓眼睛和大腦都休息
  往往回來後就看到之前忽視的線索

H+12：中段強制 20 分鐘休息
  不管打到哪，這個時間點要休息
```

## 分數計算策略

### 目標分配

```
目標：85–90 分（確保 buffer）

路線 A（穩健）：
  AD 鏈全拿（40分）+ 2台獨立機器完整（40分）= 80分
  第三台拿初始立足 = +10分

路線 B（激進）：
  3台獨立機器完整（60分）+ AD 部分（≥10分）= 70+ 分
  （AD 打一台也是 10 分）
```

### 如果 AD 卡住

```
不要在 AD 上花超過 8 小時
轉去打獨立機器，確保 3×20 = 60 分
然後回來看 AD，放鬆的狀態往往能找到新方向
```

## 考後注意事項

```
考試結束後：
1. 立刻存好截圖和筆記（考試環境 VPN 斷線後就沒了）
2. 報告撰寫有 24 小時，不要以為睡一覺再寫
3. 建議：考試結束後睡 6–8 小時，醒來立刻開始寫報告
4. 報告截止前至少 2 小時提交（不要最後一分鐘）
```

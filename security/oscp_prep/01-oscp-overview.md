# Ch 1 — OSCP 考試全解析：評分規則與思考框架

> 目標：搞清楚 OSCP 到底在考什麼、怎麼評分、要用什麼心態備考，讓後面 41 章的學習方向不偏。

## OSCP 是什麼

OSCP（Offensive Security Certified Professional）是 OffSec（原 Offensive Security）發的滲透測試認證。它難在哪？**考試是 24 小時的實機滲透，沒有選擇題，沒有填空，你要真的打進機器拿到 flag。**

這讓它成為業界含金量最高的入門認證：

```
拿到 OSCP ≠ 你學會了某個工具
拿到 OSCP  = 你能在限制時間內系統性地找到並利用漏洞
```

面試官看這張證書的意思是：「這個人不只是讀書，他上機打過機器。」

## 考試結構（PEN-200 2023 版）

```
總分：100 分，及格線：70 分

╔══════════════════════════════════════════════╗
║  獨立機器 × 3                                ║
║  每台：10分（初始立足）+ 10分（提權） = 20分  ║
║  三台合計：60 分                              ╠══ 60分
╠══════════════════════════════════════════════╣
║  Active Directory 三機器鏈                   ║
║  Machine 1（普通用戶）：10 分                 ║
║  Machine 2（橫向移動）：10 分                 ║
║  Domain Controller（完整接管）：20 分         ╠══ 40分
╚══════════════════════════════════════════════╝

時間分配：
  滲透階段：24 小時（VPN 連進考試環境）
  報告撰寫：24 小時（額外給，但要認真寫）
```

### 分數計算的實際含義

**拿 70 分的最低路徑**（夠用就好）：
- 3 台獨立機器全拿初始立足 × 3 = 30 分
- 其中 1 台完整提權 = +10 分
- AD 鏈拿前兩台 = 20 分
- 合計：60 分 ← 還不夠

**比較實際的 70 分路徑**：
- 3 台獨立機器各拿初始立足 + 1台提權 = 40 分
- AD 鏈拿完前兩台（20分）+ 部分 DC（希望有） = 20+ 分

**最安全的備考目標**：能穩定拿 80 分。預設 AD 鏈全拿（40 分）+ 至少 2 台獨立機器提權（40 分）。

### 關於報告

報告不是附加題，是正式評分的一部分。**截圖不完整可能直接扣分甚至失格。**

OffSec 要求：
- 每個步驟有截圖（含 IP 位址、hostname、時間戳可見）
- `local.txt`（初始立足 flag）和 `proof.txt`（提權後 flag）都要截圖加 `ifconfig`/`ipconfig`
- 步驟要能重現（靠截圖和指令紀錄）

這門課 Ch 41 會講報告格式，**但從第一台機器開始就要養成截圖習慣**。

## 考試的思維模型

考試不是一場 CTF，它比較像一個「有時限的真實評估」。

### 枚舉 > 一切

OSCP 最常見的失敗原因不是不會打漏洞，而是**枚舉做得不夠徹底，漏掉了入口**。

```
新手的思維：「我找不到漏洞，這台機器太難了。」
OSCP 的思維：「我還沒枚舉完，一定有我還沒看到的地方。」
```

這個心態在 Part 2（情報蒐集）會系統性建立。

### 低垂的果實先摘

考試策略是：**先拿分，再去挑戰高分。**

優先順序建議：
1. 掃所有機器的所有 port（別只掃常見 port）
2. 快速枚舉每台機器的服務，找明顯的版本漏洞
3. 先打「看起來最熟悉」的機器
4. 卡超過 45 分鐘就換下一台，別死磕

### 筆記即報告

考試 24 小時後還要交報告。你的筆記品質直接決定報告品質。

建議工具：
- **CherryTree** 或 **Obsidian**：分機器的樹狀筆記
- **Flameshot**（Linux）/ **Greenshot**：截圖工具
- 每個指令都貼進去，每個發現都截圖

## OSCP 和 PEN-200 課程的關係

OffSec 賣的是「PEN-200 課程 + 考試機會」的套裝。課程本身很好，**但不夠**：

- PEN-200 課程教你技術基礎
- 真正讓你過考試的是**大量的靶機練習**（HTB + Proving Grounds）
- 這門課的每章都附靶機推薦，理論讀完當天就要上機

你不需要先買 PEN-200 才能開始備考。這 42 章就是你的備考教材，HTB 免費機器夠用到你覺得準備好了再報名考試。

## 工具授權限制

OSCP 考試對 Metasploit 有限制：**考試中只能使用一次 Metasploit 模組（auxiliary/exploit/post）對一台機器使用**。

這代表：
- 不能對所有機器都用 Metasploit
- 要學會**手動利用漏洞**（修改 Python / C exploit 腳本）
- Ch 17 會教手動漏洞利用
